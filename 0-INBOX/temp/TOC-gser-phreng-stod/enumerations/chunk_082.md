Enumeration Block 1:
གཉིས་པ་ལ་གསུམ། མདོའི་སྒྲས་ཟིན་གྱིས་ཇི་ལྟར་བསྟན་པ་དང་། དོན་དེ་རྩ་བས་ཇི་ལྟར་བསྡུས་པ་དང་། དེ་གཉིས་འགྲེལ་བྱེད་རྣམས་ཀྱིས་ཇི་ལྟར་སྦྱར་བའོ། །
Enumeration Block 2:
གསུམ་པ་ལ་གཉིས། ཤེས་པར་བྱ་བའི་ལམ། དེ་ཤེས་པར་བྱེད་པའི་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས། ཀུན་ཉོན་དང་། རྣམ་བྱང་གི་བདེན་པ་གཉིས་ཀྱི་རྣམ་པའོ། །དང་པོ་ལ་གཉིས། སོ་སོ་བ་དང་། ཐུན་མོང་གི་རྣམ་པའོ། །དང་པོ་ལ་གཉིས། སྡུག་བསྔལ་དང་། ཀུན་འབྱུང་གི་རྣམ་པའོ། །
Enumeration Block 3:
ཀུན་འབྱུང་བའི་བདེན་པའི་ངོ་བོའི་རྣམ་པ་བཞི་ལས།
Enumeration Block 4:
སྡུག་བསྔལ་དང་ཀུན་འབྱུང་གི་བདེན་པ་དེ་དག་ཉིད་ལ་སོ་སོར་ཏེ་རེ་རེ་ལ་ཡིད་འབྱུང་བ་འདོད་ཆགས་དང་བྲལ་བ་འགོག་པའི་རྣམ་པ་གསུམ་ཡོད་པ་ལས།
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། འགོག་པ་དང་། ལམ་གྱི་རྣམ་པའོ། །དང་པོ་ནི།འགོག་པའི་བདེན་པའི་ངོ་བོའི་རྣམ་པ་བཞི་ལས།
