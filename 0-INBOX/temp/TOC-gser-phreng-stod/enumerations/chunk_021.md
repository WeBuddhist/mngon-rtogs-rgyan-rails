Enumeration Block 1:
བདེན་གཉིས་འགལ་བར་འཛིན་པའི་མི་ཤེས་པ་སྟེ། དབྱེ་ན་བཅུ་དྲུག་གོ །
Enumeration Block 2:
གསུམ་པ་ལ་བཅུ་གསུམ་ལས།
Enumeration Block 3:
མཚན་ཉིད་དམ་ལྡོག་པས་ཕྱེ་ན་རྣམ་པར་སྨིན་པ་མིན་པའི་ཆོས་ཐམས་ཅད་དང་། རྣམ་སྨིན་གྱི་ཆོས་ཐམས་ཅད་དང་། ཆོས་ཐམས་ཅད་མཚན་ཉིད་མེད་པ་དང་། ཆོས་ཐམས་ཅད་གཉིས་སུ་མེད་པར་སྐད་ཅིག་མ་གཅིག་ལ་རྟོགས་པ་བཞིའོ། །
Enumeration Block 4:
དབྱེ་བའི་ངོ་བོ་ནི་རྣམ་པ་བཞིར་ནི་ཡང་དག་པར་བརྗོད་དོ། །
Enumeration Block 5:
དེ་ལ་བཞི་ལས།
Enumeration Block 6:
གཉིས་པ་ལ་དྲུག །སྒྲུབ་པ་དང་སྦྱོར་བ་དང་། གང་ཟག་དང་། རྟོག་པ་དང་། སྒོམ་ལམ་དང་། མཐོང་ལམ་དང་། སྦྱོར་ལམ་ལ་ཟློས་པ་སྤང་བའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གཉིས། ཚིག་ལེའུར་བྱས་པ་དང་འབྲེལ་བའི་དོན་གཞན་བཤད། ཚིག་ལེའུར་བྱས་པ་ཉིད་ཀྱི་དོན་བཤད་པའོ། །དང་པོ་ལ་གཉིས། མདོ་དང་ཇི་ལྟར་སྦྱར་བ་དང་། སྦྱར་ཚུལ་ལ་རྩོད་པ་སྤང་བའོ། །
