Enumeration Block 1:
ལྔ་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང་། དོན་བཤད་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གསུམ། མཐོང་ལམ་མདོར་བསྟན། རྣམ་པ་རྒྱས་པར་བཤད། སྒོམ་ལམ་མི་སྟོན་པའི་འཐད་པའོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 3:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། བཤད་པ་དང་། བསྡུ་བའོ། །
Enumeration Block 5:
གསུམ་པ་ལ་གཉིས། དངོས་བསྟན་བྱང་སེམས་དང་། ཤུགས་བསྟན་ཉན་རང་གི་མཐོང་ལམ་མོ། །དང་པོ་ལ་གཉིས། སོ་སོར་བཤད་པ་དང་། དོན་བསྡུ་བའོ། །དང་པོ་ལ་བཞི། སྡུག་བསྔལ་དང་། ཀུན་འབྱུང་དང་། འགོག་པ། ལམ་གྱི་རྣམ་པའོ། །
