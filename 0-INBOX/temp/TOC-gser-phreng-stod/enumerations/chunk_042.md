Enumeration Block 1:
གསུམ་པ་ལ་ལྔའི་དང་པོ་རྒྱུན་ཞུགས་ལ་གསུམ་སྟེ། ཞུགས་པ་དང་། འབྲས་གནས་ཙམ་དང་། འབྲས་གནས་ཁྱད་པར་ཅན་ནོ། །
Enumeration Block 2:
གཉིས་པ་ཕྱིར་འོང་ལ་གསུམ་ལས།
Enumeration Block 3:
གསུམ་པ་ཕྱིར་མི་འོང་ལ་ཞུགས་གནས་གཉིས་ལས།
Enumeration Block 4:
ཕྱིར་མི་འོང་བ་སྟེ་དེ་ལ་ལྔ་ལས།
Enumeration Block 5:
ལྔ་པ་གོང་དུ་འཕོ་བ་ལ་གཉིས་ལས།
Enumeration Block 6:
དེ་ལ་དབྱེ་ན། མཐོང་ཆོས་ཞི་ཚེ་འདི་ལ་མྱང་འདས་འཐོབ་པ་དང་འགོག་སྙོམས་ལུས་ཀྱིས་མངོན་སུམ་དུ་བྱེད་པ་འོག་མིན་འགྲོ་ལས་གཞན་རྣམ་པ་གཉིས་སོ། །
