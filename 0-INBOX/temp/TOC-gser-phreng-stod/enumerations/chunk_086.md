Enumeration Block 1:
རྟེན་གྱི་ཁྱད་པར་ལ་གཉིས། སྒྲུབ་པ་པོའི་རྟེན་གྱི་གང་ཟག་དང་། སྒྲུབ་པའི་དམིགས་པ་ཆོས་ཉིད་ཀྱི་རྟེན་ནོ། །
Enumeration Block 2:
གསུམ་པ་ལ་གསུམ་ལས།
Enumeration Block 3:
གསུམ་པ་ལ་གཉིས། སྤྱིའི་མཚམས་སྦྱར་བ་དང་། སོ་སོའི་ངོ་བོ་བཤད་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། མཐོང་ལམ་དང་། སྒོམ་ལམ་མོ། །དང་པོ་ལ་གཉིས། སྤྱི་དང་། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ་གཉིས། མཐོང་ལམ་སྐྱེ་བའི་རྟེན། བརྟེན་པ་མཐོང་བའི་ལམ་མོ། །དང་པོ་ལ་གཉིས། ལུས་རྟེན་དང་། སེམས་རྟེན་ནོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ། མཐོང་ལམ་གྱི་སྐད་ཅིག་མ་དུར་བཤད་པ་དང་། མཐོང་སྤང་སྤོང་ཚུལ་ཇི་ལྟར་བསྟན་པ་དང་། སྐད་ཅིག་མ་དུར་སྐྱེ་བ་དཔྱད་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། བཤད་ཚུལ་དགོད། འཐད་མི་འཐད་བསམ་པའོ། །དང་པོ་ལ་གཉིས། ཆོས་མངོན་པ་ནས་ཇི་ལྟར་བཤད་པ་དང་། རྗེས་འབྲང་གིས་ཇི་ལྟར་བཀྲལ་བའི་ཚུལ་ལོ། །
