Enumeration Block 1:
གཉིས་པ་ལ་གཉིས་ལས། དང་པོ་ནི། སློབ་དཔོན་གྱི་དགོངས་པ་འགྲེལ་པར་འཆད་ལ་འཕགས་པ་ལྟར་ན་གསུམ། གཉེན་པོ་བྱེད་ཚུལ། ཡུལ་རྟོགས་ཚུལ། དེ་ལ་རྩོད་སྤང་ངོ༌། །
Enumeration Block 2:
གསུམ་པ་སྤང་བྱ་གཞི་ཤེས་ཀྱི་ཡན་ལག་རྒྱས་པར་བཤད་པ་ལ་གསུམ། འབྲེལ་བརྗོད་པས་མཚམས་སྦྱར། གཞི་ཤེས་ཀྱི་ཆོས་རྒྱས་པར་བཤད། སྐབས་བསྡུ་བའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་དྲུག །གཞི་ཤེས་ཀྱི་རང་བཞིན། ཉེ་རིང་དུ་འཇོག་པའི་རྒྱུ་མཚན། སྤང་བྱ་དང་གཉེན་པོའི་རབ་དབྱེ། ཇི་ལྟར་ཉམས་སུ་ལེན་པའི་ཚུལ། དེ་ལྟར་ཉམས་སུ་བླངས་པའི་འབྲས་བུ། མཁྱེན་པ་གསུམ་གྱི་མཇུག་བསྡུ་བའོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། རྗེས་འགྲོའི་སྒོ་ནས་བསྟན་པའི་ཐེག་ཆེན་དང་། ལྡོག་པའི་སྒོ་ནས་བསྟན་པའི་ཐེག་དམན་གྱི་གཞི་ཤེས་སོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང་། འཕྲོས་དོན་དཔྱད་པའོ། །དང་པོ་ལ་གཉིས། རྩོད་པ་དང་། ལན་ནོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། རྩ་བ་དང་། འགྲེལ་པའོ། །དང་པོ་ལ་གཉིས། ཐེག་དམན་རིང་བ་དང་། ཐེག་ཆེན་ཉེ་བར་བསྟན་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གསུམ། ཉན་རང་རིང་བ་དང་། ཐེག་ཆེན་ཉེ་བར་བསྟན་པ་དང་། བསྟན་པ་དེའི་དོན་བསྡུ་བའོ། །
Enumeration Block 8:
འདི་ལ་གཉིས། མདོ་དག་ནས་གསུངས་པའི་ཚུལ་དང་། བསྟན་བཅོས་རྣམས་ནས་ཇི་ལྟར་བཀྲལ་བའོ། །དང་པོ་ལ་གཉིས་ལས།
