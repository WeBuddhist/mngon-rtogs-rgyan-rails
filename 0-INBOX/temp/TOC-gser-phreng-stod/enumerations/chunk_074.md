Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། སྦྱོང་བྱེད་སོ་སོའི་ངོ་བོ། ཡོངས་སྦྱོང་དུ་འགྱུར་ཚུལ་ལོ། །
Enumeration Block 3:
སྦྱངས་པ་ཡང་དག་སྡོམ་བསྟེན་ལ་ཡང་ཐུན་མོང་མ་ཡིན་པ་མཆོག་དང་།
ཐུན་མོང་བ་ཕལ་པའི་དབང་དུ་བྱས་པ་གཉིས་ལས།
Enumeration Block 4:
བཅུ་གཉིས་པོ་དེ་ཡང་གང་ཞེ་ན། སོ་སོའི་དབྱེ་བ་དང་། ཐུན་མོང་གི་སྒྲ་བཤད་པ་གཉིས་ཀྱིས་རིག་པར་བྱའོ། །
Enumeration Block 5:
ལྔ་པ་ལ་གཉིས་ལས།
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། སྦྱོང་བྱེད་ཀྱི་ངོ་བོ་སྤང་གཉེན་དང་། འཐོབ་བྱེད་ཀྱི་ངོ་བོ་སྦྱོང་ཚུལ་དང་བཅས་པའོ། །
