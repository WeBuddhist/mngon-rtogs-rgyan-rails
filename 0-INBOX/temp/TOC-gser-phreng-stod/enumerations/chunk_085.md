Enumeration Block 1:
གསུམ་པ་ལ་གཉིས། ལམ་བགྲོད་པ་དང་། ཆོས་སྟོན་པའི་ཁྱད་པར་རོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། རྩོད་པ་དང་། ལན་ནོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས་ལས།
Enumeration Block 4:
འདི་ལ་གཉིས། རྒྱུ་དུས་ཀྱི་སྨོན་ལམ་འདེབས་ཚུལ་དང་། འབྲས་དུས་སུ་སྨོན་ལམ་གྲུབ་ཚུལ་མཚུངས་པར་བསྟན་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 6:
ཚུལ་ནི། བརྟེན་པ་སྤངས་རྟོགས་ཀྱི་ཁྱད་པར་གཉིས་དང་། རྟེན་རིགས་ཀྱི་ཁྱད་པར་གསུམ་གྱིས་ཡང་དག་པར་བསྡུས་པར་རོ། །
Enumeration Block 7:
དེ་ལ་གཟུང་རྟོག་སྤངས་པ་དང་འཛིན་རྟོག་མ་སྤངས་པའི་ཁྱད་པར་གཉིས་ལས།
Enumeration Block 8:
རྟེན་གྱི་ཁྱད་པར་ལ་གཉིས། སྒྲུབ་པ་པོའི་རྟེན་གྱི་གང་ཟག་དང་། སྒྲུབ་པའི་དམིགས་པ་ཆོས་ཉིད་ཀྱི་རྟེན་ནོ། །
