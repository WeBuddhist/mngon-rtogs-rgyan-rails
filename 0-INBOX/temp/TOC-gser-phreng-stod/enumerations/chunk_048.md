Enumeration Block 1:
འདིའི་ལན་ལ་གཉིས། སྒྲ་གཉིས་བརྗོད་བྱ་ཐ་དད་མེད་པ་དང་། དོན་གྱི་ཤུགས་ཀྱིས་ཆོས་ཅན་གོ་བའི་ལན་ནོ། །
Enumeration Block 2:
འདི་ལ་གཉིས། ཆོས་བརྗོད་ཀྱི་སྒྲ་དང་། ཆོས་ཅན་བརྗོད་པའི་རྣམ་གཞག་གོ །
Enumeration Block 3:
དེ་ལ་བརྡ་སྦྱར་བའི་དུས། བརྡ་སྦྱར་བའི་དགོས་པ། གང་ལ་བརྡ་སྦྱར་བའི་ཡུལ། དེ་ལ་བརྡ་སྦྱར་བའི་ཚུལ་ཏེ་བཞིའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་ཡང་སྔར་ལྟར་བཞི་ལས།
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། སྤྱི་དང་། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ་གཉིས། སྤང་བྱ་རྟོག་པ། སྤོང་བྱེད་གཉེན་པོའོ། །དང་པོ་ལ་བདུན། གང་གིས་རྟོག་པའི་ངོ་བོ། གང་ལ་རྟོག་པའི་ཡུལ། ཇི་ལྟར་རྟོག་པའི་ཚུལ། རྟོག་པ་དེའི་རབ་དབྱེ། གྲངས་ངེས་པ། གོ་རིམས་ངེས་པ། མུ་བརྩི་བའོ། །དང་པོ་ལ་གཉིས། སྤྱི་དང་། བྱེ་བྲག་ཏུ་བསམ་པའོ། །
