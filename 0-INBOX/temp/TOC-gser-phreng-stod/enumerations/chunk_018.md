Enumeration Block 1:
ལྔ་པ་ལ་བཞི། མཁྱེན་གསུམ་དང་རྣམ་ཀུན་དང་། རྣམ་མཁྱེན་དང་ལམ་ཤེས་དང་། གཞི་ཤེས་དང་། རྣམ་མཁྱེན་དང་ཆོས་སྐུ་ལ་ཟློས་པ་སྤང་བའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། དོན་དངོས་དང་། ཟློས་པ་སྤང་བའོ། །དང་པོ་ལ་གསུམ། མཁྱེན་གསུམ། སྦྱོར་བཞི། ཆོས་སྐུའི་ལུས་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གསུམ། རྣམ་མཁྱེན། ལམ་ཤེས། གཞི་ཤེས་ཀྱི་ལུས་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གསུམ། རྣམ་མཁྱེན་ཇི་ལྟར་བཤད་པའི་ཚུལ་དང་། དེའི་འཆད་བྱེད་གཏན་ལ་དབབ་པ། རྟེན་གྱི་གང་ཟག་གོ །
Enumeration Block 3:
གཉིས་པ་ལ་བཞི། ལམ་གྱི་རང་བཞིན་སེམས་བསྐྱེད་པ། སེམས་བསྐྱེད་དག་བྱེད་གདམས་ངག་ནོད་པ། གདམས་པའི་འབྲས་བུ་ངེས་འབྱེད་ཡན་ལག །གདམས་པའི་དོན་ཕྱིན་ཅི་མ་ལོག་པར་སྒྲུབ་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། སྤྱིར་གདམས་ངག་ཙམ་དང་། ཁྱད་པར་དུ་ཐེག་ཆེན་གདམས་ངག་གོ །
Enumeration Block 5:
བཞི་པ་ལ་བཞི། སྒྲུབ་པའི་རྟེན། སྒྲུབ་པའི་དམིགས་པ། སྒྲུབ་པའི་ཆེད་དུ་བྱ་བ། སྒྲུབ་པ་རང་གི་ངོ་བོའོ། །དང་པོ་ལ་གཉིས། སྤྱིར་རིགས་ཙམ་ཞིག་དང་། ཁྱད་པར་དུ་ཐེག་ཆེན་གྱི་རིགས་སོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། ཐེག་ཆེན་གྱི་རིགས་སྤྱི་ཙམ་པ་དང་། བྱེ་བྲག་འདིར་སྨོས་ཀྱི་གནས་རིགས་སོ། །
Enumeration Block 7:
བཞི་པ་ལ་གཉིས། མཚན་ཉིད་དང་། དབྱེ་བའོ། །
