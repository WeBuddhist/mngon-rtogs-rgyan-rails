Enumeration Block 1:
གཉིས་པ་ལ་གཉིས། ཚིག་ལེའུར་བྱས་པ་དང་འབྲེལ་བའི་དོན་གཞན་བཤད། ཚིག་ལེའུར་བྱས་པ་ཉིད་ཀྱི་དོན་བཤད་པའོ། །དང་པོ་ལ་གཉིས། མདོ་དང་ཇི་ལྟར་སྦྱར་བ་དང་། སྦྱར་ཚུལ་ལ་རྩོད་པ་སྤང་བའོ། །
Enumeration Block 2:
དེ་དག་ཏུ་སྦྱར་བའི་རྒྱུ་མཚན་གཉིས་ཡོད་པས་སྦྱར་དུ་རུང་སྟེ།
Enumeration Block 3:
གཉིས་པ་ལ་གསུམ། ཤེས་བྱ་མཁྱེན་པ་གསུམ། ཉམས་ལེན་སྦྱོར་བ་བཞི། འབྲས་བུ་ཆོས་སྐུའི་ཡན་ལག་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གསུམ། ཐོབ་བྱ་རྣམ་མཁྱེན། ཐོབ་བྱེད་ལམ་ཤེས། སྤང་བྱ་གཞི་ཤེས་ཀྱི་ཡན་ལག་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གསུམ། འབྲེལ་བརྗོད་པས་མཚམས་སྦྱར། རྣམ་མཁྱེན་གྱི་ཆོས་རྒྱས་པར་བཤད། སྐབས་བསྡུ་བའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་བཞི། ལམ་གྱི་རང་བཞིན་སེམས་བསྐྱེད་པ། སེམས་བསྐྱེད་དེ་དག་བྱེད་གདམས་ངག་ནོད་པ། གདམས་པའི་འབྲས་བུ་ངེས་འབྱེད་ཡན་ལག །གདམས་པའི་དོན་ཕྱིན་ཅི་མ་ལོག་པར་སྒྲུབ་པའོ། །དང་པོ་ལ་གཉིས། སྤྱི་དང་། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ་གསུམ། སེམས་བསྐྱེད་སྐྱེ་བའི་རྟེན། བརྟེན་པ་སེམས་བསྐྱེད་ཀྱི་རང་བཞིན། རང་བཞིན་དེས་བསྐྱེད་ཀྱི་ཕན་ཡོན་ནོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 5:
སེམས་རྟེན་ནི། རྒྱལ་བ་ལ་དམིགས་པའི་དད་པ། སེམས་ཅན་ལ་དམིགས་པའི་སྙིང་རྗེ། བྱང་སེམས་ཀྱི་ཕན་ཡོན་ཐོས་པ་དང་གསུམ་ཡིན་ཏེ།
Enumeration Block 6:
གཉིས་པ་ལ་གསུམ། མཚན་གཞི། མཚན་ཉིད། རབ་དབྱེའོ། །དང་པོ་ལ་གཉིས། སློབ་དཔོན་གཞན་དང་། བསྟན་བཅོས་འདི་ཡི་འགྲེལ་བྱེད་ཀྱི་ལུགས་སོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གཉིས། འཕགས་པ་རྗེས་འབྲང་དང་བཅས་པ་དང་། དེ་དང་མི་མཐུན་པའི་ལུགས་སོ། །
Enumeration Block 8:
གསུམ་པ་ལ་བཞི། ངོ་བོ། སྐྱེ་ཚུལ། ས་མཚམས། བཞེད་ཚུལ་གྱི་སྒོ་ནས་དབྱེ་བའོ། །
Enumeration Block 9:
འདི་ལ་གཉིས། ལུགས་གཞན་དགོད་པ་དང་། འཐད་ཕྱོགས་བསྟན་པའོ། །
