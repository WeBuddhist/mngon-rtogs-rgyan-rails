Enumeration Block 1:
གཉིས་པ་ལ་གསུམ། མཐོང་ལམ་གྱི་ངོ་བོ་མདོར་བསྟན། སྒོམ་ཚུལ་གྱི་རྣམ་པ་རྒྱས་པར་བཤད། རྣམ་པ་མ་བཤད་པར་འདོད་པ་དགག་པའོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 2:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 3:
གསུམ་པ་ལ་གཉིས། རྒྱས་པར་བཤད། དོན་བསྡུ་བའོ། །དང་པོ་ལ་བཞི། སྡུག་བསྔལ་དང་། ཀུན་འབྱུང་དང་། འགོག་པ་དང་། ལམ་བདེན་གྱི་རྣམ་པའོ། །
Enumeration Block 4:
གསུམ་པ་ལ་གཉིས། ཁས་བླངས་བརྗོད་པ་དང་། དེ་དགག་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། རིགས་པ་དང་། ལུང་གིས་དགག་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང་། དོན་དངོས་བཤད་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གཉིས། སྒོམ་ལམ་གྱི་བྱེད་པ་དང་། བྱེད་པ་ཅན་གྱི་སྒོམ་པའི་ལམ་མོ། །དང་པོ་ལ་གསུམ་ལས།
