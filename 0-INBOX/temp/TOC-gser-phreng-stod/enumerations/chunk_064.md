Enumeration Block 1:
གསུམ་པ་ནི། སེམས་ཅན་དང་ཆོས་དང་། དམིགས་པ་མེད་པ་ལ་དམིགས་པའི་བྱམས་སོགས་གསུམ་མོ། །
Enumeration Block 2:
གསུམ་པ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང་། སྤྱིར་བསྟན་པ་དང་། རྟོགས་དཀའ་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས་ལས།
Enumeration Block 4:
བཅུ་བདུན་པོ་འདི་ཡང་བདག་ཉིད་ཆེན་པོས་རྣམ་པ་ལྔར་བསྡུས་པ་ལྟར་གནས་པས།
Enumeration Block 5:
སྦྱོར་བས་བསྡུས་པ་ལ་སྦྱིན་སོགས་དྲུག་ལས།
Enumeration Block 6:
གཉིས་པ་མཉམ་པར་བཞག་པ་དང་མ་བཞག་པའི་དབང་དུ་བྱས་པའི་ཚོགས་བཞི་ལས།
Enumeration Block 7:
གསུམ་པ་ལྟ་བ་དང་སྤྱོད་པའི་དབང་དུ་བྱས་པའི་ཚོགས་གཉིས་ལས་
Enumeration Block 8:
བཞི་པ་འབྲས་བུ་སྒྲུབ་པ་དང་དམིགས་པ་འཛིན་པའི་དབང་དུ་བྱས་པའི་ཚོགས་གཉིས་ལས།
Enumeration Block 9:
གཉིས་པ་ལ་བཞི། སྒྲུབ་བྱེད་ཀྱི་ངོ་བོ། ཇི་ལྟར་སྒྲུབ་ཚུལ། སྒྲུབ་པའི་ངེས་ཚིག །སྒྲུབ་པའི་གྲངས་ངེས་སོ། །
