Enumeration Block 1:
གཉིས་པ་ལ་གཉིས། བཤད་པ་དང་། བསྡུ་བའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 2:
བཞི་པ་ལ་གཉིས་ལས། དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 3:
གཉིས་པ་ལ་བཤད་བསྡུ་གཉིས་ལས། དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 4:
གསུམ་པ་ལ་གཉིས། རྩོད་པ་དང་། ལན་ནོ། །
Enumeration Block 5:
ལན་ལ་གཉིས་ལས།
Enumeration Block 6:
འདིའི་ལན་ལ་གཉིས། སྒྲ་གཉིས་བརྗོད་བྱ་ཐ་དད་མེད་པ་དང་། དོན་གྱི་ཤུགས་ཀྱིས་ཆོས་ཅན་གོ་བའི་ལན་ནོ། །
Enumeration Block 7:
འདི་ལ་གཉིས། ཆོས་བརྗོད་ཀྱི་སྒྲ་དང་། ཆོས་ཅན་བརྗོད་པའི་རྣམ་གཞག་གོ །
Enumeration Block 8:
དེ་ལ་བརྡ་སྦྱར་བའི་དུས། བརྡ་སྦྱར་བའི་དགོས་པ། གང་ལ་བརྡ་སྦྱར་བའི་ཡུལ། དེ་ལ་བརྡ་སྦྱར་བའི་ཚུལ་ཏེ་བཞིའོ། །
Enumeration Block 9:
གཉིས་པ་ལ་ཡང་སྔར་ལྟར་བཞི་ལས།
