Enumeration Block 1:
གཉིས་པ་ལ་གཉིས། ལམ་ཤེས་སྐྱེ་བའི་རྟེན། བརྟེན་པ་ལམ་ཤེས་ཀྱི་ཁྱད་པར་རོ། །
Enumeration Block 2:
གཉིས་པ་ལ་རྩ་བ་ལྟར་གསུམ་ལས། དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 3:
འདིའི་མཐའ་དཔྱད་པ་ལ་གསུམ། ཐེག་གསུམ་ལ་དྲང་ངེས་སུ་འདོད་ཚུལ། ཉན་རང་ཐེག་ཆེན་དུ་གང་ནས་འཇུག་པ། འཁོར་བ་ལ་མཐའ་ཡོད་མེད་དོ། །དང་པོ་ལ་གཉིས། ངེས་དོན་དང་། དྲང་དོན་དུ་འདོད་པའི་ལུགས་སོ། །དང་པོ་ལ་གཉིས། མདོ་གང་གི་རྗེས་སུ་འབྲངས་པ་དང་། དེའི་དོན་ཇི་ལྟར་བཤད་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ། རང་གི་ལུགས་དགོད་པ་དང་། དེ་ལ་ནང་འགལ་སྤང་བ། མདོ་གཞན་དང་འགལ་བ་སྤང་བའོ། །
Enumeration Block 5:
ལུང་དང་རིགས་པ་གཉིས་ལས།
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། མདོ་གང་གི་རྗེས་སུ་འབྲང་བ་དང་། ཇི་ལྟར་རྣམ་གཞག་བྱ་བའི་ཚུལ་ལོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གཉིས།སློབ་དཔོན་གྱིས་མདོའི་དོན་ཇི་ལྟར་བཤད་པ། རྗེས་འཇུག་གིས་དེ་ལ་རྩོད་པ་སྤངས་པའི་ཚུལ་ལོ། །
