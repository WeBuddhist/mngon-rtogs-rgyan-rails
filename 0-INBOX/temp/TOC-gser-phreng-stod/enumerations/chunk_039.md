Enumeration Block 1:
དེ་ཡང་དུས་ནམ་གྱི་ཚེ་དང་། ས་གང་ལ་བརྟེན་པའི་ལམ་གྱིས་དང་། སྤང་བྱ་གང་ཇི་ལྟར་ཅིག་ཅར་སྤོང་བ་དང་། གང་ཟག་གང་ལ་བཞག་པ་དང་། འབྲས་བུ་མངོན་དུ་བྱེད་ཚུལ་དང་ལྔས་རིག་པར་བྱའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 3:
གཉིས་པ་ལ་ལྔ། གང་ལས་དབྱེ་བའི་གཞི། ཇི་ལྟར་ཕྱེ་བའི་གྲངས། ཕྱེ་བ་སོ་སོའི་རང་བཞིན། དེ་དག་གང་གིས་མཚོན་བསམ་པ། ཁྱད་པར་གྱི་ཆོས་གཞན་བསྟན་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། མདོ་དང་རྒྱན་མ་སྦྱར་བ་དང་། སྦྱར་བའི་འདྲེན་ལུགས་སོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། སྒྲ་ཇི་བཞིན་པ་དང་། ཇི་བཞིན་པ་མ་ཡིན་པར་འདྲེན་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། འཕགས་པ་དང་། སློབ་དཔོན་གྱི་ལུགས་སོ། །
Enumeration Block 7:
ཕྱིར་མི་ལྡོག་པའི་དགེ་འདུན་ནི་དབྱེ་གཞི། དབྱེ་ན་ཉི་ཤུའོ། །
