Enumeration Block 1:
གཉིས་པ་ལ་གསུམ། དམིགས་རྣམ་རྒྱུ་གསུམ་དང་། མཚུངས་ལྡན་རྟོག་པ་དང་། ཡོངས་འཛིན་དགེ་བཤེས་ཀྱི་ཁྱད་པར་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གསུམ། སྤྱིའི་མཚམས་སྦྱར་བ། སོ་སོའི་དབྱེ་བ་བཤད་པ། བརྗོད་ཚུལ་ལ་རྩོད་པ་སྤང་བའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་བཞི། དྲོད། རྩེ་མོ། བཟོད་པ། ཆོས་མཆོག་གི་དམིགས་རྣམ་མོ། །དང་པོ་ལ་གཉིས། རྩ་བ་དང་། འགྲེལ་པའོ། །དང་པོ་ལ་གསུམ། ཆུང་ངུ་འབྲིང་ཆེན་པོའི་དམིགས་རྣམ་མོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས་ལས།
Enumeration Block 4:
གསུམ་པ་ལ་གཉིས་ལས།
Enumeration Block 5:
འདི་ལ་གཉིས། དབྱེ་བ་བཤད་པ་དང་། དོན་བསྡུ་བའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས་ལས། དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 7:
རྩེ་མོ་ཆུང་ངུའི་དམིགས་རྣམ་ལ། བདེན་པ་རྣམ་པར་མ་བཞག་པ་དང་། བཞག་པ་གཉིས་ལས།
Enumeration Block 8:
འདི་ལ་བདེན་པ་བཞིའི་དབང་དུ་བྱས་པའི་དམིགས་རྣམ་གཉིས་གཉིས་ལས།
