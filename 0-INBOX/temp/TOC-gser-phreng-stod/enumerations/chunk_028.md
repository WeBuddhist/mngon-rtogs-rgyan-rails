Enumeration Block 1:
གཉིས་པ་ལ་གཉིས། མཚམས་སྦྱར། དོན་བཤད་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། གདམས་ངག་སྤྱིར་བསྟན། རྟོགས་དཀའ་བ་བྱེ་བྲག་ཏུ་བཤད་པའོ། །དང་པོ་ལ་གསུམ། བསྟན། བཤད། མཇུག་བསྡུ་བའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་བཞི། སྒྲུབ་པ་རང་གི་ངོ་བོ། དམིགས་ཡུལ་བདེན་པ་བཞི། རྟེན་དཀོན་མཆོག་གསུམ། སྒྲུབ་པ་ཕུན་ཚོགས་ཀྱི་རྒྱུ་ལ་གདམས་པའོ། །དང་པོ་ལ་གཉིས། ངོ་བོ་དང་། ཁྱད་པར་རོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། སྤྱི་དང་། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ་ལྔ། སྒྲ་བཤད། རང་བཞིན་གཅིག་ཐ་དད། གྲངས་ངེས་པ། གོ་རིམས་ངེས་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། མཚན་གཞི་དང་། མཚན་ཉིད་དོ། །དང་པོ་ལ་གཉིས། ཀུན་ཉོན་དང་། རྣམ་བྱང་གི་བདེན་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། འགོག་བདེན་དང་། ལམ་བདེན་གྱི་མཚན་གཞིའོ། །
