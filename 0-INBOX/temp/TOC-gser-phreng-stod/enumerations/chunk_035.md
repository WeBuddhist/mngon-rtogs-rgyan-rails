Enumeration Block 1:
རྒྱུ་ལ་གཉིས་ལས་འགལ་རྐྱེན་སྤོང་བའི་རྒྱུ་ལ་གསུམ་ལས།
Enumeration Block 2:
མཐུན་རྐྱེན་སྒྲུབ་པ་ལ་གསུམ་ལས།
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། མཚོན་བྱེད་དཔེ་དང་། མཚོན་བྱ་དོན་གྱི་དགེ་འདུན་ནོ། །དང་པོ་ལ་གསུམ། སྤྱིའི་རྣམ་པར་བཞག་པ། སོ་སོའི་རང་བཞིན་བསྟན་པ། འབྲས་བུ་བཞིར་འཇོག་པའི་རྒྱུ་མཚན་ནོ། །དང་པོ་ལ་བཞི། དགེ་འདུན་གྱི་གྲངས། བརྡ་སྦྱོར་བའི་ཚུལ། ཞུགས་གནས་གང་ལ་བཞག །འབྲས་བུ་རྣམས་འཐོབ་པའི་ཚུལ་ལོ། །
Enumeration Block 4:
གསུམ་པ་ལ་གསུམ། ཐོད་རྒལ་བ་དང་། རིམ་གྱིས་པ་དང་། ཅིག་ཅར་བ་གང་ལ་བཞག་པའོ། །
Enumeration Block 5:
བཞི་པ་ལ་གསུམ། འབྲས་བུ་དེ་དག་ལམ་གང་གིས་དང་། དུས་ནམ་གྱི་ཚེ་དང་། ས་གང་ལ་བརྟེན་ནས་ཐོབ་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གསུམ། ཐོད་རྒལ་བ། མཐར་གྱིས་པ། ཅིག་ཅར་བའོ། །དང་པོ་ལ་གཉིས། ཞུགས་པ་དང་། གནས་པའོ། །དང་པོ་ལ་གཉིས་ལས།
