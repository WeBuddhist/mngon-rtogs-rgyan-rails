Enumeration Block 1:
འདི་ཞིབ་པར་དཔྱད་ན་གསུམ་སྟེ། ཆོས་ཅན་དག་གཞི་གསུམ་གྱི་ངོ་བོ་དང་། བསྒྲུབ་བྱ་དག་པ་གསུམ་གཅིག་ཡིན་པ་དང་། སྒྲུབ་བྱེད་གཉིས་མེད་སོགས་བཞིར་ཕྱེ་བའི་དོན་བཤད་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། ལམ་གྱི་དབྱེ་བ་དངོས་དང་། མཐར་ཐུག་པའི་ལམ་གྱི་ཁྱད་པར་རོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། ལམ་གྱི་ཁྱད་པར་དངོས་དང་། རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ་གཉིས། དྲི་བ་དང་། ལན་ནོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས་ལས།
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། རྩོད་པ་དང་། ལན་ནོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས་ལས། དང་པོ་ནི། སློབ་དཔོན་གྱི་དགོངས་པ་འགྲེལ་པར་འཆད་ལ་འཕགས་པ་ལྟར་ན་གསུམ། གཉེན་པོ་བྱེད་ཚུལ། ཡུལ་རྟོགས་ཚུལ། དེ་ལ་རྩོད་སྤང་ངོ༌། །
