Enumeration Block 1:
གཉིས་པ་ནི། གོ་འཇུག་ཚོགས་ངེས་ཏེ་བཞིའོ། །
Enumeration Block 2:
དབྱེ་ན་ཕྱིན་དྲུག་གི་གོ་ཆ་དྲུག་གོ །
Enumeration Block 3:
དབྱེ་ན་འཇུག་སྒྲུབ་དགུའོ། །
Enumeration Block 4:
དབྱེ་ན་ཚོགས་སྒྲུབ་བཅུ་བདུན་ནོ། །
Enumeration Block 5:
དབྱེ་ན་འབྱུང་སའི་སྒོ་ནས་འབྱིན་བྱེད་ཀྱི་སྒྲུབ་པ་བརྒྱད་དོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གསུམ། ལམ་ཤེས་ཀྱི་ཆོས་དངོས། དེ་ཇི་ལྟར་མཚོན་ཚུལ། རྟེན་གྱི་གང་ཟག་གོ །དང་པོ་ལ་གཉིས། ལམ་ཤེས་ཀྱི་ཡན་ལག །ཡན་ལག་ཅན་གྱི་ལམ་མོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 8:
དབྱེ་ན་འཕགས་ལམ་དང་སྦྱོར་ལམ་གཉིས་ལས།
Enumeration Block 9:
གསུམ་པ་བྱང་སེམས་ཀྱི་ལམ་ལ་གཉིས་ལས།
Enumeration Block 10:
དབྱེ་ན་བཅུ་དྲུག་གོ །
Enumeration Block 11:
གཉིས་པ་སྒོམ་ལམ་ལ་གཉིས་ལས།
Enumeration Block 12:
དབྱེ་ན་དྲུག་གོ །
Enumeration Block 13:
གཉིས་པ་བྱེད་པ་ཅན་གྱི་སྒོམ་ལམ་ལ་གཉིས་ལས། དང་པོ་ཟག་བཅས་སྒོམ་ལམ་ལ་གསུམ་ལས། དང་པོ་ལ་དངོས་དང་། ཕན་ཡོན་གཉིས་ལས།
Enumeration Block 14:
དབྱེ་ན་ཉེར་བདུན་ནོ། །
Enumeration Block 15:
དེ་དག་ལ་ཡང་དགུ་དགུ་སྟེ་ཉེར་བདུན་ནོ། །
Enumeration Block 16:
དབྱེ་ན་བཅུ་གཉིས་སོ། །
Enumeration Block 17:
དབྱེ་ན་ཀུན་རྫོབ་དང་དོན་དམ་ཡུལ་ཅན་གྱི་ཡི་རང་གཉིས་སོ། །
Enumeration Block 18:
གཉིས་པ་ཟག་མེད་སྒོམ་ལམ་ལ་གཉིས་ལས།
