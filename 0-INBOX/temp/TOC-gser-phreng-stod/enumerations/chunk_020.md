Enumeration Block 1:
བྱང་སེམས་ཀྱི་ལམ་ལ་གཉིས་ལས།
Enumeration Block 2:
སྒོམ་ལམ་ལ་གཉིས་ལས།
Enumeration Block 3:
བྱེད་པ་ཅན་གྱི་སྒོམ་ལམ་ལ་གཉིས་ལས། དང་པོ་ཟག་བཅས་སྒོམ་ལམ་ལ་གསུམ་ལས། དང་པོ་ལ་དངོས་དང་།
ཕན་ཡོན་གཉིས་ལས།
Enumeration Block 4:
ཟག་མེད་སྒོམ་ལམ་ལ་གཉིས་ལས།
Enumeration Block 5:
གསུམ་པ་ལ་གསུམ། གཞི་ཤེས་ཀྱི་ཆོས་དངོས། དེ་ཇི་ལྟར་བཤད་ཚུལ། རྟེན་གྱི་གང་ཟག་གོ །དང་པོ་ལ་ཆོས་དགུ་ལས།
Enumeration Block 6:
གཉིས་པ་ལ་བཞི། རྣམ་ཀུན། རྩེ་མོ། མཐར་གྱིས་པ། སྐད་ཅིག་མའི་ལུས་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། རྣམ་ཀུན་གྱི་ཆོས་དངོས་དང་། དེ་ཇི་ལྟར་བཤད་པའི་ཚུལ་ལོ། །དང་པོ་ལ་བཅུ་གཅིག་ལས།
Enumeration Block 7:
གཉིས་པ་ལ་གཉིས། རྩེ་མོའི་ཆོས་དངོས། དེ་ཇི་ལྟར་མཚོན་པའི་ཚུལ་ལོ། །དང་པོ་ལ་བརྒྱད་ལས།
Enumeration Block 8:
གསུམ་པ་ལ་བཅུ་གསུམ་ལས།
