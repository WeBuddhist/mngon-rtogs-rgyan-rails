Enumeration Block 1:
དེ་ཡང་དངོས་སུ་དང་། བརྒྱུད་ནས་སམ་ལོག་པ་ལ་དང་། དབང་གི་ལོག་ཞུགས་དང་གསུམ་གྱིས་རིག་པར་བྱའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། མཚན་ཉིད་དང་དབྱེ་བའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་འཆད་ཚུལ་གཉིས་ལས།
Enumeration Block 4:
བཞི་པ་ལ་གཉིས། མཐོང་སྤང་དང་། སྒོམ་སྤང་ཇི་ལྟར་སྤོང་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས། ལུགས་གཞན་བསྟན། རང་ལུགས་བཞག་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ། ཆོས་མངོན་པ་ནས་གསུངས་པའི་ཚུལ།དེའི་དགོངས་པ་གང་ཡིན་བརྟག་པ། སྤང་གཉེན་གྱི་ཁྱད་པར་གཞན་བསྟན་པའོ། །
Enumeration Block 6:
གསུམ་པ་ལ་གསུམ། རིམ་དང་ཅིག་ཅར་དུ་སྤོང་བ་དང་། སྤང་བྱའི་ངོ་བོ་དང་དུས་དང་། སྤངས་ཤིང་གྲོལ་བའི་དོན་གང་ཡིན་བརྟག་པའོ། །དང་པོ་ལ་གཉིས། འདོད་པ་དགོད། གནས་དོན་བསམ་པའོ། །
