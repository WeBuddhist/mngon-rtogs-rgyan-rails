Enumeration Block 1:
བཞི་པ་ལ་གསུམ་ལས།
Enumeration Block 2:
གཉིས་པ་ཐོབ་བྱེད་ལམ་ཤེས་ཀྱི་ཡན་ལག་རྒྱས་པར་བཤད་པ་ལ་གསུམ། འབྲེལ་བརྗོད་པས་མཚམས་སྦྱར། ལམ་ཤེས་ཀྱི་ཆོས་རྒྱས་པར་བཤད། སྐབས་བསྡུ་བའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། ལམ་གྱི་ཡན་ལག་དང་། ཡན་ལག་ཅན་གྱི་ལམ་མོ། །དང་པོ་ལ་གཉིས། རྩ་བས་བསྟན། འགྲེལ་པས་བཤད་པའོ། །དང་པོ་ལ་གཉིས། ལམ་ཤེས་ཀྱི་རྟེན་དང་། བརྟེན་པ་ལམ་ཤེས་ཀྱི་ཁྱད་པར་རོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ། སྐྱེ་ཚུལ་དང་། ངོ་བོ་དང་། བྱེད་ལས་ཀྱི་ཁྱད་པར་རོ། །དང་པོ་ལ་གཉིས། གནས་སྐབས་དང་། མཐར་ཐུག་གི་སྐྱེ་ཚུལ་ལོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། ལམ་ཤེས་སྐྱེ་བའི་རྟེན། བརྟེན་པ་ལམ་ཤེས་ཀྱི་ཁྱད་པར་རོ། །
Enumeration Block 6:
གཉིས་པ་ལ་རྩ་བ་ལྟར་གསུམ་ལས། དང་པོ་ལ་གཉིས་ལས།
