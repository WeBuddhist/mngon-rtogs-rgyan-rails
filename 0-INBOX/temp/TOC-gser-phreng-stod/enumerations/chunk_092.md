Enumeration Block 1:
གསུམ་པ་ལ་གསུམ་ལས།
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། ཐུན་མོང་གི་མཚམས་སྦྱར། སོ་སོའི་དོན་བཤད་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། སྒྲུབ་པ་དང་། རྣམ་དག་སྒོམ་ལམ་བཤད་པའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 4:
སྒྲུབ་པ་སྒོམ་ལམ་ལ་ཡང་གཉིས་ལས།
གང་གིས་སྒྲུབ་བྱེད་ཀྱི་རང་བཞིན་ནི་དང་པོ་གསུམ་སྟེ། ངོ་བོ་དང༌ཁྱད་པར་དང༌བློའི་རྣམ་པའོ། །
Enumeration Block 5:
གང་བསྒྲུབ་བྱ་ལ་ལྟོས་པའི་ནུས་པ་ནི། ཕྱི་མ་གཉིས་(སྟེ,ཏེ)། བྱང་སེམས་ཀྱི་གནས་སྐབས་ན་གཏོད་པ་དང་སངས་རྒྱས་ཐོབ་པར་བྱེད་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། རྣམ་དག་གི་རྒྱུ་དང་། རྣམ་དག་དངོས་སོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 7:
གསུམ་པ་ལ་གཉིས། སྐྱེ་བ་དང་མི་སྐྱེ་བའི་རྒྱུའོ། །
Enumeration Block 8:
གང་ན་གསུམ་ལས།
Enumeration Block 9:
གང་ན་བཞི་ལས།
Enumeration Block 10:
གཉིས་པ་ལ་གཉིས། རྣམ་དག་སྤྱིར་བསྟན་པ་དང་། བྱེ་བྲག་ཏུ་བཤད་པའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 11:
འདི་ཞིབ་པར་དཔྱད་ན་གསུམ་སྟེ། ཆོས་ཅན་དག་གཞི་གསུམ་གྱི་ངོ་བོ་དང་། བསྒྲུབ་བྱ་དག་པ་གསུམ་གཅིག་ཡིན་པ་དང་། སྒྲུབ་བྱེད་གཉིས་མེད་སོགས་བཞིར་ཕྱེ་བའི་དོན་བཤད་པའོ། །
