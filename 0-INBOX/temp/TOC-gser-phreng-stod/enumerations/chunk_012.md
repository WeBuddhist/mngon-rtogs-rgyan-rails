Enumeration Block 1:
གཉིས་པ་ལ་གསུམ། དགོས་འབྲེལ་བཞི་ངོས་བཟུང་། དེ་དག་ངག་གིས་བསྟན་པའི་ཚུལ། བསྟན་བྱ་བཞིར་གྲངས་ངེས་པའོ། །དང་པོ་ལ་གསུམ། ངག་ཙམ་དང་། དགོས་འབྲེལ་ངག་དང་། བསྟན་བཅོས་ལུས་ལ་ཡོད་པའི་དགོས་འབྲེལ་ལོ། །
Enumeration Block 2:
གསུམ་པ་ལ་གསུམ་ལས།
Enumeration Block 3:
དེ་ལ་མོས་པ་དང་ཤེས་རབ་དམན་པའི་གང་ཟག་གཉིས་ལས།
Enumeration Block 4:
དང་པོ་ལ་གཉིས། ལུགས་གཞན་བསྟན་པ་དང་། འཐད་ཕྱོགས་ངོས་གཟུང་བའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། བཀའ་དང་བསྟན་བཅོས་ཀྱི་མཚན་གཞིའོ། །
Enumeration Block 6:
འདི་ལ་བཞི་ལས།
