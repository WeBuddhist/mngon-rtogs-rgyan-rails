Enumeration Block 1:
གཉིས་པ་ལ་གཉིས། གཟུང་རྟོག་དང་འཛིན་རྟོག་མདོར་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། རྩ་བ་དང་འགྲེལ་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས་ལས།
Enumeration Block 3:
འདི་ལ་གཉིས། གཟུང་རྟོག་དང་འཛིན་རྟོག་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། ཀུན་ནས་ཉོན་མོངས་དང་། རྣམ་བྱང་གཟུང་རྟོག་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ནི། ཀུན་ནས་ཉོན་མོངས་པའི་གཞིའི་རྟེན་ཅན་གྱི་གཟུང་རྟོག་ལ་དབྱེ་ན་དགུ་རྣམས་སུ་ཡོད་དེ།
Enumeration Block 4:
གཉིས་པ་ནི། གཉེན་པོ་རྣམ་བྱང་གི་རྟེན་ཅན་གྱི་གཟུང་རྟོག་ལ་དབྱེ་ན་རྣམ་པ་དགུར་ཡོད་དེ།
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། རྫས་འཛིན་དང་། བཏགས་འཛིན་རྟོག་པ་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ནི། གང་ཟག་སྟེ་འཛིན་པ་པོ་རྫས་སུ་ཡོད་པའི་རྟེན་ཅན་གྱི་འཛིན་རྟོག་ལ་དབྱེ་ན་རྣམ་པ་དགུ་རྣམས་སུ་ཡོད་དེ།
Enumeration Block 6:
གཉིས་པ་ནི། སྐྱེས་བུ་སྟེ་འཛིན་པ་པོ་བཏགས་པར་ཡོད་པའི་རྟེན་ཅན་གྱི་འཛིན་རྟོག་ལ་དབྱེ་ན་རྣམ་པ་དགུར་ཡོད་དེ།
