Enumeration Block 1:
གཉིས་པ་ལ་གཉིས། དངོས་དང་། ཡུམ་སྲས་སུ་འགྱུར་ཚུལ་ལོ། །
Enumeration Block 2:
འདི་ལ་གཉིས། ཡུལ་གང་ལ་དང་། ཚུལ་ཇི་ལྟར་རོ། །
Enumeration Block 3:
འདི་ལ་གསུམ། གཞི་ཤེས་ཀྱིས་ཉན་རང་དང་། ལམ་ཤེས་ཀྱིས་བྱང་སེམས། རྣམ་མཁྱེན་གྱིས་སངས་རྒྱས་ཀྱི་བཞེད་པ་སྒྲུབ་ཚུལ་ལོ། །
Enumeration Block 4:
འདི་ལ་ཨ་དུ་ལ་བཞེད་པ་ལྟར། རྟེན་ཐབས་འབྲས་བུ་གསུམ་དང་། དེའི་འཐད་པ་བསྣན་པ་སྟེ་བཞིའོ། །
Enumeration Block 5:
འདིའི་མཐའ་དཔྱད་པ་ལ་གསུམ། ཉན་ཐོས་སྡེ་པ་དང་། སེམས་ཙམ་པ་དང་། དབུ་མ་པའི་ལུགས་སོ། །དང་པོ་ལ་གཉིས། ལྷག་མ་ཡོད་མེད་ཀྱི་དོན། མྱང་འདས་གང་ལ་འདོད་པའོ། །
Enumeration Block 6:
སྤྱིར་མྱང་འདས་བཞིར་གསུང་རབ་ལས་འབྱུང་སྟེ། རང་བཞིན་དང་། མི་གནས་པ་དང་། ལྷག་བཅས་དང་། ལྷག་མེད་ཀྱི་མྱང་འདས་སོ། །
Enumeration Block 7:
ཐ་མ་གཉིས་ལ་གཉིས་ལས།
