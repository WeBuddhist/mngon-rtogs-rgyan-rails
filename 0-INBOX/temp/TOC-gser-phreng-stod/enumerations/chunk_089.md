Enumeration Block 1:
གཉིས་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང་། དོན་དངོས་བཤད་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། སྒོམ་ལམ་གྱི་བྱེད་པ་དང་། བྱེད་པ་ཅན་གྱི་སྒོམ་པའི་ལམ་མོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། མཚམས་སྦྱར། སོ་སོའི་ངོ་བོའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། ཟག་བཅས་དང་། ཟག་མེད་ཀྱི་སྒོམ་ལམ་མོ། །དང་པོ་ལ་གསུམ། དབྱེ་བ་བསྟན་ཏེ་མཚམས་སྦྱར། ཕྱེ་བ་སོ་སོའི་རང་བཞིན་བཤད། བྱེད་ལས་ཀྱི་སྒོ་ནས་དོན་བསྡུ་བའོ། །དང་པོ་ལ་གཉིས། དངོས་དང་། ས་མཚམས་བསྟན་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ། མོས་པ། བསྔོ་བ། ཡི་རང་ངོ་། །དང་པོ་ལ་གཉིས། དངོས་དང་། ཕན་ཡོན་ནོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 6:
གཉིས་པ་ལ་བཞི། རྩ་བ། ཡན་ལག །ཉིང་ལག་གི་དབྱེ་བ་དང་། དོན་བསྡུ་བའོ། །
Enumeration Block 7:
འདི་ལ་བཞི། མོས་པའི་ཡུལ། མོས་པའི་ངོ་བོ། མོས་པའི་རྒྱུ། མོས་པའི་བྱེད་ལས་སོ། །
