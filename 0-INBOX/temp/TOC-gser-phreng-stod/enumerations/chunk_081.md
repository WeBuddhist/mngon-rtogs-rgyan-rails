Enumeration Block 1:
འདིའི་ལན་ལ་གཉིས། སྐྱེ་བ་ལེན་པའི་རྒྱུ་བསྟན། དེ་བརྒལ་ལན་གྱིས་གཏན་ལ་དབབ་པའོ། །དང་པོ་ལ་གཉིས་ལས་
Enumeration Block 2:
གཉིས་པ་མདོ་ནས་བཤད་པ་ལ་ཡང་གཉིས་ལས།
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། བཏགས་པའི་མཐའ་དགག །གནས་པའི་དོན་དགོད་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ། ཉན་ཐོས་དང་། རང་རྒྱལ་དང་། བྱང་སེམས་ཀྱི་ལམ་མོ། །དང་པོ་ལ་གཉིས། ལམ་གྱི་ངོ་བོ་དང་། དེའི་རྒྱུ་ངེས་འབྱེད་ཆ་མཐུན་ནོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། དངོས་ཀྱི་དོན་མདོ་དང་སྦྱར་བ། ལམ་དེ་མདོ་བསྟན་བཅོས་ནས་གསུངས་ཚུལ་ལོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གསུམ། མདོའི་སྒྲས་ཟིན་གྱིས་ཇི་ལྟར་བསྟན་པ་དང་། དོན་དེ་རྩ་བས་ཇི་ལྟར་བསྡུས་པ་དང་། དེ་གཉིས་འགྲེལ་བྱེད་རྣམས་ཀྱིས་ཇི་ལྟར་སྦྱར་བའོ། །
