Enumeration Block 1:
གཉིས་པ་ལ་གཉིས། མཚན་ཉིད་དང་། རབ་དབྱེའོ། །དང་པོ་ལ་གཉིས། མཚན་ཉིད་དངོས་དང་། དེ་མདོ་དང་སྦྱར་བའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 2:
འདི་ལ་གཉིས། མཚན་ཉིད་དངོས་དང་། རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། རྩོད་པ་དང༌ལན་ནོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། རྒྱུ་མིང་འབྲས་བུ་དང་། གྲོགས་མིང་གྲོགས་ཅན་ལ་བཏགས་པའོ། །
Enumeration Block 5:
འདི་ལ་གསུམ་ལས་འདོགས་པའི་རྒྱུ་མཚན་ནི། འདྲ་བ་རྒྱུ་མཚན་དུ་བྱས་པ་མི་བླུན་པོ་ལ་བ་ལང་དུ་བརྗོད་པ་ལྟ་བུ་དང་། འབྲེལ་བ་རྒྱུ་མཚན་དུ་བྱས་པ་ལ་གསུམ། ཡན་ལག་དང་ཡན་ལག་ཅན་དང་། བརྗོད་བྱ་དང་རྗོད་བྱེད་དང་། རྒྱུ་དང་འབྲས་བུར་འབྲེལ་བའོ། །
Enumeration Block 6:
གསུམ་པ་ལ་ཡང་རྒྱུ་ལ་འབྲས་བུ་དང་འབྲས་བུ་ལ་རྒྱུའི་མིང་གིས་བཏགས་པ་གཉིས་སོ། །
