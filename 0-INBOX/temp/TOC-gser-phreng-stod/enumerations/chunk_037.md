Enumeration Block 1:
དེ་ལྟར་རིགས་སྐྱེ་དེ་ལ་ལྷ་མིའི་རིགས་སྐྱེ་གཉིས་སོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས་ལས།
Enumeration Block 3:
གསུམ་པ་ལ་གཉིས། ཞུགས་པ་དང་། གནས་པའོ། །
Enumeration Block 4:
དེ་ལ་ཡང་འབྲས་བུ་ཙམ་དང་ཁྱད་པར་ཅན་ལ་གནས་པ་གཉིས་སོ། །
Enumeration Block 5:
ཕྱིར་མི་འོང་ལ་ཁམས་གོང་མར་འགྲོ་བ་དང་། འདོད་པའི་རྟེན་དེ་ཉིད་ལ་འདའ་བ་གཉིས་ཡོད་ལ། དང་པོ་ལ་གསུམ། གཟུགས་དང་། གཟུགས་མེད་དུ་ཉེ་བར་འགྲོ་བ་དང་། དེ་དག་གི་རྟེན་བསམ་པའོ། །དང་པོ་ལ་བར་དོར་དང་། སྐྱེས་ནས་འདའ་བ་དང་། གོང་དུ་འཕོ་བ་སྟེ་གསུམ་མོ། །
Enumeration Block 6:
འདི་ལ་བར་སྲིད་གྲུབ་མ་ཐག་དང་། གྲུབ་ནས་སྐྱེ་སྲིད་ཚོལ་བའི་སྣང་བ་མ་བྱུང་ཙམ་དང་། སྐྱེ་སྲིད་དུ་འགྲོ་བར་སེམས་པའི་ཚེ་ལྷག་མེད་དུ་འདའ་བ་གསུམ་མོ། །
Enumeration Block 7:
འདི་ལ་སྐྱེས་ཙམ་ནས་དང་། འདུ་བྱེད་དང་བཅས་པ་དང་། དེ་མེད་པར་འདའ་བ་གསུམ་མོ། །
Enumeration Block 8:
འདི་ལ་རྒྱུའི་སྒོ་ནས་བསམ་གཏན་སྤེལ་མ་སྤེལ་དང་། འབྲས་བུའི་སྒོ་ནས་འོག་མིན་དང་སྲིད་རྩེར་འགྲོ་བ་གཉིས་སོ། །
Enumeration Block 9:
འདི་ལ་འཕར་བ་ཕྱེད་འཕར་གནས་ཐམས་ཅད་དུ་འཆི་འཕོ་བ་གསུམ་ཡོད་པར་མཛོད་ལས།
Enumeration Block 10:
འདིའི་མཐའ་དཔྱད་པ་ལ་གཉིས། སྒོམ་པའི་རྟེན། བརྟེན་པའི་སྒོམ་མོ། །
Enumeration Block 11:
གཉིས་པ་ལ་གསུམ། སྤེལ་བའི་སྦྱོར་བ། གྲུབ་པའི་ཚད། སྤེལ་མ་དངོས་སོ། །
Enumeration Block 12:
འབྲས་བུ་གནས་གཙང་ལྔར་སྐྱེ་བའི་རྒྱུ་སྤེལ་མ་སྒོམ་པ་ཡང་ལྔ་ཡོད་དོ། །
