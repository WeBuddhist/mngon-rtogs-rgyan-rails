Enumeration Block 1:
འདི་ལ་གཉིས། རང་ལན་གདབ། གཞན་ལན་དགག་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། སྤྱི་དང་། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ་བཞི། འདི་དག་འགྲེལ་པ་གང་དུ་བཀོད་པ། གང་ཟག་སུའི་འདོད་པ་ཡིན་པ། གཞུང་གང་ལས་འབྲེལ་དཔྱད་པ། འཆད་ཚུལ་གཞན་དགག་པའོ། །
Enumeration Block 3:
བཞི་པ་ལ་གཉིས། དགག་པ་དངོས་དང་། རང་ལུགས་བསྟན་པའོ། །
Enumeration Block 4:
བརྟག་པ་གཉིས་བྱ་སྟེ། རྣམ་པ་གཞི་བཅས་སམ་གཞི་མེད་ཅིག་སྟོན།
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། རྩོད་པ་དང་ལན་ནོ། །དང་པོ་ལ་གཉིས། དྲི་བ་དགོད་པ་དང་། དེ་ལ་སྐྱོན་བརྗོད་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་བཞི། ལན་དངོས། ཤེས་བྱེད་ཀྱི་ཁུངས་དགོད། (སྡུ་,བསྡུ་)བྱེད་གསུམ་ངོས་གཟུང་། དེ་དག་གིས་གྲུབ་པའི་དོན་བསྡུ་བའོ། །
