Enumeration Block 1:
བརྟག་པ་གཉིས་བྱ་སྟེ། རྣམ་པ་གཞི་བཅས་སམ་གཞི་མེད་ཅིག་སྟོན།
Enumeration Block 2:
གཉིས་པ་ལ་བཞི། ལན་དངོས། ཤེས་བྱེད་ཀྱི་ཁུངས་དགོད། (སྡུ་,བསྡུ་)བྱེད་གསུམ་ངོས་གཟུང་། དེ་དག་གིས་གྲུབ་པའི་དོན་བསྡུ་བའོ། །
Enumeration Block 3:
འདི་ལ་གསུམ། ཡུམ་བར་མ་དང་། བསྡུས་པ་དང་། རྒྱས་པ་ཁུངས་སུ་དགོད་པའོ། །དང་པོ་ལ་གཉིས། མདོར་བསྟན། རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ། གཞི་ཤེས། ལམ་ཤེས། རྣམ་མཁྱེན་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས་ལས།
Enumeration Block 6:
འདིར་ཅུང་ཟད་ཅིག་མཐའ་དཔྱད་ན། ཡུལ་ལམ་གསུམ་པོ་དེ་མཚན་ཉིད་པ་ཡིན་མིན། དེ་དག་གི་སྤངས་རྟོགས་གང་དུ་རྫོགས། དམིགས་བསལ་གྱི་དོན་བརྟག་པ། ཡང་དག་མཐའ་ངོས་གཟུང་བ་དང་བཞིས་རིག་པར་བྱའོ། །
