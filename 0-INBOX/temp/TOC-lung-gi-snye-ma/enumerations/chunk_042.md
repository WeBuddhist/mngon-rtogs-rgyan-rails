Enumeration Block 1:
གཉིས་པ་སྒྲིབ་པ་སྤང་པའི་དོན་དུ་བརྩོན་འགྲུས་རྩོམ་པ་རྩོལ་བ་ལས་བྱུང་བའི་ལམ་ལ་ཡང་དག་པར་སྤོང་བའི་རྣམ་པ་བཞི་ལ་སྔར་བཞིན་ལྔ་ལས།
Enumeration Block 2:
བརྩོན་འགྲུས་ཏེ། འདི་ལ་གསུམ་ལས།
Enumeration Block 3:
མཚན་གཞི་ལ། ཐུན་མོང་གི་དབྱེ་བ་དང་། ཕྱེ་བའི་ས་མཚམས་གཉིས། དང་པོ་ལ་བཞི་ལས།
Enumeration Block 4:
བཞི་པ་ལ། སྒོམ་ཚུལ་དང་། སྒོམ་པའི་དབྱེ་བ་གཉིས་སོ། །
Enumeration Block 5:
གསུམ་པ་ནི། སྒྲིབ་པ་སྦྱངས་ནས་འདུན་པ་ལ་སོགས་པས་ཏིང་ངེ་འཛིན་ཡོངས་སུ་སྦྱོར་བའི་ལམ་ལ། རྫུ་འཕྲུལ་གྱི་རྐང་པའི་རྣམ་པ་བཞི་ལ་སྔར་བཞིན་ལྔ་ལས།
Enumeration Block 6:
འདི་ལ་གསུམ་ལས།
Enumeration Block 7:
མཚན་གཞི་ལ། དབྱེ་བ་དང་། ས་མཚམས་སོ། །དང་པོ་ལ་བཞི་སྟེ།
Enumeration Block 8:
བཞི་པ་བདེན་པ་མངོན་པར་རྟོགས་པ་དྲོད་རྩེ་ལ་སྦྱོར་བའི་ལམ་ལ་དབང་པོའི་རྣམ་པ་ལྔ་ལ་སྔར་བཞིན་ལྔ་ལས།
Enumeration Block 9:
དད་སོགས་ཏེ། འདི་ལ་གསུམ་ལས།
Enumeration Block 10:
མཚན་གཞི་ལ། དབྱེ་བ་དང་། ས་མཚམས་གཉིས་ཀྱི་དང་པོ་ལ།
Enumeration Block 11:
ལམ་ལ་སྟོབས་ཀྱི་རྣམ་པ་ལྔ་ནི། སྔར་གྱི་དབང་པོ་ལྔ་པོ་ཉིད། མི་མཐུན་ཕྱོགས་ངེས་པར་བསྲབས་པས་ཚུར་མི་རྫི་བས་སྟོབས་ཏེ། འདི་ལའང་ལྔ་ལས།
Enumeration Block 12:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 13:
མཚན་གཞི་ལ། དབྱེ་བ། ས་མཚམས་གཉིས་ཀྱི་དང་པོ་ལ་བཞི་ལས།
Enumeration Block 14:
དྲུག་པ་ནི། དེ་ཁོ་ན་ཉིད་སོ་སོ་རང་གིས་མངོན་པར་རྟོགས་པའི་ལམ་ལ་བྱང་ཆུབ་ཡན་ལག་གི་རྣམ་པ་བདུན་ལ་སྔར་བཞིན་ལས།
Enumeration Block 15:
དྲན་སོགས་བདུན་ཏེ། འདི་ལ་གསུམ་ལས།
Enumeration Block 16:
མཚན་གཞི་ལ། དབྱེ་བ། ས་མཚམས་གཉིས་སོ། །དང་པོ་ལ།
