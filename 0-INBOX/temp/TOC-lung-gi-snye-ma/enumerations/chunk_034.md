Enumeration Block 1:
མཚན་མཚོན་གཞི་གསུམ་ལས།
Enumeration Block 2:
དེ་ལ་གཉིས་ལས།
Enumeration Block 3:
ངོ་བོ་གཅིག་ལ་ཡུལ་གྱིས་ཕྱེ་བས་བཅུའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་བཞི་སྟེ། དམིགས་པ། ཡིད་ལ་བྱེད་པ། སེམས་གནས་པའི་ཐབས། དེ་དག་ལས་སེམས་ལས་སུ་རུང་བ་ཐོབ་ཚུལ་ལོ། །
Enumeration Block 5:
དང་པོ་ནི། སེམས་དྲུག་སྟེ། རྩ་བའི་སེམས། རྗེས་སུ་དཔྱོད་པའི་སེམས། རྣམ་པར་དཔྱོད་པའི་སེམས། ངེས་པར་འཛིན་པའི་སེམས། སྡོམ་པའི་སེམས། སྨོན་པའི་སེམས་སོ། །
Enumeration Block 6:
གསུམ་པ་ལ། དོན་དང་ཡི་གེ་དཔྱོད་པ་གཉིས་ལས། དང་པོ་ལ། བགྲང་བ། འཇལ་བ། རྟོག་པ། སོ་སོར་རྟོག་པ་བཞི་ལས།
Enumeration Block 7:
གཉིས་པ་ནི། ཡིད་ལ་བྱེད་པ་བཅུ་གཅིག་སྟེ།
