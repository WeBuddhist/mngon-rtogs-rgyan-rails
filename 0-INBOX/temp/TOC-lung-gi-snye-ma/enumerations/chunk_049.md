Enumeration Block 1:
གཉིས་པ་ལ་བཞི་སྟེ། སེམས་བསྐྱེད་ཀྱི་མཚན་ཉིད། དམིགས་ཡུལ། རབ་དབྱེ། ས་མཚམས་སོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 2:
འགྲེལ་པ་ལ། མཚན་ཉིད་ཅན་གྱི་དབྱེ་བ་དང་། མཚན་ཉིད་ལ་རྩོད་པ་སྤང་བ་གཉིས་སོ། །
Enumeration Block 3:
དེ་ཡང་འགྲོ་བར་འདོད་པ་དང་འགྲོ་བའི་བྱེ་བྲག་ལྟར་འབྲས་བུ་ཙམ་ཐོབ་པར་འདོད་པ་སྨོན་པ་དང་། དེའི་ཆེད་དུ་སྒྲུབ་པ་ལ་འཇུག་པ་འཇུག་པའི་ངོ་བོ་ཉིད་རྣམ་པ་གཉིས་སོ། །
Enumeration Block 4:
གཉིས་པ་ལ། རྩོད་ལན་གཉིས་ལས།
Enumeration Block 5:
ལན་ལ། རྒྱུ་མིང་འབྲས་བུ་ལ་བཏགས་པ་དང་། གྲོགས་མིང་གྲོགས་ཅན་ལ་བཏགས་པའི་ལན་གཉིས་སོ། །
Enumeration Block 6:
གཉིས་པ་ལ་ལྔ་སྟེ། སྔ་འགྲེལ། རྩ་བ། འགྲེལ་པ། དོན་བསྡུ། མདོ་གཞན་མ་བྲིས་པའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 7:
གསུམ་པ་ལ་བཞི་ལས།
Enumeration Block 8:
རྩ་བ་ལ་བཞི་ལས།
