Enumeration Block 1:
གཉིས་པ་ལ་གཉིས་ཏེ། རྩོད་ལན་ནོ། །རྩོད་པ་ལ། ཁས་བླངས་བརྗོད་པ་དང༌། ཐལ་བ་དགོད་པ་གཉིས་སོ། །
Enumeration Block 2:
ལན་ལ། བསྟན་བཅོས་དང་། ལོ་ཀ་ལ་གྲགས་པའི་ལན་གཉིས་སོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 4:
གཉིས་པ་ལ། སྔ་འགྲེལ། རྩ་བ། འགྲེལ་པ། དགག་སྒྲུབ་བསྟན་པ་དང་བཞིའོ། །
Enumeration Block 5:
གསུམ་པ་ལ་གསུམ་ལས།
Enumeration Block 6:
བཞི་པ་ལ་གསུམ་སྟེ། སྒྲུབ་པ་སྤྱིའི་ངོ་བོ། བྱེ་བྲག་གི་ས་མཚམས། སོ་སོའི་དོན་ནོ། །
Enumeration Block 7:
གཉིས་པ་ལ། དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 8:
གསུམ་པ་ལ་བཞི་སྟེ། གོ་འཇུག་ཚོགས་ངེས་སོ། །དང་པོ་ལ། སྔ་འགྲེལ། རྩ་བ། འགྲེལ་པ་ལས།
Enumeration Block 9:
གཉིས་པ་ལ། སྤྱི་གཞུང་གཉིས་སོ། །
Enumeration Block 10:
ཞེས་པ་བཅུའི་སྟེང་དུ་ཁྱད་པར་དཔྱད་པ་དང་བཅུ་གཅིག་གིས་བཤད་པར་བྱའོ། །དང་པོ་ལ་དྲུག་སྟེ། རང་དོན། གཉིས་དོན། གཞན་དོན། ཐེག་ཆེན་ལམ། བསླབ་གསུམ་ལ་ལྟོས་ཏེ་ཕྱིན་དྲུག་ཏུ་གྲངས་ངེས་སོ། །
