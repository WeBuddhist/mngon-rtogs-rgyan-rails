Enumeration Block 1:
གསུམ་པ་ལ་གསུམ་ལས།
Enumeration Block 2:
སྦྱོར་བ་ལ་བཞི་སྟེ། དབང་ཐོབ་པའི་དོན་དུ་སྒོམ་པ་རྣམ་ཀུན། དབང་ཐོབ་པའི་ཚུལ་གྱིས་སྒོམ་པ་རྩེ་སྦྱོར། བརྟན་པ་ཐོབ་པའི་དོན་དུ་སྒོམ་པ་མཐར་གྱིས་པ། བརྟན་པ་ཐོབ་ནས་གཅིག་ཅར་སྒོམ་པ་སྐད་ཅིག་མའོ། །
དང་པོ་ལ། མཚམས་སྦྱར། སྦྱོར་བ་རྒྱས་བཤད། སྐབས་བསྡུ་བ་གསུམ་མོ། །
Enumeration Block 3:
གཉིས་པ་ལ། རྣམ་ཀུན་ཙམ་དང་། རྣམ་ཀུན་ཁྱད་པར་ཅན་གྱི་སྒོམ་རིམ་གཉིས་སོ། །
དང་པོ་ལ་བཞི་སྟེ། སྦྱར་ས་རྣམ་པ། སྦྱོར་བ་པོ་གང་ཟག །སྦྱོར་བ་རང་གི་ངོ་བོ། །
སྦྱོར་བའི་སྔོན་འགྲོའོ། །
དང་པོ་ལ་གསུམ་སྟེ། མདོར་བསྟན། རྒྱས་བཤད། དོན་བསྡུ་བའོ། །
མདོར་བསྟན་ལ་གཉིས་ཏེ། རྩ་བ་ལ། སྤྱི་གཞུང་གཉིས་སོ། །
དང་པོ་ལ།
དགག་གཞག་སྤང་གསུམ་ལས།
Enumeration Block 4:
འདི་ལ་གསུམ་ལས།
Enumeration Block 5:
མཚན་གཞི་ལ་བཞི་ལས།
Enumeration Block 6:
དབྱེ་ངོ་དོན་རྣམ་དང་། ཤེས་རྣམ་གཉིས་སོ། །
Enumeration Block 7:
གཉིས་པ་ནི། ངོ་བོ་དང་། དབྱེ་བ་གཉིས་སོ། །
Enumeration Block 8:
གཉིས་པ་ལ་བཞི་ལས།
Enumeration Block 9:
དབྱེ་ངོ་གཞི་ཤེས་ཀྱི་དང་། ལམ་ཤེས་ཀྱི་དང་། རྣམ་མཁྱེན་གྱི་རྣམ་པ་སྟེ། རྣམ་པ་གསུམ་དུ་འདོད་དོ། །
Enumeration Block 10:
འགྲེལ་པ་ལ་གཉིས་ཏེ། ངོ་བོ་དང་། དབྱེ་བའོ། །
Enumeration Block 11:
གཉིས་པ་ལ་གསུམ་ལས།
དབྱེ་གཞི་རྣམ་པ་དེ་དག་ཀྱང་དབྱེ་ངོ་རྣམ་པ་གསུམ་མོ། །
