Enumeration Block 1:
ཚོགས་སྦྱོར། ས་བཅུ། ཁྱད་པར་གྱི་ལམ། སངས་རྒྱས་ཀྱི་སས་བསྡུས་པ་ལྔ་ལས།
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས་ཏེ། གདམས་ངག་བཅུ་སྤྱིར་བསྟན་པ་དང་། དགེ་འདུན་དཀོན་མཆོག་བྱེ་བྲག་ཏུ་བཤད་པའོ། །དང་པོ་ལ། སྔ་འགྲེལ། རྩ་བ། འགྲེལ་པ། གྲངས་ངེས་ཀྱི་སྒོ་ནས་དོན་བསྡུ་དང་བཞིའོ། །
Enumeration Block 3:
གསུམ་པ་ལ་བཞི་སྟེ། སྒྲུབ་པ་རང་གི་ངོ་བོ། དམིགས་ཡུལ་བདེན་པ་བཞི། རྟེན་དཀོན་མཆོག་གསུམ། སྒྲུབ་པ་ཕུན་སུམ་ཚོགས་པའི་རྒྱུ་ལ་གདམས་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ། སྤྱི་གཞུང་གཉིས་སོ། །དང་པོ་ལ་བཞི་སྟེ། བདེན་བཞིའི་མཚན་ཉིད། དབྱེ་བ། རང་བཞིན། རྩོད་སྤང་ངོ༌། །
Enumeration Block 5:
གཉིས་པ་ལ་བཞི་ལས། དབྱེ་གཞི་བདེན་པ་ཙམ་མོ། །དབྱེ་ངོ་བཞིའོ། །
Enumeration Block 6:
གསུམ་པ་ལ། སྡུག་ཀུན་འགོག་ལམ་བཞི་ལས། དང་པོ་ལ། མཚན་གཞི་དང་། མཚན་ཉིད་གཉིས་སོ། །
Enumeration Block 7:
གཉིས་པ་ལ། རང་མཚན། སྤྱི་མཚན་གཉིས་ལས།
Enumeration Block 8:
གཉིས་པ་ལ། མཚན་གཞི་དང་། མཚན་ཉིད་གཉིས་ལས། དང་པོ་ནི། ཉོན་མོངས་དང་། ལས་གཉིས་སོ། །དང་པོ་ལ། རྒྱུ། ངོ་བོ། འབྲས་བུ། སྤོང་ཚུལ་བཞིའོ། །
Enumeration Block 9:
ངོ་བོ་ལ། མཚན་ཉིད། དབྱེ་བ་གཉིས་སོ། །
Enumeration Block 10:
གཉིས་པ་ལ། མཐོང་སྤང་དང་། སྒོམ་སྤང་དང་། དེ་དག་ལ་རྩོད་པ་སྤང་བ་གསུམ་ལས། དང་པོ་ལ། ཉན་ཐོས་ཀྱི་དང་། ཐེག་ཆེན་གྱི་ལུགས་སོ། །
Enumeration Block 11:
དེའང་ལོག་པར་ཞུགས་ཚུལ་གྱིས་ཕྱེ་ན། སྡུག་ཀུན་ལ་དངོས་སུ་དང་། ལོག་པ་ལ་དང་། དབང་གིས་ལོག་ཞུགས་དང་གསུམ། འགོག་ལམ་ལ་དངོས་སུ་དང་། ལོག་པ་ལ་ལོག་ཞུགས་གཉིས་སོ། །
Enumeration Block 12:
གསུམ་པ་ལ། དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 13:
བཞི་པ་ལ། དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 14:
གཉིས་པ་ནི། ཇི་ལྟར་སྤོང་བ་དང་། ཡིད་ལ་བྱེད་པ་ཅི་འདྲ༌བ༌དང་། གང་ཞིག་གང་ལས་སྤོང་བ་གསུམ་མོ། །
Enumeration Block 15:
གཉེན་པོ་དེའང་བཞི་སྟེ། རྒྱུད་ཡོངས་སུ་སྨིན་པར་བྱེད་པའི་དང་། ཉེ་བར་སྤོང༌བའི་དང་། ཕྱོགས་གཅིག་སྤོང་བའི་དང་། མཐའ་དག་སྤོང་བའི་གཉེན་པོའོ། །
Enumeration Block 16:
གཉིས་པ་ལ། སེམས་པ་དང་བསམ་པའི་ལས་གཉིས་སོ། །
Enumeration Block 17:
གསུམ་པ་ལ། ལོ་ཀའི་ལམ་གྱིས་ཉོན་མོངས་ཀྱི་ས་བོན་ཉམས་སྨད་པ། བརྡའི་འགོག་པ་སྟེ། བཏགས་པ་བ། འཕགས་པའི་ཤེས་རབ་ཀྱིས་ས་བོན་ཀུན་ཏུ་བཅོམ་པས་འགོག་པ་དོན་དམ་པའི་སྟེ། མཚན་ཉིད་པ་དང་གཉིས་སོ། །
Enumeration Block 18:
སློབ་པའི་འབྲས་བུས་བསྡུས་པ་མ་རྫོགས་པ་དང༌། མི་སློབ་པའི་འབྲས་བུས་བསྡུས་པ་རྫོགས་པ་སྟེ། གཉིས་ལས།
Enumeration Block 19:
གཉིས་པ་ལ། ཚོགས་སྦྱོར་མཐོང་སྒོམ་མི་སློབ་ལམ་དང་ལྔ་ལས། དང་པོ་ལ། མཚན་ཉིད། མཚོན་བྱ། མཚན་ཉིད་ངོས་གཟུང་བ་གསུམ་ལས།
Enumeration Block 20:
གསུམ་པ་ལ། རྒྱུ། ངོ་བོ། འབྲས་བུ་གསུམ་ལས།
Enumeration Block 21:
གསུམ་པ་ལ། དགག་བཞག་སྤང་གསུམ་ལས།
