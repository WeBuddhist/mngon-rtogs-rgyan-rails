Enumeration Block 1:
སྙོམས་འཇུག་མངོན་དུ་བྱེད་པས་ཇི་ལྟར་འདོད་པ་བཞིན་ལན་མང་དུ་འཇུག་པ་སྟེ། འདི་ལ་སྦྱོར་དངོས་གཉིས་སོ། །
Enumeration Block 2:
ལུགས་དང་མཐུན་པ་དང་། ལུགས་དང་མི་མཐུན་པ་རྣམ་པ་གཉིས་སོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གསུམ་སྟེ། དངོས་གཞི་ཙམ་དང་། ཁྱད་པར་ཅན་དང་། ཆེས་ཁྱད་པར་ཅན་ནོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ།
Enumeration Block 5:
རྒྱས་བཤད་ལ་གཉིས་ཏེ། གཟུང་རྟོག་འཛིན་རྟོག་གོ །
དང་པོ་ལ་གཉིས་ཏེ། འཇུག་པ་དང༌། ལྡོག་པ་གཟུང་རྟོག་གོ །
དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 6:
རྩ་བ་ནི། རྟོག་པའི་ཡུལ། ངོ་བོ། སྦྱར་ཏེ་བཤད་པ། དེའི་གཉེན་པོ་བཞིའོ། །
Enumeration Block 7:
འགྲེལ་པ་ལ། རྟོག་པའི་ཡུལ། རྟོག་པའིངོ་བོ། རྟོག་པའི་གཉེན་པོ། རྟོགས་པའི་དབྱེ་གྲངས་དང་བཞིའོ། །
Enumeration Block 8:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 9:
གཉིས་པ་ལ་གཉིས་ཏེ། རྫས་འཛིན་དང་། བཏགས་འཛིན་ནོ། །
དང་པོ་ལ་གསུམ་ལས།
