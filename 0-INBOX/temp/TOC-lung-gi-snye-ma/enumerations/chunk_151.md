Enumeration Block 2:

Enumeration Block 3:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 4:
རྩ་བ་ལ་གསུམ་སྟེ། སྤྱིར་རྒྱུ་རྐྱེན་གྱི་མཚན་ཉིད། གང་གང་ལས་སྐྱེ་ཚུལ། གཞུང་ལ་སྦྱར་བའོ། །
Enumeration Block 5:

Enumeration Block 6:
འགྲེལ་པ་ལ་གསུམ་སྟེ། བསལ་བྱ། སེལ་བྱེད། དེས་བསྙད་ཚུལ་ལོ། །
Enumeration Block 7:
རྒྱས་བཤད་ལ་གསུམ་ལས།
Enumeration Block 8:
