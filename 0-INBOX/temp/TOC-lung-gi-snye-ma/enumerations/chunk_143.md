Enumeration Block 3:
རྩ་བ་ལ་གསུམ་སྟེ། ཡུལ་དང་། ངོ་བོ་དང་། སྦྱར་ཏེ་བཤད་པའོ། །
Enumeration Block 4:
འགྲེལ་པ་ལ་ལྔ་སྟེ། རྟོག་པའི་ཡུལ། ངོ་བོ། གྲངས། བར་ཆད་མེད་ལམ་གྱི་སྤང་བྱར་བསྟན། སྦྱར་ཏེ་བཤད་པའོ། །
Enumeration Block 5:

Enumeration Block 6:
རྩ་བ་ལ། གཞན་འབྲས་བུ་རྟོགས་པའི་ཆོས་ལ་འགོད་པ་དང་། རྒྱུ་ལུང་གི་ཆོས་ལ་འགོད་པ་དང་། རང་གི་རྒྱུད་སྦྱོང་བ་གསུམ་མོ། །
Enumeration Block 7:
འགྲེལ་པ་ལ་སྔར་བཞིན་གསུམ་ལས།
Enumeration Block 8:
གསུམ་པ་ལ་གསུམ་སྟེ། དབུ་མ་པའི་བྱང་ཆུབ་ཆེན་པོ་བསྟན། དངོས་སྨྲ་བའི་བྱང་ཆུབ་ཆེན་པོ་དགག །ཐར་པ་འདོད་ན། སྟོང་ཉིད་ཁས་བླང་དགོས་པར་བསྟན་པའོ། །
དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 9:
གཉིས་པ་ལ། ལུང་གིས་སྒྲུབ་པ་དང༌། རིགས་པས་སྒྲུབ་པ་གཉིས་སོ། །
