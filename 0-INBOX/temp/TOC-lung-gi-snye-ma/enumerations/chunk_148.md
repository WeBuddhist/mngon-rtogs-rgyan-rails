Enumeration Block 1:
བཞི་པ་ལ། གོ་རིམ་དང་། ཐ་དད་དང་། རྐྱེན་བྱེད་ཚུལ་ངེས་པ་བསམ་པ་དང་། ལུགས་མཐུན་ལུགས་མི་མཐུན་བསྟན་པ་དང་བཞིའོ། །
Enumeration Block 2:
བཞི་པ་ལ་གཉིས་ཏེ། ཀུན་ནས་ཉོན་མོངས་ཀྱི་དང་། རྣམ་བྱང་གི་ལུགས་འབྱུང་ལུགས་ལྡོག་གོ །
Enumeration Block 3:
འགྲེལ་པ་ལ།
མཉམ་རྗེས་གཉིས་ལས།
Enumeration Block 4:
གསུམ་པ་ལ་གསུམ་སྟེ། རྟེན་སྒོམ་པའི་ལམ། སྤང་བྱ་རྣམ་རྟོག །བརྟེན་པ་ཡོན་ཏན་ནོ། །
དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 5:
དང་པོ་ལ་གཉིས་ཏེ། སྦྱོར་བ་སེངྒེ་རྣམ་བསྒྱིངས་དང་། དངོས་གཞི་ཐོད་རྒལ་ལོ། །
Enumeration Block 6:
འགོག་པ་དང་བཅས་པའི་སྙོམས་འཇུག་དགུ་ལ་ལུགས་དང་མཐུན་པ་དང་། ལུགས་དང་མི་མཐུན་པར་སྙོམས་པར་འཇུག་པ་གཉིས་སོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གསུམ་སྟེ། དངོས་གཞི་ཙམ་དང་། ཁྱད་པར་ཅན་དང༌། ཆེས་ཁྱད་པར་ཅན་ནོ། །
Enumeration Block 8:
འགྲེལ་པ་ལ། སྙོམས་པར་འཇུག་པའི་ཆོས་བཞི་སྟེ། གང་། གང་ལ། ཇི་ལྟར། དགོས་པ་ཅིའི་དོན་དུའོ། །
Enumeration Block 9:
འདི་ལ་སྦྱོར་དངོས་གཉིས་སོ། །
Enumeration Block 10:
དེ་ལྟར་ལུགས་དང་མཐུན་པ་དང་། ལུགས་དང་མི་མཐུན་པ་རྣམ་པ་གཉིས་སོ། །
Enumeration Block 11:
གཉིས་པ་ལ་གསུམ་སྟེ། དངོས་གཞི་ཙམ་དང་། ཁྱད་པར་ཅན་དང་། ཆེས་ཁྱད་པར་ཅན་ནོ། །
