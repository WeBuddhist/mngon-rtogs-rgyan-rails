Enumeration Block 1:
གསུམ་པ་ལ། ཆོས་སྐུ་རྟག་པ་དང་། ཁྱབ་རྟག་གཉིས་ཀ་ལ་རྩོད་སྤང་ངོ༌། །དང་པོ་ལ། རྩོད་ལན་གཉིས་ལས།
Enumeration Block 2:
ལན་ལ་གཉིས་ཏེ། གདུལ་བྱ་ལ་ལྟོས་ཏེ་འདོད་པའི་ལན། གདུལ་བྱ་མིན་པ་ལ་ལྟོས་ཏེ་ཁྱབ་པ་མེད་པའི་ལན་ནོ། །དང་པོ་ལ་གཉིས་ཏེ།
Enumeration Block 3:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 4:
གཉིས་པ་ལ། རྩོད་ལན་གཉིས་ལས།
Enumeration Block 5:
གསུམ་པ་ལ་གཉིས་ཏེ། རང་བཞིན་མདོར་བསྟན། ཡོན་ཏན་རྒྱས་བཤད་དོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས་ཏེ། མཚན་དང་། དཔེ་བྱད་དོ། །དང་པོ་ལ། མཚན་གྱི་དབྱེ་བ་དང་། དེ་སྐྱེད་བྱེད་ཀྱི་རྒྱུའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 7:
གཉིས་པ་ལ་གཉིས་ཏེ། རྒྱུ་རྫོགས་པས་མཚན་འགྲུབ་པར་བསྟན། སྒྲུབ་བྱེད་རྒྱུའི་དབྱེ་བའོ། །དང་པོ་ལ་གསུམ་ལས།
