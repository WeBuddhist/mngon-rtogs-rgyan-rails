Enumeration Block 1:
འགྲེལ་པ་ལ་ལྔའི་དང་པོ་རྒྱུན་ཞུགས་ལ་གསུམ་སྟེ། འབྲས་ཞུགས་དང༌། འབྲས་གནས་ཙམ་དང༌། ཁྱད་པར་ཅན་ནོ། །
Enumeration Block 2:
དེ་ཡང་དབང་རྟུལ་དད་པའི་རྗེས་འབྲང་དང་། དབང་རྣོན་ཆོས་ཀྱི་རྗེས་འབྲང་གཉིས་སོ། །

Enumeration Block 4:

Enumeration Block 5:

Enumeration Block 6:
ལྔ་པ་གོང་དུ་འཕོ་བ་ལ། འོག་མིན་དང་སྲིད་རྩེར་འགྲོ་བ་གཉིས་ལས།
Enumeration Block 7:
དབྱེ་ན། ཚངས་རིས་ནས་འོག་མིན་དུ་འཕར་བ་དང༌། ཚངས་རིས་ནས་གནས་གཙང་མའི་བར་འོག་མ། དེ་ནས་འོག་མིན་དུ་འགྲོ་བ་ཕྱེད་དུ་འཕར་བ་དང༌། གཟུགས་ཀྱི་གནས་ཐམས་ཅད་དུ་འཆི་འཕོ་བ་ཉིད་ཀྱིས་འོག་མིན་དུ་འགྲོ་བ་གོང་དུ་འཕོ་བ། སྲིད་རྩེར་འགྲོ་བ་ལས་གཞན་རྣམ་པ་གསུམ་མོ། །
Enumeration Block 8:
དབྱེ་ན། མཐོང་བའི་ཆོས་ཚེ་འདི་ལ་ཞི་བ་ཐོབ་པ་དང་། ལུས་ཀྱི་འགོག་པ་མངོན་སུམ་དུ་བྱེད་པ་སྟེ། འོག་མིན་འགྲོ་ལས་གཞན་རྣམ་པ་གཉིས་སོ། །
Enumeration Block 9:
རྒྱུན་ཞུགས་ལྔ། ཕྱིར་འོང་གསུམ། ཕྱིར་མི་འོང་བཅུ། དགྲ་བཅོམ་འབྲས་ཞུགས། རང་རྒྱལ་ཏེ། ཉི་ཤུའོ། །
Enumeration Block 10:
གསུམ་པ་ལ། སྤྱི་གཞུང་གཉིས་ལས། དང་པོ་ལ། མཚན་མཚོན་གཞི་གསུམ་མོ། །
Enumeration Block 11:
གསུམ་པ་ལ་བཞི་སྟེ། ངོ་བོ། ཆེ་འབྲིང༌། ཁྱད་པར་གྱི་དབྱེ་བ། ཕྱེ་བའི་བློ་གང་ཡིན་དཔྱད་པའོ། །དང་པོ་ནི། དྲོད་རྩེ་བཟོད་མཆོག་བཞི་ལས།
Enumeration Block 12:
ཆོས་ལ་ངེས་པར་སེམས་པའི་བཟོད་པ་ཆུང་འབྲིང་ཆེ་གསུམ་མོ། །གསུམ་པ་ལ་དྲུག་སྟེ། རྗེས་སུ་མཐུན་པ་བ། ཁྱད་པར་བ། རབ་ཏུ་གཏོགས་པ་བ། གཞན་དུ་ཡོངས་སུ་བསྒྱུར་བ་པ། སྐྱེ་བ་གཅིག་པ། སྟན་གཅིག་པའོ། །
Enumeration Block 13:
བཞི་པ་ལ། དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 14:
དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 15:
མཐོང་ལམ་དེའི་ཡན་ལག་ནི། རྒྱུ་སྟེ། ཆུང་ངུ་། འབྲིང༌། ཆེན་པོ། ཆེན་པོའི་ཆེན་པོ་སྟེ། བཞི་ཡོད་པ་རྣམས་འཆད་དོ། །
Enumeration Block 16:
འགྲེལ་པ་ལ་བཞི་སྟེ། ཐེག་ཆེན་སྦྱོར་ལམ་ཁྱད་པར་ལྔ་དང་ལྡན་པ་དང་། ཉན་རང་གི་སྦྱོར་ལམ་ཁྱད་པར་ལྔ་དང་བྲལ་བ་དང་། བྱང་སེམས་ཀྱི་དམིགས་ཚུལ་སྣ་ཚོགས་སུ་བསྟན་པ་དང་། རྩོད་སྤང་ངོ་། །
Enumeration Block 17:
གསུམ་པ་ལ་གསུམ་སྟེ། དམིགས་རྣམ་རྒྱུ་གསུམ་དང༌། མཚུངས་ལྡན་རྟོག་པ་དང༌། ཡོངས་འཛིན་དགེ་བཤེས་དང༌། ཐབས་མཁས་ཀྱི་ཁྱད་པར་བཤད་པའོ། །དང་པོ་ལ་གསུམ་སྟེ། མཚམས་སྦྱོར། བརྗོད་བྱ་དམིགས་རྣམ་རྒྱུ་གསུམ་རྒྱས་པར་བཤད་པ་དང༌། ཆོས་ཅན་བརྗོད་པ་ཆད་པའི་རྩོད་སྤང་ངོ་། །
