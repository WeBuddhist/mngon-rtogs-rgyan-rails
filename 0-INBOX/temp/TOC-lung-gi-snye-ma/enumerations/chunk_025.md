Enumeration Block 1:
དབྱེ་ན། ཉན་རང་གི་དང་། བྱང་སེམས་ཀྱི་དང་། སངས་རྒྱས་ཀྱི་དང་གསུམ་མོ། །
Enumeration Block 2:
གཉིས་པ་ལ་མཚན་ཉིད་དང་། མཚོན༌བྱ༌དང་། མཚན་གཞི་གསུམ་ལས།
Enumeration Block 3:
གསུམ་པ་ལ། མཚན་ཉིད་པ་དང་བཏགས་པ་བ་གཉིས་སོ། །
Enumeration Block 4:
བཞི་པ་རྣམ་ཀུན་ལ། དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 5:
གཉིས་པ་ལ། མཚན་མཚོན་གཞི་གསུམ་ལས།
Enumeration Block 6:
དབྱེ་བ་ནི། ལམ་བཞིའམ། ཉི་ཤུའོ། །
Enumeration Block 7:
རྣམ་ཀུན་མཚན་ཉིད་པ་དང་བཏགས་པ་བ་གཉིས་ལས།
