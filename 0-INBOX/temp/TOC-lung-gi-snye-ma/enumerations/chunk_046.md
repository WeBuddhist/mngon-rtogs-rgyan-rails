Enumeration Block 1:
གཉིས༌པ༌ལ་གཉིས་ཏེ། སེམས་ཙམ་པ་དང་། དབུ་མའི་ལུགས་གཉིས་སོ། །
Enumeration Block 2:
འདི་ལ་བཞི་སྟེ། རྟེན་གྱི་ཁྱད་པར། མ་སྐྱེས་པ་སྐྱེད་པའི་ཁྱད་པར། སྐྱེས་པ་མི་ཉམས་པར་སྲུང་བའི་ཁྱད་པར། ཉམས་ན་ཕྱིར་བཅོས་ཀྱི་ཁྱད་པར་རོ། །
Enumeration Block 3:
འདི་ལའང་སྔར་བཞིན་བཞི་ལས།
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ་སྟེ། སྦྱོར་བ་སེམས་ཀྱི་ཐ་བ་སྦྱང་། དངོས་གཞི་བྱང་ཆུབ་ཀྱི་སེམས་ཀྱི་ས་བོན་གདབ། རྗེས་རང་གཞན་དགའ་བ་བསྐྱེད་དེ་བརྟན་པར་བྱ་བའོ། །
Enumeration Block 5:
དང་པོ་ལ་གསུམ་སྟེ། རྟེན་བཤམ། གསོལ་བ་གདབ། ཡན་ལག་བདུན་པ་བྱ་བའོ། །
Enumeration Block 6:
ཡན་ལག་བདུན་པ་དངོས་ལ། མཆོད་པ། སྡིག་བཤགས། ཡི་རང་། འཁོར་ལོ་བསྐོར་བ། གསོལ་བ་འདེབས་པ། བསྔོ་བ། སྐྱབས་སུ་འགྲོ་བ་དང་བདུན་ནོ། །
Enumeration Block 7:
དང་པོ་ལ་ལྔ། བསྟོད་ཅིང་ཕྱག་འཚལ་བ། བཀུར་སྟིའི་མཆོད་པ། ཡོ་བྱད་བློས་སྤྲུལ་པ། ལུས་འབུལ་བ། སྒྲུབ་པའི་མཆོད་པའོ། །
