Enumeration Block 1:
གསུམ་པ་ལ་གསུམ་ལས།
Enumeration Block 2:
གསུམ་པ་ལ་བཞི་སྟེ། སྐབས་ཀྱི་མཚམས་སྦྱར་དང་། ངོ་བོ་གཞི་ཤེས་བཤད་པ་དང་། མཁྱེན་གསུམ་གྱི་དོན་བསྡུ། སྐབས་བསྡུ་བའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གསུམ་སྟེ། འཇུག་ཡུལ་གཞི་ཤེས། འཇུག་པ་སྦྱོར་བ། ཞུགས་འབྲས་མཐོང་ལམ་མོ། །དང་པོ་ལ་གསུམ་སྟེ། ཆོས་ཅན་གཞི་ཤེས་གཉིས་ཀྱི་རང་བཞིན། བསྒྲུབ་བྱ་འབྲས་ཡུམ་ལ་ཉེ་རིང་གི་ཁྱད་པར། སྒྲུབ་བྱེད་མི་མཐུན་ཕྱོགས་དང་གཉེན་པོའི་རབ་དབྱེའོ།།དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 4:
འགྲེལ་པ་ལ། དངོས་བསྟན་གཉེན་པོ་གཞི་ཤེས་བཤད། ཤུགས་བསྟན་མཚན་འཛིན་གཞི་ཤེས་བཤད་པ་གཉིས་སོ། །
Enumeration Block 5:
གཉིས་པ་ལ་བཞི་ལས།
Enumeration Block 6:
འགྲེལ་པ་ལ། ཉན་རང་གི་ཡུམ་རིང་བ་དང་། བྱང་སེམས་ཀྱི་ཡུམ་ཉེ་བར་བསྟན་པ་གཉིས་སོ། །
Enumeration Block 7:
གསུམ་པ་ལ། གཞི་ལམ་ལ་མཚན་འཛིན་གྱི་སྤང་གཉེན། འབྲས་བུ་ལ་མཚན་འཛིན་གྱི་སྤང་གཉེན། དེ་དག་གི་དོན་བསྡུ་དང་གསུམ་མོ། །དང་པོ་ལ། སྤང་གཉེན་གཉིས་ལས། དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 8:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 9:
གཉིས་པ་ལ། སྤང་གཉེན་གཉིས་ལས། དང་པོ་ཆགས་པ་ཕྲ་མོ་མི་མཐུན་ཕྱོགས་སུ་བསྟན་པ་དང་། དེའི་སྒྲུབ་བྱེད་བསྟན་པ་གཉིས་སོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 10:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 11:
གཉིས་པ་ལ། སྤོང་བའི་གཉེན་པོ་དང་། ཟབ་པ་སོགས་ཀྱི་རྒྱུ་བསྟན་པ་གཉིས་སོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 12:
གཉིས་པ་ལ། ཟབ་པའི་དང་། རྟོགས་དཀའ་བའི་རྒྱུ་མཚན་གཉིས་སོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 13:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 14:
གསུམ་པ་ལ་གསུམ་ལས།
Enumeration Block 15:
གཉིས་པ་ལ། སྦྱོར་བའི་དབྱེ་བ་དང་། སྦྱོར་བའི་མཉམ་ཉིད་གཉིས་སོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 16:
རྩ་བ་ནི། སྦྱོར་བའི་ཡུལ་དང་། ངོ་བོ་གཉིས་སོ། །དང་པོ་ནི། ལ་ཀུན་གྱི་མཇུག་ཏུ་སྦྱར་བ་ཞེན་སྤྱོད་དགག་པའི་ཡུལ་བཅུའོ། །
Enumeration Block 17:
འགྲེལ་པ་ལ་གསུམ། དངོས་བསྟན་བྱང་སེམས་ཀྱི་སྦྱོར་བ། ཤུགས་བསྟན་ཉན་རང་གི་སྦྱོར་བ། རྣམ་གཞག་དཔྱད་པའོ། །
Enumeration Block 18:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 19:
གཟུགས་ལ་སོགས་པ་དངོས་པོའི་དོན་དང་། སོགས་པ་མཚན་མ་དང་། སྤྲོས་པ་དང་། རྟོག་པ་ལ་རློམ་པ་མེད་པ་རྣམ་པ་བཞི་སྦྱོར་བ་དེའི་མཉམ་ཉིད་དོ། །
Enumeration Block 20:
གསུམ་པ་ལ། མཐོང་ལམ་མདོར་བསྟན། དེའི་རྣམ་པ་རྒྱས་བཤད། སྒོམ་ལམ་མི་སྟོན་པའི་རྒྱུ་མཚན་དང་གསུམ་མོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 21:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 22:
འགྲེལ་པ་ལ་གཉིས་ཏེ། དངོས་བསྟན་བྱང་སེམས་ཀྱི་དང་། ཤུགས་བསྟན་ཉན་རང་གི་མཐོང་ལམ་མོ། །
Enumeration Block 23:
གསུམ་པ་ལ་གསུམ་ལས།
