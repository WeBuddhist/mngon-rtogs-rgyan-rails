Enumeration Block 1:
གཉིས་པ་ལ་གསུམ་སྟེ། འཇུག་ཡུལ་མཁྱེན་གསུམ། འཇུག་པ་སྦྱོར་བཞི། ཞུགས་འབྲས་ཆོས་སྐུའི་ཡན་ལག་རྒྱས་བཤད་དོ། །
Enumeration Block 2:
དང་པོ་ལ། འབྲས་བུ་ཐུན་མོང་མ་ཡིན་པ་རྣམ་མཁྱེན། རྒྱུ་ཐུན་མོང་མ་ཡིན་པ་ལམ་ཤེས། རྒྱུའི་བླང་དོར་ཐུན་མོང་མ་ཡིན་པ་གཞི་ཤེས་ཀྱི་ཡན་ལག་རྒྱས་བཤད་གསུམ་མོ། །
Enumeration Block 3:
དང་པོ་ལ་གསུམ་སྟེ། མཚམས་སྦྱར། བརྗོད་བྱ་ཆོས་བཅུ་བཤད། སྐབས་བསྡུ་བའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་བཞི་སྟེ། ལམ་གྱི་རང་བཞིན་བྱང་ཆུབ་ཏུ་སེམས་བསྐྱེད་པ། དེ་རྣམ་པར་དག་བྱེད་གདམས་ངག་ནོད་པ། དེ་བསྒོམས་པའི་འབྲས་བུ་ངེས་འབྱེད་ཡན་ལག །གདམས་པའི་དོན་ཕྱིན་ཅི་མ་ལོག་པར་སྒྲུབ་པའོ། །
Enumeration Block 5:
དང་པོ་ལ། སྤྱི་གཞུང་གཉིས་སོ། །
Enumeration Block 6:
དང་པོ་ལ་གཉིས་ཏེ། སེམས་བསྐྱེད་སྡོམ་པའི་རང་བཞིན་གཏན་ལ་དབབ་པ་དང་། དེ་ཡང་དག་པར་བླངས་ཏེ་བསླབ་པའོ། །
Enumeration Block 7:
དང་པོ་ལ་གསུམ་སྟེ། སེམས་བསྐྱེད་ཀྱི་རང་བཞིན། སྡོམ་པའི་རང་བཞིན། དེ་དག་གི་ཁྱད་པར་རོ། །
Enumeration Block 8:
དང་པོ་ལ། རྒྱུ་ངོ་བོ་འབྲས་བུ་གསུམ་མོ། །
Enumeration Block 9:
རྒྱུ་ལ་གཉིས་ཏེ། སྐྱེ་བའི་དང། ལྡོག་པའི་རྒྱུའོ། །
Enumeration Block 10:
འོན་ཀྱང་འདིར་བསྡུས་ན་གསུམ་སྟེ། སེམས་བསྐྱེད་ཆགས་པའི་རྟེན། ཉེར་ལེན་གྱི་རྒྱུ། དེའི་རྐྱེན་ནོ། །
Enumeration Block 11:
དང་པོ་ལ། ལུས་དང་།

བསམ་པའི་རྟེན་གཉིས་ལས། དང་པོ་ལམ་ཤེས་སྐྱེ་རུང་གི་གང་ཟག་ལྷ་དང་མི་ལ་སོགས་པའོ། །
Enumeration Block 12:
གཉིས་པ་ལ། སྙིང་རྗེ། དད་པ།

འདོད་པ་གསུམ་ལས།
Enumeration Block 13:
གཉིས་པ་ལ། མཚན་ཉིད། མཚོན་བྱ། མཚན་གཞི་གཏན་ལ་དབབ་པ་དང་གསུམ་མོ། །
Enumeration Block 14:
དགག་བཞག་སྤང་གསུམ་ལས།
