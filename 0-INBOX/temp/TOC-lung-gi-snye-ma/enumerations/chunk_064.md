Enumeration Block 1:
གཉིས་པ་ལ་གཉིས་ལས།
Enumeration Block 2:
བཞི་པ་ནི། གདམས་ངག་ནི་ཆོས་ཅན། རྣམ་པ་བཅུར་ངེས་སོ། །
Enumeration Block 3:
རྒྱུ་ལའང་འགལ་རྐྱེན་སྤོང་བ་དང༌། མཐུན་རྐྱེན་སྒྲུབ་པ་གཉིས་ལས།
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 5:
རྩ་བ་ལ་མཚོན་བྱེད་དཔེའི་དགེ་འདུན། མཚོན་བྱ་དོན་གྱི་དགེ་འདུན། དེ་དག་གི་རྣམ་གཞག་དཔྱད་པ་དང་གསུམ་མོ། །
དང་པོ་ལ། ཆགས་བྲལ་སྔོན་སོང་དང༌། སྔོན་དུ་མ་སོང་བ་གཉིས་སོ། །
Enumeration Block 6:
གཉིས་པ་ལ། གཅིག་ཅར་བ་དང་། རིམ་གྱིས་པ་གཉིས་སོ། །
Enumeration Block 7:
གཉིས་པ་ལ་བཞི་སྟེ། རྒྱུན་ཞུགས། ཕྱིར་འོང༌། ཕྱིར་མི་འོང༌། དགྲ་བཅོམ་པའོ། །
དང་པོ་ལ། འབྲས་བུ་ལ་ཞུགས་པ་ནི། བཤད་ཟིན་ལ། གནས་པ་ལ་གཉིས་ཏེ། སྲིད་པ་ལན་བདུན་པ་དང༌། རིགས་ནས་རིགས་སྐྱེའོ། །
Enumeration Block 8:
དེ་ལ་གཉིས་ལས།
