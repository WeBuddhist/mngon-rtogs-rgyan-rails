Enumeration Block 1:
འགྲེལ་པ་ལ་གཉིས། མཐོང་ལམ་རྣམ་པའི་སྒོ་ནས་བཤད་པ་དང་། རྣམ་པ་མ་བཤད་པར་འདོད་པ་དགག་པའོ། །དང་པོ་ལ། སྡུག་ཀུན་འགོག་ལམ་གྱི་རྣམ་པ་བཤད་པ་དང་བཞིའོ། །
Enumeration Block 2:
གཉིས་པ་ལ། ཁས་བླང་བརྗོད་པ་དང་། དེ་དགག་པ་གཉིས་སོ། །
Enumeration Block 3:
གཉིས་པ་ལ། རིགས་པ་དང་། ལུང་གིས་དགག་པ་གཉིས་སོ། །
Enumeration Block 4:
གཉིས་པ་ལ། སྒོམ་ལམ་གྱི་བྱེད་པ་དང་། བྱེད་པ་ཅན་གྱི་སྒོམ་ལམ་གཉིས་སོ། །

དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 5:
སྒོམ་ལམ་ཡུམ་གྱི་འབྲས་བུ་དྲུག་སྟེ།
Enumeration Block 6:
གཉིས་པ་ལ། ཐུན་མོང་གི་བྱེ་བ་དང་། ཕྱེ་བ་སོ་སོའི་དོན་གཉིས་སོ། །
Enumeration Block 7:
དེ་ལ་བཞི་ལས།
Enumeration Block 8:
དབྱེ་ངོ་ཟག་བཅས་ཟག་མེད་རྣམ་པ་གཉིས་སོ། །
Enumeration Block 9:
གཉིས་པ་ལ། སྒོམ་ལམ་ཟག་བཅས་ཟག་མེད་གཉིས་སོ། །

དང་པོ་ལ། ཐུན་མོང་གི་དབྱེ་བ། ཕྱེ་བ་སོ་སོའི་དོན། དོན་བསྡུ་བ་དང་གསུམ་མོ། །

དང་པོ་ལ་བཞི་ལས།
Enumeration Block 10:
དབྱེ་ངོ་ནི། མོས་པ་དང་། བསྔོ་བ་དང་། རྗེས་སུ་ཡི་རང་བ་ཡིད་ལ་བྱེད་པ་ཞེས་བྱ་བ་གསུམ་མོ། །
Enumeration Block 11:
གཉིས་པ་ལ། མོས་བསྔོ་ཡི་རང་གསུམ་མོ། །

དང་པོ་ལ། མོས་པའི་ངོ་བོ་དང་། ཕན་ཡོན་གཉིས་སོ། །

དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 12:
རྩ་བ་ལ། མོས་པའི་རྒྱུ། ཡུལ། ངོ་བོ། གྲོགས།

བྱེད་ལས།

དབྱེ་བ་དྲུག་གོ།
Enumeration Block 13:
དྲུག་པ་ལ་བཞི་ལས།
Enumeration Block 14:
དབྱེ་ངོ་ནི། ལུས་དང་། ཡན་ལག་དང་། ཉིང་ལག་གི་དབྱེ་བ་གསུམ་མོ། །
Enumeration Block 15:
རང་དོན་མོས་པ་དེ་ཡང་ནི། ཆུང་ངུ་དང་། འབྲིང་དང་།ཆེན་པོ་སྟེ། རྣམ་པ་གསུམ་དུ་འདོད་དོ། །
Enumeration Block 16:
གཉིས་དོན་མོས་པ་གསུམ། གཞན་དོན་མོས་པ་གསུམ་སྟེ། དགུའོ། །
