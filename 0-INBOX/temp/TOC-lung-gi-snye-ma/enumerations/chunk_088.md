Enumeration Block 3:

Enumeration Block 4:
རྩ་བ་ལ། འཇུག་ཡུལ་ཐེག་ཆེན་ངོས་བཟུང་བ་དང༌། དེ་ལ་འཇུག་པའི་སྒྲུབ་པའོ། །

Enumeration Block 5:
གསུམ་པ་ལ། སྤྱིར་ཐེག་ཆེན་ནི། བགྲོད་པ་གང་ཞིག །ཆེན་པོ་བདུན་ལྡན། ཁྱད་པར་རྒྱུའི་ཐེག་ཆེན་ནི། ཆེན་པོ་བདུན་ལྡན་གང་ཞིག །འདིས་བགྲོད་པར་བྱེད་པ། འབྲས་བུའི་ཐེག་ཆེན་ནི། ཆེན་པོ་བདུན་ལྡན་གང་ཞིག །བགྲོད་བྱ་མཐར་ཐུག་པའོ། །
Enumeration Block 6:

Enumeration Block 7:
འདིའི་མཐའ་དཔྱད་པ་ལ། ངོ་བོ་དང༌། ཡན་ལག་དང་། སྙོམས་པར་འཇུག་པ་དང་། ཉོན་མོངས་པ་དང་། རྣམ་བྱང་དང་། ཚད་དང་དྲུག་གོ། །
