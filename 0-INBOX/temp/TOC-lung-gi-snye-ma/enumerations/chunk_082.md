Enumeration Block 1:
གཉིས་པ་ལ་གཉིས་ཏེ། རྩོད་ལན་ནོ། །
རྩོད་པ་ལ། ཁས་བླངས་བརྗོད་པ་དང༌། ཐལ་བ་དགོད་པ་གཉིས་སོ། །
Enumeration Block 2:
ལན་ལ། བསྟན་བཅོས་དང་། ལོ་ཀ་ལ་གྲགས་པའི་ལན་གཉིས་སོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 4:
གཉིས་པ་ལ། སྔ་འགྲེལ། རྩ་བ། འགྲེལ་པ། དགག་སྒྲུབ་བསྟན་པ་དང་བཞིའོ། །
Enumeration Block 5:
གསུམ་པ་ལ་གསུམ་ལས།
Enumeration Block 6:
བཞི་པ་ལ་གསུམ་སྟེ། སྒྲུབ་པ་སྤྱིའི་ངོ་བོ། བྱེ་བྲག་གི་ས་མཚམས། སོ་སོའི་དོན་ནོ། །
