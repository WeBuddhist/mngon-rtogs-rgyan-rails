Enumeration Block 1:
གཉིས་པ་ལ། མཚན་ཉིད། མཚོན་བྱ། མཚན་གཞི་གསུམ་ལས།
Enumeration Block 2:
གསུམ་པ་ལ། ཐུན་མོང་གི་དབྱེ་བ་དང་། ཕྱེ་བའི་ས་མཚམས་སོ། །དང་པོ་ལ་བཞི་ལས། དབྱེ་གཞི་ལམ་ཤེས་ཙམ་མོ། །དབྱེ་ངོ་མཚན་ཉིད་པ་དང་། བཏགས་པ་བ་གཉིས་སོ། །མཚན་ཉིད་པ་ལ་ཡང་ཇི་ལྟ་བ་མཁྱེན་པ་མཉམ་གཞག་དང་། ཇི་སྙེད་པ་མཁྱེན་པ་རྗེས་ཐོབ་གཉིས་སོ། །མཉམ་གཞག་ལ། སྤྱིར་ལོ་ཀ་པའི་མཉམ་གཞག་བསམ་གཏན་སོགས་དང་། ལོ་ཀ་ལས་འདས་པའི་མཉམ་གཞག་རྣམ་པར་མི་རྟོག་པ་གཉིས་སོ། །
Enumeration Block 3:
གསུམ་པ་གཞི་ཤེས་ལ། དགག་བཞག་སྤང་གསུམ་ལས། དང་པོ་ལ་གཉིས་ཏེ། ཉན་རང་ལ་ཆོས་ཀྱི་བདག་མེད་ཤེས་པ་ཡོད་མེད་དཔྱད། སྐབས་དོན་གཞི་ཤེས་ལ་ལོག་པར་རྟོག་པ་དགག་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་མཚན་ཉིད་དང་། མཚོན༌བྱ༌དང་། མཚན་གཞི་གསུམ་ལས།
Enumeration Block 5:
གསུམ་པ་ལ། མཚན་ཉིད་པ་དང་བཏགས་པ་བ་གཉིས་སོ། །
Enumeration Block 6:
བཞི་པ་རྣམ་ཀུན་ལ། དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 7:
གཉིས་པ་ལ། མཚན་མཚོན་གཞི་གསུམ་ལས།
Enumeration Block 8:
ལྔ་པ་རྩེ་སྦྱོར་ལ། དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 9:
གཉིས་པ་ལ། མཚན་མཚོན་གཞི་གསུམ་ལས།
Enumeration Block 10:
དྲུག་པ་མཐར་གྱིས་པ་ལ་དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 11:
གཉིས་པ་ལ། མཚན་མཚོན་གཞི་གསུམ་ལས།
