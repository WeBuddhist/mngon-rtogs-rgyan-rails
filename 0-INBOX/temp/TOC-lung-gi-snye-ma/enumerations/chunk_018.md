Enumeration Block 1:
གཉིས་པ་ལ། བསམ་པ་སྦྱང་བ་དང་། ཆོ་ག་བརྗོད་པ་གཉིས་སོ། །
Enumeration Block 2:
གསུམ་པ་ལ་གཉིས་ཏེ། རང་དགའ་བ་བསྐྱེད་པ་དང་། གཞན་དགའ་བ་བསྐྱེད་པའོ། །
Enumeration Block 3:
གསུམ་པ་ལ་གསུམ་སྟེ། ཐུན་མོང་གི་བསླབ་བྱ་མདོར་བསྟན། སོ་སོའི་བསླབ་བྱ་རྒྱས་པར་བཤད། ཆོས་གཅིག་གིས་དོན་བསྡུ་བའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས་ཏེ། སྨོན་པ་དང་། འཇུག་པའི་བསླབ་བྱ་བཤད་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། འགལ་རྐྱེན་སྤང་བ་དང་། མཐུན་རྐྱེན་སྒྲུབ་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས་ཏེ། འགལ་རྐྱེན་སྤང་། མཐུན་རྐྱེན་སྒྲུབ་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས་ཏེ། མི་ཉམས་པའི་རྒྱུ་དང་། འཕེལ་བའི་རྐྱེན་ལ་བསླབ་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་བཞི་སྟེ། སེམས་བསྐྱེད་ཀྱི་མཚན་ཉིད། དམིགས་ཡུལ། རབ་དབྱེ། ས་མཚམས་སོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 8:
འགྲེལ་པ་ལ། མཚན་ཉིད་ཅན་གྱི་དབྱེ་བ་དང་། མཚན་ཉིད་ལ་རྩོད་པ་སྤང་བ་གཉིས་སོ། །
Enumeration Block 9:
གཉིས་པ་ལ། རྩོད་ལན་གཉིས་ལས།
Enumeration Block 10:
ལན་ལ། རྒྱུ་མིང་འབྲས་བུ་ལ་བཏགས་པ་དང་། གྲོགས་མིང་གྲོགས་ཅན་ལ་བཏགས་པའི་ལན་གཉིས་སོ། །
Enumeration Block 11:
གཉིས་པ་ལ་ལྔ་སྟེ། སྔ་འགྲེལ། རྩ་བ། འགྲེལ་པ། དོན་བསྡུ། མདོ་གཞན་མ་བྲིས་པའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 12:
གསུམ་པ་ལ་བཞི་ལས།
Enumeration Block 13:
རྩ་བ་ལ་བཞི་ལས།
Enumeration Block 14:
ཚོགས་སྦྱོར། ས་བཅུ། ཁྱད་པར་གྱི་ལམ། སངས་རྒྱས་ཀྱི་སས་བསྡུས་པ་ལྔ་ལས།
Enumeration Block 15:
གཉིས་པ་ལ་གཉིས་ཏེ། གདམས་ངག་བཅུ་སྤྱིར་བསྟན་པ་དང་། དགེ་འདུན་དཀོན་མཆོག་བྱེ་བྲག་ཏུ་བཤད་པའོ། །དང་པོ་ལ། སྔ་འགྲེལ། རྩ་བ། འགྲེལ་པ། གྲངས་ངེས་ཀྱི་སྒོ་ནས་དོན་བསྡུ་དང་བཞིའོ། །
Enumeration Block 16:
གསུམ་པ་ལ་བཞི་སྟེ། སྒྲུབ་པ་རང་གི་ངོ་བོ། དམིགས་ཡུལ་བདེན་པ་བཞི། རྟེན་དཀོན་མཆོག་གསུམ། སྒྲུབ་པ་ཕུན་སུམ་ཚོགས་པའི་རྒྱུ་ལ་གདམས་པའོ། །
Enumeration Block 17:
གཉིས་པ་ལ། སྤྱི་གཞུང་གཉིས་སོ། །དང་པོ་ལ་བཞི་སྟེ། བདེན་བཞིའི་མཚན་ཉིད། དབྱེ་བ། རང་བཞིན། རྩོད་སྤང་ངོ༌། །
