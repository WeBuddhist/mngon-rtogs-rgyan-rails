Enumeration Block 1:
བཞི་པ་ལ་གསུམ་སྟེ། སྒྲུབ་པ་སྤྱིའི་ངོ་བོ། བྱེ་བྲག་གི་ས་མཚམས། སོ་སོའི་དོན་ནོ། །
Enumeration Block 2:
གཉིས་པ་ལ། དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 3:
སྦྱོར་བའི་ལམ་ལ་དངོས་དང༌། བརྒྱུད་པ་དང༌། མངོན་སུམ་དུ་སྦྱོར་བ་གསུམ་ལས།
Enumeration Block 4:
གསུམ་པ་ལ་བཞི་སྟེ། གོ་འཇུག་ཚོགས་ངེས་སོ། །
Enumeration Block 5:
གཉིས་པ་ལ། སྤྱི་གཞུང་གཉིས་སོ། །
Enumeration Block 6:
ཞེས་པ་བཅུའི་སྟེང་དུ་ཁྱད་པར་དཔྱད་པ་དང་བཅུ་གཅིག་གིས་བཤད་པར་བྱའོ། །
Enumeration Block 7:
དང་པོ་ལ་དྲུག་སྟེ། རང་དོན། གཉིས་དོན། གཞན་དོན། ཐེག་ཆེན་ལམ། བསླབ་གསུམ་ལ་ལྟོས་ཏེ་ཕྱིན་དྲུག་ཏུ་གྲངས་ངེས་སོ། །
