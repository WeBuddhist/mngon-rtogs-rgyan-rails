Enumeration Block 1:
ལམ་ལ་སྟོབས་ཀྱི་རྣམ་པ་ལྔ་ནི། སྔར་གྱི་དབང་པོ་ལྔ་པོ་ཉིད། མི་མཐུན་ཕྱོགས་ངེས་པར་བསྲབས་པས་ཚུར་མི་རྫི་བས་སྟོབས་ཏེ། འདི་ལའང་ལྔ་ལས།
Enumeration Block 2:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 3:
མཚན་གཞི་ལ། དབྱེ་བ། ས་མཚམས་གཉིས་ཀྱི་དང་པོ་ལ་བཞི་ལས།
Enumeration Block 4:
དྲུག་པ་ནི། དེ་ཁོ་ན་ཉིད་སོ་སོ་རང་གིས་མངོན་པར་རྟོགས་པའི་ལམ་ལ་བྱང་ཆུབ་ཡན་ལག་གི་རྣམ་པ་བདུན་ལ་སྔར་བཞིན་ལས།
Enumeration Block 5:
དྲན་སོགས་བདུན་ཏེ། འདི་ལ་གསུམ་ལས།
Enumeration Block 6:
མཚན་གཞི་ལ། དབྱེ་བ། ས་མཚམས་གཉིས་སོ། །དང་པོ་ལ།
Enumeration Block 7:
བདུན་པ་སྒོམ་སྤང་རྣམ་པར་དག་པ་ངེས་པར་འབྱུང་བའི་ལམ་ལ། འཕགས་པའི་ལམ་ཡན་ལག་གི་རྣམ་པ་བརྒྱད་ལ་སྔར་བཞིན་ལྔ་ལས།
Enumeration Block 8:
ལྟ་བ་སོགས་བརྒྱད་དེ། འདི་ལ་གསུམ་ལས།
Enumeration Block 9:
མཚན་གཞི་གཉིས་ཏེ། དབྱེ་བ་དང་། ས་མཚམས་སོ། །
Enumeration Block 10:
གཉིས་པ་ལམ་ཤེས་ཉིད་ཀྱི་རྣམ་པ་ལ། ལམ་དྲུག་སྟེ། གཉེན་པོའི་དང་། སྤྲུལ་པའི་དང་། མཐོང་བའི་ཆོས་ལ་བདེ་བར་གནས་པའི་དང་། ལོ་ཀ་ལས་འདས་པའི་དང་། སྤོང་བའི་དང་། སངས་རྒྱས་ཉིད་ཀྱི་ལམ་གྱི་རྣམ་པའོ། །དང་པོ་ལ། སྤྱི་གཞུང་གཉིས་སོ། །དང་པོ་ལ་གསུམ་སྟེ། ཡུལ་རྣམ་ཐར་སྒོ་གསུམ། ཡུལ་ཅན་ཏིང་ངེ་འཛིན་གསུམ། དེའི་རྒྱུ་ཆོས་ཀྱི་སྡོམ་བཞིའོ། །
Enumeration Block 11:
གཉིས་པ་སྤྲུལ་པའི་ལམ་ལ་གཉིས་ཏེ། རྣམ་པ་སྤྱིའི་ངོ་བོ་དང་། ཁྱད་པར་སྡུག་པའི་རྣམ་ཐར་རོ། །དང་པོ་ལ་གཉིས་ཏེ། གཟུགས་ཅན་གཟུགས་ལ་ལྟ་བ་དང་། གཟུགས་མེད་གཟུགས་ལ་ལྟ་བ་གཉིས་སོ། །
Enumeration Block 12:
གཉིས་པ་ལ། སྒོམ་གཞིར་བྱས་པའི་ཆོས་བཞི་སྟེ།
