Enumeration Block 1:
རྩོད་ལན་གཉིས་ལས།
Enumeration Block 2:
ལན་ལ་གཉིས་ལས། རྩ་བ་ལ་གཉིས་ཏེ། དོན་དམ་དུ་རྟགས་མ་གྲུབ་དང་། ཀུན་རྫོབ་ཏུ་ཁྱབ་པ་མ་གྲུབ་པའོ། །
Enumeration Block 3:
འགྲེལ་པ་ལ་གཉིས་ལས།
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ་སྟེ། རྩོད་པ་དང་། ལན་དང་། ལན་ལ་རྩོད་སྤང་ངོ་། །དང་པོ་ལ་གསུམ་སྟེ།
Enumeration Block 5:
འགྲེལ་པ་ལ་གཉིས་ཏེ། ཐལ་བ་དང་། ཆོས་གསུམ་མོ། །
Enumeration Block 6:
ལན་ལ་གསུམ་ལས།
Enumeration Block 7:
འགྲེལ་པ་ལ། ཀུན་རྫོབ་ཏུ་མ་ངེས་པ་དང་། དོན་དམ་དུ་འདོད་པ་གཉིས་སོ། །དང་པོ་ལ། དཔེ་དོན་གཉིས་ལས།
Enumeration Block 8:
གསུམ་པ་ལ་རྩོད་ལན་གཉིས་ཀྱི་རྩོད་པ་ལ་གསུམ་ལས།
Enumeration Block 9:
འགྲེལ་པ་ལ་གཉིས་ཏེ། ཐལ་བ་དགོད་པ་དང་། དེའི་རྟགས་སྒྲུབ་པའོ། །
Enumeration Block 10:
དེ་སྒྲུབ་པ་ལ་གསུམ་སྟེ། སྔ་ཕྱི་རེ་རེས་དང་། མང་པོ་གཅིག་ཅར་འབྱུང་བས་དང་། མང་པོ་རིམ་གྱིས་འབྱུང་བས་མི་སྐྱེད་པར་བསྟན་པའོ། །
