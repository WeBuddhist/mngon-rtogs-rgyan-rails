Enumeration Block 1:
གསུམ་པ་ལ་གཉིས་ཏེ། ཚོགས་སྒྲུབ་བཅུ་བདུན་སྤྱིར་བསྟན་པ་དང༌། རྟོགས་དཀའ་བ་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 2:
དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 3:
འགྲེལ་པ་ལ། ངོ་བོ། ངེས་ཚིག །གྲངས་ངེས་གསུམ་མོ། །
Enumeration Block 4:
འདི་ལ་གསུམ། ངོ་བོ། དབྱེ་བ། བྱེད་ལས་སོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ་སྟེ། ཡེ་ཤེས་དང༌། ས་དང༌། གཉེན་པོའི་ཚོགས་བྱེ་བྲག་ཏུ་བཤད་པའོ། །དང་པོ་ལ། ཡུལ་ཅན་ཡེ་ཤེས་ཀྱི་ས་མཚམས་དང༌། ཡུལ་སྟོང་ཉིད་བསྟན་པ་གཉིས་སོ། །དང་པོ་ལ། དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 6:
གཉིས་པ་ལ། སྤྱི་གཞུང་གཉིས་ལས།
Enumeration Block 7:
འདི་ལ་གསུམ་ལས།
Enumeration Block 8:
མཚན་གཞི་ལ། དབྱེ་བ་དངོས་དང༌། ཕྱེ་བའི་ཁྱད་པར་གཉིས་སོ། །
Enumeration Block 9:
གཉིས་པ་ལ། རྟགས་དང༌། ཡོན་ཏན་དང༌། སྐྱེ་བ་དང༌། སློབ་ཚུལ་དང༌། སྤང་བྱ་དང་། སྤྱོད་པ་དང་། སྤངས་རྟོགས་དང་། འབྲས་བུའི་ཁྱད་པར་དང་བརྒྱད་དོ། །དང་པོ་ལ། ཞུགས་པ་དང༌། རྨི་ལྟས་ཀྱི་རྟགས་གཉིས་ལས།
Enumeration Block 10:
གཉིས་པ་ལ། སྤྱི་དང་བྱེ་བྲག་གི་ཡོན་ཏན་གཉིས་ལས།
