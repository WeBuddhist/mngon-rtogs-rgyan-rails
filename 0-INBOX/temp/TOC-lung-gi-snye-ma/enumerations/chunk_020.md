Enumeration Block 1:
གཉིས་པ་ལ། ཚོགས་སྦྱོར་མཐོང་སྒོམ་མི་སློབ་ལམ་དང་ལྔ་ལས། དང་པོ་ལ། མཚན་ཉིད། མཚོན་བྱ། མཚན་ཉིད་ངོས་གཟུང་བ་གསུམ་ལས།
Enumeration Block 2:
གསུམ་པ་ལ། རྒྱུ། ངོ་བོ། འབྲས་བུ་གསུམ་ལས།
Enumeration Block 3:
གསུམ་པ་ལ། དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 4:
གཉིས་པ་ལ། ལྔ་སྟེ། བརྟགས་ན་མི་འཐད་པ་དང༌། རྗེས་ཐོབ་མི་འཐད་པ་དང༌། སྤང་བྱ་རིམ་གྱིས་སྤོང་བར་ཐལ་བ་དང་། བཟོད་པ་ཆོས་མཆོག་ཏུ་ཐལ་བ་དང༌། ཤེས་པ་སྒོམ་ལམ་དུ་ཐལ་བ་སྤང་པའོ། །
Enumeration Block 5:

Enumeration Block 6:
འདིར་ཟག་བཅས་ཟག་མེད་གཉིས་སོ། །དེ་གཉིས་ཀྱི་ཁྱད་པར་ལ། དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 7:
ལྔ་པ་ལ། མཚན་མཚོན་གཞི་གསུམ་ལས།
Enumeration Block 8:
རྡོ་རྗེ་ལྟ་བུའི་ཏིང་ངེ་འཛིན་སྒོམ་སྤང་ཆུང་ངུའི་ཆུང་ངུ་སྤོང་བའི་གཉེན་པོ་སྟེ། སྦྱོར་བའི་ལམ་དང༌། བར་ཆད་མེད་ལམ་གཉིས་སོ། །
Enumeration Block 9:
གཉིས་པ་ལ་བཞི་སྟེ། འཁོར་བའི་འབྲས་བུ་དུཿཁ། རྒྱུ་ཀུན་འབྱུང༌། རྣམ་བྱང་གི་འབྲས་བུ་འགོག་པ། རྒྱུ་ལམ་བདེན་ལ་གདམས་པའོ། །དང་པོ་ལ། གང་ལ་གདམས་པ། ཇི་ལྟར་གདམས་པ་གཉིས་ལས།
