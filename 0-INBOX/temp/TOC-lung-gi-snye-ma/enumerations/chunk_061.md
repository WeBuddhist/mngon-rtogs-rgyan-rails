Enumeration Block 1:
གཉིས་པ་ལ། སངས་རྒྱས་དང༌། ཆོས་དང༌། དགེ་འདུན་ལ་གདམས་པ་གསུམ་ལས། དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 2:
གཉིས་པ་ལ། ཡུལ་དང་ཡུལ་ཅན་དང༌། མཚོན་བྱ་དང་མཚན་ཉིད་དང༌། རྒྱུ་མཚན་དང་རྒྱུ་མཚན་ཅན་དུ་མི་སྦྱོར་བར་གདམས་པ་གསུམ་མོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས་ལས།
Enumeration Block 4:
གསུམ་པ་ལ་གཉིས་ལས།
Enumeration Block 5:
གང་ལ་འཇུག་ན། གསུམ་ལས།
Enumeration Block 6:
བཞི་པ་ལ་བཞི་སྟེ། སྒྲུབ་པའི་མི་མཐུན་ཕྱོགས་སྤང་བའི་རྒྱུ་བརྩོན་འགྲུས། སྒྲུབ་པ་ལ་གཞན་གྱིས་དྲིང་མི་འཇོག་པའི་རྒྱུ་སྤྱན་ལྔ། སྒྲུབ་པའི་ཡོན་ཏན་ཐམས་ཅད་རྫོགས་པའི་རྒྱུ་མངོན་ཤེས་དྲུག །སྒྲུབ་པ་མཐར་ཐུག་པའི་རྒྱུ་ལམ་ལ་གདམས་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ། གང་ལ་དང༌། ཇི་ལྟར་གདམས་པ་གཉིས་ལས། དང་པོ་ལ། རྒྱུ། ངོ་བོ། འབྲས་བུའོ། །
Enumeration Block 8:
ངོ་བོ་ལ། མཚན་མཚོན་གཞི་གསུམ་ལས།
Enumeration Block 9:
གསུམ་པ་ལ་བཞི་ལས། དབྱེ་གཞི་སྤྱན་ཙམ་མོ། །
