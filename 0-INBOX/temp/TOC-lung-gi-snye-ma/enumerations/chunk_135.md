Enumeration Block 1:
འགྲེལ་པ་ལ། སྐད་ཅིག་མ་བཅུ་དྲུག་བཤད། དེས་ཕྱིར་མི་ལྡོག་ཏུ་སྒྲུབ་པ་གཉིས་སོ། །
Enumeration Block 2:
གསུམ་པ་ལ་གསུམ་སྟེ། སྒོམ་ལམ་གྱི་ཁྱད་པར་བྱེད་ཆོས། ཁྱད་པར་གྱི་གཞི་སྒོམ་ལམ། སྒོམ་ལམ་རྟགས་ཀྱི་དོན་བསྟན་པའོ། །
དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 3:
རྩ་བ་ལ་གསུམ་སྟེ། ཟབ་པར་བསྟན། ཟབ་པའི་ངོ་བོ། ཟབ་པར་སྒྲུབ་པའོ། །
Enumeration Block 4:
འགྲེལ་པ་ལ་གསུམ་ལས།
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ་སྟེ། སྒོམ་ཚུལ། ཚུལ་དེ་ལྡན་གྱི་དབྱེ་བ། ཕྱེ་བའི་བྱེད་པའོ། །
དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས་ཏེ། དགུར་དབྱེ་བ་དང་། གྲངས་ཉུང་བའི་རྩོད་སྤང་ངོ་། །
དང་པོ་ལ་གསུམ་ལས།
