Enumeration Block 1:
རང་བའི་རྣམ་པ་གསུམ་ལས།
Enumeration Block 2:
མོས་བསྔོ་ཡི་རང་གསུམ་ལས།
Enumeration Block 3:
གཉིས་པ་ལ། དབྱེ་བ་མདོར་བསྟན། ཕྱེ་བ་རྒྱས་བཤད་གཉིས་སོ། །
Enumeration Block 4:
དམན་པ་དང་།མཆོག་གི་གོ་རིམ་གྱི་སྒོམ་ལམ་ཟག་པ་དང་བཅས་པའི་འོག་ཏུ་ཟག་པ་མེད་པའི་སྒོམ་པའི་ལམ་སྟོན་པ་ལ་བཞི་སྟེ། དབྱེ་གཞི། སྒོམ་ལམ་ཟག་མེད་དེ་ཡང་ངོ་། །དབྱེ་ངོ་སྒྲུབ་པ་དང་། རྣམ་དག་སྒོམ་ལམ་རྣམ་པ་གཉིས་སོ། །
Enumeration Block 5:
གཉིས་པ་ལ། ཡོན་ཏན་མངོན་པར་སྒྲུབ་པའི་དང་། དྲི་མས་རྣམ་པར་དག་པའི་སྒོམ་ལམ་གཉིས་སོ། །
དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 6:
གཉིས་པ་ལ། མཚམས་སྦྱར་དང་། ངག་བཤད་པ་གཉིས་སོ། །
Enumeration Block 7:
གཉིས་པ་ལ། རྣམ་དག་སྐྱེ་མི་སྐྱེའི་རྒྱུ། འབྲས་བུ་རྣམ་དག་དངོས་བཤད་པ་གཉིས་སོ། །
དང་པོ་ལ་གཉིས་ལས།
རྩ་བ་ལ། སྐྱེ་བ་དང་།
མི་སྐྱེ་བའི་རྒྱུ་གཉིས་ལས།
Enumeration Block 8:
འགྲེལ་པ་ལ་གཉིས་ལས།
Enumeration Block 9:
གཉིས་པ་ལ་གཉིས་ཏེ། རྣམ་དག་སྤྱིར་བསྟན་པ་དང་། ཁྱད་པར་དུ་བསྟན་པའོ། །
དང་པོ་ལ་བཞི་ལས།
Enumeration Block 10:
འགྲེལ་པ་ལ། རྟགས་དགོད་དང་། ཕྱོགས་ཆོས་སྒྲུབ་པ་གཉིས་སོ། །
