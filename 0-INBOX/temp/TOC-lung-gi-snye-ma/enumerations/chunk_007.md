Enumeration Block 1:
དུས་དང་། སྟོན་པ་དང་། གནས་དང་། འཁོར་བཞི་ལས།
Enumeration Block 2:
གཉིས་པ་ལ། གདན་དང་བཞུགས་པ་བཤམ། བཞུགས་ནས་ཆོ་འཕྲུལ་མཛད། མཛད་ནས་ཆོས་གསུང་བའི་དུས་གཟིགས་པ་གསུམ་མོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 3:
གཉིས་པ་ནི། མཐོ་རིས་དང་། མཐོ་རིས་ཉེས་པ་མེད་པ་དང་། སྤྱོད་པ་དག་པ་དང་། བསམ་པ་ཁྱད་པར་ཅན་དང་། བདེ་ལྡན་དང་། ཤེས་ལྡན་ལ་དགོད་པ་དྲུག་གོ།
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས་ཏེ། སྤྲུལ་པ་དང་། བྱིན་གྱིས་བརླབས་པའི་ཆོ་འཕྲུལ་ལོ། །
Enumeration Block 5:
དང་པོ་ལ། ཞུས༌པ༌དང་བསྟན༌པ༌གཉིས་ལས།
Enumeration Block 6:
གཉིས་པ་ལ་བཞི་ལས།
Enumeration Block 7:
གཉིས་པ་ལ་གསུམ་སྟེ། རྒྱས་པ་ལ་དད་པ་ལ་བརྒྱད། བར་པ་ལ་དད་པ་ལ་དྲུག །བསྡུས་པ་ལ་དད་པ་ལ་གསུམ་དུ་དབྱེ་བའོ། །དང་པོ་ལ། བསྡུས་དོན་ལུས་རྣམ་གཞག །ཚིག་དོན་ཡན་ལག་རྒྱས་བཤད་གཉིས་སོ། །དང་པོ་ལ་བཞི་སྟེ། དགོས་པ་བསྟན་པས་མཚམས་སྦྱར། དགོས་ལྡན་ལུས་བཤད། བཤད་པའི་བསྡུས་དོན་བསྟན། མ་བཀྲོལ་བའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 8:
གཉིས་པ་ལ། ལུས་མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། ཡུམ་དངོས་བརྒྱད་ཀྱིས་བཤད་པར་བསྟན། འཆད་བྱེད་དངོས་བརྒྱད་གཏན་ལ་དབབ་པའོ། །
Enumeration Block 9:
གཉིས་པ་ལ་གཉིས་ཏེ། དངོས་བརྒྱད་སོ་སོའི་དོན་དང་། ངེས་པ་བསམ་པའོ། །དང་པོ་ལ་བརྒྱད་ལས། རྣམ་མཁྱེན་ལ་དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 10:
བཞི་པ་ལ། སངས་རྒྱས་ལ་ཡེ་ཤེས་ཡོད་མེད་དང་། སྣང་བཅས་ཡོད་མེད་དང་། སྐབས་དོན་ངོ་བོ་གཏན་ལ་དབབ་པ་གསུམ་མོ། །
Enumeration Block 11:
གསུམ་པ་ལ། མཚན་ཉིད། དབྱེ་བ། ངོ་བོ། ས་མཚམས་ལ་རྩོད་སྤང་དང་བཞི་ལས།
Enumeration Block 12:
གཉིས་པ་ལམ་ཤེས་ལ། དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 13:
གཉིས་པ་ལ། མཚན་ཉིད། མཚོན་བྱ། མཚན་གཞི་གསུམ་ལས།
Enumeration Block 14:
གསུམ་པ་ལ། ཐུན་མོང་གི་དབྱེ་བ་དང་། ཕྱེ་བའི་ས་མཚམས་སོ། །དང་པོ་ལ་བཞི་ལས། དབྱེ་གཞི་ལམ་ཤེས་ཙམ་མོ། །དབྱེ་ངོ་མཚན་ཉིད་པ་དང་། བཏགས་པ་བ་གཉིས་སོ། །མཚན་ཉིད་པ་ལ་ཡང་ཇི་ལྟ་བ་མཁྱེན་པ་མཉམ་གཞག་དང་། ཇི་སྙེད་པ་མཁྱེན་པ་རྗེས་ཐོབ་གཉིས་སོ། །མཉམ་གཞག་ལ། སྤྱིར་ལོ་ཀ་པའི་མཉམ་གཞག་བསམ་གཏན་སོགས་དང་། ལོ་ཀ་ལས་འདས་པའི་མཉམ་གཞག་རྣམ་པར་མི་རྟོག་པ་གཉིས་སོ། །
