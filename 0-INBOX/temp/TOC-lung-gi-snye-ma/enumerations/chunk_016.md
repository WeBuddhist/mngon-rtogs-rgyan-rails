Enumeration Block 1:
གཉིས་པ་ལ་གསུམ་སྟེ། རང་དོན། གཞན་དོན། གཉིས་དོན་ནོ། །
Enumeration Block 2:
གཉིས་པ་ལ། སྤྱིར་ཆོས་ཉིད་ཀྱིས་ཐོབ་པ་བསམ་གཏན་དང་ཟག་མེད་ཀྱི་སྡོམ་པ་དང་། ཡང་དག་པར་བླངས་པ་བརྡ་ལས་བྱུང་བའི་སྡོམ་པ་གཉིས་ལས། འདི་ལ། རྒྱུ། ངོ་བོ། འབྲས་བུ་གསུམ་ལས། དང་པོ་ལ། སྐྱེ་བའི་དང་། ལྡོག་པའི་རྒྱུ་གཉིས་སོ། །དང་པོ་ལ། རྟེན། རྒྱུ། བདག་རྐྱེན་གསུམ་ལས།
Enumeration Block 3:
གཉིས་པ་ལ། མཚན་མཚོན་གཞི་གསུམ་ལས།
Enumeration Block 4:
གསུམ་པ་ལ་བཞི་ལས།
Enumeration Block 5:
དབྱེ་ངོ་ནི། སྡོམ་པ། དགེ་བ་ཆོས་སྡུད། སེམས་ཅན་དོན་བྱེད་གསུམ་མོ། །
Enumeration Block 6:
གསུམ་པ་ལ་གཉིས་ཏེ། ཉམས་པ་ཉེས་དམིགས་ཀྱི་དང་། ཐོབ་པ་ཕན་ཡོན་གྱིའོ། །
Enumeration Block 7:
གཉིས་པ་ལ། ཐུན་མོང་བ་སྔར་དང་འདྲ་བ་ལ། ཐུན་མོང་མ་ཡིན་པ་ལ། གནས་སྐབས་དང་། མཐར་ཐུག་གི་འབྲས་བུའོ། །དང་པོ་ལ། ལས་མཐའ་དང་། སྤྱོད་པ་དང་། སྐྱེས་ཐོབ་ཀྱི་ཚུལ་ཁྲིམས་གསུམ་ལས།
Enumeration Block 8:
གཉིས་པ་སྤངས་རྟོགས་ཕྲིན་ལས་གསུམ་མོ། །གསུམ་པ་ལ་གཉིས་ཏེ། སྐྱབས་འགྲོ་དང་སེམས་བསྐྱེད་ཀྱི་ཁྱད་པར། སེམས་བསྐྱེད་དང་སྡོམ་པའི་ཁྱད་པར་རོ། །
Enumeration Block 9:
གཉིས༌པ༌ལ་གཉིས་ཏེ། སེམས་ཙམ་པ་དང་། དབུ་མའི་ལུགས་གཉིས་སོ། །
Enumeration Block 10:
འདི་ལ་བཞི་སྟེ། རྟེན་གྱི་ཁྱད་པར། མ་སྐྱེས་པ་སྐྱེད་པའི་ཁྱད་པར། སྐྱེས་པ་མི་ཉམས་པར་སྲུང་བའི་ཁྱད་པར། ཉམས་ན་ཕྱིར་བཅོས་ཀྱི་ཁྱད་པར་རོ། །
