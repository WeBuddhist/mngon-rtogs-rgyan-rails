Enumeration Block 2:
གཉིས་པ་ལ་བཞི་སྟེ། སྤང་བྱ་གཉེན་པོ་དང་བཅས་པ་དང་། བྱང་ཆུབ་ཆེན་པོ་སྐྱེད་པའི་རྒྱུ་དང་། འབྲས་བུ་བྱང་ཆུབ་ཆེན་པོ་དང་། ངོ་བོ་མཐོང་ལམ་རྩེ་སྦྱོར་བཤད་པའོ། །
དང་པོ་ལ་གསུམ་སྟེ། མདོར་བསྟན། རྒྱས་བཤད། དོན་བསྡུ་བའོ། །
མདོར་བསྟན་ལ། གཟུང་རྟོག་མདོར་བསྟན། འཛིན་རྟོག་མདོར་བསྟན་པའོ། །
དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 3:
སྔར་བཞིན་གསུམ་ལས། དང་པོ་ལ་གསུམ་སྟེ། འཇུག་པ་གཟུང་རྟོག །ལྡོག་པ་གཟུང་རྟོག །མི་མཐུན་ཕྱོགས་སུ་བསྟན་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 5:
རྒྱུ་མཚན་གསུམ་ལས།
Enumeration Block 6:
སྔར་བཞིན་གསུམ་ལས། དང་པོ་ལ་གསུམ་སྟེ། རྫས་འཛིན་རྟོག་པ། བཏགས་འཛིན་རྟོག་པ། མི་མཐུན་ཕྱོགས་སུ་བསྟན་པའོ། །
Enumeration Block 7:
རྒྱས་བཤད་ལ། གཟུང་རྟོག་དང་། འཛིན་རྟོག་བཤད་པ་གཉིས་སོ། །
དང་པོ་ལ་གཉིས་ཏེ། འཇུག་པ་དང་། ལྡོག་པ་གཟུང་རྟོག་བཤད་པའོ། །
དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 8:
རྩ་བ་ལ་བཞི་སྟེ། རྟོག་པའི་ཡུལ། ངོ་བོ། གྲངས། དེ་དག་སྦྱར་ཏེ་བཤད་པའོ། །
