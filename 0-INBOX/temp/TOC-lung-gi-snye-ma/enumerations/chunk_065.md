Enumeration Block 1:
གཉིས་པ་ལ། ཞུགས་གནས་གཉིས་ལས།
Enumeration Block 2:
དྲུག་པ་ནས་བརྒྱད་པ་སྤངས་པའི་བར་ཏེ། དེ་ལ་འབྲས་གནས་ཙམ་དང༌། ཁྱད་པར་ཅན་བར་ཆད་གཅིག་པ་གཉིས་སོ། །
Enumeration Block 3:
གསུམ་པ་ལ། ཞུགས་གནས་གཉིས་ལས།
Enumeration Block 4:
དེ་ལ་བཞི་སྟེ། ཕྱིར་མི་འོང་ཐོབ་པའི་ཚེ་དེ་ལ་གཟུགས་ཀྱི་ཉོན་མོངས་མ་སྤངས་པ་གཟུགས་སུ་ཉེར་འགྲོ། དེ་སྤངས་ཀྱང་གཟུགས་མེད་ཀྱི་ཉོན་མོངས་མ་སྤངས་པ་གཟུགས་མེད་དུ་ཉེར་འགྲོ། ཟག་པ་ཐམས་ཅད་ཟད་པར་བྱེད་པ་མཐོང་བའི་ཆོས་ལ་ཞི་བ། ཐོབ་པ་འགོག་པ་ལུས་ཀྱིས་མངོན་སུམ་དུ་བྱེད་པའོ། །
དང་པོ་ལ་གསུམ་སྟེ། མངོན་པར་འགྲུབ་པ་ཙམ་གྱི་ལས་ཅན་དང༌། སྐྱེས་ནས་མྱོང་འགྱུར་གྱི་ལས་ཅན་དང༌། ལན་གྲངས་གཞན་ལ་མྱོང་འགྱུར་གྱི་ལས་ཅན་ནོ། །
Enumeration Block 5:
འདི་ལ་ལྷག་མཐོང་ཤས་ཆེར་སྤྱོད་པ་འོག་མིན་གྱི་དང༌། ཞི་གནས་ཤས་ཆེར་སྤྱོད་པ་སྲིད་རྩེའི་མཐར་ཐུག་པར་འགྲོ་བ་གཉིས་སོ། །
Enumeration Block 6:
འོག་མིན་དུ་འདའ་བ་ལ་རྟུལ་པོའི་རྣོ་འབྲིང་རྟུལ་གསུམ་གྱིས་འཕར་བ་དང༌། ཕྱེད་དུ་འཕར་བ་དང༌། གནས་ཐམས་ཅད་དུ་འཆི་འཕོ་བའོ། །
Enumeration Block 7:
ཚངས་ཆེན་གསུམ་ལས།
Enumeration Block 8:
གཟུགས་མེད་དུ་སྐྱེས་ནས་དགྲ་བཅོམ་པ་ཐོབ་པར་བྱེད་པ་ལ། སྐྱེས་ནས་འདའ་བ། འདུ་བྱེད་པ་དང་བཅས་ཏེ་འདའ་བ། འདུ་བྱེད་པ་མེད་པར་འདའ་བ། གོང་དུ་འཕོ་བ་དང་བཞིའོ། །
Enumeration Block 9:
བཞི་པ་ལ། ཞུགས་གནས་གཉིས་ལས།
