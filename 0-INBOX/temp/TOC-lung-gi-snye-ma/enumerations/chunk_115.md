Enumeration Block 1:
གཉིས་པ་ལ་བཞི་ལས།
Enumeration Block 2:
འགྲེལ་པ་ལ་གཉིས་ཏེ། ངོ་བོ་དང་། དབྱེ་བའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ་སྟེ། གཞི་ཤེས་ཀྱི་དང། ལམ་ཤེས་ཀྱི་དང་། རྣམ་མཁྱེན་གྱི་རྣམ་པ་བཤད་པའོ། །
Enumeration Block 5:
དང་པོ་ལ། སྔ་འགྲེལ། རྩ་བ། འགྲེལ་པ། དོན་བསྡུའོ། །
Enumeration Block 6:
འགྲེལ་པ་ལ། བདེན་གསུམ་གྱི་རྣམ་པ་བཅུ་གཉིས་དང་། ལམ་བདེན་གྱི་རྣམ་པ་བཅོ་ལྔ་བཤད་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གསུམ་སྟེ། ལམ་དང་པོའི་བཞི། གཉིས་པའི་ལྔ། གསུམ་པའི་དྲུག་བཤད་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལ་གསུམ་སྟེ།
Enumeration Block 9:
གཉིས་པ་རྒྱས་བཤད་ལ་བཞི་སྟེ། ཀུན་འབྱུང་གི་རྣམ་པ་སྤང་གཉེན་གྱི་སྒོ་ནས་དང་། ལམ་དམ་བཅའ་དང་རྟགས་ཀྱི་དང་། དུཿཁ་རང་སྤྱིའི་མཚན་ཉིད་ཀྱི་དང་། འགོག་པ་སྟོང་ཉིད་ཀྱི་སྒོ་ནས་བསྟན་པའོ། །
Enumeration Block 10:
ངེས་འབྱུང་ལ་གཉིས་ལས།
