Enumeration Block 1:
ལྔའི་དང་པོ་རྒྱུན་ཞུགས་ལ་གསུམ་སྟེ། འབྲས་ཞུགས་དང༌། འབྲས་གནས་ཙམ་དང༌། ཁྱད་པར་ཅན་ནོ། །
Enumeration Block 2:
གཉིས་པ་ནི། ཕྱིར་འོང་ལ་གསུམ་ལས།
Enumeration Block 3:
གསུམ་པ་ཕྱིར་མི་འོང་ལ་གཉིས་ལས།
Enumeration Block 4:
དེ་ལ་ལྔ་ལས།
Enumeration Block 5:
ལྔ་པ་གོང་དུ་འཕོ་བ་ལ། འོག་མིན་དང་སྲིད་རྩེར་འགྲོ་བ་གཉིས་ལས།
Enumeration Block 6:
གསུམ་པ་ལ། སྤྱི་གཞུང་གཉིས་ལས། དང་པོ་ལ། མཚན་མཚོན་གཞི་གསུམ་མོ། །
Enumeration Block 7:
གསུམ་པ་ལ་བཞི་སྟེ། ངོ་བོ། ཆེ་འབྲིང༌། ཁྱད་པར་གྱི་དབྱེ་བ། ཕྱེ་བའི་བློ་གང་ཡིན་དཔྱད་པའོ། །
Enumeration Block 8:
དྲོད་རྩེ་བཟོད་མཆོག་བཞི་ལས།
