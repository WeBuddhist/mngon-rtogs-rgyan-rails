Enumeration Block 1:
གཉིས་པ་ལ་བཞི་སྟེ། ཐ་དད་དང་། གོ་རིམ་དང་། གྲངས་ངེས་དང་། ཟློས་པ་སྤང་བའོ། །
Enumeration Block 2:
གསུམ་པ་ལ། འཇུག་ཡུལ། འཇུག་པ། ཞུགས་འབྲས་གསུམ་དུ་ངེས་ལ།
Enumeration Block 3:
བཞི་པ་ལ་བཞི་སྟེ། མཁྱེན་གསུམ་དང་རྣམ་ཀུན་ལ་དང་། རྣམ་མཁྱེན་དང་ལམ་ཤེས་ལ་དང་། ལམ་ཤེས་དང་གཞི་ཤེས་ལ་དང་། རྣམ་མཁྱེན་དང་ཆོས་སྐུ་ལ་ཟློས་པ་སྤང་བའོ། །
Enumeration Block 4:
གཉིས་པ་ལ། དོན་བདུན་ཅུ་བཤད་པ་དང་། ཟློས་པ་སྤང་བ་གཉིས་སོ། །དང་པོ་ལ་བརྒྱད་ལས། རྣམ་མཁྱེན་གྱི་དངོས་པོ་བཅུ་བཤད་པ་ལ་བཞི་ལས།
Enumeration Block 5:
གཉིས་པ་སྨིན་ཅིང་དག་པར་བྱེད་པའི་གདམས་ངག་ལ་གཉིས་ཏེ། གདམས་ངག་རྙེད་པའི་ཚུལ། རྙེད་ནས་ཉམས་སུ་ལེན་ཚུལ་ལོ། །དང་པོ་ནི། གང་ཟག་གང་གིས། དུས་ནམ་གྱི་ཚེ། རྒྱུ་གང་ལས། སྟོན་པ་གང་ལ། དགོས་པ་ཅིའི་དོན་དུ། དོན་གང་རྙེད་པའོ། །
Enumeration Block 6:
གསུམ་པ་ནི། ཆོས་རྒྱུན་ཏིང་ངེ་འཛིན་གྱི་རྒྱུ་ལས་སོ། །འདི་ལ། མཚན་མཚོན་གཞི་གསུམ་ལས།
Enumeration Block 7:
དེ་ལ་གཉིས་ལས།
Enumeration Block 8:
གཉིས་པ་ལ་བཞི་སྟེ། དམིགས་པ། ཡིད་ལ་བྱེད་པ། སེམས་གནས་པའི་ཐབས། དེ་དག་ལས་སེམས་ལས་སུ་རུང་བ་ཐོབ་ཚུལ་ལོ། །དང་པོ་ནི། སེམས་དྲུག་སྟེ། རྩ་བའི་སེམས། རྗེས་སུ་དཔྱོད་པའི་སེམས། རྣམ་པར་དཔྱོད་པའི་སེམས། ངེས་པར་འཛིན་པའི་སེམས། སྡོམ་པའི་སེམས། སྨོན་པའི་སེམས་སོ། །
Enumeration Block 9:
གསུམ་པ་ལ། དོན་དང་ཡི་གེ་དཔྱོད་པ་གཉིས་ལས། དང་པོ་ལ། བགྲང་བ། འཇལ་བ། རྟོག་པ། སོ་སོར་རྟོག་པ་བཞི་ལས།
Enumeration Block 10:
གཉིས་པ་ནི། ཡིད་ལ་བྱེད་པ་བཅུ་གཅིག་སྟེ།
Enumeration Block 11:
དེ་ལ་དང་པོ་གསུམ། ལམ་གྱི་རྒྱུ། དེ་འོག་གསུམ། ལམ་གྱི་ངོ་བོ། དེ་འོག་གསུམ། ལམ་མི་ཉམས་པར་བྱེད་པ། ཐ་མ་གཉིས།
Enumeration Block 12:
གསུམ་པ་ནི། སེམས་གནས་པའི་ཐབས་དགུ་སྟེ།
