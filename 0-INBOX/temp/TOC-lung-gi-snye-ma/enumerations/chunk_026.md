Enumeration Block 1:
གསུམ་པ་ལ་གསུམ་སྟེ། དམིགས་རྣམ་རྒྱུ་གསུམ་དང༌། མཚུངས་ལྡན་རྟོག་པ་དང༌། ཡོངས་འཛིན་དགེ་བཤེས་དང༌། ཐབས་མཁས་ཀྱི་ཁྱད་པར་བཤད་པའོ། །དང་པོ་ལ་གསུམ་སྟེ། མཚམས་སྦྱོར། བརྗོད་བྱ་དམིགས་རྣམ་རྒྱུ་གསུམ་རྒྱས་པར་བཤད་པ་དང༌། ཆོས་ཅན་བརྗོད་པ་ཆད་པའི་རྩོད་སྤང་ངོ་། །
Enumeration Block 2:
གཉིས་པ་ལ་བཞི་སྟེ། དྲོད་རྩེ་བཟོད་མཆོག་གོ། དྲོད་ལ། རྩ་འགྲེལ་དོན་བསྡུ་གསུམ་ལས།
Enumeration Block 3:
གཉིས་པ་ལ། དྲོད་ཆེ་འབྲིང་ཆུང་གསུམ་ཡོད་པ་དེ་ལ།
Enumeration Block 4:
གཉིས་པ་ལ། རྩ་འགྲེལ་དོན་བསྡུ་གསུམ་ལས།
Enumeration Block 5:
གསུམ་པ་ལ། ·རྩ་འགྲེལ་དོན་བསྡུ་གསུམ་ལས།
Enumeration Block 6:
བཞི་པ་ལ། རྩ་འགྲེལ་དོན་བསྡུ་གསུམ་ལས།
Enumeration Block 7:
གསུམ་པ་ལ། རྩོད་ལན་གཉིས་ལས།
Enumeration Block 8:
འདིའི་མཐའ་དཔྱད་པ་ལ་གསུམ་ལས། སྒྲ་གཉིས་ཀྱི་ངོ་བོ། དོན་ལ་ཁྱད་མེད་ཚུལ། ཁྱད་པར་གཞན་སྤོང་མི་སྤོང་གི་སྒོ་ནས་བརྡའི་བྱེ་བྲག་བསྟན་པའོ། །
Enumeration Block 9:
གཉིས་པ་ལ། སྤྱི་གཞུང་གཉིས་སོ། །དང་པོ་ལ། དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 10:
གཉིས་པ་ལ། སྤང་བྱ་རྣམ་རྟོག །སྤོང་བྱེད་གཉེན་པོའོ། །དང་པོ་ལ། རྟོག་པའི་རང་བཞིན་དང། ཁྱད་པར་དུ་བྱེད་ཆོས་སུ་འགྱུར་ཚུལ་ལོ། །དང་པོ་ལ། མཚན་མཚོན་གཞི་གསུམ་ལས།
Enumeration Block 11:
དེ་ལ། ཡོད་དོ། །ཡིན་ནོ། །ཞེས་རྟོག་པ་སྒྲུབ་རྟོག །མེད་དོ། །མིན་ནོ། །ཞེས་རྟོག་པ་དགག་རྟོག་གཉིས་ལས། འདིར་ཕྱི་མའོ། །དེ་ལ་གཉིས་ལས།
Enumeration Block 12:
དེ་ལ་ཀུན་ནས་ཉོན་མོངས་དང༌། རྣམ་བྱང་གཟུང་རྟོག་གཉིས་ལས།
Enumeration Block 13:
དེ་ལ༌རྫས་འཛིན་དང༌། བཏགས་འཛིན་རྟོག་པ་གཉིས་ལས།
Enumeration Block 14:
གསུམ་པ་ལ། རྟོག་པ་བཞིར་དབྱེ། དེ་ཉིད་མུ་བཞིར་དབྱེ། མཐོང་སྤང་དང་སྒོམ་སྤང་དུ་དབྱེ། མངོན་གྱུར་དང་ས་བོན་དུ་དབྱེ་བ་བཞིའོ། །
Enumeration Block 15:
དང་པོ་ལ་བཞི་ལས།
Enumeration Block 16:
གཉིས་པ་ལ་བཞི་སྟེ། མཚམས་སྦྱར། མདོར་བསྟན། རྒྱས་པར་བཤད། དོན་བསྡུའོ། །
Enumeration Block 17:
གཉིས་པ་ལ་གཉིས་ཏེ། གཟུང་རྟོག་མདོར་བསྟན། འཛིན་རྟོག་མདོར་བསྟན་ནོ། །
Enumeration Block 18:
དང་པོ་ལ་གཉིས་ཏེ། རྩ་བ་འགྲེལ་བའོ། །
Enumeration Block 19:
གཉིས་པ་ལ། ལུས་དང་ཡན་ལག་གི་དབྱེ་བ་གཉིས་ལས།
