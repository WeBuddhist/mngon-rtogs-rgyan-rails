Enumeration Block 1:
གཉིས་པ་གསུམ་ལས།
Enumeration Block 2:
གང་གསུངས་པ་བརྗོད་བྱ་དང་། གང༌གི་དོན་དུ་གསུངས་པ་དགོས་པ་གཉིས་སོ། །
Enumeration Block 3:
གཉིས་པ་ལ། དགོས་པ་དང་། ཉིང་དགོས་གཉིས་ལས། དང་པོ་ལ། རྣམ་བཅད་དང་། ཡོངས་གཅོད་ཀྱི་དགོས་པ་གཉིས་སོ། །
Enumeration Block 4:
རྩ་བ་ལ་དགོས་བསྡུས་ཚིག་གསུམ་མོ། །དང་པོ་ལ། དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 5:
གསུམ་པ་ལ། རྣམ་བཅད་དང་ཡོངས་གཅོད་ཀྱི་དགོས་པ་ལ་རྩོད་པ་སྤང་བ་གཉིས་སོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གསུམ་སྟེ། བསྟན་བྱ་དགོས་འབྲེལ་བཞི་ངོས་གཟུང་། དེ་དག་གིས་བསྟན་ཚུལ། བསྟན་པ་བཞིར་གྲངས་ངེས་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། དགོས་འབྲེལ་ངག་གི་དགོས་འབྲེལ་དང་། རྒྱན་གྱི་དགོས་འབྲེལ་ལོ། །དང་པོ་ལ་བཞི་ལས།
Enumeration Block 7:
གཉིས་པ་ལ་བཞི་ལས།
Enumeration Block 8:
འདི་ལ་ལུགས་གཉིས་ལས།
Enumeration Block 9:
གསུམ་པ་ལ། དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 10:
གསུམ་པ་ལ་གསུམ་སྟེ། བསལ་བྱ་བློ་དང་། བསལ་བའི་གཞི་དང་། སེལ་བའི་ཚུལ་ལ་རྩོད་སྤང་ངོ་། །
Enumeration Block 11:
གསུམ་པ་ལ། བརྗོད་བྱ། དགོས་པ། ཉིང་དགོས་གསུམ་མོ། །
Enumeration Block 12:
འགྲེལ་པ་ལ་བཞི་སྟེ། བརྗོད་བྱ། འབྲེལ་བ། ཉིང་དགོས། དགོས་པའོ། །
Enumeration Block 13:
གསུམ་པ་ལ། སྤྱི་གཞུང་གཉིས་ལས།
Enumeration Block 14:
འདིར་གླེང་གཞི་ཅུང་ཟད་བཤད་པ་ལ་གཉིས་ཏེ། སྡུད་པ་པོས་གླེང་བསླང་བ་དང་། གླེང་གཞི་དངོས་སོ། །
Enumeration Block 15:
དུས་དང་། སྟོན་པ་དང་། གནས་དང་། འཁོར་བཞི་ལས།
Enumeration Block 16:
གཉིས་པ་ལ། གདན་དང་བཞུགས་པ་བཤམ། བཞུགས་ནས་ཆོ་འཕྲུལ་མཛད། མཛད་ནས་ཆོས་གསུང་བའི་དུས་གཟིགས་པ་གསུམ་མོ། །དང་པོ་ལ་གཉིས་ལས།
