Enumeration Block 1:
བཞི་པ་ལ། དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 2:
གཉིས་པ་ལ། ཉན་ཐོས་རང་རྒྱལ་བྱང་སེམས་ཀྱི་ལམ་ཤེས་གསུམ་མོ། །དང་པོ་ལ། འབྲས་བུ་ལམ་ཤེས་ཀྱི་རང་བཞིན། རྒྱུ་ངེས་འབྱེད་ཆ་མཐུན་ནོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 3:
འདིའི་མཐའ་དཔྱད་པ་ལ། ཉན་ཐོས་ཀྱི་ལམ། དེ་བྱང་སེམས་ཀྱིས་ཤེས་པའི་ཚུལ། མདོ་དང་བསྟན་བཅོས་སུ་བསྟན་ཚུལ་གསུམ་མོ། །དང་པོ་ལ། ལམ་ལྔ་ལས།
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 5:
འགྲེལ་པ་ལ། གང་གིས་དམིགས་པའི་རྣམ་པ། གང་ལ་དམིགས་པའི་ཡུལ། བློའི་ངོ་བོ་དང་གསུམ་མོ། །
Enumeration Block 6:
གཉིས་པ་ལ། སྤྱི་གཞུང་གཉིས་སོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 7:
གང་ཟག་གི་དབྱེ་བ་ལ། བསེ་རུ་ལྟ་བུ། ཚོགས་དང་སྤྱོད་པ་ཆེན་པོ་དང་། ཆུང་ངུ་དང་གསུམ་མོ། །དང་པོ་ལ། སྒྲུབ་པ་པོ་གང་ཟག །སྒྲུབ་པ་ལམ། བསྒྲུབས་པའི་འབྲས་བུའི་ཁྱད་པར་གསུམ་མོ། །
Enumeration Block 8:
གཉིས་པ་ལ།ཚོགས་གསོག་པའི་ཁྱད་པར། ལམ་བགྲོད་པའི་ཁྱད་པར་གཉིས་སོ། །
