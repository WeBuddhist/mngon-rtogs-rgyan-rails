Enumeration Block 1:
གསུམ་པ་བྱང་སེམས་ཀྱི་ལམ་ཤེས་ལ་གཉིས་ལས།
Enumeration Block 2:
གཉིས་པ་སྒོམ་ལམ་ལ་གཉིས་ལས།
Enumeration Block 3:
གཉིས་པ་བྱེད་པའི་རྒྱུ་སྒོམ་ལམ་ལ། ཤེས་སྒྲིབ་ཀྱི་ཟག་པ་ཡོད་མེད་གཉིས་ལས། དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 4:
ཟག་མེད་སྒོམ་ལམ་ལ་གཉིས་ལས།
Enumeration Block 5:
གསུམ་པ་གཞི་ཤེས་ཀྱི་དངོས་པོ་དགུ་ལས།
Enumeration Block 6:
བཞི་པ་རྣམ་ཀུན་གྱི་དངོས་པོ་བཅུ་གཅིག་ལས།
Enumeration Block 7:
དྲུག་པ་བསྟན་པ་ལ་འཇུག་པ་ཐར་པ་ཆ་མཐུན་ལ། མཚན་མཚོན་གཞི་གསུམ་ལས།
Enumeration Block 8:
ལྔ་པ་རྩེ་སྦྱོར་གྱི་དངོས་པོ་བརྒྱད་ལས།
Enumeration Block 9:
དྲུག་པ་མཐར་གྱིས་པའི་དངོས་པོ་བཅུ་གསུམ་ནི།
Enumeration Block 10:
བདུན་པ་སྐད་ཅིག་མའི་དངོས་པོ་བཞི་ནི། རྣམ་སྨིན་མིན་པ་དང་། རྣམ་སྨིན་དང་། མཚན་ཉིད་མེད་པ་དང་། གཉིས་སུ་མེད་པ་སྟེ།
Enumeration Block 11:
བརྒྱད་པ་ཆོས་སྐུའི་དངོས་པོ་བཞི་ལ་བཞི་ལས།
