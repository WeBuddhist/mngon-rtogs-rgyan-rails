Enumeration Block 1:
འགྲེལ་པས་རྒྱས་པར་བཤད་པ་ལ། དགོས་དོན། བསྡུས་དོན། ཚིག་དོན། མཚམས་སྦྱར། བརྒལ་ལན་གྱིས་གཏན་ལ་དབབ་པ་དང་ལྔའོ། །དང་པོ་ལ་གཉིས་ཏེ། དགོས་པ་སོ་སོའི་རང་བཞིན་དང་། ཐུན་མོང་གི་མཇུག་བསྡུ་བའོ། །དང་པོ་ལ་བཞི་སྟེ། ཐོས་པ་ལས་དང་བ་དང་། དང་བ་ལས་གུས་པ་དང་། གུས་པ་ལས་འཇུག་པ་དང་། ཞུགས་པ་ལས་ལེགས་པའི་མཆོག་ཐོབ་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། དང་བའི་རྐྱེན། དང་བའི་རང་བཞིན་ནོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས་ཏེ། དད་པའི་རྗེས་འབྲང་དང་། ཆོས་ཀྱི་རྗེས་འབྲང་དང་བའོ། །
Enumeration Block 3:
དེའི་རྒྱུ་མཚན་ལ། གནོད་བྱེད་མ་མཐོང་བ་དང་། སྒྲུབ་བྱེད་གཟུང་བ་གཉིས་སོ། །
Enumeration Block 4:
འདིའི་མཐའ་དཔྱད་པ་ལ་བཞི་ལས། གཅིག་དང་དུ་བྲལ་ལ། རྟགས་དགོད། དོན་གསུམ་གཏན་ལ་དབབ་པ་གཉིས་སོ། །
Enumeration Block 5:
གཉིས་པ་ལ། ཆོས་ཅན་གྱི་དོན། བསྒྲུབ་བྱའི་དོན། རྟགས་ཀྱི་དོན་དང་གསུམ་མོ། །
Enumeration Block 6:
གཉིས་པ་ལ། དགག་བྱའི་ཆོས། བསྒྲུབ་བྱའི་ཆོས། བསྒྲུབ་བྱ་དངོས་དང་གསུམ་མོ། །དང་པོ་ལ། དགག་གཞག་སྤང་གསུམ་ལས།
Enumeration Block 7:
གསུམ་པ་ལ། དགག་གཞག་སྤང་གསུམ་ལས། དང་པོ་ནི། བདེན་གཉིས་ཚོགས་པ་བསྒྲུབ་བྱར་འདོད་པ་དང་། བསྒྲུབ་བྱ་ཆ་གཉིས་སུ་འདོད་པ་དགག་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལ། ཕྱི་གཟུང་བ་དང་། ནང་འཛིན་པ་དང་། རྒྱུན་དང་སྐད་ཅིག་གི་དངོས་པོ་བདེན་མེད་དུ་བསྟན་པ་གསུམ་མོ། །དང་པོ་ལ། རགས་པ་དང་། རྡུལ་ཕྲན་གཅིག་བདེན་མེད་པར་བསྟན་པའོ། །
Enumeration Block 9:
གཉིས་པ་ལ་གཉིས་ཏེ། ཤེས་པ་རྣམ་བཅས་དགག །རྣམ་མེད་དགག་པའོ། །
Enumeration Block 10:
གསུམ་པ་ལ། རྒྱུན་དང་སྐད་ཅིག་དགག་པ་གཉིས་སོ། །
