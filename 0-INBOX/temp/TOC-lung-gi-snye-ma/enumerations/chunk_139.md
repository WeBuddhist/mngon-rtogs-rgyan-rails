Enumeration Block 1:
བཞི་པ་ལ་གསུམ་ལས།
Enumeration Block 2:
ལྔ་པ་ལ་གསུམ་ལས།
Enumeration Block 3:
རྩ་བ་ལ་གསུམ་སྟེ། སྦྱོར་བའི་ཡུལ། ཡུལ་ཅན་སྦྱོར་བའི་ངོ་བོ། ཁྱད་པར་གྱི་དབྱེ་བའོ། །
Enumeration Block 4:
སྦྱོར་བ་འདི་ནི་དབྱེ་ན། རྣམ་པ་བཅུ་སྟེ།
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ་སྟེ། འབྲེལ་དགོད་པས་མཚམས་སྦྱར། རྩེ་སྦྱོར་རྒྱས་པར་བཤད། སྐབས་བསྡུ་བའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་བཞི་སྟེ། སྦྱོར་མཐོང་། སྒོམ་ལམ་བར་ཆད་མེད་པའི་རྩེ་སྦྱོར་རོ། །
དང་པོ་ལ་གཉིས་ཏེ། སོ་སོར་བཤད་པ་དང་། བསྡུས་ཏེ་བསྟན་པའོ། །
Enumeration Block 7:
ལས་དང་པོ་ལ་གཉིས་ལས།
