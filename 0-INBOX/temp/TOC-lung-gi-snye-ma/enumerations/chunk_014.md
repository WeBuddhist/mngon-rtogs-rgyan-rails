Enumeration Block 1:
དབྱེ་ན། བཟོ་དང་། སྐྱེ་བ་དང་། བྱང་ཆུབ་མཆོག་གི་སྤྲུལ་པ་དང་། མྱ་ངན་ལས་འདའ་བར་སྟོན་པ་སྟེ་བཞིའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་དྲུག་སྟེ། སྒྲུབ་པ་དང་། སྦྱོར་བ་ལན་གཉིས་དང་། སྒོམ་ལམ་ལན་གསུམ་དང་། གང་ཟག་ལན་བཞི་དང་། རྟོག་པ་ལན་བཞི་དང་། མཐོང་ལམ་ལན་ལྔ་དང་། སྦྱོར་ལམ་ལན་དྲུག་སྟོན་པ་ལ་ཟློས་པ་སྤང་བའོ། །
Enumeration Block 3:
གསུམ་པ་ལ་གསུམ་སྟེ། མདོར་བསྟན། རྒྱས་བཤད། ལེགས་བཤད་དུ་བསྟན་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ་སྟེ། འཇུག་ཡུལ་མཁྱེན་གསུམ། འཇུག་པ་སྦྱོར་བཞི། ཞུགས་འབྲས་ཆོས་སྐུའི་ཡན་ལག་རྒྱས་བཤད་དོ། །དང་པོ་ལ། འབྲས་བུ་ཐུན་མོང་མ་ཡིན་པ་རྣམ་མཁྱེན། རྒྱུ་ཐུན་མོང་མ་ཡིན་པ་ལམ་ཤེས། རྒྱུའི་བླང་དོར་ཐུན་མོང་མ་ཡིན་པ་གཞི་ཤེས་ཀྱི་ཡན་ལག་རྒྱས་བཤད་གསུམ་མོ། །དང་པོ་ལ་གསུམ་སྟེ། མཚམས་སྦྱར། བརྗོད་བྱ་ཆོས་བཅུ་བཤད། སྐབས་བསྡུ་བའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་བཞི་སྟེ། ལམ་གྱི་རང་བཞིན་བྱང་ཆུབ་ཏུ་སེམས་བསྐྱེད་པ། དེ་རྣམ་པར་དག་བྱེད་གདམས་ངག་ནོད་པ། དེ་བསྒོམས་པའི་འབྲས་བུ་ངེས་འབྱེད་ཡན་ལག །གདམས་པའི་དོན་ཕྱིན་ཅི་མ་ལོག་པར་སྒྲུབ་པའོ། །དང་པོ་ལ། སྤྱི་གཞུང་གཉིས་སོ། །དང་པོ་ལ་གཉིས་ཏེ། སེམས་བསྐྱེད་སྡོམ་པའི་རང་བཞིན་གཏན་ལ་དབབ་པ་དང་། དེ་ཡང་དག་པར་བླངས་ཏེ་བསླབ་པའོ། །དང་པོ་ལ་གསུམ་སྟེ། སེམས་བསྐྱེད་ཀྱི་རང་བཞིན། སྡོམ་པའི་རང་བཞིན། དེ་དག་གི་ཁྱད་པར་རོ། །དང་པོ་ལ། རྒྱུ་ངོ་བོ་འབྲས་བུ་གསུམ་མོ། །རྒྱུ་ལ་གཉིས་ཏེ། སྐྱེ་བའི་དང། ལྡོག་པའི་རྒྱུའོ། །
Enumeration Block 6:
འདིར་བསྡུས་ན་གསུམ་སྟེ། སེམས་བསྐྱེད་ཆགས་པའི་རྟེན། ཉེར་ལེན་གྱི་རྒྱུ། དེའི་རྐྱེན་ནོ། །དང་པོ་ལ། ལུས་དང་། བསམ་པའི་རྟེན་གཉིས་ལས།
Enumeration Block 7:
གཉིས་པ་ལ། སྙིང་རྗེ། དད་པ། འདོད་པ་གསུམ་ལས།
Enumeration Block 8:
གཉིས་པ་ལ། མཚན་ཉིད། མཚོན་བྱ། མཚན་གཞི་གཏན་ལ་དབབ་པ་དང་གསུམ་མོ། །དང་པོ་ལ། དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 9:
གསུམ་པ་ལ། ངོ་བོ་ངོས་གཟུང་། དེ་གཏན་ལ་དབབ། དེའི་རབ་ཏུ་དབྱེ་བ་གསུམ་མོ། །དང་པོ་ལ། དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 10:
གསུམ་པ་ལ། ངོ་བོ་དང་། སྐྱེ་ཚུལ་དང་། ས་མཚམས་དང་། གྲོགས་དང་། བཞེད་ཚུལ་གྱིས་དབྱེ་བ་སྟེ། ལྔའོ། །
Enumeration Block 11:
དང་པོ་ནི། སྨོན་འཇུག་གཉིས་ཏེ།
