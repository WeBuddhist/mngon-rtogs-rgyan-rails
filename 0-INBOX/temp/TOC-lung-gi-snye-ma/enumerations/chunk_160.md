Enumeration Block 1:
ལྔ་པ་ལ་གསུམ་ལས།
Enumeration Block 2:
ངོ་བོ་བཞི་ལས།
Enumeration Block 3:
གཉིས་ལས།
Enumeration Block 4:
རྩ་བ་ལ་གསུམ་སྟེ། དུས་ཀྱི་སྒོ་ནས་མདོར་བསྟན། དབྱེ་བའི་སྒོ་ནས་རྒྱས་པར་བཤད། གྲངས་ཀྱི་སྒོ་ནས་དོན་བསྡུ་བའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ་སྟེ། ལམ་གྱི་རྟེན་དང་། ལམ་དང་། ལམ་འབྲས་ལ་འགོད་པའོ། །
Enumeration Block 6:
གསུམ་པ་ལ་བཞི་སྟེ། ཚོགས་སྦྱོར་མཐོང་ལམ་སྒོམ་ལམ་ལ་འགོད་པའོ། །
Enumeration Block 7:
དང་པོ་ལ་ལྔའི་དང་པོ། སེམས་ཅན་རྣམས་བསྡུ་བའི་དངོས་པོ་སྦྱིན་པ། ཚིག་སྙན་པ། དོན་སྤྱོད་པ། དོན་མཐུན་རྣམ་པ་བཞི་ལ་འགོད་པ་སྟེ།
Enumeration Block 8:
བཞི་པ་ལ་དྲུག་སྟེ། ས་ལྔ་པའི་བར་དང་། དྲུག་པ་དང་། བདུན་པ་དང་། བརྒྱུད་པ་དང་། དགུ་པ་དང་། བཅུ་པ་ལ་འགོད་པའོ། །
Enumeration Block 9:
བཞི་པ་ལ་གཉིས་ཀྱི་དང་པོ།
Enumeration Block 10:
དྲུག་པ་ལ་གསུམ་སྟེ། ས་བཅུ་ཐོབ་མ་ཐག་དང་། སྐྱེ་བ་གཅིག་གིས་ཐོགས་པ་དང་། སྲིད་པ་ཐ་མ་པ་ལ་འགོད་པའོ། །
Enumeration Block 11:
འདིར་དབང་བསྐུར་བའི་ཚུལ་ལ་གཉིས་ཏེ། སྣང་བས་འཕྲིན་ལས་སྒྲུབ་པ་དང་། མཆོད་པས་དབང་བསྐུར་ཐོབ་པའོ། །
Enumeration Block 12:
འཕྲིན་ལས་སྒྲུབ་པ་གསུམ་ལས།
Enumeration Block 13:
གཉིས་པ་ལ་གཉིས་ཏེ། མཆོད་པ་དང་། དབང་བསྐུར་བའོ། །
Enumeration Block 14:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ།
Enumeration Block 15:
གསུམ་པ་ལ་བཞི་སྟེ། ནུས་པ། རྟོགས་པ། སྤངས་པ། དག་པའི་རྒྱུ་ཚོགས་ཏེ། རེ་རེ་ལ་གཉིས་གཉིས་སོ། །
