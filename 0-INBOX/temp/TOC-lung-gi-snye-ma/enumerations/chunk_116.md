Enumeration Block 1:
གཉིས་པ་རྒྱས་བཤད་ལ་བཞི་སྟེ། ཀུན་འབྱུང་གི་རྣམ་པ་སྤང་གཉེན་གྱི་སྒོ་ནས་དང་། ལམ་དམ་བཅའ་དང་རྟགས་ཀྱི་དང་། དུཿཁ་རང་སྤྱིའི་མཚན་ཉིད་ཀྱི་དང་། འགོག་པ་སྟོང་ཉིད་ཀྱི་སྒོ་ནས་བསྟན་པའོ། །
Enumeration Block 2:
ངེས་འབྱུང་ལ་གཉིས་ལས།
Enumeration Block 3:
གསུམ་པ་ལ་གཉིས་ཀྱི་དང་པོ་མདོར་བསྟན་ལ་གསུམ་ལས།
Enumeration Block 4:
རྒྱས་བཤད་ལ་གསུམ་སྟེ། གཞི་ཤེས་དང་རྗེས་སུ་མཐུན་པའི་དང་། ལམ་ཤེས་དང་རྗེས་སུ་མཐུན་པའི་དང་། ཐུན་མོང་མིན་པ་རྣམ་མཁྱེན་གྱི་རྣམ་པ་བཤད་པའོ། །
Enumeration Block 5:
ཐམས་ཅད་ཤེས་པ་ཉིད་ཀྱི་རྣམ་པ་ལ་བདུན་ཏེ། དངོས་པོ་ལ་རྟོག་པའི་དང་། རྩོལ་བ་ལས་བྱུང་བའི་དང་། ཏིང་ངེ་འཛིན་ཡོངས་སུ་སྦྱོང་བའི་དང་། མངོན་པར་རྟོགས་པ་ལ་སྦྱོར་བའི་དང་། མངོན་པར་རྟོགས་པ་ལ་འབྲེལ་བའི་དང་། མངོན་པར་རྟོགས་པའི་དང་།རྣམ་པར་དག་པ་ངེས་པར་འབྱིན་པའི་ལམ་གྱི་རྣམ་པའོ། །
Enumeration Block 6:
དྲན་པ་ཉེར་གཞག་རྣམ་པ་བཞི་ལ། དམིགས་པ་དང་། ངོ་བོ་དང་། གྲོགས་དང་། སྒོམ་པ་དང་། བསྒོམས་པའི་འབྲས་བུ་དང་ལྔའོ། །
Enumeration Block 7:
འདི་ལ་གསུམ་ལས།
Enumeration Block 8:
དང་པོ་ལ་བཞི་སྟེ།
Enumeration Block 9:
ཡང་དག་པར་སྤོང་བའི་རྣམ་པ་བཞི་ལ་སྔར་བཞིན་ལྔ་ལས།
