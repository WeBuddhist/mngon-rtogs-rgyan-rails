Enumeration Block 1:
མཚོན་བྱ་ལ་གཉིས་ཏེ། སྤྱི་དང་བྱེ་བྲག་གི་མཚོན་བྱའོ། །
Enumeration Block 2:
གསུམ་པ་ལ། དབྱེ་བ་དང་། བསྡུ་བ་གཉིས་སོ། །དང་པོ་ལ། ངོ་བོ་དང་། བྱེད་ལས་ཀྱི་དབྱེ་བ་གཉིས་སོ། །
Enumeration Block 3:
གཉིས་པ་ལ་བཞི་སྟེ། རྒྱུ་བདུན་དང་། ཡན་ལག་བཞི་དང་། ལམ་གསུམ་དང་། ཉོན་མོངས་པ་གཉིས་སུ་བསྡུ་བའོ། །
Enumeration Block 4:
བཞི་པ་ལ། གོ་རིམ་དང་། ཐ་དད་དང་། རྐྱེན་བྱེད་ཚུལ་ངེས་པ་བསམ་པ་དང་། ལུགས་མཐུན་ལུགས་མི་མཐུན་བསྟན་པ་དང་བཞིའོ། །དང་པོ་ལ། ལུགས་མཐུན་གྱི་དང་། ལུགས་མི་མཐུན་གྱི་གོ་རིམ་མོ། །
Enumeration Block 5:
བཞི་པ་ལ་གཉིས་ཏེ། ཀུན་ནས་ཉོན་མོངས་ཀྱི་དང་། རྣམ་བྱང་གི་ལུགས་འབྱུང་ལུགས་ལྡོག་གོ །
Enumeration Block 6:
འགྲེལ་པ་ལ། མཉམ་རྗེས་གཉིས་ལས།
Enumeration Block 7:
གསུམ་པ་ལ་གསུམ་སྟེ། རྟེན་སྒོམ་པའི་ལམ། སྤང་བྱ་རྣམ་རྟོག །བརྟེན་པ་ཡོན་ཏན་ནོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 8:
རྩ་བ་ལ། དངོས་དང་། རྩོད་སྤང་ངོ་། །དང་པོ་ལ་གཉིས་ཏེ། སྦྱོར་བ་སེངྒེ་རྣམ་བསྒྱིངས་དང་། དངོས་གཞི་ཐོད་རྒལ་ལོ། །དང་པོ་ནི། འགོག་པ་དང་བཅས་པའི་སྙོམས་འཇུག་དགུ་ལ་ལུགས་དང་མཐུན་པ་དང་། ལུགས་དང་མི་མཐུན་པར་སྙོམས་པར་འཇུག་པ་གཉིས་སོ། །གཉིས་པ་ལ་གསུམ་སྟེ། དངོས་གཞི་ཙམ་དང༌། ཁྱད་པར་ཅན་དང༌། ཆེས་ཁྱད་པར་ཅན་ནོ། །
Enumeration Block 9:
འགྲེལ་པ་ལ། སྙོམས་པར་འཇུག་པའི་ཆོས་བཞི་སྟེ། གང་། གང་ལ། ཇི་ལྟར། དགོས་པ་ཅིའི་དོན་དུའོ། །
Enumeration Block 10:
འདི་ལ་སྦྱོར་དངོས་གཉིས་སོ། །
Enumeration Block 11:
གཉིས་པ་ལ་གསུམ་སྟེ། དངོས་གཞི་ཙམ་དང་། ཁྱད་པར་ཅན་དང་། ཆེས་ཁྱད་པར་ཅན་ནོ། །
Enumeration Block 12:

Enumeration Block 13:
རྒྱས་བཤད་ལ་གཉིས་ཏེ། གཟུང་རྟོག་འཛིན་རྟོག་གོ །དང་པོ་ལ་གཉིས་ཏེ། འཇུག་པ་དང༌། ལྡོག་པ་གཟུང་རྟོག་གོ །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 14:
རྩ་བ་ནི། རྟོག་པའི་ཡུལ། ངོ་བོ། སྦྱར་ཏེ་བཤད་པ། དེའི་གཉེན་པོ་བཞིའོ། །
Enumeration Block 15:
འགྲེལ་པ་ལ། རྟོག་པའི་ཡུལ། རྟོག་པའིངོ་བོ། རྟོག་པའི་གཉེན་པོ། རྟོགས་པའི་དབྱེ་གྲངས་དང་བཞིའོ། །འོག་མ་གསུམ་ཡང་འདི་བཞིན་ནོ། །
Enumeration Block 16:
གཉིས་པ་ལ་གཉིས་ཏེ། རྫས་འཛིན་དང་། བཏགས་འཛིན་ནོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 17:
རྩ་བ་ལ་གསུམ་སྟེ། ཡུལ། ངོ་བོ། སྦྱར་ཏེ་བཤད་པའོ། །

Enumeration Block 19:
