Enumeration Block 1:
གཉིས་པ་ལ། སྤྱི་གཞུང་གཉིས་སོ། །དང་པོ་ལ་བཞི་སྟེ། བདེན་བཞིའི་མཚན་ཉིད། དབྱེ་བ། རང་བཞིན། རྩོད་སྤང་ངོ༌། །
Enumeration Block 2:
གཉིས་པ་ལ་བཞི་ལས།
Enumeration Block 3:
གསུམ་པ་ལ། སྡུག་ཀུན་འགོག་ལམ་བཞི་ལས། དང་པོ་ལ། མཚན་གཞི་དང་། མཚན་ཉིད་གཉིས་སོ། །
Enumeration Block 4:
གཉིས་པ་ལ། རང་མཚན། སྤྱི་མཚན་གཉིས་ལས།
Enumeration Block 5:
གཉིས་པ་ལ། མཚན་གཞི་དང་། མཚན་ཉིད་གཉིས་ལས།
Enumeration Block 6:
དང་པོ་ལ། རྒྱུ། ངོ་བོ། འབྲས་བུ། སྤོང་ཚུལ་བཞིའོ། །
Enumeration Block 7:
ངོ་བོ་ལ། མཚན་ཉིད། དབྱེ་བ་གཉིས་སོ། །
Enumeration Block 8:
གཉིས་པ་ལ། མཐོང་སྤང་དང་། སྒོམ་སྤང་དང་། དེ་དག་ལ་རྩོད་པ་སྤང་བ་གསུམ་ལས། དང་པོ་ལ། ཉན་ཐོས་ཀྱི་དང་། ཐེག་ཆེན་གྱི་ལུགས་སོ། །
Enumeration Block 9:
དེའང་ལོག་པར་ཞུགས་ཚུལ་གྱིས་ཕྱེ་ན། སྡུག་ཀུན་ལ་དངོས་སུ་དང་། ལོག་པ་ལ་དང་། དབང་གིས་ལོག་ཞུགས་དང་གསུམ། འགོག་ལམ་ལ་དངོས་སུ་དང་། ལོག་པ་ལ་ལོག་ཞུགས་གཉིས་སོ། །
