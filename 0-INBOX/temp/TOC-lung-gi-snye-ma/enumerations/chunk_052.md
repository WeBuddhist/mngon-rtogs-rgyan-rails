Enumeration Block 1:
དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 2:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 3:
རྩ་བ་ལ་གསུམ་སྟེ། སྤྱིར་རྒྱུ་རྐྱེན་གྱི་མཚན་ཉིད། གང་གང་ལས་སྐྱེ་ཚུལ། གཞུང་ལ་སྦྱར་བའོ། །
Enumeration Block 4:
གསུམ་པ་ལ་གཉིས་ཏེ། མདོར་བསྟན་ལ་གཉིས་ལས།
Enumeration Block 5:
འགྲེལ་པ་ལ་གསུམ་སྟེ། བསལ་བྱ། སེལ་བྱེད། དེས་བསྙད་ཚུལ་ལོ། །
Enumeration Block 6:
རྒྱས་བཤད་ལ་གསུམ་ལས།
Enumeration Block 7:
རྩ་བ་ལ། བསལ་བྱ་ཀླན་ཀ། སེལ་བྱེད་ལན། དེ་གཉིས་སྦྱར་ཏེ་བཤད་པའོ། །དང་པོ་ལ། ལོག་པར་རྟོག་པའི་ཆོས་བཞི་སྟེ། ཡུལ་གང་ལ། གང་ཟག་དང་། ཇི་ལྟར། གྲངས་ངེས་སོ། །
Enumeration Block 8:
འགྲེལ་པ་ལ་གསུམ་སྟེ། བསལ་བྱ་ཀླན་ཀ། སེལ་བྱེད་ལན། བསལ་ནས་ཏིང་ངེ་འཛིན་སྐྱེད་ཚུལ་ལོ། །དང་པོ་ལ་ལྔ་སྟེ། ལོག་པར་རྟོག་པའི་ཡུལ། རྟོག་བྱེད་གང་ཟག །རྟོག་པའི་ངོ་བོ། རྟོག་པའི་གྲངས། རྟོག་ཚུལ་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 9:
གསུམ་པ་ལ་བཞི་སྟེ། སྔ་འགྲེལ། རྩ་བ། འགྲེལ་པ། སྐབས་བསྡུ་བའོ། །
Enumeration Block 10:
འགྲེལ་པ་ལ། གསུམ་སྟེ། གང་། གང་དུ། ཇི་ལྟར་བཞེད་པའོ། །
Enumeration Block 11:
དང་པོ་ལ་གསུམ་སྟེ། ཕྱིན་དྲུག་དང་། རྗེས་དྲན་དྲུག་དང་། དངོས་མེད་ངོ་བོ་ཉིད་དོ། །
Enumeration Block 12:
བཞི་པ་ལ་གསུམ་སྟེ། འབྲེལ་བཀོད་པས་མཚམས་སྦྱར། སྐད་ཅིག་མ་རྒྱས་པར་བཤད། སྐབས་བསྡུ་བའོ། །དང་པོ་ལ། ངོ་བོ་དང་། དབྱེ་བ་གཉིས་སོ། །
Enumeration Block 13:
གཉིས་པ་ལ་བཞི་སྟེ། རྣམ་སྨིན་མིན་པ་དང༌། རྣམ་སྨིན་དང་། མཚན་ཉིད་མེད་པ་དང་། གཉིས་སུ་མེད་པའི་སྐད་ཅིག་མའོ། །དང་པོ་ལ། དོན་དགོད་པ་དང་། དེ་ཉིད་དཔེས་སྒྲུབ་པའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 14:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 15:
གཉིས་པ་ལ་གསུམ་ལས།
