Enumeration Block 1:
གསུམ་པ་ལ་རྩོད་ལན་གཉིས་ཀྱི་རྩོད་པ་ལ་གསུམ་ལས།
Enumeration Block 2:
འགྲེལ་པ་ལ་གཉིས་ཏེ། ཐལ་བ་དགོད་པ་དང་། དེའི་རྟགས་སྒྲུབ་པའོ། །
Enumeration Block 3:
དེ་སྒྲུབ་པ་ལ་གསུམ་སྟེ། སྔ་ཕྱི་རེ་རེས་དང་། མང་པོ་གཅིག་ཅར་འབྱུང་བས་དང་། མང་པོ་རིམ་གྱིས་འབྱུང་བས་མི་སྐྱེད་པར་བསྟན་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 5:
འགྲེལ་པ་ལ། དཔེ་དོན་གཉིས་ལས། དཔེ་ལ་གསུམ་སྟེ། ལྟོས་མེད་དུ་མི་བསྲེག་པ་དང་། ལྟོས་ནས་བསྲེག་པ་དང་། དོན་བསྡུ་བའོ། །དང་པོ་ལ། སྐད་ཅིག་དང་པོ་དང་། ཕྱི་མས་མི་བསྲེག་པ་གཉིས་སོ། །
Enumeration Block 6:
གསུམ་པ་ལ་གསུམ་ལས།
Enumeration Block 7:
གསུམ་པ་ལ་གསུམ་ལས།
Enumeration Block 8:
གཉིས་པ་ལ་བཞི་ལས། ལས་མེད་པ་དང་། ཧ་ཅང་ཐལ་བ་དང་། ལུང་དང་འགལ་བ་དང་། རྨི་ལམ་ན་ལམ་གསོག་པར་ཐལ་བའི་ཀླན་ཀ་སྤང་བའོ། །
