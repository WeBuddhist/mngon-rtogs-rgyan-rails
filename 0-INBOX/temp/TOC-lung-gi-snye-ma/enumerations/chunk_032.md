Enumeration Block 1:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 2:
དབྱེ་ན་དུ་ཞེ་ན། དགུ་ཡོད་དེ།
Enumeration Block 3:
འདིའི་མཐའ་དཔྱད་པ་ལ། ངོ་བོ་དང༌། ཡན་ལག་དང་། སྙོམས་པར་འཇུག་པ་དང་། ཉོན་མོངས་པ་དང་། རྣམ་བྱང་དང་། ཚད་དང་དྲུག་གོ། །
Enumeration Block 4:
བསམ་གཏན་དང་པོ་ལ་ཡན་ལག་ལྔ་སྟེ།
Enumeration Block 5:
གཉིས་པ་ལ་ཡན་ལག་བཞི་སྟེ།
Enumeration Block 6:
གསུམ་པ་ལ་ཡན་ལག་ལྔ་སྟེ།
Enumeration Block 7:
བཞི་པ་ལ། ཡན་ལག་བཞི་སྟེ།
Enumeration Block 8:
ཡིད་ལ་བྱེད་པ་བདུན་གྱིས་བསམ་གཏན་དང་པོ་ལ་སྙོམས་པར་འཇུག་སྟེ། མཚན་ཉིད་རབ་ཏུ་རིག་པ་དང་། མོས་པ་ལས་བྱུང་བ་དང༌། རབ་ཏུ་དབེན་པ་དང༌། དགའ་བ་སྡུད་པ་དང༌། དཔྱོད་པ་དང༌། སྦྱོར་བའི་མཐའ་དང༌། སྦྱོར་བའི་མཐའི་འབྲས་བུ་ཡིད་ལ་བྱེད་པའོ། །
Enumeration Block 9:
ཚད་མེད་བཞི་ལ། རྒྱུ། ངོ་བོ། འབྲས་བུའོ། །
Enumeration Block 10:
ངོ་བོ་ལ། མཚན་མཚོན་གཞི་གསུམ་ལས།
Enumeration Block 11:
གསུམ་པ་ལ། གསུམ་དང༌། དྲུག༌དང༌། བཅུར་དབྱེ་བའོ། །དང་པོ་ལ། སྤྱིའི་དབྱེ༌བ༌དང༌། བྱེ་བྲག༌གི༌དབྱེ་བ་གཉིས་སོ། །དང་པོ་ལ། ལྟ་བ་དང༌། ས་མཚམས་དང༌། དམིགས་པ་དང༌། བསམ་པའི་སྒོ་ནས་དབྱེ་བ་བཞིའོ། །
Enumeration Block 12:
འབྲས་བུ་ལ་གཉིས་ཏེ། མ་བསྒོམས་པའི་ཉེས་དམིགས་དང༌། བསྒོམས་པའི་ཕན་ཡོན་ནོ། །
Enumeration Block 13:
གཉིས་པ་ལ་གསུམ་སྟེ། གནས་སྐབས་ཀྱི་དང༌། གཙོ་བོར་སྙིང་རྗེའི་དང༌། མཐར་ཐུག་གི་འབྲས་བུའོ། །
Enumeration Block 14:
གསུམ་པ་ལ་གཉིས་ཏེ། ཚོགས་སྒྲུབ་བཅུ་བདུན་སྤྱིར་བསྟན་པ་དང༌། རྟོགས་དཀའ་བ་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 15:
དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 16:
འགྲེལ་པ་ལ། ངོ་བོ། ངེས་ཚིག །གྲངས་ངེས་གསུམ་མོ། །
Enumeration Block 17:
འདི་ལ་གསུམ། ངོ་བོ། དབྱེ་བ། བྱེད་ལས་སོ། །
