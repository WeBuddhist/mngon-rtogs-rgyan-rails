Enumeration Block 1:
གཉིས་པ་སྤྲུལ་པའི་ལམ་ལ་གཉིས་ཏེ། རྣམ་པ་སྤྱིའི་ངོ་བོ་དང་། ཁྱད་པར་སྡུག་པའི་རྣམ་ཐར་རོ། །དང་པོ་ལ་གཉིས་ཏེ། གཟུགས་ཅན་གཟུགས་ལ་ལྟ་བ་དང་། གཟུགས་མེད་གཟུགས་ལ་ལྟ་བ་གཉིས་སོ། །
Enumeration Block 2:
གཉིས་པ་ལ། སྒོམ་གཞིར་བྱས་པའི་ཆོས་བཞི་སྟེ།
Enumeration Block 3:
འདུ་ཤེས་གསུམ་སྟེ་ཕན་ཚུན་ལྟོས་པའི་དང་། རྗེས་སུ་འབྲེལ་པའི་དང་། རོ་གཅིག་པའི་འདུ་ཤེས་སོ། །
Enumeration Block 4:
གསུམ་པ་ནི། གཞན་གྱི་དོན་གྱི་ཆེད་དུ་བྱ་བ་ཅན། རང་གི་དོན་མཐོང་བའི་ཆོས་ཚེ་འདི་ལ་ལུས་སེམས་བདེ་བར་གནས་པའི་ལམ་ལ་གཉིས་ལས།
Enumeration Block 5:
བཞི་པ་ལ། ལོ་ཀ་ལས་འདས་པའི་ལམ་ལ། མཐར་གྱིས་གནས་པའི་སྙོམས་འཇུག་གི་རྣམ་པ་དགུའོ། །
Enumeration Block 6:
འགོག་པའི་སྙོམས་པར་འཇུག་པ་ལ་བདུན་ཏེ། གང་ཟག་གང་གིས་དང་། སེམས་གང་ལ་བརྟེན་ནས་དང་། ཡིད་ལ་བྱེད་པ་གང་གིས་དང་། དགག་བྱ་གང་འགོག་པ་དང་། ངོ་བོ་དང་། དུས་དང་། རྟེན་གང་གིས་སྙོམས་པར་འཇུག་པའོ། །
Enumeration Block 7:
ལྔ་པ་ཉོན་མོངས་པ་སྤོང་བའི་ལམ་ལ། བདེན་པ་བཞིས་བསྡུས་པ་ཀུན་ནས་ཉོན་མོངས་པ་དང་མི་ལྡན་པའི་མཚན་ཉིད་བཟོད་པ་བར་ཆད་མེད་པའི་ལམ་གྱི་རྣམ་པ། བདེན་བཞི་ལ་བརྟེན་པའི་བྱེ་བྲག་གིས་བཞིའོ། །
Enumeration Block 8:
དྲུག་པ། སངས་རྒྱས་ཉིད་ཀྱི་ལམ་ལ། སྦྱིན་པ་ལ་སོགས་ཕར་ཕྱིན་བཅུའི་རྣམ་པ་བཅུ་སྟེ།
Enumeration Block 9:
གསུམ་པ་ལ་གཉིས་སོ། །
Enumeration Block 10:
རྒྱས་བཤད་ལ་བཞི་སྟེ། ཡོན་ཏན་གྱི་དབྱེ་བ་དང་། དེ་བཞིན་ཉིད་དང་། རང་བྱུང་དང་། སངས་རྒྱས་ཀྱི་རྣམ་པའོ། །དང་པོ་ལ་བཞི་སྟེ། སྟོབས་བཅུ་དང་། མི་འཇིགས་པ་བཞི་དང་། སོ་སོར་ཡང་དག་རིག་པ་བཞི་དང་། ཆོས་མ་འདྲེས་པ་བཅོ་བརྒྱད་དོ། །
Enumeration Block 11:
རང་བྱུང་སྟེ། འདི་ལ་གཉིས་ཏེ། ཆོས་ཀྱི་དབྱིངས་དང་། རྣམ་མཁྱེན་གྱི་ཡེ་ཤེས་སོ། །
Enumeration Block 12:
གཉིས་པ་ལ་གསུམ་སྟེ།
Enumeration Block 13:
རྩ་བ་ལ་བཞི་སྟེ། ཉན་པ་དང་། ལེན་པ་དང་། མི་བརྗེད་པ་དང་། ཚུལ་བཞིན་ཡིད་ལ་བྱེད་པའི་སྣོད་དོ། །
Enumeration Block 14:
གསུམ་པ་ལ་གསུམ་སྟེ།
Enumeration Block 15:
འདི་ལ་གཉིས་ཏེ། རང་བཞིན་གྱི་སྦྱོར་བ་ལྔ། གནས་སྐབས་ཀྱི་སྦྱོར་བ་བཅོ་ལྔའོ། །
