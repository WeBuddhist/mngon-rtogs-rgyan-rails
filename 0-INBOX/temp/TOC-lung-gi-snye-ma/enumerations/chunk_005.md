Enumeration Block 2:
གཉིས་པ་ལ་སྤྱི་གཞུང་གཉིས་སོ། །དང་པོ་ལ། རྟགས་དགོད། དོན་གསུམ་གཏན་ལ་དབབ་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 4:
རྟགས་ལ། ཕྱོགས་ཆོས་དང་ཁྱབ་པ་སྒྲུབ་པ་གཉིས་ལས། དང་པོ་ལ། རྟེན་བརྟན་པ་ནི། རིག་པ་འདས་པ་དང་མ་འོངས་པ་ཐུག་མེད་དུ་སྒྲུབ་པ་གཉིས་ལས།
Enumeration Block 5:
གསུམ་པ་ལ། གང་ཟག་གསུམ་གྱི་བཞེད་དོན་སྒྲུབ་པ་དང་། དོན་བསྡུས་ཏེ་སངས་རྒྱས་འཁོར་བཅས་ཀྱི་ཡུམ་དུ་བསྒྲུབས་པས་ཕྱག་འཚལ་བ་གཉིས་སོ། །དང་པོ་ལ། རྩ་བ་བཞིན་གསུམ་ལས།
Enumeration Block 6:
ལྔ་པ་ལ། བརྒལ་བ་དང་། ལན་གཉིས་སོ། །
Enumeration Block 7:
གཉིས་པ་ལ། རྟགས་དགོད། ཁྱབ་པ་སྒྲུབ། དོན་བསྡུ་གསུམ་མོ། །
Enumeration Block 8:
གཉིས་པ་ལ། ཁྱབ་པ་གྲུབ་ཚུལ། དེའི་ཤེས་བྱེད་དྲང་། དྲངས་པའི་དོན་བསྡུས་ཏེ་བཤད་པ་གསུམ་མོ། །
Enumeration Block 9:
གཉིས་པ་ལ་གསུམ་སྟེ། བར་མ་དང་། བསྡུས་པ་དང་། རྒྱས་པའི་ལུང་དྲང་པའོ། །དང་པོ་ལ། མདོར་བསྟན། རྒྱས་བཤད་གཉིས་ལས།
Enumeration Block 10:
གཉིས་པ་ལ་གསུམ་སྟེ། གཞི་ཤེས་ཀྱིས་ཉན་རང་དང་། ལམ་ཤེས་ཀྱིས་བྱང་སེམས་དང་། རྣམ་མཁྱེན་གྱིས་སངས་རྒྱས་ཀྱི་མངོན་རྟོགས་བསྡུས་ཚུལ་ལོ། །དང་པོ་ལ། དྲིས་ལན་གཉིས་ལས།
Enumeration Block 11:
གཉིས་པ་ལ་གཉིས་ལས།
Enumeration Block 12:

Enumeration Block 13:
གཉིས་པ་གསུམ་ལས།
Enumeration Block 14:
གང་གསུངས་པ་བརྗོད་བྱ་དང་། གང༌གི་དོན་དུ་གསུངས་པ་དགོས་པ་གཉིས་སོ། །
Enumeration Block 15:
གཉིས་པ་ལ། དགོས་པ་དང་། ཉིང་དགོས་གཉིས་ལས། དང་པོ་ལ། རྣམ་བཅད་དང་། ཡོངས་གཅོད་ཀྱི་དགོས་པ་གཉིས་སོ། །
Enumeration Block 16:
རྩ་བ་ལ་དགོས་བསྡུས་ཚིག་གསུམ་མོ། །དང་པོ་ལ། དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 17:
གསུམ་པ་ལ། རྣམ་བཅད་དང་ཡོངས་གཅོད་ཀྱི་དགོས་པ་ལ་རྩོད་པ་སྤང་བ་གཉིས་སོ། །
