Enumeration Block 1:
གསུམ་པ་ལ་གསུམ་ལས།
Enumeration Block 2:
གཉིས་པ་ལ་བཞི་ལས།
ལས་མེད་པ་དང་། ཧ་ཅང་ཐལ་བ་དང་། ལུང་དང་འགལ་བ་དང་། རྨི་ལམ་ན་ལམ་གསོག་པར་ཐལ་བའི་ཀླན་ཀ་སྤང་བའོ། །
Enumeration Block 3:
འགྲེལ་པ་ལ་གཉིས་ཏེ། དངོས་ཀྱི་དོན་དང་། ཀླན་ཀ་སྤང་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས་ཏེ་ཀླན་ཀ་དང་། ལན་ནོ། །
Enumeration Block 5:
གཉིས་པ་ལན་ནི། གཉིས་ཏེ། དོན་མི་རིགས་པ་དང་། དཔེ་མ་གྲུབ་པའོ། །
དང་པོ་ལ་གཉིས་ཏེ། ཉན་ཐོས་རང་ལ་གྲུབ་པ་དཔེར་བསྟན། དེ་དབུ་མ་པ་ལའང་མཚུངས་པར་བསྟན་པའོ། །
དང་པོ་ལ་གསུམ་སྟེ། ཉན་ཐོས་པའི་འདོད་པ་བསྟན། དེ་ལ་ཐལ་བ་དགོད། དེའི་ལན་ནོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས་ཏེ། ལུང་གཞན་གྱི་དང་། ལུང་འདིའི་དོན་བཤད་པས་དཔེ་མ་གྲུབ་པར་བསྟན་པའོ། །
Enumeration Block 7:
བཞི་པ་ལ་གསུམ་ལས།
Enumeration Block 8:
ལྔ་པ་ལ་གསུམ་ལས།
