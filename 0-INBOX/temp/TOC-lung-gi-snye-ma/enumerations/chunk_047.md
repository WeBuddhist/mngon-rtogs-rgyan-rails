Enumeration Block 1:
དྲོད་རྩེ་བཟོད་མཆོག་བཞི་ལས།
Enumeration Block 2:
ལན་ལ་གཉིས་ཏེ། སྐབས་དང་པོ་གསུམ་གྱི་ལམ་གསུམ་མཚན་ཉིད་པར་བསྟན། འོག་མ་གསུམ་གྱི་ལམ་གསུམ་བཏགས་པར་བསྟན་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གསུམ་གྱི་མདོར་བསྟན་ལ་གསུམ་ལས།
Enumeration Block 4:
རྩ་བ་ལ་གསུམ་ལས།
Enumeration Block 5:
རྒྱས་པར་བཤད་པ་ལ་གསུམ་སྟེ། སྦྱོར་མཐོང་སྒོམ་གསུམ་པ་ཕྱིར་མི་ལྡོག་ཏུ་སྒྲུབ་པའོ། །དང་པོ་ལ་གཉིས་ཏེ། མདོར་བསྟན་ལ་གསུམ་ལས།
Enumeration Block 6:
རྒྱས་བཤད་ལ་གསུམ་ལས།
Enumeration Block 7:
རྩ་བ་ལ་བཞི་སྟེ། དྲོད་རྩེ་བཟོད་མཆོག་གི་མཚན་ཉིད་དོ། །
Enumeration Block 8:
གོ་རིམ་བཞིན་དུ་དྲོད་ཀྱི་བཅུ་གཅིག །རྩེ་མོའི་དྲུག །བཟོད་པའི་གཉིས། ཆོས་མཆོག་གི་གཅིག་སྟེ། རྟགས་ཉི་ཤུ་པོ་འདི་དེ་དག་གིས་སོ། །
Enumeration Block 9:
གཉིས་པ་ལ་གཉིས་ཀྱི་མདོར་བསྟན་ལ་གསུམ་ལས།
Enumeration Block 10:
རྒྱས་བཤད་ལ་གསུམ་ལས།
Enumeration Block 11:
འདིའི་མཐའ་དཔྱད་པ་ལ། ཆོས་ལྔ་ངོས་བཟུང་། དེ་འགོག་ཚུལ་ལོ། །དང་པོ་ལ། དབང་པོ། དབང་རྟེན། དབང་ཡུལ། བདག ། བདག་གི་བ་སྟེ། ལྔའོ། །
Enumeration Block 12:
འགྲེལ་པ་ལ། སྐད་ཅིག་མ་བཅུ་དྲུག་བཤད། དེས་ཕྱིར་མི་ལྡོག་ཏུ་སྒྲུབ་པ་གཉིས་སོ། །
Enumeration Block 13:
གསུམ་པ་ལ་གསུམ་སྟེ། སྒོམ་ལམ་གྱི་ཁྱད་པར་བྱེད་ཆོས། ཁྱད་པར་གྱི་གཞི་སྒོམ་ལམ། སྒོམ་ལམ་རྟགས་ཀྱི་དོན་བསྟན་པའོ། །
Enumeration Block 14:
དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 15:
རྩ་བ་ལ་གསུམ་སྟེ། ཟབ་པར་བསྟན། ཟབ་པའི་ངོ་བོ། ཟབ་པར་སྒྲུབ་པའོ། །
Enumeration Block 16:
འགྲེལ་པ་ལ་གསུམ་ལས།
Enumeration Block 17:
གཉིས་པ་ལ་གསུམ་སྟེ། སྒོམ་ཚུལ། ཚུལ་དེ་ལྡན་གྱི་དབྱེ་བ། ཕྱེ་བའི་བྱེད་པའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 18:
གཉིས་པ་ལ་གཉིས་ཏེ། དགུར་དབྱེ་བ་དང་། གྲངས་ཉུང་བའི་རྩོད་སྤང་ངོ་། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 19:
གཉིས་པ་ལ། རྩོད་ལན་གཉིས་ལས།
Enumeration Block 20:
ལན་ལ་གཉིས་ལས། རྩ་བ་ལ་གཉིས་ཏེ། དོན་དམ་དུ་རྟགས་མ་གྲུབ་དང་། ཀུན་རྫོབ་ཏུ་ཁྱབ་པ་མ་གྲུབ་པའོ། །
Enumeration Block 21:
འགྲེལ་པ་ལ་གཉིས་ལས།
Enumeration Block 22:
གཉིས་པ་ལ་གསུམ་སྟེ། རྩོད་པ་དང་། ལན་དང་། ལན་ལ་རྩོད་སྤང་ངོ་། །དང་པོ་ལ་གསུམ་སྟེ།
