Enumeration Block 1:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 2:
འགྲེལ་པ་ལ་གསུམ་སྟེ། ཡུལ་བདེན་མེད་དུ་རྟོགས་ན། ཡུལ་ཅན་སྤང་ནུས་པར་བསྟན། ཡུལ་བདེན་པར་གྲུབ་ན། ཡུལ་ཅན་སྤང་མི་ནུས་པར་བསྟན། དེས་ན་འགལ་བ་ཁས་བླངས་པར་བསྟན་པའོ། །
Enumeration Block 3:
དང་པོ་ལ། རྣལ་འབྱོར་གྱི་ས་བཞི་སྟེ། བདག་མེད་པ་ལ་དམིགས་པ་དང་། སེམས་ཙམ་དང་། དེ་བཞིན་ཉིད་དང་། སྣང་བ་མེད་པ་ལ་དམིགས་པའི་རྣལ་འབྱོར་གྱི་སའོ། །དང་པོ་ནི། ལྟ་བ་ཆོས་བདག་མེད་དུ་གཏན་ལ་དབབ། དེ་སྒོམ་པའི་ཚུལ། བསྒོམས་པའི་འབྲས་བུའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ་སྟེ། ལྟ་བ་སེམས་ཙམ་དུ་གཏན་ལ་དབབ། དེ་སྒོམ་པའི་ཚུལ། བསྒོམས་པའི་འབྲས་བུའོ། །
Enumeration Block 5:
འདི་ལ་ཆོས་ཅན། དམ་བཅའ། རྟགས་གསུམ་མོ། །
Enumeration Block 6:
བཞི་པ་ལ་གསུམ་སྟེ། ལྟ་བ་མཐའ་བྲལ་བསྟན། དེ་སྒོམ་པའི་ཚུལ། དེ་བསྒོམས་པའི་འབྲས་བུའོ། །
Enumeration Block 7:
གསུམ་པ་ལ་གསུམ་ལས།
Enumeration Block 8:
རྩ་བ་ལ་གསུམ་སྟེ། ལྟ་བ་ཆོས་ཐམས་ཅད་མཐའ་བྲལ་དུ་བསྟན། དེ་རྟོགས་ཡང་དག་པའི་ལྟ་བ། རྟོགས་ནས་གྲོལ་ཚུལ་ལོ། །
Enumeration Block 9:
བཞི་པ་ལ་གཉིས་ཏེ། མཐོང་ལམ་རྩེ་སྦྱོར་གྱི་ངོ་བོ་དང་། དེའི་བྱེད་པའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 10:
རྩ་བ་ལ། ཡུལ་ཡུལ་ཅན་གཉིས་ལས།
Enumeration Block 11:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 12:
རྩ་བ་ལ། མཉམ་རྗེས་གཉིས་ལས།
Enumeration Block 13:
དེ་ལའང་སྐད་ཅིག་མ་དང་། འབྲེལ་བ་ཅན་དང་། གནས་སྐབས་པ་དང་། རྒྱུན་ཆགས་པ་སྟེ། བཞིའོ། །
Enumeration Block 14:
འདི་ལ་དབྱེ་ན། ཐོགས་མེད་ཀྱིས་བརྒྱད་བཤད་དེ།
Enumeration Block 15:
བཞི་པ་ལ་བཞི་སྟེ། མཚན་ཉིད། མཚོན་བྱ། མཚན་གཞིའི་དབྱེ་བསྡུ། ངེས་པ་བསམ་པའོ། །
Enumeration Block 16:
མཚོན་བྱ་ལ་གཉིས་ཏེ། སྤྱི་དང་བྱེ་བྲག་གི་མཚོན་བྱའོ། །
Enumeration Block 17:
གསུམ་པ་ལ། དབྱེ་བ་དང་། བསྡུ་བ་གཉིས་སོ། །དང་པོ་ལ། ངོ་བོ་དང་། བྱེད་ལས་ཀྱི་དབྱེ་བ་གཉིས་སོ། །
Enumeration Block 18:
གཉིས་པ་ལ་བཞི་སྟེ། རྒྱུ་བདུན་དང་། ཡན་ལག་བཞི་དང་། ལམ་གསུམ་དང་། ཉོན་མོངས་པ་གཉིས་སུ་བསྡུ་བའོ། །
