Enumeration Block 1:
འགྲེལ་པ་ལ་གཉིས་ཏེ། དངོས་བསྟན་བྱང་སེམས་ཀྱི་དང་། ཤུགས་བསྟན་ཉན་རང་གི་མཐོང་ལམ་མོ། །
Enumeration Block 2:
གསུམ་པ་ལ་གསུམ་ལས།
Enumeration Block 3:
རྣལ་འབྱོར་ཉམས་སུ་ལེན་པའི་སྦྱོར་བ་ལ་བཞི་སྟེ། དབང་ཐོབ་པའི་དོན་དུ་སྒོམ་པ་རྣམ་ཀུན། དབང་ཐོབ་པའི་ཚུལ་གྱིས་སྒོམ་པ་རྩེ་སྦྱོར། བརྟན་པ་ཐོབ་པའི་དོན་དུ་སྒོམ་པ་མཐར་གྱིས་པ། བརྟན་པ་ཐོབ་ནས་གཅིག་ཅར་སྒོམ་པ་སྐད་ཅིག་མའོ། །དང་པོ་ལ། མཚམས་སྦྱར། སྦྱོར་བ་རྒྱས་བཤད། སྐབས་བསྡུ་བ་གསུམ་མོ། །
Enumeration Block 4:
གཉིས་པ་ལ། རྣམ་ཀུན་ཙམ་དང་། རྣམ་ཀུན་ཁྱད་པར་ཅན་གྱི་སྒོམ་རིམ་གཉིས་སོ། །དང་པོ་ལ་བཞི་སྟེ། སྦྱར་ས་རྣམ་པ། སྦྱོར་བ་པོ་གང་ཟག །སྦྱོར་བ་རང་གི་ངོ་བོ། །སྦྱོར་བའི་སྔོན་འགྲོའོ། །དང་པོ་ལ་གསུམ་སྟེ། མདོར་བསྟན། རྒྱས་བཤད། དོན་བསྡུ་བའོ། །མདོར་བསྟན་ལ་གཉིས་ཏེ། རྩ་བ་ལ། སྤྱི་གཞུང་གཉིས་སོ། །དང་པོ་ལ། དགག་གཞག་སྤང་གསུམ་ལས།
Enumeration Block 5:
འདི་ལ་གསུམ་ལས།
Enumeration Block 6:
མཚན་གཞི་ལ་བཞི་ལས། དབྱེ་གཞི། རྣམ་པ་ཙམ་མོ། །དབྱེ་ངོ་དོན་རྣམ་དང་། ཤེས་རྣམ་གཉིས་སོ། །དོན་རྣམ་ལ། བདེན་པ་བཞིའི་རྣམ་པ་རིམ་པ་ལྟར་དགུ། བཅུ་གཉིས། ཉི་ཤུ། བརྒྱ་སོ་གཉིས་སོ། །ཤེས་རྣམ་ལ། གཞི་ཤེས་ཀྱི་རྣམ་པ་ཉི་ཤུ་རྩ་བདུན། ལམ་ཤེས་ཀྱི་རྣམ་པ་སོ་དྲུག །རྣམ་མཁྱེན་གྱི་རྣམ་པ་བརྒྱ་དང་བཅུའོ། །
Enumeration Block 7:
གཉིས་པ་ནི། ངོ་བོ་དང་། དབྱེ་བ་གཉིས་སོ། །
Enumeration Block 8:
གཉིས་པ་ལ་བཞི་ལས། གཉེན་པོའི་ཕྱོགས་ཤེས་པའི་རྣམ་པ་དེ་ནི། དབྱེ་གཞི། དབྱེ་ངོ་གཞི་ཤེས་ཀྱི་དང་། ལམ་ཤེས་ཀྱི་དང་། རྣམ་མཁྱེན་གྱི་རྣམ་པ་སྟེ། རྣམ་པ་གསུམ་དུ་འདོད་དོ། །
Enumeration Block 9:
འགྲེལ་པ་ལ་གཉིས་ཏེ། ངོ་བོ་དང་། དབྱེ་བའོ། །
Enumeration Block 10:
གཉིས་པ་ལ་གསུམ་ལས། དབྱེ་གཞི་རྣམ་པ་དེ་དག་ཀྱང་དབྱེ་ངོ་རྣམ་པ་གསུམ་མོ། །
Enumeration Block 11:
གཉིས་པ་ལ་གསུམ་སྟེ། གཞི་ཤེས་ཀྱི་དང། ལམ་ཤེས་ཀྱི་དང་། རྣམ་མཁྱེན་གྱི་རྣམ་པ་བཤད་པའོ། །དང་པོ་ལ། སྔ་འགྲེལ། རྩ་བ། འགྲེལ་པ། དོན་བསྡུའོ། །
Enumeration Block 12:
འགྲེལ་པ་ལ། བདེན་གསུམ་གྱི་རྣམ་པ་བཅུ་གཉིས་དང་། ལམ་བདེན་གྱི་རྣམ་པ་བཅོ་ལྔ་བཤད་པའོ། །
Enumeration Block 13:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མདོར་བསྟན་ལ་གསུམ་གྱི་
Enumeration Block 14:
དབྱེ་ངོ་ནི། ལམ་ཟག་མེད་གཉིས་དང་། ཟག་བཅས་གཅིག་སྟེ། རྣམ་པ་གསུམ།
Enumeration Block 15:
གཉིས་པ་ལ་གསུམ་སྟེ། ལམ་དང་པོའི་བཞི། གཉིས་པའི་ལྔ། གསུམ་པའི་དྲུག་བཤད་པའོ། །
Enumeration Block 16:
གཉིས་པ་ལ་གསུམ་སྟེ། མདོར་བསྟན་ལ་གསུམ་གྱི་
Enumeration Block 17:
གཉིས་པ་རྒྱས་བཤད་ལ་བཞི་སྟེ། ཀུན་འབྱུང་གི་རྣམ་པ་སྤང་གཉེན་གྱི་སྒོ་ནས་དང་། ལམ་དམ་བཅའ་དང་རྟགས་ཀྱི་དང་། དུཿཁ་རང་སྤྱིའི་མཚན་ཉིད་ཀྱི་དང་། འགོག་པ་སྟོང་ཉིད་ཀྱི་སྒོ་ནས་བསྟན་པའོ། །
Enumeration Block 18:
ངེས་འབྱུང་ལ་གཉིས་ལས།
Enumeration Block 19:
གསུམ་པ་ལ་གཉིས་ཀྱི་དང་པོ་མདོར་བསྟན་ལ་གསུམ་ལས།
Enumeration Block 20:
རྒྱས་བཤད་ལ་གསུམ་སྟེ། གཞི་ཤེས་དང་རྗེས་སུ་མཐུན་པའི་དང་། ལམ་ཤེས་དང་རྗེས་སུ་མཐུན་པའི་དང་། ཐུན་མོང་མིན་པ་རྣམ་མཁྱེན་གྱི་རྣམ་པ་བཤད་པའོ། །
Enumeration Block 21:
ཐམས་ཅད་ཤེས་པ་ཉིད་ཀྱི་རྣམ་པ་ལ་བདུན་ཏེ། དངོས་པོ་ལ་རྟོག་པའི་དང་། རྩོལ་བ་ལས་བྱུང་བའི་དང་། ཏིང་ངེ་འཛིན་ཡོངས་སུ་སྦྱོང་བའི་དང་། མངོན་པར་རྟོགས་པ་ལ་སྦྱོར་བའི་དང་། མངོན་པར་རྟོགས་པ་ལ་འབྲེལ་བའི་དང་། མངོན་པར་རྟོགས་པའི་དང་།རྣམ་པར་དག་པ་ངེས་པར་འབྱིན་པའི་ལམ་གྱི་རྣམ་པའོ། །
Enumeration Block 22:
དྲན་པ་ཉེར་གཞག་རྣམ་པ་བཞི་ལ། དམིགས་པ་དང་། ངོ་བོ་དང་། གྲོགས་དང་། སྒོམ་པ་དང་། བསྒོམས་པའི་འབྲས་བུ་དང་ལྔའོ། །
Enumeration Block 23:
འདི་ལ་གསུམ་ལས།
Enumeration Block 24:
མཚན་གཞི་ལ། ཐུན་མོང་གི་དབྱེ་བ་དང་། ཕྱེ་བའི་ས་མཚམས་སོ། །དང་པོ་ལ་བཞི་སྟེ།
Enumeration Block 25:
དབྱེ་ངོ་། ལུས། ཚོར་བ། སེམས། ཆོས་དྲན་པ་ཉེར་གཞག་བཞིའོ། །
Enumeration Block 26:
བཞི་པ་ལ། ཐེག་པ་ཐུན་མོང་གི་ལུགས་དང། ཐེག་ཆེན་གྱི་ལུགས་སོ། །དང་པོ་ལ། སྤྱིར་བསྟན། གཉེན་པོ་སྒོམ་པ་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 27:
ཡང་དག་པར་སྤོང་བའི་རྣམ་པ་བཞི་ལ་སྔར་བཞིན་ལྔ་ལས།
Enumeration Block 28:
འདི་ལ་གསུམ་ལས།
