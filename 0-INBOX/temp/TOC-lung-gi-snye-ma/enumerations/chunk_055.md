Enumeration Block 1:
བཞི་པ་ལ་དྲུག་སྟེ། ས་ལྔ་པའི་བར་དང་། དྲུག་པ་དང་། བདུན་པ་དང་། བརྒྱུད་པ་དང་། དགུ་པ་དང་། བཅུ་པ་ལ་འགོད་པའོ། །
Enumeration Block 2:
བཞི་པ་ལ་གཉིས་ཀྱི་དང་པོ།
Enumeration Block 3:
དྲུག་པ་ལ་གསུམ་སྟེ། ས་བཅུ་ཐོབ་མ་ཐག་དང་། སྐྱེ་བ་གཅིག་གིས་ཐོགས་པ་དང་། སྲིད་པ་ཐ་མ་པ་ལ་འགོད་པའོ། །
Enumeration Block 4:
འདིར་དབང་བསྐུར་བའི་ཚུལ་ལ་གཉིས་ཏེ། སྣང་བས་འཕྲིན་ལས་སྒྲུབ་པ་དང་། མཆོད་པས་དབང་བསྐུར་ཐོབ་པའོ། །
Enumeration Block 5:
དང་པོ་ལ། སྣོད་དག་པ། བཅུད་དག་པའི་སྣང་བ། འཕྲིན་ལས་སྒྲུབ་པ་གསུམ་ལས།
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས་ཏེ། མཆོད་པ་དང་། དབང་བསྐུར་བའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ།
Enumeration Block 8:
གསུམ་པ་ལ་བཞི་སྟེ། ནུས་པ། རྟོགས་པ། སྤངས་པ། དག་པའི་རྒྱུ་ཚོགས་ཏེ། རེ་རེ་ལ་གཉིས་གཉིས་སོ། །
Enumeration Block 9:
འགྲེལ་པ་ལ་གསུམ་སྟེ། འཕྲིན་ལས་ཀྱི་དབྱེ་བ་དང་། དེའི་དུས་དང་། རིམ་པ་དེས་གཞན་ཡང་མཚོན་པར་བསྟན་པའོ། །དང་པོ་ལ། སྔར་བཞིན་གསུམ་ལས།
Enumeration Block 10:
ལམ་ལ་འགོད་པ་ལ་བཞི་སྟེ། ཚོགས་སྦྱོར་མཐོང་སྒོམ་ལའོ། །དང་པོ་ལ། སྦྱོར་བ། ལྟ་བ། སྤྱོད་པ་རྣམ་དག་གོ །
Enumeration Block 11:
གསུམ་པ་ལ། འགོད་པའི་ཆོས་བཞི་སྟེ། དུས་ནམ་གྱི་ཚེ། གང་ལ་བརྟེན་ནས། སྐབས་གང་དུ། ཚུལ་ཇི་ལྟ་བུ་ལ་སྟེ།
Enumeration Block 12:
བཞི་པ་ལ། ས་ལྔ་པའི་བར་ལ་དང་། དྲུག་པ་དང་། བདུན་པ། བརྒྱད་པ། དགུ་པ། ས་བཅུ་ཐོབ་མ་ཐག་པ། སྐྱེ་བ་གཅིག་གིས་ཐོགས་པ། སྲིད་པ་ཐ་མ་པ་ལ་འགོད་པའོ། །དང་པོ་ལ་བཞི་ལས།
Enumeration Block 13:
ཚུལ་ནི། བརྒྱད་ལས།
Enumeration Block 14:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 15:
གསུམ་པ་ལ་གསུམ་ལས།
Enumeration Block 16:
གསུམ་པ་ལ་ལྔ་སྟེ། བཤད་པར་བྱ་བའི་ཁྱད་པར། ཇི་ལྟར་བཤད་པའི་ཚུལ། དེའི་བསོད་ནམས་བསྔོ་བ། ཁེངས་བསྐྱུངས་ཏེ་བཟོད་པར་གསོལ་བ། འབད་པ་དོན་ཅན་དུ་བསྟན་པས་སྤྲོ་བ་སྒྲུབ་པའོ། །
