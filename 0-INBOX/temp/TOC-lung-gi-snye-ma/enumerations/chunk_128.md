Enumeration Block 1:
གསུམ་པ་ལ་གཉིས་ཏེ། བྱེད་སྒྲུབ་དང། ལས་སྒྲུབ་བོ། །
དང་པོ་ལ་གསུམ་སྟེ། ཤེས་པ། ཁྱད་པར། བྱེད་པའོ། །
Enumeration Block 2:
རྩོད་པ་སང་བ་ལ་གསུམ་སྟེ། འབྲས་བུའི་མཚན་ཉིད་ལ་དང། རྒྱུའི་ལ་དང་། འབྲས་བུ་མཚོན་ཚུལ་ལ་རྩོད་སྤང་ངོ་། །
Enumeration Block 3:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མདོར་བསྟན་ལ།
གསུམ་ལས།
Enumeration Block 4:
རྩ་བ་ལ་གཉིས་ཏེ། བྱེད་སྒྲུབ་དང། ལས་སྒྲུབ་བོ། །
Enumeration Block 5:
བྱེད་སྒྲུབ་ཀྱི་མཚན་ཉིད་དེའང་རྣམ་པ་གསུམ་སྟེ། ཤེས་པའི་བདག་ཉིད་ཀྱི་མཚན་ཉིད་དང། ཉན་རང་དང་ཐུན་མོང་མིན་པའི་ཆོས་ཁྱད་པར་གྱི་དང། གཞན་ལ་ཕན་པ་སྒྲུབ་པ་བྱེད་པའི་མཚན་ཉིད་དོ། །
Enumeration Block 6:
རྒྱས་བཤད་ལ་བཞི་སྟེ། ཤེས་པ་དང། ཁྱད་པར་དང། བྱེད་པ་དང། ངོ་བོ་ཉིད་ཀྱི་མཚན་ཉིད་དོ། །
དང་པོ་ལ་གསུམ་སྟེ། གཞི་ཤེས་དང། ལམ་ཤེས་དང། རྣམ་མཁྱེན་གྱི་ཤེས་པའི་མཚན་ཉིད་དོ། །
དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 7:
ཤེས་པའི་མཚན་ཉིད་ལའང་ཐམས་ཅད་མཁྱེན་པ་ཉིད་གསུམ་གྱི་དབྱེ་བས་མཚན་ཉིད་ཐ་དད་པ་གསུམ་ཡོད་པ་ལས།
Enumeration Block 8:
