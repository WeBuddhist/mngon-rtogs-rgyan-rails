Enumeration Block 1:
འདི་བཤད་པ་དངོས་ལ་གསུམ་སྟེ། བསྟན་བཅོས་ལ་འཇུག་པའི་ཡན་ལག །ཡན་ལག་ཅན་གྱི་བསྟན་བཅོས། བསྟན་བཅོས་ཇི་ལྟར་འགྱུར་ཚུལ་ལོ། །དང་པོ་ལ་གསུམ་སྟེ། ཐ་སྙད་རྟོགས་པའི་ཡན་ལག་ཏུ་མཚན་གྱི་དོན། གཞུང་ཚད་རྟོགས་པའི་ཡན་ལག་ཏུ་བམ་པོའི་གྲངས། གུས་པས་འཇུག་པའི་ཡན་ལག་ཏུ་ཕྱག་བྱ་བའོ། །དང་པོ་ལ་གསུམ་སྟེ། མཚན་གྱི་ངོ་བོ། འདོགས་པའི་རྒྱུ། བཏགས་པའི་དགོས་པའོ། །དང་པོ་ལ། མཚན་བསྒྱུར་བ་དང་། བཤད་པ་གཉིས་སོ། །
Enumeration Block 2:
གཉིས་པ་ལ་བརྒྱད་ལས།
Enumeration Block 3:
གསུམ་པ་བསྟན་བཅོས་ལ་གསུམ་ལས།
Enumeration Block 4:
གསུམ་པ་ལ་གསུམ་སྟེ། རྒྱ་སྐད་དང་། བོད་སྐད་དང་། གཉིས་ཀ་ཀླད་དུ་སྨོས་པའི་དགོས་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ་སྟེ། རྒྱན་གྱི་བཤད་པ་ལ་འཇུག་པ་དང་། བཤད་པ་ཉེ་བར་དགོད་པ་དང་། བཤད་པ་མཐར་ཕྱིན་པའི་བྱ་བའོ། །དང་པོ་ལ། མཆོད་པར་བརྗོད་ཅིང་རྩོམ་པར་དམ་བཅའ་བ་དང་། བླ་མ་བརྒྱུད་པས་ཇི་ལྟར་ཕྱེ་ཚུལ་དང་། དབྱེ་བར་རིགས་པའི་རྒྱུ་མཚན་ཁེངས་བསྐྱུངས་དང་བཅས་པའོ། །དང་པོ་ལ། དགོས་བསྡུས་ཚིག་གསུམ་ལས། དང་པོ་ལ་གསུམ་སྟེ། རང་དོན། གཞན་དོན། གཉིས་དོན་ནོ། །
Enumeration Block 6:
གསུམ་པ་ལ། མཆོད་བརྗོད་དང་། དམ་བཅའ་དང་། དགོས་འབྲེལ་གྱི་ཚིག་གི་དོན་བཤད་པ་གསུམ་མོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 7:
འདིའི་མཐའ་དཔྱད་པ་ལ། གཞན་གྱི་ལོག་རྟོག་དགག །གཞུང་གི་དགོངས་པ་བསྟན། དེ་ལ་རྩོད་པ་སྤང་བ་གསུམ་ལས།
