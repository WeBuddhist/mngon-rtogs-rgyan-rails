Enumeration Block 1:
གསུམ་པ་ནི། ལམ་པ་གང་ཟག་དང་། ཆོས་ཉིད་རིགས་ཀྱི་རྟེན་གཉིས་ལས།
Enumeration Block 2:
འགྲེལ་པ་ལ། ལམ་དང་། ལམ་ཤེས་གཉིས་སོ། །
Enumeration Block 3:
གསུམ་པ་ལ་གསུམ་ལས།
Enumeration Block 4:
འགྲེལ་པ་ལ།རྣམ་པ། དམིགས་པ། བློའི་ངོ་བོ་གསུམ་ལས།
Enumeration Block 5:
གསུམ་པ་ལ། མཚམས་སྦྱར་དང་། ལམ་བཤད་པ་གཉིས་སོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས་ཏེ། མཐོང་ལམ་ཤེས་པ་ཕན་ཡོན་དང་བཅས་པ་དང་། སྒོམ་ལམ་ཤེས་པ་བྱེད་པ་དང་བཅས་པའོ། །དང་པོ་ལ་གཉིས་ལས། མདོར་བསྟན་ལ། རྩ་འགྲེལ་གཉིས་སོ། །
Enumeration Block 7:
རྒྱས་བཤད་ལ་གསུམ་ལས།
Enumeration Block 8:
འགྲེལ་པ་ལ་གཉིས། མཐོང་ལམ་རྣམ་པའི་སྒོ་ནས་བཤད་པ་དང་། རྣམ་པ་མ་བཤད་པར་འདོད་པ་དགག་པའོ། །དང་པོ་ལ། སྡུག་ཀུན་འགོག་ལམ་གྱི་རྣམ་པ་བཤད་པ་དང་བཞིའོ། །
