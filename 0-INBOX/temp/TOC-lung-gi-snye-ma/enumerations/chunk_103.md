Enumeration Block 1:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 2:
འཕགས་པ་ཉན་ཐོས་ཀྱི་སྦྱོར་ལམ་ལ་བཞི་ལས།
Enumeration Block 3:
འགྲེལ་པ་ལ། གང་གིས་དམིགས་པའི་རྣམ་པ། གང་ལ་དམིགས་པའི་ཡུལ། བློའི་ངོ་བོ་དང་གསུམ་མོ། །
Enumeration Block 4:
གཉིས་པ་ལ། སྤྱི་གཞུང་གཉིས་སོ། །
དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 5:
གང་ཟག་གི་དབྱེ་བ་ལ། བསེ་རུ་ལྟ་བུ། ཚོགས་དང་སྤྱོད་པ་ཆེན་པོ་དང་། ཆུང་ངུ་དང་གསུམ་མོ། །
དང་པོ་ལ། སྒྲུབ་པ་པོ་གང་ཟག །སྒྲུབ་པ་ལམ། བསྒྲུབས་པའི་འབྲས་བུའི་ཁྱད་པར་གསུམ་མོ། །
Enumeration Block 6:
གཉིས་པ་ལ།ཚོགས་གསོག་པའི་ཁྱད་པར། ལམ་བགྲོད་པའི་ཁྱད་པར་གཉིས་སོ། །
