Enumeration Block 1:
དེ་དག་གིས་བདེ་བར་གནས་པ་དང་། སངས་རྒྱས་མཆོད་པ་དང༌། སེམས་ཅན་སྦྱོང་བ་དང་གསུམ་མོ། །འཕགས་པས། སེམས་ཅན་རྣམས་ཆོས་མཉམ་པ་ཉིད་ལ་དགོད་པ་དང༌། འཕགས་པ་ཐམས་ཅད་བྱམས་པ་ཡིད་དུ་འོང་བའི་ཡུལ་དང་ཕྲད་པ། ལྷ་རྣམས་ཀྱིས་ཕྱག་བྱ་བར་འོས་པ་དང་། ལུང་བསྟན་པ་གཉིས་སོ། །བཞི་པ་ལ་དྲུག་ལས།
Enumeration Block 2:
སེམས་ཅན་སྨིན་པར་བྱེད་ནུས་པ། སངས་རྒྱས་ཀྱིས་བསྔགས་པ། ཚིག་སེམས་ཅན་རྣམས་ཀྱིས་གཟུང་བར་འོས་པ་གསུམ་མོ། །
Enumeration Block 3:
མཐུ་ནི། དབྱེ་བ་དྲུག་གིས་འཇུག་སྟེ། རིག་པ་གསུམ་ནི། སྔོན་གྱི་གནས་དང༌། འཆི་འཕོ་སྐྱེ་བ་དང༌། ཟག་པ་ཟད་པ་རིག་པའོ། །
Enumeration Block 4:
འགྲོ་བ་ཉོན་མོངས་པས་དབང་མེད་པ་རྣམས་རང་དབང་ཡོད་པ་ལ་འགོད་པས་དབང་ཆེ་བ། རྟག་ཏུ་གཞན་ལ་ཕན་འདོགས་པར་དགའ་བས་དགའ་བ་ཆེ་བ། སྲིད་པས་མི་འཇིགས་པས་མི་འཇིགས་པ་ཆེ་བ་གསུམ་མོ། །
Enumeration Block 5:
བཞི་པ་ལ་གཉིས་ཏེ། མཐོང་ལམ་དང༌། སྒོམ་ལམ་ལ་གདམས་པའོ། །དང་པོ་ལ། གང་ལ་དང༌། ཇི་ལྟར་རོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས་ལས།
Enumeration Block 7:
བཞི་པ་ནི། གདམས་ངག་ནི་ཆོས་ཅན། རྣམ་པ་བཅུར་ངེས་སོ། །
Enumeration Block 8:
སྒྲུབ་པའི་ངོ་བོ། དམིགས་ཡུལ། རྟེན། རྒྱུ་བཞིར་ངེས་ལ།
Enumeration Block 9:
རྒྱུ་ལའང་འགལ་རྐྱེན་སྤོང་བ་དང༌། མཐུན་རྐྱེན་སྒྲུབ་པ་གཉིས་ལས།
Enumeration Block 10:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 11:
རྩ་བ་ལ་མཚོན་བྱེད་དཔེའི་དགེ་འདུན། མཚོན་བྱ་དོན་གྱི་དགེ་འདུན། དེ་དག་གི་རྣམ་གཞག་དཔྱད་པ་དང་གསུམ་མོ། །དང་པོ་ལ། ཆགས་བྲལ་སྔོན་སོང་དང༌། སྔོན་དུ་མ་སོང་བ་གཉིས་སོ། །
Enumeration Block 12:
གཉིས་པ་ལ། གཅིག་ཅར་བ་དང་། རིམ་གྱིས་པ་གཉིས་སོ། །
Enumeration Block 13:
གཉིས་པ་ལ་བཞི་སྟེ། རྒྱུན་ཞུགས། ཕྱིར་འོང༌། ཕྱིར་མི་འོང༌། དགྲ་བཅོམ་པའོ། །
Enumeration Block 14:
གནས་པ་ལ་གཉིས་ཏེ། སྲིད་པ་ལན་བདུན་པ་དང༌། རིགས་ནས་རིགས་སྐྱེའོ། །
Enumeration Block 15:
དེ་ལ་གཉིས་ལས།
Enumeration Block 16:
གཉིས་པ་ལ། ཞུགས་གནས་གཉིས་ལས།
Enumeration Block 17:
དེ་ལ་འབྲས་གནས་ཙམ་དང༌། ཁྱད་པར་ཅན་བར་ཆད་གཅིག་པ་གཉིས་སོ། །
Enumeration Block 18:
གསུམ་པ་ལ། ཞུགས་གནས་གཉིས་ལས།
Enumeration Block 19:
དེ་ལ་བཞི་སྟེ། ཕྱིར་མི་འོང་ཐོབ་པའི་ཚེ་དེ་ལ་གཟུགས་ཀྱི་ཉོན་མོངས་མ་སྤངས་པ་གཟུགས་སུ་ཉེར་འགྲོ། དེ་སྤངས་ཀྱང་གཟུགས་མེད་ཀྱི་ཉོན་མོངས་མ་སྤངས་པ་གཟུགས་མེད་དུ་ཉེར་འགྲོ། ཟག་པ་ཐམས་ཅད་ཟད་པར་བྱེད་པ་མཐོང་བའི་ཆོས་ལ་ཞི་བ། ཐོབ་པ་འགོག་པ་ལུས་ཀྱིས་མངོན་སུམ་དུ་བྱེད་པའོ། །
Enumeration Block 20:
དང་པོ་ལ་གསུམ་སྟེ། མངོན་པར་འགྲུབ་པ་ཙམ་གྱི་ལས་ཅན་དང༌། སྐྱེས་ནས་མྱོང་འགྱུར་གྱི་ལས་ཅན་དང༌། ལན་གྲངས་གཞན་ལ་མྱོང་འགྱུར་གྱི་ལས་ཅན་ནོ། །
Enumeration Block 21:
དེ་ལའང་དབང་པོ་སོགས་ཆུང་འབྲིང་ཆེ་གསུམ་གྱིས་བར་དོའི་ཚེ་སྟོད་དང༌། ཚེ་དཀྱིལ་དང༌། ཚེ་གཞུག་ཏུ་འདའ་བ། དཔེ་གསུམ་གྱིས་མྱུར་བ་དང་། མྱུར་བ་མ་ཡིན་པ་དང་། ཡུན་རིང་མོ་ཞིག་ནས་འདའ་བ་གསུམ་མོ། །
Enumeration Block 22:
འབྲིང་པོའི་རྣོ་འབྲིང་རྟུལ་གསུམ་གྱིས་གཟུགས་སུ་སྐྱེས་མ་ཐག་ལྷག་བཅས་སུ་འདའ་བ་དང༌། ཚེ་དཀྱིལ་ལ་འབད་རྩོལ་ལ་བརྟེན་ནས་ཐོབ་པ་མངོན་པར་འདུ་བྱེད་པ་དང་བཅས་ཏེ་འདའ་བ་དང༌། ཚེ་གཞུག་ཏུ་འབད་མི་དགོས་པར་ཐོབ་པ་འདུ་བྱེད་མེད་པར་འདའ་བ་གསུམ་མོ། །
Enumeration Block 23:
འདི་ལ་ལྷག་མཐོང་ཤས་ཆེར་སྤྱོད་པ་འོག་མིན་གྱི་དང༌། ཞི་གནས་ཤས་ཆེར་སྤྱོད་པ་སྲིད་རྩེའི་མཐར་ཐུག་པར་འགྲོ་བ་གཉིས་སོ། །
Enumeration Block 24:
རྟུལ་པོའི་རྣོ་འབྲིང་རྟུལ་གསུམ་གྱིས་འཕར་བ་དང༌། ཕྱེད་དུ་འཕར་བ་དང༌། གནས་ཐམས་ཅད་དུ་འཆི་འཕོ་བའོ། །
