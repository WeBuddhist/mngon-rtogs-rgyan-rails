Enumeration Block 1:
དེ་ལ་འབྲས་གནས་ཙམ་དང༌། ཁྱད་པར་ཅན་བར་ཆད་གཅིག་པ་གཉིས་སོ། །
Enumeration Block 2:
གསུམ་པ་ལ། ཞུགས་གནས་གཉིས་ལས།
Enumeration Block 3:
དེ་ལ་བཞི་སྟེ། ཕྱིར་མི་འོང་ཐོབ་པའི་ཚེ་དེ་ལ་གཟུགས་ཀྱི་ཉོན་མོངས་མ་སྤངས་པ་གཟུགས་སུ་ཉེར་འགྲོ། དེ་སྤངས་ཀྱང་གཟུགས་མེད་ཀྱི་ཉོན་མོངས་མ་སྤངས་པ་གཟུགས་མེད་དུ་ཉེར་འགྲོ། ཟག་པ་ཐམས་ཅད་ཟད་པར་བྱེད་པ་མཐོང་བའི་ཆོས་ལ་ཞི་བ། ཐོབ་པ་འགོག་པ་ལུས་ཀྱིས་མངོན་སུམ་དུ་བྱེད་པའོ། །
Enumeration Block 4:
དང་པོ་ལ་གསུམ་སྟེ། མངོན་པར་འགྲུབ་པ་ཙམ་གྱི་ལས་ཅན་དང༌། སྐྱེས་ནས་མྱོང་འགྱུར་གྱི་ལས་ཅན་དང༌། ལན་གྲངས་གཞན་ལ་མྱོང་འགྱུར་གྱི་ལས་ཅན་ནོ། །
Enumeration Block 5:
དེ་ལའང་དབང་པོ་སོགས་ཆུང་འབྲིང་ཆེ་གསུམ་གྱིས་བར་དོའི་ཚེ་སྟོད་དང༌། ཚེ་དཀྱིལ་དང༌། ཚེ་གཞུག་ཏུ་འདའ་བ། དཔེ་གསུམ་གྱིས་མྱུར་བ་དང་། མྱུར་བ་མ་ཡིན་པ་དང་། ཡུན་རིང་མོ་ཞིག་ནས་འདའ་བ་གསུམ་མོ། །
Enumeration Block 6:
འབྲིང་པོའི་རྣོ་འབྲིང་རྟུལ་གསུམ་གྱིས་གཟུགས་སུ་སྐྱེས་མ་ཐག་ལྷག་བཅས་སུ་འདའ་བ་དང༌། ཚེ་དཀྱིལ་ལ་འབད་རྩོལ་ལ་བརྟེན་ནས་ཐོབ་པ་མངོན་པར་འདུ་བྱེད་པ་དང་བཅས་ཏེ་འདའ་བ་དང༌། ཚེ་གཞུག་ཏུ་འབད་མི་དགོས་པར་ཐོབ་པ་འདུ་བྱེད་མེད་པར་འདའ་བ་གསུམ་མོ། །
Enumeration Block 7:
འདི་ལ་ལྷག་མཐོང་ཤས་ཆེར་སྤྱོད་པ་འོག་མིན་གྱི་དང༌། ཞི་གནས་ཤས་ཆེར་སྤྱོད་པ་སྲིད་རྩེའི་མཐར་ཐུག་པར་འགྲོ་བ་གཉིས་སོ། །
Enumeration Block 8:
རྟུལ་པོའི་རྣོ་འབྲིང་རྟུལ་གསུམ་གྱིས་འཕར་བ་དང༌། ཕྱེད་དུ་འཕར་བ་དང༌། གནས་ཐམས་ཅད་དུ་འཆི་འཕོ་བའོ། །
Enumeration Block 9:
སྐྱེས་ནས་འདའ་བ། འདུ་བྱེད་པ་དང་བཅས་ཏེ་འདའ་བ། འདུ་བྱེད་པ་མེད་པར་འདའ་བ། གོང་དུ་འཕོ་བ་དང་བཞིའོ། །
Enumeration Block 10:
བཞི་པ་ལ། ཞུགས་གནས་གཉིས་ལས།
Enumeration Block 11:
གཉིས་པ་ལ། འབྲས་བུ་ལ་ཞུགས་པ་ལྔ། གནས་པ་བཅུ་བཞི། རང་རྒྱལ་སྟེ། ཉི་ཤུ་ལས།
Enumeration Block 12:
དེ་ལ་འོག་མིན་དང་སྲིད་རྩེར་འགྲོ་བ་གཉིས་ལས། འོག་མིན་འགྲོ་ནི། གསུམ་སྟེ།
Enumeration Block 13:
གསུམ་པ་ལ། ས་དང༌། གྲངས་དང༌། མཚན་བཏགས་ཀྱི་རྣམ་གཞག་དཔྱད་པ་གསུམ་མོ། །
Enumeration Block 14:
གཉིས་པ་ལ། དགག་བཞག་སྤང་གསུམ་ལས།
Enumeration Block 15:
འགྲེལ་པ་ལ་ལྔའི་དང་པོ་རྒྱུན་ཞུགས་ལ་གསུམ་སྟེ། འབྲས་ཞུགས་དང༌། འབྲས་གནས་ཙམ་དང༌། ཁྱད་པར་ཅན་ནོ། །
Enumeration Block 16:
དེ་ཡང་དབང་རྟུལ་དད་པའི་རྗེས་འབྲང་དང་། དབང་རྣོན་ཆོས་ཀྱི་རྗེས་འབྲང་གཉིས་སོ། །
Enumeration Block 17:
ཕྱིར་འོང་ལ་གསུམ་ལས།
Enumeration Block 18:
ཕྱིར་མི་འོང་ལ་གཉིས་ལས།
Enumeration Block 19:
དེ་ལ་ལྔ་ལས།
Enumeration Block 20:
ལྔ་པ་གོང་དུ་འཕོ་བ་ལ། འོག་མིན་དང་སྲིད་རྩེར་འགྲོ་བ་གཉིས་ལས།
Enumeration Block 21:
དབྱེ་ན། ཚངས་རིས་ནས་འོག་མིན་དུ་འཕར་བ་དང༌། ཚངས་རིས་ནས་གནས་གཙང་མའི་བར་འོག་མ། དེ་ནས་འོག་མིན་དུ་འགྲོ་བ་ཕྱེད་དུ་འཕར་བ་དང༌། གཟུགས་ཀྱི་གནས་ཐམས་ཅད་དུ་འཆི་འཕོ་བ་ཉིད་ཀྱིས་འོག་མིན་དུ་འགྲོ་བ་གོང་དུ་འཕོ་བ། སྲིད་རྩེར་འགྲོ་བ་ལས་གཞན་རྣམ་པ་གསུམ་མོ། །
Enumeration Block 22:
དབྱེ་ན། མཐོང་བའི་ཆོས་ཚེ་འདི་ལ་ཞི་བ་ཐོབ་པ་དང་། ལུས་ཀྱི་འགོག་པ་མངོན་སུམ་དུ་བྱེད་པ་སྟེ། འོག་མིན་འགྲོ་ལས་གཞན་རྣམ་པ་གཉིས་སོ། །
Enumeration Block 23:
རྒྱུན་ཞུགས་ལྔ། ཕྱིར་འོང་གསུམ། ཕྱིར་མི་འོང་བཅུ། དགྲ་བཅོམ་འབྲས་ཞུགས། རང་རྒྱལ་ཏེ། ཉི་ཤུའོ། །
