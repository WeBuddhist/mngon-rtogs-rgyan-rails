Enumeration Block 1:
གཉིས་པ་ལ། བསམ་པ་སྦྱང་བ་དང་། ཆོ་ག་བརྗོད་པ་གཉིས་སོ། །
Enumeration Block 2:
གསུམ་པ་ལ་གཉིས་ཏེ། རང་དགའ་བ་བསྐྱེད་པ་དང་། གཞན་དགའ་བ་བསྐྱེད་པའོ། །
Enumeration Block 3:
གསུམ་པ་ལ་གསུམ་སྟེ། ཐུན་མོང་གི་བསླབ་བྱ་མདོར་བསྟན། སོ་སོའི་བསླབ་བྱ་རྒྱས་པར་བཤད། ཆོས་གཅིག་གིས་དོན་བསྡུ་བའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས་ཏེ། སྨོན་པ་དང་། འཇུག་པའི་བསླབ་བྱ་བཤད་པའོ། །
དང་པོ་ལ་གཉིས་ཏེ། འགལ་རྐྱེན་སྤང་བ་དང་། མཐུན་རྐྱེན་སྒྲུབ་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས་ཏེ། འགལ་རྐྱེན་སྤང་། མཐུན་རྐྱེན་སྒྲུབ་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས་ཏེ། མི་ཉམས་པའི་རྒྱུ་དང་། འཕེལ་བའི་རྐྱེན་ལ་བསླབ་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་བཞི་སྟེ། སེམས་བསྐྱེད་ཀྱི་མཚན་ཉིད། དམིགས་ཡུལ། རབ་དབྱེ། ས་མཚམས་སོ། །
དང་པོ་ལ་གསུམ་ལས།
