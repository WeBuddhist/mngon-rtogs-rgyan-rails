Enumeration Block 1:
གཉིས་པ་ལ། ཐུན་མོང་བ་སྔར་དང་འདྲ་བ་ལ། ཐུན་མོང་མ་ཡིན་པ་ལ། གནས་སྐབས་དང་། མཐར་ཐུག་གི་འབྲས་བུའོ། །དང་པོ་ལ། ལས་མཐའ་དང་། སྤྱོད་པ་དང་། སྐྱེས་ཐོབ་ཀྱི་ཚུལ་ཁྲིམས་གསུམ་ལས།
Enumeration Block 2:
གཉིས་པ་སྤངས་རྟོགས་ཕྲིན་ལས་གསུམ་མོ། །གསུམ་པ་ལ་གཉིས་ཏེ། སྐྱབས་འགྲོ་དང་སེམས་བསྐྱེད་ཀྱི་ཁྱད་པར། སེམས་བསྐྱེད་དང་སྡོམ་པའི་ཁྱད་པར་རོ། །
Enumeration Block 3:
གཉིས༌པ༌ལ་གཉིས་ཏེ། སེམས་ཙམ་པ་དང་། དབུ་མའི་ལུགས་གཉིས་སོ། །
Enumeration Block 4:
འདི་ལ་བཞི་སྟེ། རྟེན་གྱི་ཁྱད་པར། མ་སྐྱེས་པ་སྐྱེད་པའི་ཁྱད་པར། སྐྱེས་པ་མི་ཉམས་པར་སྲུང་བའི་ཁྱད་པར། ཉམས་ན་ཕྱིར་བཅོས་ཀྱི་ཁྱད་པར་རོ། །
Enumeration Block 5:
འདི་ལའང་སྔར་བཞིན་བཞི་ལས།
Enumeration Block 6:
གཉིས་པ་ལ་གསུམ་སྟེ། སྦྱོར་བ་སེམས་ཀྱི་ཐ་བ་སྦྱང་། དངོས་གཞི་བྱང་ཆུབ་ཀྱི་སེམས་ཀྱི་ས་བོན་གདབ། རྗེས་རང་གཞན་དགའ་བ་བསྐྱེད་དེ་བརྟན་པར་བྱ་བའོ། །དང་པོ་ལ་གསུམ་སྟེ། རྟེན་བཤམ། གསོལ་བ་གདབ། ཡན་ལག་བདུན་པ་བྱ་བའོ། །
Enumeration Block 7:
ཡན་ལག་བདུན་པ་དངོས་ལ། མཆོད་པ། སྡིག་བཤགས། ཡི་རང་། འཁོར་ལོ་བསྐོར་བ། གསོལ་བ་འདེབས་པ། བསྔོ་བ། སྐྱབས་སུ་འགྲོ་བ་དང་བདུན་ནོ། །དང་པོ་ལ་ལྔ། བསྟོད་ཅིང་ཕྱག་འཚལ་བ། བཀུར་སྟིའི་མཆོད་པ། ཡོ་བྱད་བློས་སྤྲུལ་པ། ལུས་འབུལ་བ། སྒྲུབ་པའི་མཆོད་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལ། བསམ་པ་སྦྱང་བ་དང་། ཆོ་ག་བརྗོད་པ་གཉིས་སོ། །
