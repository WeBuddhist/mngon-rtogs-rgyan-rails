Enumeration Block 1:
ལྔ་པ་ལ་གཉིས་ཏེ། ཐུན་མོང་གི་དང༌། སོ་སོའི་བསླབ་བྱའོ། །
Enumeration Block 2:
དྲུག་པ་ལ། ཐུན་མོང་དང་ཐུན་མོང་མ་ཡིན་པ། རྒྱུ་དང་འབྲས་བུ། བརྟན་མི་བརྟན། གནས་སྐབས་དང་མཐར་ཐུག་གི་སྐྱབས་འགྲོའོ། །
Enumeration Block 3:
བརྒྱད་པ་ནི། གཉིས་ཏེ། མཐར་ཐུག་གི་དང༌། གནས་སྐབས་ཀྱི་ཕན་ཡོན་ནོ། །
Enumeration Block 4:
གཉིས་པ་ལ་བཞི་ལས།
Enumeration Block 5:
གཉིས་པ་ལ། སངས་རྒྱས་དང༌། ཆོས་དང༌། དགེ་འདུན་ལ་གདམས་པ་གསུམ་ལས། དང་པོ་ལ་གཉིས་ལས། གང་ལ་ན། སངས་རྒྱས་དཀོན་མཆོག་ལའོ། །གཉིས་པ་ལ། ཡུལ་དང་ཡུལ་ཅན་དང༌། མཚོན་བྱ་དང་མཚན་ཉིད་དང༌། རྒྱུ་མཚན་དང་རྒྱུ་མཚན་ཅན་དུ་མི་སྦྱོར་བར་གདམས་པ་གསུམ་མོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས་ལས། གང་ལ་ན། ཆོས་དཀོན་མཆོག་ལའོ། །
Enumeration Block 7:
གསུམ་པ་ལ་གཉིས་ལས། གང་ལ་ན། དགེ་འདུན་དཀོན་མཆོག་ལའོ། །
Enumeration Block 8:
གང་ལ་འཇུག་ན། གསུམ་ལས།
Enumeration Block 9:
བཞི་པ་ལ་བཞི་སྟེ། སྒྲུབ་པའི་མི་མཐུན་ཕྱོགས་སྤང་བའི་རྒྱུ་བརྩོན་འགྲུས། སྒྲུབ་པ་ལ་གཞན་གྱིས་དྲིང་མི་འཇོག་པའི་རྒྱུ་སྤྱན་ལྔ། སྒྲུབ་པའི་ཡོན་ཏན་ཐམས་ཅད་རྫོགས་པའི་རྒྱུ་མངོན་ཤེས་དྲུག །སྒྲུབ་པ་མཐར་ཐུག་པའི་རྒྱུ་ལམ་ལ་གདམས་པའོ། །
Enumeration Block 10:
གཉིས་པ་ལ། གང་ལ་དང༌། ཇི་ལྟར་གདམས་པ་གཉིས་ལས། དང་པོ་ལ། རྒྱུ། ངོ་བོ། འབྲས་བུའོ། །
Enumeration Block 11:
ངོ་བོ་ལ། མཚན་མཚོན་གཞི་གསུམ་ལས།
Enumeration Block 12:
གསུམ་པ་ལ་བཞི་ལས། དབྱེ་གཞི་སྤྱན་ཙམ་མོ། །
Enumeration Block 13:
གསུམ་པ་ལ་གསུམ་ལས། གང་ལ་གདམས་པ་ལ། རྒྱུ། ངོ་བོ། འབྲས་བུ། བྱེད་ལས། ལྡན་པའི་ཡོན་ཏན། འཇུག་པའི་རབ་དབྱེ། གཞན་ལ་ཕན་འདོགས་པའི་ཆེ་བའི་བདག་ཉིད་དང་བདུན་ནོ། །རྒྱུ་ནི། ཐུན་མོང་དང༌། སོ་སོའི་རྒྱུ་གཉིས་ལས།
Enumeration Block 14:
ངོ་བོ་ལ། མཚན་མཚོན་གཞི་གསུམ་ལས།
Enumeration Block 15:
གསུམ་པ་ལ་བཞི་ལས། དབྱེ་གཞི་མངོན་ཤེས་ཙམ་མོ། །དབྱེ་ངོ་དྲུག་སྟེ།
Enumeration Block 16:
དེ་དག་གིས་བདེ་བར་གནས་པ་དང་། སངས་རྒྱས་མཆོད་པ་དང༌། སེམས་ཅན་སྦྱོང་བ་དང་གསུམ་མོ། །འཕགས་པས། སེམས་ཅན་རྣམས་ཆོས་མཉམ་པ་ཉིད་ལ་དགོད་པ་དང༌། འཕགས་པ་ཐམས་ཅད་བྱམས་པ་ཡིད་དུ་འོང་བའི་ཡུལ་དང་ཕྲད་པ། ལྷ་རྣམས་ཀྱིས་ཕྱག་བྱ་བར་འོས་པ་དང་། ལུང་བསྟན་པ་གཉིས་སོ། །བཞི་པ་ལ་དྲུག་ལས།
