Enumeration Block 1:
གཉིས་པ་ལ་བཞི་སྟེ། མཚམས་སྦྱར། མདོར་བསྟན། རྒྱས་པར་བཤད། དོན་བསྡུའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས་ཏེ། གཟུང་རྟོག་མདོར་བསྟན། འཛིན་རྟོག་མདོར་བསྟན་ནོ། །
Enumeration Block 3:
དང་པོ་ལ་གཉིས་ཏེ། རྩ་བ་འགྲེལ་བའོ། །
Enumeration Block 4:
གཉིས་པ་ལ། ལུས་དང་ཡན་ལག་གི་དབྱེ་བ་གཉིས་ལས།
Enumeration Block 5:
གཉིས་པ་ལ། ལས་དང་། ཡན་ལག་གི་དབྱེ་བ་གཉིས་ལས། དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 6:
གཟུང་རྟོག་རྒྱས་པར་བཤད་པ་དང༌། འཛིན་རྟོག་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ། ཀུན་ནས་ཉོན་མོངས་གཟུང་རྟོག་རྒྱས་བཤད་དང༌། རྣམ་བྱང་གཟུང་རྟོག་རྒྱས་བཤད་གཉིས་སོ། །
Enumeration Block 7:
གསུམ་པ་ལ་གསུམ་ལས།
Enumeration Block 8:
རྩ་བ་ལ། ནང་ཡོངས་འཛིན་ཐབས་མཁས། ཕྱི་ཡོངས་འཛིན་དགེ་བཤེས། དེའི་མི་མཐུན་ཕྱོགས་བོར་བ་དང་གསུམ་མོ། །
Enumeration Block 9:
གསུམ་པ་ལ། ནང་གི་དང་ཕྱིའི་མི་མཐུན་ཕྱོགས་བོར་བ་གཉིས་སོ། །
Enumeration Block 10:
བཞི་པ་རྟེན་རང་བཞིན་གནས་རིགས་ལ་བཞི་སྟེ། གང་ལ་བརྟེན་ནས་སྒྲུབ་པ་འབྱུང་བའི་རྒྱུ་རིགས། གང་ལ་དམིགས་ཏེ་སྒྲུབ་པའི་ཡུལ་དམིགས་པ། གང་གི་དོན་དུ་སྒྲུབ་པའི་འབྲས་བུ་ཆེད་དུ་བྱ་བ། ཇི་ལྟར་སྒྲུབ་པ་རང་གི་ངོ་བོའོ། །དང་པོ་ལ། སྤྱི་གཞུང་གཉིས་སོ། །དང་པོ་ལ། རིགས་ཀྱི་རང་བཞིན་དང་། སྒྲུབ་བྱེད་དང། ཡོན་ཏན། ཉེས་པ། རྟགས། ངེས་ཚིག །
དབྱེ་བ། རིགས་ཆད་མ་ཆད་ཀྱི་དོན་བསྟན་པ། དཔེ། འབྲས་བུའི་ཁྱད་པར་དང་བཅུའོ། །
Enumeration Block 11:
གཉིས་པ་ལ་བཞི་སྟེ། སྤྱིར་རིགས་ཀྱིས་ཁྱབ་པ་ཡི་དང༌། གནས་སྐབས་རིགས་ཐ་དད་ཀྱི་དང༌། ཐེག་ཆེན་གྱི་རིགས་མཆོག་ཏུ་དང༌། རང་བཞིན་དུ་གནས་པའི་རིགས་སྟོང་ཞིང་བསམ་གྱིས་མི་ཁྱབ་པའི་སྒྲུབ་བྱེད་དོ། །
