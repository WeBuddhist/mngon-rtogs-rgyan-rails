Enumeration Block 1:
འགྲེལ་པ་ལ། རང་བཞིན་གྱི་སྦྱོར་བ་ལྔ་དང་། གནས་སྐབས་ཀྱི་སྦྱོར་བ་བཅོ་ལྔ་གཉིས་སོ། །
Enumeration Block 2:
བཞི་པ་ལ་བཞི་སྟེ། ཡོན་ཏན་ཤེས་པས་ལེན་པ་དང་། སྐྱོན་ཤེས་ནས་འདོར་བ་དང་། མཚན་ཉིད་ཤེས་པ་དང་། ཐར་པའི་ཆ་མཐུན་ཤེས་པ་སྔོན་དུ་འགྲོ་བའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 3:
རྩ་བ་ནི། བདུད་ཀྱི་མཐུ་བཅོམ་པ་དང་། སོགས་པ་ངེས་པར་ཐོབ་པའི་བར་སྦྱོར་བའི་ཡོན་ཏན་རྣམ་པ་བཅུ་བཞིའོ། །
Enumeration Block 4:
འགྲེལ་པ་ལ། འོག་མ་རྒྱུར་གྱུར་པའི་ཡོན་ཏན་བཅུ་བཞི་དང་། གོང་མ་འབྲས་བུར་གྱུར་པའི་ཡོན་བཅུ་བཞི་གྲངས་བཞིན་དུ་སྦྱར་ཏེ་བཤད་པ་ནི།
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 6:
རྩ་བ་ནི། སྦྱོར་བའི་སྐྱོན་བཅུ་ཚན་བཞིར་བཅས་པའི་དྲུག་སྟེ། ཞེ་དྲུག་ཏུ་ངེས་པར་རྟོགས་པར་བྱའོ། །
Enumeration Block 7:
འགྲེལ་པ་ལ། བསལ་བྱ་སྐྱོན་གྱི་དབྱེ་བ། དེ་སེལ་བྱེད་གཉེན་པོའོ། །
Enumeration Block 8:
དང་པོ་ལ། འགལ་རྐྱེན་ཉེ་བར་གནས་པ་ཉེར་གསུམ། མཐུན་རྐྱེན་མ་ཚང་བ་ཉེར་གསུམ་མོ། །དང་པོ་ལ། རང་ལ་བརྟེན་པ་སྤོབས་པ་གཉིས། གནས་ངན་ལེན་གསུམ། ཐེག་ཆེན་སྤོང་བའི་རྒྱུ་བདུན། རྣམ་གཡེང་བརྒྱད་དོ། །གཞན་ལ་བརྟེན་པ་ཐ་མ་གསུམ་མོ། །གཉིས་པ་ལ། དཔོན་སློབ་གང་རུང་ལ་བརྟེན་པ་བཅུ་བཞི། རང་ལ་བརྟེན་པ་གཉིས། གཉིས་ཀ་ལ་བརྟེན་པ་བདུན་ནོ། །
Enumeration Block 9:
གསུམ་པ་ལ། སྤྱི་གཞུང་གཉིས་སོ། །དང་པོ་ལ་གཉིས་ཏེ། ཤེས་བྱ་མཚན་ཉིད་ཀྱིས་མཚོན་བྱ་མཚོན་ཚུལ་དང་། དེ་ཤེས་པ་སྔོན་དུ་འགྲོ་བའི་རྒྱུ་མཚན་ནོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 10:
འདིའི་མཐའ་དཔྱད་པ་ལ། འབྲས་བུའི་མཚན་ཉིད་དང། རྒྱུའི་མཚན་ཉིད་དང། འབྲས་བུ་མཚོན་ཚུལ་གསུམ་མོ། །
Enumeration Block 11:
དེ་ལ་གཉིས་ལས། རང་དོན་མཐར་ཐུག་གི་མཚན་ཉིད།
Enumeration Block 12:
དེ་ལ་གཉིས་ལས། སྤངས་པ་མཐར་ཐུག་གི་མཚན་ཉིད།
Enumeration Block 13:
རྟོགས་པ་མཐར་ཐུག་ལ་གསུམ་སྟེ། ཤེས་པ། ཁྱད་པར། ངོ་བོ་ཉིད་དོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 14:
དེ་ལ་གཞི་ཤེས་ལས་གཞན་དོན་སྒྲུབ་པ་ཕན་བདེ་སྐྱོབ་པ་གསུམ། ལམ་ཤེས་ལས་གཞན་དོན་སྒྲུབ་པ་སྐྱབས་སོགས་བདུན། རྣམ་མཁྱེན་ལས་གཞན་དོན་སྒྲུབ་པ་རྟེན་གྱི་མཛད་པའོ། །
Enumeration Block 15:
གསུམ་པ་ལ་གཉིས་ཏེ། བྱེད་སྒྲུབ་དང། ལས་སྒྲུབ་བོ། །དང་པོ་ལ་གསུམ་སྟེ། ཤེས་པ། ཁྱད་པར། བྱེད་པའོ། །
Enumeration Block 16:
རྩོད་པ་སང་བ་ལ་གསུམ་སྟེ། འབྲས་བུའི་མཚན་ཉིད་ལ་དང། རྒྱུའི་ལ་དང་། འབྲས་བུ་མཚོན་ཚུལ་ལ་རྩོད་སྤང་ངོ་། །
Enumeration Block 17:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མདོར་བསྟན་ལ། གསུམ་ལས།
Enumeration Block 18:
རྩ་བ་ལ་གཉིས་ཏེ། བྱེད་སྒྲུབ་དང། ལས་སྒྲུབ་བོ། །
Enumeration Block 19:
འདིས་མཚོན་པར་བྱེད་པ་བྱེད་སྒྲུབ་ཀྱི་མཚན་ཉིད་དེའང་རྣམ་པ་གསུམ་སྟེ། ཤེས་པའི་བདག་ཉིད་ཀྱི་མཚན་ཉིད་དང། ཉན་རང་དང་ཐུན་མོང་མིན་པའི་ཆོས་ཁྱད་པར་གྱི་དང། གཞན་ལ་ཕན་པ་སྒྲུབ་པ་བྱེད་པའི་མཚན་ཉིད་དོ། །
Enumeration Block 20:
ཇི་ལྟར་ན། རྣམ་པ་བཞིར་རོ། །
Enumeration Block 21:
རྒྱས་བཤད་ལ་བཞི་སྟེ། ཤེས་པ་དང། ཁྱད་པར་དང། བྱེད་པ་དང། ངོ་བོ་ཉིད་ཀྱི་མཚན་ཉིད་དོ། །དང་པོ་ལ་གསུམ་སྟེ། གཞི་ཤེས་དང། ལམ་ཤེས་དང། རྣམ་མཁྱེན་གྱི་ཤེས་པའི་མཚན་ཉིད་དོ། །དང་པོ་ལ་གསུམ་ལས།
