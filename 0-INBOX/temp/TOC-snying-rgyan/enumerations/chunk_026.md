Enumeration Block 1:
ཞེས་སོགས་ཀྱི་དོན་ཅུང་ཟད་བཤད་ན། ལུགས་གཉིས་དགོད་པ་དང་། ལུགས་ཕྱི་མ་འཐད་པར་བསྒྲུབ་པ་དང་། དེ་ལ་གཞན་གྱི་ཀླན་ཀ་སྤང་བ་དང་། ལུགས་སྔ་མ་དགག་པ་དང་། ཡེ་ཤེས་ཀྱི་དབྱེ་བ་གཞན་མ་སྨོས་པའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 2:
གཉིས་པ་སའི་ཚོགས་བྱེ་བྲག་ཏུ་བཤད་པ་ལ། སྤྱིའི་དོན་དང་། ཡན་ལག་གི་དོན་ནོ། །
དང་པོ་ལ། ངོ་བོ་དང་། དབྱེ་བ་དང་། ཁྱད་ཆོས་དང་། འཕོ་ཚུལ་དང་། མིང་དོན་ནོ། །
Enumeration Block 3:
གསུམ་པ་ལ། ངོ་བོའི་ཁྱད་པར་དང་། སྤང་བྱའི་ཁྱད་པར་རོ། །
Enumeration Block 4:
གཉིས་པ་ཡན་ལག་གི་དོན་ལ། སྤྱིའི་མཚམས་སྦྱར་བ་དང་། སོ་སོའི་རང་བཞིན་ནོ། །
Enumeration Block 5:
གཉིས་པ་ལ། རྒྱུའི་ས་དགུ་དང་། འབྲས་བུའི་ས་བཅུ་པའོ། །
དང་པོ་ལ་དགུའི་དང་པོ། ས་དང་པོ་ལ་རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 6:
གཉིས་པ་ས་གཉིས་པ་ལ། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 7:
གསུམ་པ་ས་གསུམ་པ་འོད་བྱེད་པ་ལ། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 8:
བཞི་པ་ས་བཞི་པ་འོད་འཕྲོ་བ་ལ། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 9:
ལྔ་པ་ས་ལྔ་པ་སྦྱང་དཀའ་བ་ལ། རྩ་བ་དང་། འགྲེལ་པའོ། །
