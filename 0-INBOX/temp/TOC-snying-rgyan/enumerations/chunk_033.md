Enumeration Block 1:
གཉིས་པ་ཡན་ལག་གི་དོན་ལ། སྐད་ཅིག་མ་མདོར་བསྟན། རྣམ་པ་སྒོམ་ཚུལ་རྒྱས་པར་བཤད། རྣམ་པ་མ་བསྟན་པར་འདོད་པ་དགག་པའོ། །
དང་པོ་ལ་གཉིས་ཀྱི་དང་པོ་རྩ་བ་ནི།
Enumeration Block 2:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 3:
གསུམ་པ་འགྲེལ་པ་ལ། རྒྱས་པར་བཤད་པ་དང་། དོན་བསྡུ་བའོ། །
དང་པོ་ལ་བཞིའི་དང་པོ་སྡུག་བསྔལ་གྱི་རྣམ་པ་ནི།
Enumeration Block 4:
གསུམ་པ་ལ། ཁས་བླངས་བརྗོད་པ་དང་། དེ་དགག་པའོ། །
Enumeration Block 5:
གཉིས་པ་སྒོམ་ལམ་ལ། སྤྱིའི་མཚམས་སྦྱར་བ་དང་། སོ་སོའི་དོན་བཤད་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ། སྒོམ་ལམ་གྱི་བྱེད་པ་དང་། བྱེད་པ་ཅན་གྱི་སྒོམ་ལམ་མོ། །
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 7:
སྒོམ་ལམ་གྱི་བྱེད་པ་དྲུག་ཡོད་དེ། སྐྱེས་བུ་བྱེད་འབྲས་དང་པོ་བཞི་དང་། རྒྱུ་མཐུན་གྱི་འབྲས་བུ་ལྔ་པ་དང་། བདག་པོའི་འབྲས་བུ་དྲུག་པ་རྣམས་ཡོད་པའི་ཕྱིར།
Enumeration Block 8:
གཉིས་པ་ལ། དབྱེ་བ་བསྟན་ཏེ་མཚམས་སྦྱར་བ་དང་། སོ་སོའི་ངོ་བོའོ། །
