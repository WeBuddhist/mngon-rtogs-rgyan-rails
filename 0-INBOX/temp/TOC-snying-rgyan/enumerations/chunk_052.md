Enumeration Block 1:
དགུ་པོ་གང་ཞེ་ན། ཉན་རང་གི་ལམ་འབྲས་རྟོགས་པ་དམན་པ་དང་། བདག་རྐྱེན་ཡོངས་འཛིན་དམན་པ་དང་།དོན་གཉིས་སྒྲུབ་པའི་ཐབས་དམན་པ་དང་། སྤངས་རྟོགས་ཁྱད་པར་ཅན་ལས་ཉམས་པ་དང་། ལམ་འབྲས་ཁྱད་པར་ཅན་མ་ཐོབ་པས་ཉམས་པའོ། །
Enumeration Block 2:
གསུམ་པ་ལ། གཞན་དོན་སྒྲུབ་པའི་ཐབས་དམན་པ་དང་། རང་དོན་སྒྲུབ་པའི་ཐབས་དམན་པ་དང་། གཉིས་ཀའི་དོན་སྒྲུབ་པའི་ཐབས་དམན་པའོ། །
Enumeration Block 3:
བཞི་པ་ལ། སྤངས་པ་དམན་པ་དང་། རྟོགས་པ་དམན་པའོ། །
Enumeration Block 4:
ལྔ་པ་ལ། ལམ་ཁྱད་པར་ཅན་མ་ཐོབ་པས་ཉམས་པ་དང་། འབྲས་བུ་ཁྱད་པར་ཅན་མ་ཐོབ་པས་ཉམས་པའོ། །
Enumeration Block 5:
གཉིས་པ་འཛིན་རྟོག་རྒྱས་བཤད་ལ། རྫས་འཛིན་རྟོག་པ་དང་། བཏགས་འཛིན་རྟོག་པའོ། །
Enumeration Block 6:
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 7:
དགུ་གང་ཞེ་ན། རྣམ་མཁྱེན་གྱི་རྒྱུ་ལས་ཉམས་པ་དང་། འབྲས་བུ་རྣམ་མཁྱེན་ལས་ཉམས་པའོ། །
Enumeration Block 8:
དང་པོ་ལ་སྤྱོད་པ་ལ་ཞེན་པ་དང་། ཤེས་བྱ་ལ་ཞེན་པ་དང་། སྤང་གཉེན་ལ་ཞེན་པའོ། །
Enumeration Block 9:
དང་པོ་ལ། བླང་དོར་དུ་ཞེན་པ་དང་། དེའི་ཀུན་སློང་བདེན་པར་ཡིད་ལ་བྱེད་པ་དང་། དེའི་ཉེས་དམིགས་སོ། །
Enumeration Block 10:
གཉིས་པ་ལ། དངོས་པོ་ལ་བདེན་པར་ཞེན་པ། བདེན་མེད་དུ་ཞེན་པ་དང་། བཏགས་པ་ཙམ་དུ་ཞེན་པའོ། །
Enumeration Block 11:
གསུམ་པ་ལ། མི་མཐུན་ཕྱོགས་ལ་ཞེན་པ་དང་། གཉེན་པོ་ལ་ཞེན་པའོ། །
Enumeration Block 12:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 13:
དགུ་གང་ཞེ་ན། འབྲས་བུ་འདོད་པ་བཞིན་མི་ཐོབ་པ་དང་། ཕྱིན་ཅི་ལོག་ཏུ་ཞེན་པ་དང་། ཡང་དག་པའི་ལམ་དང་འགལ་བའོ། །
Enumeration Block 14:
གཉིས་པ་ལ། ལམ་ལ་ཕྱིན་ཅི་ལོག་ཏུ་ཞེན་པ་དང་། ཤེས་བྱ་ལ་ཕྱིན་ཅི་ལོག་ཏུ་ཞེན་པའོ། །
Enumeration Block 15:
གཉིས་པ་ལ། དགག་སྒྲུབ་བདེན་པར་འཛིན་པ་དང་། ཆོས་ལྡན་མི་ལྡན་བདེན་པར་འཛིན་པ་དང་། གནས་ལུགས་ཀྱི་དོན་བདེན་པར་འཛིན་པའོ། །
Enumeration Block 16:
གསུམ་པ་ལ། དམན་པའི་རིགས་ཉམས་པ་དང་། མཐུན་རྐྱེན་མ་ཚང་བ་དང་། འགལ་རྐྱེན་གྱིས་ཟིན་པའོ། །
Enumeration Block 17:
གཉིས་པ་ལ། འབྲས་བུ་ཁྱད་པར་ཅན་ལ་དོན་གཉེར་མེད་པ་དང་། དེའི་རྒྱུ་ཤེར་ཕྱིན་མེད་པའོ། །
Enumeration Block 18:
སྤང་བྱ་རྣམ་རྟོག་ལ་ཡུལ་གྱི་སྒོ་ནས་མུ་བཞི་རྣམ་པར་བཞག་པ་ནི།
Enumeration Block 19:
གཉིས་པ་གཉེན་པོ་ལ། མཐོང་ལམ་རྩེ་སྦྱོར་གྱི་རྒྱུ། མཐོང་ལམ་རྩེ་སྦྱོར་གྱི་འབྲས་བུ་བྱང་ཆུབ་ཆེན་པོ། མཐོང་ལམ་རྩེ་སྦྱོར་རང་གི་ངོ་བོའོ། །
Enumeration Block 20:
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 21:
གསུམ་པ་འགྲེལ་པ་ལ། བྱང་ཆུབ་ལ་འགོད་པ་དང་། དེའི་རྒྱུ་ལ་འགོད་པ་དང་། རང་ཉིད་བར་ཆད་མེད་པའི་རྒྱུ་སྒོམ་པའོ། །
Enumeration Block 22:
གཉིས་པ་ལ། རང་ལུགས་ཀྱི་བྱང་ཆེན་ངོས་བཟུང་བ། དངོས་པོ་བདེན་པར་ཁས་ལེན་པ་ལ་དེ་མི་འཐད་པ། མཐར་ཐུག་གི་བྱང་ཆེན་ཐོབ་པར་འདོད་པས་ཆོས་ཐམས་ཅད་བདེན་སྟོང་དུ་ཁས་བླང་དགོས་པར་བསྟན་པའོ། །
Enumeration Block 23:
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
