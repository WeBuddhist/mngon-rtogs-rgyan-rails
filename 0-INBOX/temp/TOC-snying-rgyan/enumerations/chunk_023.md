Enumeration Block 1:
བཞི་པ་སྒྲུབ་པའི་ངོ་བོ་ལ་གཉིས། སྒྲུབ་པ་སྤྱིའི་རྣམ་གཞག་དང་། སོ་སོའི་རང་བཞིན་བཤད་པའོ། །དང་པོ་ལ། སྟོན་ཚུལ་གྱི་སྒོ་ནས་གཉིས་སུ་དབྱེ་བ་དང་། མཚན་གཞིའི་སྒོ་ནས་བཞིར་དབྱེ་བའོ། །
Enumeration Block 2:
སྒྲུབ་པའི་ངོ་བོ་དེ་ལ་གཉིས་སུ་ཡོད་དེ། སྟོན་ཚུལ་མི་འདྲ་བའི་སྒོ་ནས་མཁྱེན་གསུམ་སྤྱིར་ཡུལ་དུ་བྱས་པའི་སྒྲུབ་པ་དང་། ཕར་ཕྱིན་དྲུག་ལྡན་དུ་བསྟན་པའི་སྒྲུབ་པ་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
ཡུལ་གྱི་སྒོ་ནས་རྣམ་པ་དགུར་དབྱེའོ། །
Enumeration Block 4:
འཇུག་པའི་སྒྲུབ་པ་རྣམ་པ་དགུ་པོ་དེ་ཡང་གཉིས་སུ་འདུས་ཏེ། རྒྱུ་ཐེག་པ་ཆེན་པོའི་ལམ་ལ་འཇུག་པ་དང་། དེའི་འབྲས་བུ་ལ་འཇུག་པ་གཉིས་སུ་ངེས་པའི་ཕྱིར།
Enumeration Block 5:
དང་པོ་ལ་གསུམ་ཡོད་དེ། རྟེན་ཐེག་ཆེན་གྱིས་བསྡུས་པའི་འཇིག་རྟེན་པའི་ལམ་བསམ་གཏན་ནས་གཟུགས་མེད་པའི་སྙོམས་པར་འཇུག་པ་ཉམས་སུ་ལེན་པའི་བྱ་བ་གཅིག་དང་། འཇིག་རྟེན་ལས་འདས་པའི་ལམ་ལ་འཇུག་པ་དང་། དེ་གཉིས་ཀ་ཐེག་དམན་ལས་འབྱེད་པའི་ཆོས་རྣམས་ཡོད་པའི་ཕྱིར།
