Enumeration Block 1:
དེའི་འོག་ཏུ་ཕྱིར་མི་འོང་བ་ཞེས་རྣམ་པར་བཞག་པ་ལ་རྣམ་པ་བཞིའོ། །
Enumeration Block 2:
འོག་མིན་གྱི་མཐར་ཐུག་པར་འགྲོ་བ་སྟེ་དེ་ལ་སྔར་གྱི་གྲངས་འཛིན་ལྔ་ལས་གཞན་རྣམ་པ་གསུམ་ཡོད་དེ།
Enumeration Block 3:
སྲིད་རྩེའི་ཉོན་མོངས་དང་ལྡན་པ་བྱང་ཆུབ་སེམས་དཔའ་ས་དྲུག་པ་བ་དེ་ལ་ཉི་ཤུའི་གྲངས་འཛིན་བརྒྱད་ལས་གཞན་རྣམ་པ་གཉིས་སོ། །
མཐོང་བའི་ཆོས་ལ་ཞི་བ་ལས་ཉོན་གྱི་དབང་གིས་ཉིང་མཚམས་སྦྱོར་བའི་སྐྱེ་བ་ཟད་པ་ཐོབ་པ་དང་རྣམ་ཐར་བརྒྱད་ཏིང་ངེ་འཛིན་གྱི་ལུས་ཀྱིས་མངོན་སུམ་དུ་བྱེད་པ་གཉིས་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
གཉིས་པ་གདམས་ངག་གི་དོན་བསྒོམས་པས་སྟོང་ཉིད་ལ་དམིགས་པའི་སྒོམ་བྱུང་སྐྱེས་པའི་ཐོག་མ་བཤད་པ་ལ། སྤྱིའི་དོན་དང་། ཡན་ལག་གི་དོན་ནོ། །
དང་པོ་ལ། རྟེན་དང་། ངོ་བོ་དང་། བློ་རིགས་དཔྱད་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ། མཚན་ཉིད་དང་། དབྱེ་བ་དང་། སྐྱེ་ཚུལ་དང་། ཕྱེ་བ་སོ་སོའི་དོན་ནོ། །
Enumeration Block 6:
གཉིས་པ་ལ། མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པའོ། །
དང་པོ་ལ། མཚམས་སྦྱར་བ་དང་། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 7:
གསུམ་པ་ལ་གཉིས། དམན་པའི་སྦྱོར་ལམ་ལས་ཁྱད་ཞུགས་པར་བསྒྲུབ་པ་དང་། དམིགས་ཚུལ་བཅུ་གཉིས་བཞིར་བསྡུ་བའོ། །དང་པོ་ལ་གཉིས། ཁྱད་པར་འཕགས་ཚུལ་དང་། དེའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 8:
གཉིས་པ་ལ་བཞི། དངོས་དང་། རྣམ་པ་གཞན་གྱི་སྒོ་ནས་དམིགས་པ་དང་། དེ་འདིར་དངོས་སུ་མི་སྟོན་པའི་རྒྱུ་མཚན་དང་། རྩོད་པ་སྤང་བའོ། །
