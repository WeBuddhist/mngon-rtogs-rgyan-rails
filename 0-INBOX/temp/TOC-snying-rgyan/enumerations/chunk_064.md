Enumeration Block 1:
གསུམ་པ་བསྡུས་དོན་གཞན་བསྟན་པ་ལ། དོན་དྲུག་ཏུ་བསྡུ་བ་དང་། དོན་གསུམ་དུ་བསྡུ་བའོ། །
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 2:
རྒྱན་གྱི་དོན་བསྡུས་བརྒྱད་ལས་གཞན་ཏེ་རྣམ་པ་དྲུག་ཏུ་ཤེས་པར་བྱ་སྟེ། མཁྱེན་པ་གསུམ་གྱི་ངོ་བོར་གྱུར་པའི་མཚན་ཉིད་དང་། མཁྱེན་གསུམ་དེའི་ཉམས་སུ་ལེན་པའི་རྣམ་རྫོགས་སྦྱོར་བ་དང་། སྦྱོར་བ་དེ་རབ་ཏུ་གྱུར་པའི་རྩེ་མོ་དང་། མཁྱེན་གསུམ་དེའི་ཉམས་ལེན་གྱི་གོ་རིམས་མཐར་གྱིས་པ་དང་། མཁྱེན་གསུམ་དེའི་སྦྱོར་བ་མཐར་ཐུག་པ་སྐད་ཅིག་མ་དང་། མཁྱེན་གསུམ་དེའི་རྣམ་སྨིན་ཆོས་སྐུ་དང་དྲུག་ནི།
Enumeration Block 3:
གསུམ་པ་འགྲེལ་པ་ལ། སོ་སོར་བཤད་པ་དང་། དོན་བསྡུས་ནས་ཚིག་དོན་རྒྱས་པ་སྔ་མ་ལ་ཁ་འཕང་བའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 5:
ཡུམ་གསུམ་གྱི་དོན་བསྡུས་པ་སྔ་མ་གཉིས་ལས་གཞན་ཏེ། ཡུལ་དང་རྒྱུ་དང་འབྲས་བུ་རྣམ་པ་གསུམ་མོ། །
Enumeration Block 6:
གསུམ་པ་བཤད་པ་མཐར་ཕྱིན་པའི་བྱ་བ་ལ་གསུམ། བཤད་བྱ་འཆད་བྱེད་ཀྱི་ཁྱད་པར་དང་། བརྩམས་པའི་དགེ་བ་བསྔོ་བ་དང་། ཁེངས་སྐྱུང་ཞིང་འགྲེལ་པ་རྩོམ་པ་སྤྲོ་བའི་རྒྱུ་མཚན་ནོ། །དང་པོ་ལ། བཤད་བྱའི་ཁྱད་པར་དང་། གང་ལ་བརྟེན་ནས་ཚུལ་ཇི་ལྟར་བཤད་པའོ། །
Enumeration Block 7:
གསུམ་པ་ལ་ཁེངས་སྐྱུང་བ་དང་། ནོངས་པ་བཟོད་པར་གསོལ་བ་དང་། འགྲེལ་པ་རྩོམ་པར་སྤྲོ་བའི་རྒྱུ་མཚན་ནོ། །
དང་པོ་ལ་གཉིས་ཀྱི་དང་པོ།
Enumeration Block 8:
གསུམ་པ་མཇུག་གི་དོན་ལ། བསྟན་བཅོས་མཛད་པ་པོ་དང་། གང་གིས་བསྒྱུར་བའི་ཚུལ་ལོ། །
