Enumeration Block 1:
གསུམ་པ་ས་གསུམ་པ་འོད་བྱེད་པ་ལ། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 2:
བཞི་པ་ས་བཞི་པ་འོད་འཕྲོ་བ་ལ། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 3:
ལྔ་པ་ས་ལྔ་པ་སྦྱང་དཀའ་བ་ལ། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 4:
དྲུག་པ་ས་དྲུག་པ་མངོན་དུ་གྱུར་པ་ལ། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 5:
བདུན་པ་ས་བདུན་པ་རིང་དུ་གྱུར་པ་ལ། སྤང་བྱ་ཉི་ཤུ་སྤོང་བ་དང་། གཉེན་པོ་ཉི་ཤུ་བསྟེན་པར་བསྟན་པའོ། །
དང་པོ་ལ། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ། མཚམས་སྦྱར་བ་དང་། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 7:
བརྒྱད་པ་ས་བརྒྱད་པ་མི་གཡོ་བ་ལ། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 8:
ས་དགུ་པ་ལེགས་པའི་བློ་གྲོས་ལ། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 9:
གཉིས་པ་འབྲས་བུའི་ས་བཅུ་པ་ལ། མཚམས་སྦྱར་བ་དང་། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 10:
གསུམ་པ་ལ། འདའ་བྱ་ས་དགུ་བཤད་པ་དང་། དེ་ལས་འདས་པ་ས་བཅུ་པ་བཤད་པའོ། །
Enumeration Block 11:
གསུམ་པ་གཉེན་པོའི་ཚོགས་བྱེ་བྲག་ཏུ་བཤད་པ་ལ། མཚམས་སྦྱར་བ་དང་། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 12:
བཞི་པ་ངེས་པར་འབྱུང་བའི་སྒྲུབ་པ་ལ། མཚམས་སྦྱར་བ་དང་། རྩ་བ་དང་། འགྲེལ་པའོ། །
