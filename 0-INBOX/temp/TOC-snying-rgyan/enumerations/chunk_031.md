Enumeration Block 1:
གཉིས་པ་ལ། མཚམས་སྦྱར་བ་དང་། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 2:
གཉིས་པ་རང་རྒྱལ་གྱི་ལམ་ཤེས་པའི་རང་བཞིན་ལ། སྤྱི་དང་། ཡན་ལག་གི་དོན་ནོ། །
Enumeration Block 3:
གཉིས་པ་ལ་རྟེན་གྱི་ཁྱད་པར། དེའི་ལམ་ཇི་ལྟར་ཤེས་པའི་ཚུལ། དེའི་རྒྱུ་ངེས་འབྱེད་ཆ་མཐུན་བཤད་པའོ། །
དང་པོ་ལ། ཁྱད་ཆོས་དངོས་དང་། རྩོད་སྤང་ངོ༌། །
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 4:
གསུམ་པ་འགྲེལ་པ་ལ། ལམ་བགྲོད་པའི་ཁྱད་པར་དང་། ཆོས་སྟོན་པའི་ཁྱད་པར་རོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 6:
གཉིས་པ་ལ། མཚམས་སྦྱར་བ་དང་། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ། ཚིག་དོན་དང་། མཐའ་དཔྱད་པའོ། །
