Enumeration Block 1:
གཉིས་པ་ཡན་ལག་གི་དོན་ལ། སྤྱིའི་མཚམས་སྦྱར་བ་དང་། སོ་སོའི་དོན་བཤད་པ་དང་། དོན་བསྡུ་བའོ། །
Enumeration Block 2:
གཉིས་པ་ལ། བསྟན་པ་དང་། བཤད་པའོ། །
དང་པོ་ལ། གཟུང་རྟོག་བཤད་པ་དང་། འཛིན་རྟོག་བཤད་པ་གཉིས་ཀྱི་དང་པོ་ལ། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ། མཚམས་སྦྱར་བ་དང་། སོ་སོའི་དོན་ནོ། །
Enumeration Block 4:
གཉིས་པ་ལ། གཟུང་རྟོག་དང་། འཛིན་རྟོག་གོ །
Enumeration Block 5:
གཉིས་པ་ལ། རྫས་འཛིན་རྟོག་པ་དང་། བཏགས་འཛིན་རྟོག་པའོ། །
Enumeration Block 6:
གསུམ་པ་ཡོངས་འཛིན་བཤད་པ་ལ་གསུམ། གོ་རིམས་གཞན་གྱི་དགོས་པ་བསྟན་པས་མཚམས་སྦྱར་བ་དང་། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 7:
གསུམ་པ་གདམས་དོན་ཇི་ལྟར་སྒྲུབ་པའི་སྒྲུབ་པ་བཤད་པ་ལ་བཞི། སྒྲུབ་པའི་རྟེན་དང་། དམིགས་པ་དང་། ཆེད་དུ་བྱ་བ་དང་། སྒྲུབ་པའི་ངོ་བོའོ། །དང་པོ་ལ། སྤྱིའི་དོན་དང་། ཡན་ལག་གི་དོན་ནོ། །
དང་པོ་ལ། ངོ་བོ་དང་། དབྱེ་བ་དང་། རྩོད་པ་སྤང་བ་དང་། རིགས་ནས་ཇི་ལྟར་འཁྲིད་པའི་ཚུལ་ལོ། །
དང་པོ་ལ། སེམས་ཙམ་པའི་ལུགས་བཀོད་ནས་འཐད་མི་འཐད་དཔྱད་པ་དང་། རང་གི་ལུགས་སོ། །
