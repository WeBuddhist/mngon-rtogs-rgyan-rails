Enumeration Block 1:
གཉིས་པ་ལ། གོ་རིམས་ངེས་པ་དང་། གྲངས་ངེས་པ་དང་། ཡུམ་སྲས་ཀྱི་དོན་དང་། བསྟོད་ཡུལ་གྱི་མཁྱེན་གསུམ་ངོས་བཟུང་བའོ། །
Enumeration Block 2:
གསུམ་པ་ལ། བསྡུས་པའི་དོན་དང་། དགོས་པའི་དོན་དང་། རྩོད་པ་སྤོང་བ་དང་། ཚིག་གི་དོན་ནོ། །
Enumeration Block 3:
གཉིས་པ་ལ། རྒྱས་པར་བཤད་པ་དང་། དོན་བསྡུ་བའོ། །
དང་པོ་ལ། དད་པ་སྐྱེ་ཚུལ་དང་། དེ་ལས་དོན་གཉེར་གྱི་འདུན་པ་སྐྱེ་བ་དང་། དེ་ལས་ཞུགས་ནས་འབྲས་བུ་ཐོབ་པའི་ཚུལ་ལོ། །
དང་པོ་ལ། དབང་རྟུལ་དད་པ་སྐྱེ་ཚུལ་དང་། དབང་རྣོན་དད་པ་སྐྱེ་ཚུལ་ལོ། །
Enumeration Block 4:
དེ་ལ་སློབ་དཔོན་ཉིད་བཞེད་པའི་དགག་བྱའི་ཆོས་ངོས་བཟུང་བ་དང་། དེ་གཞི་གཞན་གྱི་སྟེང་དུ་འགོག་པའི་གཏན་ཚིགས་སོ། །
Enumeration Block 5:
གཉིས་པ་ལ། རྟགས་དགོད་པ་དང་། ཚུལ་བསྒྲུབ་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ། ཕྱོགས་ཆོས་བསྒྲུབ་པ་དང་། ཁྱབ་པ་བསྒྲུབ་པའོ། །
དང་པོ་ལ། བདེན་པའི་གཅིག་བྲལ་དུ་བསྒྲུབ་པ་དང་། དུ་བྲལ་དུ་བསྒྲུབ་པའོ། །
Enumeration Block 7:
བཞི་པ་ལ། ཡོན་ཏན་སོ་སོའི་སྒོ་ནས་བསྟོད་པ་དང་། བསྡུས་ཏེ་ཕྱག་འཚལ་བའོ། །
