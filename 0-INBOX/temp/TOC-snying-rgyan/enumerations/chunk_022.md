Enumeration Block 1:
གཉིས་པ་ལ། མཚམས་སྦྱར་བ་དང་། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 2:
གཉིས་པ་སྒྲུབ་པའི་དམིགས་པ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང་། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ། ཚིག་དོན་དང་། མཐའ་དཔྱད་པའོ། །
Enumeration Block 4:
འདིའི་དོན་གཞན་གྱིས་བཞག་པ་མི་འཐད་པ་དང་། རང་གི་ལུགས་སོ། །
དང་པོ་ལ། གཞན་གྱི་འདོད་པ་བཀོད་པ་ཕ་རོལ་པོའི་འདོད་པ་མ་ཡིན་པ་དང་། རང་གི་ལུགས་བཞག་པ་མི་འཐད་པའོ། །
Enumeration Block 5:
གསུམ་པ་ལ། སྤྱིར་བསྟན་པ་དང་། སོ་སོར་བཤད་པ་དང་། དམིགས་པ་བཅུ་གཅིག་ལ་རིམ་གྱིས་དམིགས་པར་བསྟན་པའོ། །
Enumeration Block 6:
གསུམ་པ་སྒྲུབ་པའི་ཆེད་དུ་བྱ་བ་ལ། མཚམས་སྦྱར་བ་དང་། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 7:
བཞི་པ་སྒྲུབ་པའི་ངོ་བོ་ལ་གཉིས། སྒྲུབ་པ་སྤྱིའི་རྣམ་གཞག་དང་། སོ་སོའི་རང་བཞིན་བཤད་པའོ། །དང་པོ་ལ། སྟོན་ཚུལ་གྱི་སྒོ་ནས་གཉིས་སུ་དབྱེ་བ་དང་། མཚན་གཞིའི་སྒོ་ནས་བཞིར་དབྱེ་བའོ། །
