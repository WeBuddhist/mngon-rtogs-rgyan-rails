Enumeration Block 1:
བྱང་ཆུབ་སེམས་དཔའི་ལམ་ཤེས་ལ་གཉིས་ཀྱི་དང་པོ།
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས་ཀྱི་དང་པོ་ཐེག་ཆེན་སྒོམ་ལམ་གྱི་བྱེད་པའི་མཚན་ཉིད། དེ་བསྒོམས་སྟོབས་ཀྱིས་ཐོབ་པའི་ཕན་ཡོན་ནོ། །
Enumeration Block 3:
གཉིས་པ་ལ། ཟག་བཅས་སྒོམ་ལམ་དང་། ཟག་མེད་སྒོམ་ལམ་མོ། །
དང་པོ་ལ་གསུམ་གྱི་དང་པོ།
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས་ཀྱི་དང་པོ།
Enumeration Block 5:
གསུམ་པ་ལ། གཞི་ཤེས་མཚོན་བྱེད་ཀྱི་ཆོས་དང་། བསྟན་བཤད་སྦྱར་བའོ། །
དང་པོ་ལ། འབྲས་ཡུམ་ལ་ཉེ་རིང་གི་རྒྱུ་མཚན་དང་། རྒྱུ་མཚན་དེ་ཉིད་སྒྲུབ་པ་དང་། མི་མཐུན་པ་དང་གཉེན་པོའི་ཕྱོགས་ཀྱི་དབྱེ་བ་དང་། གཞི་ཤེས་ཀྱི་སྦྱོར་བའོ། །
Enumeration Block 6:
བཞི་པ་ལ་གཞི་ཤེས་སྦྱོར་བའི་དབྱེ་བ་དང་། འཛིན་སྟངས་དང་འབྲས་བུའོ། །
Enumeration Block 7:
བྱང་ཆུབ་སེམས་དཔའི་རྒྱུད་ལ་ཤེས་པར་བྱ་བའི་མངོན་རྟོགས་དང་།
མངོན་དུ་བྱ་བའི་མངོན་རྟོགས་གཉིས་ལས།
Enumeration Block 8:
གཉིས་པ་ལ། དབང་དུ་བྱ་བ་རྒྱུ་འབྲས་དང་། བརྟན་པ་རྒྱུ་འབྲས་སོ། །
དང་པོ་ལ་གཉིས་ཀྱི་དང་པོ། རྣམ་རྫོགས་སྦྱོར་བ་ལ་གཉིས། མཚོན་བྱེད་ཀྱི་ཆོས་དང་། བསྟན་བཤད་སྦྱར་བའོ། །དང་པོ་ལ། དགེ་རྩ་གསོག་པའི་རྟེན་གྱི་དབང་དུ་བྱས་ནས་སྤྱིའི་རྣམ་གཞག་དང་། དགེ་རྩ་སྨིན་པའི་རྟེན་གྱི་དབང་དུ་བྱས་ནས་རྒྱུད་ལ་སྐྱེ་བའི་རིམ་པ་དངོས་སུ་བསྟན་པའོ། །
Enumeration Block 9:
དང་པོ་ལ། ལམ་ཤེར་ཕྱིན་གྱི་རྣལ་འབྱོར་སྒོམ་པའི་འཛིན་སྟངས་ཀྱི་དབྱེ་བ་དང་། མཉམ་གཞག་གི་སྦྱོར་བ་དང་། སྦྱོར་བ་སྒོམ་པའི་སྐྱོན་ཡོན་དང་། ལམ་ཤེར་ཕྱིན་གྱི་རྣལ་འབྱོར་དུ་མཚོན་པའི་མཚན་ཉིད་དོ། །
Enumeration Block 10:
གཉིས་པ་ལ། སྦྱོར་བ་སྐྱེས་པའི་གནས་སྐབས་དང་། སྨིན་པའི་སྐབས་དང་། རྟེན་གྱི་གང་ཟག་དང་། གང་ཟག་གི་སྒོམ་རིམ་མོ། །
Enumeration Block 11:
བཞི་པ་ལ་གསུམ་གྱི་དང་པོ།
Enumeration Block 12:
གཉིས་པ་རྩེ་སྦྱོར་ལ་བཞིའི་དང་པོ།
