Enumeration Block 1:
གཉིས་པ་རྒྱས་བཤད་ལ། མཁྱེན་པ་གསུམ་གྱི་ལུས་བཤད་པ་དང་། སྦྱོར་བ་བཞིའི་ལུས་བཤད་པ་དང་། ཆོས་སྐུའི་ལུས་བཤད་པའོ། །
དང་པོ་ལ། རྣམ་མཁྱེན་གྱི་ལུས་དང་། ལམ་ཤེས་ཀྱི་ལུས་དང་། གཞི་ཤེས་ཀྱི་ལུས་བཤད་པའོ། །
དང་པོ་ལ། ཆོས་བཅུའི་རང་བཞིན། དེས་རྣམ་མཁྱེན་མཚོན་ཚུལ། གོ་རིམས་ངེས་པ། བསྟན་བཤད་སྦྱར་བའོ། །
དང་པོ་ལ། བསམ་པ་དམ་བཅའ་དང་། དེའི་དོན་སྒྲུབ་པའི་ཐབས་སྟོན་པ་གདམས་ངག་དང་། དམ་བཅའི་དོན་སྒྲུབ་བྱེད་ཀྱི་སྒྲུབ་པའོ། །
Enumeration Block 2:
གསུམ་པ་ལ། སྟོང་ཉིད་རྟོགས་པའི་སྒོམ་བྱུང་གི་སྒྲུབ་པ་ཐོག་མ་ངོས་བཟུང་བ་དང་། སྒྲུབ་པ་སྤྱིའི་རྣམ་གཞག་གོ །
Enumeration Block 3:
གཉིས་པ་ལ། སྒྲུབ་པའི་རྟེན་དང་། བརྟེན་པ་བསྒྲུབ་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ། སྒྲུབ་པའི་དམིགས་པ་དང་། ཆེད་དུ་བྱ་བ་དང་། སྒྲུབ་པའི་དབྱེ་བའོ། །
Enumeration Block 5:
གཉིས་པ་ལ། ཆོས་བཅུ་གཅིག་གིས་ལམ་ཤེས་མཚོན་པ་དང་། བསྟན་བཤད་སྦྱར་བའོ། །
དང་པོ་ལ། ལམ་ཤེས་ཀྱི་ཡན་ལག་དང་། ཡན་ལག་ཅན་གྱི་ལམ་ཤེས་སོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ།
Enumeration Block 7:
གསུམ་པ་བྱང་ཆུབ་སེམས་དཔའི་ལམ་ཤེས་ལ་གཉིས་ཀྱི་དང་པོ།
Enumeration Block 8:
གཉིས་པ་ལ་གཉིས་ཀྱི་དང་པོ།
Enumeration Block 9:
གཉིས་པ་ལ། ཟག་བཅས་སྒོམ་ལམ་དང་། ཟག་མེད་སྒོམ་ལམ་མོ། །
དང་པོ་ལ་གསུམ་གྱི་དང་པོ།
Enumeration Block 10:
གཉིས་པ་ལ་གཉིས་ཀྱི་དང་པོ།
