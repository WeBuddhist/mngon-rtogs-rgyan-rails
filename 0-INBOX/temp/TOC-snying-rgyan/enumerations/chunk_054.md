Enumeration Block 1:
གཉིས་པ་ལ། སྒྲིབ་པ་དོན་དམ་དུ་ཡོད་པ་ལ་གནོད་བྱེད་བསྟན་པ་དང་། དེ་ཁས་ལེན་པ་དང་ཤེས་སྒྲིབ་ཀྱི་ས་བོན་སྤོང་ནུས་པར་འདོད་པ་ཁས་བླངས་འགལ་བའོ། །
Enumeration Block 2:
གསུམ་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 3:
གཉིས་པ་རྩ་བ་ལ། གཞི་དངོས་པོའི་གནས་ལུགས་དང་། དེ་རྟོགས་པའི་ལྟ་བ་དང་། ལྟ་བ་གོམས་པའི་འབྲས་བུའོ། །
Enumeration Block 4:
གསུམ་པ་མཐོང་ལམ་རྩེ་སྦྱོར་གྱི་ངོ་བོ་ལ། དངོས་དང་། སྤངས་པ་ལ་དབང་བྱེད་པའོ། །
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 5:
གསུམ་པ་འགྲེལ་པ་ལ། དངོས་དང་། དེའི་བྱེད་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 7:
གསུམ་པ་འགྲེལ་པ་ལ། མཉམ་གཞག་གིས་བསྡུས་པའི་མཐོང་ལམ་རྩེ་སྦྱོར། དེའི་རྗེས་ལ་ཐོབ་པའི་ཤེས་མཐོང་གིས་བལྟས་ནས་འདའ་བར་བྱ་བའི་མཐོང་ལམ་རྩེ་སྦྱོར་རོ། །
Enumeration Block 8:
གསུམ་པ་སྒོམ་ལམ་རྩེ་སྦྱོར་ལ། གཉེན་པོ་སྒོམ་ལམ། སྤང་བྱ་རྟོག་པ། གཉེན་པོས་སྤང་བྱ་སྤངས་པའི་ཕན་ཡོན་ནོ། །
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 9:
གཉིས་པ་རྩ་བ་ལ། མདོ་ལས་བསྟན་ཚུལ། བསྟན་བཅོས་ཀྱིས་བསྡུས་ཚུལ། ཐོད་བརྒལ་གྱི་རང་བཞིན་བཤད་པ་གསུམ་གྱིས་སྤྱིའི་རྣམ་གཞག་དང་། ཚིག་དོན་ནོ། །
Enumeration Block 10:
གསུམ་པ་འགྲེལ་པ་ལ། སྦྱོར་བ། དངོས་གཞི། མཇུག་བསྡུ་བའོ། །
