Enumeration Block 1:
གཉིས་པ་སྒོམ་ལམ་ལ། སྤྱིའི་མཚམས་སྦྱར་བ་དང་། སོ་སོའི་དོན་བཤད་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ། སྒོམ་ལམ་གྱི་བྱེད་པ་དང་། བྱེད་པ་ཅན་གྱི་སྒོམ་ལམ་མོ། །
Enumeration Block 3:
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 4:
གཉིས་པ་ལ། དབྱེ་བ་བསྟན་ཏེ་མཚམས་སྦྱར་བ་དང་། སོ་སོའི་ངོ་བོའོ། །
Enumeration Block 5:
གཉིས་པ་ལ། ཟག་བཅས་སྒོམ་ལམ་དང་། ཟག་མེད་སྒོམ་ལམ་མོ། །
Enumeration Block 6:
དང་པོ་ལ་གསུམ། དབྱེ་བས་མཚམས་སྦྱར་བ་དང་། སོ་སོའི་དོན་བཤད་པ་དང་། དོན་བསྡུ་བའོ། །
Enumeration Block 7:
གཉིས་པ་ལ། མོས་པ། བསྔོ་བ། རྗེས་སུ་ཡི་རང་བའོ། །
Enumeration Block 8:
དང་པོ་ལ་དངོས་དང་ཕན་ཡོན་གཉིས་ཀྱི་དང་པོ་ལ། གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 9:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 10:
གཉིས་པ་བསྔོ་བ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 11:
གསུམ་པ་རྗེས་སུ་ཡི་རང་བ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 12:
གཉིས་པ་ཟག་མེད་སྒོམ་ལམ་ལ། དབྱེ་བས་མཚམས་སྦྱར་བ་དང་། སོ་སོའི་ངོ་བོའོ། །
Enumeration Block 13:
གཉིས་པ་ལ། སྒྲུབ་པ་སྒོམ་ལམ་དང་། རྣམ་དག་སྒོམ་ལམ་མོ། །
Enumeration Block 14:
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 15:
གཉིས་པ་ལ་བཞི། རྒྱུའི་ཁྱད་པར་དང་། ཡུལ་དང་། འབྲས་བུ་དང་། ངོ་བོའི་ཁྱད་པར་རོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
