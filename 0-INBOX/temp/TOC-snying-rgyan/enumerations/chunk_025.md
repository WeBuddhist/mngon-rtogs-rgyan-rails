Enumeration Block 1:
བསམ་གཏན་དང་པོ་ལ་ཡན་ལག་ལྔ་སྟེ་རྟོག་དཔྱོད་དང་། དབེན་པ་ལས་སྐྱེས་པའི་དགའ་བདེ་དང་། སེམས་རྩེ་གཅིག་པའོ། །
གཉིས་པ་ལ་བཞི་སྟེ། ནང་རབ་ཏུ་དང་བ་དང་། ཏིང་ངེ་འཛིན་ལས་སྐྱེས་པའི་དགའ་བདེ་དང་། སེམས་རྩེ་གཅིག་པའོ། །
གསུམ་པ་ལ་ལྔ་སྟེ། དྲན་ཤེས་བཞིན་བཏང་སྙོམས་དང་། བདེ་བ་དང་། སེམས་རྩེ་གཅིག་པའོ། །
བཞི་པ་ལ་ཡན་ལག་བཞི་སྟེ། དྲན་པ་དང་བཏང་སྙོམས་ཡོངས་སུ་དག་པ་དང་། ཚོར་བ་བཏང་སྙོམས་དང་། སེམས་རྩེ་གཅིག་པའོ། །
Enumeration Block 2:
གསུམ་པ་ལ།སྤྱིར་བསྟན་པ་དང་། ཚོགས་གསུམ་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
དང་པོ་ལ། མཚམས་སྦྱར་བ་དང་། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 3:
གསུམ་པ་ལ། སོ་སོའི་ངོ་བོ་དང་། ཚོགས་སུ་འཇོག་པའི་རྒྱུ་མཚན་དང་། གྲངས་ངེས་སོ། །
Enumeration Block 4:
དབྱེ་ན། བཟོད་པའི་གཟུངས་དང་། གསང་སྔགས་ཀྱི་གཟུངས་དང་། ཚིག་དང་དོན་གྱི་གཟུངས་སོ། །
Enumeration Block 5:
གཉིས་པ་ལ། ཡེ་ཤེས་ཀྱི་ཚོགས་བྱེ་བྲག་ཏུ་བཤད་པ་དང་། སའི་ཚོགས་དང་། གཉེན་པོའི་ཚོགས་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
དང་པོ་ལ། དགག་གཞིའི་དབྱེ་བས་སྟོང་ཉིད་ཉི་ཤུ་དང་། ཡུལ་ཅན་དེ་རྟོགས་པའི་ཡེ་ཤེས་ཉི་ཤུ་དང་། ཡེ་ཤེས་ཀྱི་དམིགས་པ་གང་ཡིན་དཔྱད་པའོ། །
Enumeration Block 6:
ཡེ་ཤེས་ཀྱི་ཚོགས་ནི་སོ་སོ་སྐྱེ་བོའི་ས་དང་། ས་བཅུ་དང་། སངས་རྒྱས་ཀྱི་ཡེ་ཤེས་ཀྱིས་བསྡུས་པའོ། །
Enumeration Block 7:
ལུགས་གཉིས་དགོད་པ་དང་། ལུགས་ཕྱི་མ་འཐད་པར་བསྒྲུབ་པ་དང་། དེ་ལ་གཞན་གྱི་ཀླན་ཀ་སྤང་བ་དང་། ལུགས་སྔ་མ་དགག་པ་དང་། ཡེ་ཤེས་ཀྱི་དབྱེ་བ་གཞན་མ་སྨོས་པའི་རྒྱུ་མཚན་ནོ། །
