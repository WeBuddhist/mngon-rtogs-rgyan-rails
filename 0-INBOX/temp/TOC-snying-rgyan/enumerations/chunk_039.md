Enumeration Block 1:
གཉིས་པ་ལ། རྣམ་རྫོགས་སྦྱོར་བ་སྤྱིའི་རྣམ་གཞག་དང་། ཐར་པ་ཆ་མཐུན་ནས་བཟུང་སྟེ་རྒྱུད་ལ་སྐྱེ་བའི་རིམ་པ་བཤད་པའོ། །
དང་པོ་ལ། རྣམ་རྫོགས་སྦྱོར་བའི་ངོ་བོ་དང་། སྦྱོར་བ་སྒོམ་པའི་སྐྱོན་ཡོན་དང་། སྦྱོར་བའི་མཚན་ཉིད་དོ། །
དང་པོ་ལ། མི་མཐུན་ཕྱོགས་མ་ལུས་པའི་གཉེན་པོ་ཤེས་པའི་ཡན་ལག་རྣམ་པའི་དབྱེ་བ་དང་། བདེན་འཛིན་དངོས་སུ་འཇོམས་བྱེད་ཀྱི་སྦྱོར་བ་ཁྱད་པར་ཅན་ངོས་བཟུང་བའོ། །
དང་པོ་ལ། མདོར་བསྟན་དང་། རྒྱས་བཤད་དང་། དོན་བསྡུ་བའོ། །
དང་པོ་ལ་གཉིས་ཀྱི་དང་པོ་རྩ་བ་ནི།
Enumeration Block 2:
གཉིས་པ་ལ། གཞི་ཤེས་ཀྱི་རྣམ་པ་དང་། ལམ་ཤེས་ཀྱི་རྣམ་པ་དང་། རྣམ་མཁྱེན་གྱི་རྣམ་པའོ། །
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 3:
གསུམ་པ་འགྲེལ་པ་ལ། བདེན་པ་དང་པོ་གསུམ་གྱི་རྣམ་པ་དང་། ལམ་བདེན་གྱི་རྣམ་པ་དང་། གྲངས་ཀྱི་དོན་བསྡུ་བའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ། ལམ་བདེན་གྱི་དབྱེ་བ་མདོར་བསྟན་ནི།
Enumeration Block 5:
གཉིས་པ་རྒྱས་བཤད་ལ་གསུམ་གྱི་དང་པོ། ཉོན་སྒྲིབ་ཀྱི་གཉེན་པོ་ལ་བཞིར་དབྱེ་བ་ནི། ལམ་གསུམ་ཡོད་པ་དེ་ལ་ལམ་དང་པོ་ལ་རྣམ་པ་བཞི་ཡོད་དེ།
Enumeration Block 6:
གཉིས་པ་ལམ་ཤེས་ཀྱི་རྣམ་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 7:
གསུམ་པ་འགྲེལ་པ་ལ། སྤྱིར་བསྟན། སོ་སོར་བཤད། སྤྱིའི་དོན་བསྡུ་བའོ། །
Enumeration Block 8:
གཉིས་པ་ལ་བཞིའི་དང་པོ། ཀུན་འབྱུང་སྤང་གཉེན་གྱི་སྒོ་ནས་བསྟན་པ་ནི།
Enumeration Block 9:
གསུམ་པ་རྣམ་མཁྱེན་གྱི་རྣམ་པ་ལ། མདོར་བསྟན་པ། རྒྱས་པར་བཤད་པའོ། །
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
