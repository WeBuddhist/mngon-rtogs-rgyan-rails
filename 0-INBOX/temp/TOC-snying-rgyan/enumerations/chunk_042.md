Enumeration Block 1:
གསུམ་པ་འགྲེལ་པ་ལ། དངོས་གཞིའི་སྦྱོར་བ་ལྔ་ནི།
Enumeration Block 2:
སྔ་མ་ལྔ་དང་། ཕྱི་མ་རྣམ་པ་བཅོ་ལྔ་སྟེ་སྦྱོར་བ་ཉི་ཤུ་ཡིན་ནོ། །
Enumeration Block 3:
གཉིས་པ་སྦྱོར་བ་སྒོམ་པའི་སྐྱོན་ཡོན་ལ། སྦྱོར་བའི་ཡོན་ཏན་དང་། སྦྱོར་བ་སྒོམ་པའི་གེགས་སོ། །
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 4:
སྦྱོར་བ་སྒོམ་པའི་སྟོབས་ཀྱིས་བདུད་ཀྱི་མཐུ་བཅོམ་པ་དང་། ལ་སོགས་པ་ངེས་པར་འཐོབ་པའི་བར་གྱི་ཡོན་ཏན་རྣམ་པ་བཅུ་བཞི་འབྱུང་བའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 6:
སྦྱོར་བ་སྐྱེ་བའི་གེགས་དང་། རྒྱུན་གནས་པའི་གེགས་སྐྱོན་ནི་བཅུ་ཚན་བཞི་དང༌བཅས་པ་དྲུག་ཏུ་ངེས་པར་རྟོགས་པར་བྱའོ། །
Enumeration Block 7:
གསུམ་པ་འགྲེལ་པ་ལ། སོ་སོར་བཤད་པ་དང་། གྲངས་བསྡུ་བའོ། །
དང་པོ་ལ། སྦྱོར་བའི་འགལ་རྐྱེན་རང་ལ་བརྟེན་པ་ཉི་ཤུ། རང་གཞན་གང་རུང་ལ་བརྟེན་པ་མཐུན་རྐྱེན་མ་ཚང་བ་ཉེར་གསུམ། འགལ་རྐྱེན་གཞན་ལ་བརྟེན་པ་གསུམ་མོ། །
Enumeration Block 8:
གཉིས་པ་ལ། སློབ་དཔོན་ལ་བརྟེན་པ། རང་ཉིད་ལ་བརྟེན་པ། གཉིས་ཀ་ལ་བརྟེན་པའོ། །
Enumeration Block 9:
སྔ་མ་བཅུ་དང་། ཕྱི་མ་བཞི་དང་བཅུ་ཚན་བཅུ་བཞིའོ། །
Enumeration Block 10:
དེ་ལྟར་འགལ་རྐྱེན་ཉེ་བར་གནས་པ་ཉེར་གསུམ་དང་། མཐུན་རྐྱེན་མ་ཚང་བ་ཉེར་གསུམ་ཡོད་པ་དེ་ལྟར་ན་སྐྱོན་བཞི་བཅུ་རྩ་དྲུག་ཡིན་ནོ། །
Enumeration Block 11:
གསུམ་པ་སྦྱོར་བའི་མཚན་ཉིད་ལ། སྤྱིའི་དོན་དང་། ཡན་ལག་གི་དོན་ནོ། །
དང་པོ་ལ་སློབ་དཔོན་སྔ་མའི་ལུགས་དགོད་པ་དང་། རང་གི་ལུགས་གཞག་པའོ། །
Enumeration Block 12:
སྦྱོར་བའི་མཚན་ཉིད་ནི་མཚོན་པ་དང་། མཚན་གཞི་དང་། མཚོན་བྱ་དང་། མཚན་ཉིད་བཞིའོ། །
Enumeration Block 13:
དེ་ལ་དབྱེ་ན་ཁྱད་མཚན་བཅུ་དྲུག་དང་། བྱེད་མཚན་བཅུ་གཅིག་གོ །
Enumeration Block 14:
གཉིས་པ་རང་གི་ལུགས་ནི། མཚན་གཞི་དང་། མཚོན་བྱ་དང་། མཚན་ཉིད་དང་། ཇི་ལྟར་མཚོན་པའི་ཚུལ་དང་། ས་མཚམས་སོ། །
Enumeration Block 15:
གཉིས་པ་ནི། སྤྱི་དང་བྱེ་བྲག་གཉིས་ལས་དང་པོ་ནི།
Enumeration Block 16:
ལམ་དང་འབྲས་བུའི་ཤེར་ཕྱིན་ཉིད་ལ་མངོན་པར་རྟོགས་པ་བརྒྱད་དུ་ཕྱེ་བ་ཡིན་ནོ། །
