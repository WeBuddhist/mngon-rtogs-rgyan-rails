Enumeration Block 1:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 2:
གསུམ་པ་ལ། དབྱེ་བ་དངོས་དང་། རྩོད་པ་སྤང་བའོ། །
Enumeration Block 3:
དང་པོ་ལ་གཉིས་ཀྱི་དྲི་བ་ནི།
Enumeration Block 4:
ལན་ལ་གཉིས་ཀྱི་དང་པོ་རྩ་བ་ནི།
Enumeration Block 5:
གཉིས་པ་ལ། གྲངས་ངེས་ལ་རྩོད་སྤང་དང་། བྱེད་པ་ལ་རྩོད་པ་སྤང་བའོ། །
Enumeration Block 6:
དང་པོ་ལ་གཉིས་ཀྱི་དང་པོ་རྩོད་པ་ནི།
Enumeration Block 7:
གཉིས་པ་ལན་ལ་གཉིས་ཀྱི་དང་པོ་རྩ་བ་ནི།
Enumeration Block 8:
གཉིས་པ་འགྲེལ་པ་ལ། དོན་དམ་ལ་ལྟོས་ཏེ་རྟགས་མ་གྲུབ་པ་དང་། ཀུན་རྫོབ་ལ་ཁྱབ་པ་མ་གྲུབ་པའི་ལན་ནོ། །
Enumeration Block 9:
གཉིས་པ་ལ། དོན་དམ་ལ་ལྟོས་པའི་རྩོད་སྤང་དང་། ཐ་སྙད་ལ་ལྟོས་པའི་རྩོད་སྤང་ངོ༌། །
Enumeration Block 10:
དང་པོ་ལ་གཉིས། རྩོད་པ་དང་། ལན་ནོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 11:
གཉིས་པ་ལན་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 12:
གསུམ་པ་འགྲེལ་པ་ལ། ཐ་སྙད་དུ་ཁྱབ་པ་མ་གྲུབ་པ་དང་། དོན་དམ་ལ་ལྟོས་ཏེ་འདོད་ལན་ནོ། །
Enumeration Block 13:
དང་པོ་ལ་གཉིས་ཀྱི་དང་པོ་དཔེ་སྒྲུབ་པ་ནི།
Enumeration Block 14:
གཉིས་པ་ལ། རྩོད་པ་དང་།ལན་ནོ། །
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 15:
གཉིས་པ་ལན་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 16:
གསུམ་པ་འགྲེལ་པ་ལ། རྩོད་པའི་ལན་དངོས་དང་། དེས་གཞན་ཡང་མཚོན་ཚུལ་ལོ། །
དང་པོ་ལ་གཉིས། དཔེ་བསྒྲུབ་པ་དང་། དཔེ་དོན་སྦྱར་བའོ། །དང་པོ་ལ་ལྟོས་མེད་དུ་མི་སྲེག །ལྟོས་ནས་སྲེག་པའོ། །
དང་པོ་ལ་གཉིས་ཀྱི་དང་པོ། སྐད་ཅིག་དང་པོས་ལྟོས་མེད་དུ་མི་སྲེག་པ་ནི།
Enumeration Block 17:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 18:
གསུམ་པ་འགྲེལ་པ་ལ། ཟབ་མོའི་ངོ་བོ་དང་། དེ་རྟོགས་པ་རྟགས་སུ་འགྱུར་ཚུལ་ལོ། །
Enumeration Block 19:
གཉིས་པ་ལ། ཆོས་སྐུའི་རྒྱུ་སྲིད་ཞི་མཉམ་ཉིད་ཀྱི་སྦྱོར་བ། ལོངས་སྐུའི་རྒྱུ་ཞིང་དག་པའི་སྦྱོར་བ། སྤྲུལ་སྐུའི་རྒྱུ་ཐབས་ལ་མཁས་པའི་སྦྱོར་བའོ། །
དང་པོ་ལ། མཚམས་སྦྱར་བ། རྩ་བ། འགྲེལ་པའོ། །
