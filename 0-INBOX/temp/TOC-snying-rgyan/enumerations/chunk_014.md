Enumeration Block 1:
ཐེག་ཆེན་གྱི་གདམས་ངག་ནི་འདིར་བསྟན་པ་རྣམ་པ་བཅུར་ངེས་པའོ། །
Enumeration Block 2:
དགེ་འདུན་དཀོན་མཆོག་བྱེ་བྲག་ཏུ་བཤད་པ་ལ་གཉིས། སྤྱིའི་དོན་དང་། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ། མཚོན་བྱེད་ཀྱི་དཔེ་དང་། མཚོན་བྱའི་དོན་ནོ། །དང་པོ་ལ། འབྲས་བུ་རྣམ་པར་བཞག་པ་དང་། གང་ཟག་རྣམ་པར་བཞག་པའོ། །
Enumeration Block 3:
དབྱེ་ན་དད་པའི་རྗེས་འབྲང་དང་ཆོས་ཀྱི་རྗེས་འབྲང་གཉིས་ཡོད་དོ། །
Enumeration Block 4:
དབྱེ་ན། དབང་པོས་ཕྱེ་བ་དད་མོས་དང་། མཐོང་ཐོབ་གཉིས་དང་། སྦྱོར་བས་ཕྱེ་བ་འབྲས་གནས་ཙམ་པོ་དང་ཁྱད་པར་ཅན་གཉིས་ཏེ།
Enumeration Block 5:
སྐྱེ་བའི་ཁྱད་པར་གྱིས་ཕྱེ་ན་དེ་ལྟར་ཐོགས་ན་ལན་བདུན་པ་དང་། རིགས་ནས་རིགས་སུ་སྐྱེ་བ་གཉིས་སོ། །
Enumeration Block 6:
དབྱེ་ན། རྒྱུན་ཞུགས་འབྲས་གནས་ཙམ་པོ་དང་ཁྱད་པར་ཅན་གཉིས་ལས།
Enumeration Block 7:
དབྱེ་བ་ནི། མཐར་གྱིས་པ་དང་། ཐོད་རྒལ་བའི་ཕྱིར་འོང་ཞུགས་པ་གཉིས་སོ། །
Enumeration Block 8:
དབྱེ་བ་འབྲས་བུ་ཐོབ་ཚུལ་གྱིས་ཕྱེ་ན་མཐར་གྱིས་པ་དང་། ཐོད་རྒལ་བ་གཉིས་ཡོད་དོ། །
Enumeration Block 9:
དབྱེ་བ་ནི། འབྲས་བུ་ཐོབ་ཚུལ་གྱིས་ཕྱེ་ན། མཐར་གྱིས་པ་དང་། ཆགས་བྲལ་སྔོན་སོང་གི་ཕྱིར་མི་འོང་གཉིས། འཕགས་ཆོས་བསྟེན་ཚུལ་གྱིས་ཕྱེ་ན། འདོད་པར་ཚེ་ཡོངས་སུ་གྱུར་པ་དང་མ་གྱུར་པའི་ཕྱིར་མི་འོང་གཉིས།
Enumeration Block 10:
དབྱེ་བ་ལ་ལྔའི་དང་པོ།
