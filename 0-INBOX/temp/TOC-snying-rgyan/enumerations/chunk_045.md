Enumeration Block 1:
ལམ་ཤེས་པ་ཉིད་ཀྱི་སྦྱོར་བའི་བྱེད་པ་སྐྱབས་ལ་སོགས་པ་བྱེད་པ་བདུན་ནོ། །
Enumeration Block 2:
རྣམ་པ་ཐམས་ཅད་མཁྱེན་པ་ཉིད་ཀྱི་སྦྱོར་བ་ལ་ནི་འཇིག་རྟེན་གྱི་རྟེན་གྱི་མཛད་པ་གཅིག་སྟེ། བྱེད་པ་བཅུ་གཅིག་གོ །
Enumeration Block 3:
བཞི་པ་ངོ་བོ་ཉིད་ཀྱི་མཚན་ཉིད་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 4:
དང་པོ་ལ་གཞི་ཤེས་སྦྱོར་བའི་ངོ་བོ་ཉིད་ནི། ཐམས་ཅད་ཤེས་པ་ཉིད་ཀྱི་སྦྱོར་བ་ཉོན་མོངས་པའི་སྒྲིབ་པ་ཅི་རིགས་པས་དབེན་པའི་ངོ་བོ་ཉིད་བཞིའོ། །
Enumeration Block 5:
ལམ་ཤེས་སྦྱོར་བའི་ངོ་བོ་ནི་ལམ་ཤེས་པ་ཉིད་ཀྱི་སྦྱོར་བའི་ངོ་བོ་ཉིད་ལྔའོ། །
Enumeration Block 6:
རྣམ་པ་ཐམས་ཅད་མཁྱེན་པ་ཉིད་ཀྱི་སྦྱོར་བའི་ངོ་བོ་ཉིད་བདུན་ནོ། །
Enumeration Block 7:
གཉིས་པ་ཐར་པ་ཆ་མཐུན་ནས་བཟུང་སྟེ་རྒྱུད་ལ་སྐྱེ་བའི་རིམ་པ་བཤད་པ་ལ་གསུམ། བསྐལ་པ་གྲངས་མེད་གསུམ་ནས་འཚང་རྒྱ་བའི་ལམ་གྱི་ཐོག་མ་བཤད་པའི་སྒོ་ནས་རྒྱན་གྱི་ཆེད་དུ་བྱ་བའི་གདུལ་བྱ་ངོས་བཟུང་བ་དང་། རྒྱུད་སྨིན་བྱེད་ཀྱི་ལམ་སྐྱེ་བའི་རིམ་པ་དང་། དེ་ལ་བརྟེན་ནས་མངོན་རྟོགས་ཁྱད་པར་ཅན་རྒྱུད་ལ་སྐྱེ་བའི་རིམ་པ་བཤད་པའོ། །དང་པོ་ལ། ལམ་སྤྱིའི་མཚན་ཉིད་དང་། ལམ་གྱི་ཆིངས་ལྔར་བསྡུས་ནས་དེ་ལ་མཁས་པའི་གདུལ་བྱ་ངོས་བཟུང་བའོ། །
Enumeration Block 8:
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 9:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 10:
དང་པོ་ལ་གཉིས་ཀྱི་དང་པོ།
Enumeration Block 11:
གཉིས་པ་ལ་གཉིས་ཀྱི་དང་པོ་བསམ་གཏན་གྱི་ཕར་ཕྱིན་ལ་བསླབ་པ་ནི།
Enumeration Block 12:
རྒྱན་གྱི་ཆེད་དུ་བྱ་བའི་གདུལ་བྱ་དེ་ལ་དབང་པོའི་རིམ་པས་གཉིས་སུ་ཡོད་དེ།
Enumeration Block 13:
རྒྱན་གྱི་ཆེད་དུ་བྱ་བའི་གདུལ་བྱ་དེ་ལ། དད་པའི་རྗེས་འབྲང་དང་། ཆོས་ཀྱི་རྗེས་འབྲང་གཉིས་སུ་ངེས་པར་སྟོན་པ་ཡིན་གྱི།
Enumeration Block 14:
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 15:
དང་པོ་ལ་བཞིའི་དང་པོ་དྲོ་བ་ནི།
