Enumeration Block 1:
འདི་ལ་གཞན་གྱི་འདོད་པ་སུན་དབྱུང་བ་དང་། རང་གི་ལུགས་རྣམ་པར་བཞག་པའོ། །
Enumeration Block 2:
བཞི་པ་ལམ་ཤེས་ཀྱི་རང་བཞིན་ལ། ཚིག་དོན་དང་། མཐའ་དཔྱད་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལམ་ཤེས་ཀྱི་རང་བཞིན་ལ། ཉན་ཐོས་དང་། རང་རྒྱལ་དང་། བྱང་སེམས་ཀྱི་ལམ་གྱི་རང་བཞིན་ཤེས་པའོ། །
དང་པོ་ལ། ལམ་ཤེས་ཀྱི་ངོ་བོ་དང་། རྒྱུ་ངེས་འབྱེད་ཆ་མཐུན་ནོ། །
Enumeration Block 4:
གསུམ་པ་འགྲེལ་པ་ལ། ཤེས་བྱའི་ལམ་དང་། དེ་ཇི་ལྟར་ཤེས་པའི་ཚུལ་ལོ། །
Enumeration Block 5:
འགྲེལ་པས་འཆད་པ་ལ་གསུམ། སྡུག་ཀུན་གྱི་རྣམ་པ་དང་། འགོག་བདེན་གྱི་རྣམ་པ་དང་། ལམ་བདེན་གྱི་རྣམ་པའོ། །
དང་པོ་ལ་སྡུག་ཀུན་སོ་སོའི་རྣམ་པ་དང་། ཐུན་མོང་གི་རྣམ་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ། མཚམས་སྦྱར་བ་དང་། རྩ་བ་དང་། འགྲེལ་པའོ། །
