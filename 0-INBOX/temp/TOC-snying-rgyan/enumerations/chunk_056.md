Enumeration Block 1:
གསུམ་པ། སྤང་བྱ་སྤངས་པས་ཐོབ་པའི་ཡོན་ཏན་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 2:
བཞི་པ་བར་ཆད་མེད་པའི་རྩེ་སྦྱོར་ལ་གཉིས། དངོས་དང་། ལོག་རྟོག་བསལ་བའོ། །
དང་པོ་ལ་གཉིས། བསོད་ནམས་མང་པོས་མཚོན་ཏེ་བསྟན་པ་དང་། དམིགས་རྣམ་བཤད་པའོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 3:
གཉིས་པ་ལ། དྲི་བ་དང་། ལན་གཉིས་ཀྱི་དང་པོ་ནི།
Enumeration Block 4:
ལན་ལ་གཉིས་ཀྱི་དང་པོ་རྩ་བ་ནི།
Enumeration Block 5:
གསུམ་པ་འགྲེལ་པ་ལ། དངོས་དང་། གནས་འདི་ཟབ་པར་བསྟན་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 7:
བཅུ་དྲུག་པོ་གང་ཞེ་ན། ལམ་སྒོམ་པའི་དམིགས་རྣམ་ལ་ལོག་པར་རྟོག་པ་གཉིས་དང་། སྒོམ་པའི་འབྲས་བུ་ལ་ལོག་པར་རྟོག་པ་གཅིག་དང་། གཞིའི་གནས་ལུགས་ཀུན་རྫོབ་དང་། དོན་དམ་བདེན་པ་མི་འཐད་པར་རྩོད་པ་གཉིས་དང་། སྤྱོད་པ་མི་འཐད་པར་ཐལ་བ་གཅིག་དང་། སྤྱོད་པའི་རྟེན་སྐྱབས་འགྲོ་ཡུལ་དང་བཅས་པ་མི་འཐད་པར་ཐལ་བ་གསུམ་དང། སྤྱོད་པའི་ཁྱད་པར་མི་འཐད་པར་ཐལ་བ་གཅིག་དང་། མངོན་རྟོགས་དང་། དེའི་སྤང་བྱ་མི་འཐད་པར་ཐལ་བ་གཉིས་དང་། ལམ་གྱི་ངོ་བོ་མི་འཐད་པར་ཐལ་བ་གཅིག་དང་། སྤང་གཉེན་གྱི་དབྱེ་བ་མི་འཐད་པར་ཐལ་བ་གཅིག་དང་། བསྒོམ་བྱ་རང་སྤྱིའི་མཚན་ཉིད་མི་འཐད་པར་ཐལ་བ་གཅིག་དང་། དེ་བསྒོམ་པ་མི་འཐད་པར་ཐལ་བ་གཅིག་གོ །
Enumeration Block 8:
གསུམ་པ་འགྲེལ་པ་ལ། བསལ་བྱ་ལོག་རྟོག་ངོས་བཟུང་བ་དང་། དེ་བསལ་ནས་བར་ཆད་མེད་པའི་རྩེ་སྦྱོར་བསྐྱེད་པར་གདམས་པའོ། །
Enumeration Block 9:
གཉིས་པ་བརྟན་པ་རྒྱུ་འབྲས་ལ་གཉིས།བརྟན་པ་ཐོབ་དོན་དུ་བསྒོམ་པ་མཐར་གྱིས་སྦྱོར་དང་། བརྟན་པ་ཐོབ་པ་སྐད་ཅིག་མའི་སྦྱོར་བའོ། །དང་པོ་ལ། འབྲེལ་བཀོད་པས་མཚམས་སྦྱར་བ་དང་། ལེའུའི་གཞུང་བཤད་པ་དང་། སྐབས་བསྡུ་བའོ། །
Enumeration Block 10:
གཉིས་པ་ལ་གཉིས་ཀྱི་དང་པོ་རྩ་བ་ནི།
