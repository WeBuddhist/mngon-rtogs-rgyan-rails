Enumeration Block 1:
གསུམ་པ་མཐོང་ཆོས་བདེ་གནས་ཀྱི་ལམ་ནི། མཐོང་བའི་ཆོས་ཚེ་འདི་ལ་ལུས་སེམས་བདེ་བར་གནས་པའི་ལམ་ལ་རྣམ་པ་ལྔའོ། །
Enumeration Block 2:
བཞི་པ་འཇིག་རྟེན་ལས་འདས་པའི་ལམ་ནི།འཇིག་རྟེན་ལས་འདས་པའི་ལམ་ལ་མཐར་གྱིས་གནས་པའི་སྙོམས་པར་འཇུག་པ་དགུའོ། །
Enumeration Block 3:
ལྔ་པ་སྤོང་བའི་ལམ་ནི། སྤོང་བའི་ལམ་ལ་རྣམ་པ་བཞིའོ། །
Enumeration Block 4:
དྲུག་པ་སངས་རྒྱས་ཀྱི་ལམ་ནི་སངས་རྒྱས་ཉིད་ཀྱི་ལམ་ལ་བཅུ་སྟེ།
Enumeration Block 5:
གསུམ་པ་རྣམ་མཁྱེན་གྱི་རྣམ་པ་ལ། མདོར་བསྟན་པ། རྒྱས་པར་བཤད་པ། དོན་བསྡུ་བའོ། །
Enumeration Block 6:
གཉིས་པ་ལ། ཡོན་ཏན་གྱི་དབྱེ་བ་དང་། ངོ་བོ་དང་། རྟེན་དང་། ཆེད་དུ་བྱ་བའོ། །
Enumeration Block 7:
དང་པོ་ལ་བཞིའི་དང་པོ། སྟོབས་བཅུ་ནི། རྣམ་མཁྱེན་གྱི་རྣམ་པ་དེ་ལ་ནི། སྟོབས་ཀྱི་རྣམ་པ་བཅུ་ཡོད་དེ།
Enumeration Block 8:
གཉིས་པ་མི་འཇིགས་པ་བཞི་ནི། མི་འཇིགས་པའི་རྣམ་པ་བཞི་ཡོད་དེ།
Enumeration Block 9:
གསུམ་པ་སོ་སོ་ཡང་དག་པར་རིག་པ་བཞི་ནི། སོ་སོ་ཡང་དག་པར་རིག་པའི་རྣམ་པ་བཞི་ཡོད་དེ།
Enumeration Block 10:
བཞི་པ་སངས་རྒྱས་ཀྱི་ཆོས་མ་འདྲེས་པ་བཅོ་བརྒྱད་ནི། དེ་ལྟར་སངས་རྒྱས་ཀྱི་ཆོས་རྟེན་འོག་མ་རྣམས་དང་མ་འདྲེས་པ་བཅོ་བརྒྱད་ཀྱི་རྣམ་པ་དག་ནི་སྤྱོད་པས་བསྡུས་པ་དྲུག་དང་རྟོགས་པས་བསྡུས་པ་དྲུག་དང་། འཕྲིན་ལས་ཀྱིས་བསྡུས་པ་གསུམ་དང་། ཡེ་ཤེས་ཀྱིས་བསྡུས་པ་གསུམ་སྟེ་བཅོ་བརྒྱད་དོ། །
Enumeration Block 11:
གསུམ་པ་དོན་བསྡུ་བ་ལ་གཉིས་ཀྱི་དང་པོ་ངོ་བོའི་དོན་བསྡུ་བ་ནི།
Enumeration Block 12:
གཉིས་པ་བདེན་འཛིན་དངོས་སུ་འཇོམས་བྱེད་ཀྱི་སྦྱོར་བ་ཁྱད་པར་ཅན་ངོས་བཟུང་བ་ལ། དགེ་བའི་རྩ་བ་གསོག་པའི་རྟེན་དང་། སྦྱོར་བ་དངོས་སོ། །
Enumeration Block 13:
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 14:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 15:
གཉིས་པ་རྩ་བ་ནི། སྦྱོར་བ་རང་གི་ངོ་བོ་དང་། རྟེན་གྱི་གང་ཟག་གི་སྒོ་ནས་དབྱེ་བ་དང་། སྦྱོར་བ་རྫོགས་པའི་ཐབས་ཀྱི་སྒོ་ནས་དབྱེ་བ་དང་། འབྲས་བུ་དང་དུས་ཀྱི་སྒོ་ནས་བཞག་པའོ། །
Enumeration Block 16:
སྦྱོར་བ་པོའི་སྒོ་ནས་དབྱེ་བ་ནི་བརྒྱད་དེ།
Enumeration Block 17:
སྐྲག་པ་ཤས་ཆེར་མི་འབྱུང་བའི་རྟེན་གྱི་དབང་དུ་བྱས་ནས་རང་དོན་དང་ལྡན་པའི་སྦྱོར་བ་དང་། གཞན་དོན་དང་ལྡན་པའི་སྦྱོར་བའོ། །
