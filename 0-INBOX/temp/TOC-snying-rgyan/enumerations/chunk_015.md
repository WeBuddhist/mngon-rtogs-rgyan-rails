Enumeration Block 1:
དབྱེ་བ་ནི། འབྲས་བུ་ཐོབ་ཚུལ་གྱིས་ཕྱེ་ན། མཐར་གྱིས་པ་དང་། ཆགས་བྲལ་སྔོན་སོང་གི་ཕྱིར་མི་འོང་གཉིས། འཕགས་ཆོས་བསྟེན་ཚུལ་གྱིས་ཕྱེ་ན། འདོད་པར་ཚེ་ཡོངས་སུ་གྱུར་པ་དང་མ་གྱུར་པའི་ཕྱིར་མི་འོང་གཉིས།
Enumeration Block 2:
དང་པོ་ལ་ཡང་། འཕར་བ་དང་། ཕྱེད་དུ་འཕར་བ་དང་། ཚངས་ཆེན་མ་གཏོགས་པའི་གཟུགས་ཀྱི་གནས་གཞན་ཐམས་ཅད་དུ་འཆི་འཕོ་བའི་རིགས་ཅན་གསུམ་ཡོད་དོ། །
Enumeration Block 3:
དེ་ལ་དབྱེ་ན་བར་དོར་འདའ་བ་མ་གཏོགས་པ་བཞིའོ། །
Enumeration Block 4:
དབྱེ་བ་ནི། མཐར་གྱིས་པ་དང་ཅིག་ཅར་བའི་དགྲ་བཅོམ་ཞུགས་པ་གཉིས་སོ། །
Enumeration Block 5:
དབྱེ་བ་ནི། སྤང་བྱ་སྤོང་ཚུལ་གྱིས་ཕྱེ་ན། མཐར་གྱིས་པ་དང་། ཅིག་ཅར་བའི་དགྲ་བཅོམ་པ་གཉིས། དབང་པོའི་སྒོ་ནས་ཕྱེ་ན་དྲུག་སྟེ། ཡོངས་སུ་ཉམས་པའི་ཆོས་ཅན། བདག་གསོད་པའི་ཆོས་ཅན། རྗེས་སུ་སྲུང་བའི་ཆོས་ཅན། གནས་པ་ལས་མི་བསྐྱོད་པའི་ཆོས་ཅན། རྟོགས་པའི་འོས་སུ་གྱུར་པ། མི་གཡོ་བའི་ཆོས་ཅན་རྣམས་སོ། །
Enumeration Block 6:
གཉིས་པ་ཡན་ལག་གི་དོན་ལ་གསུམ། མཚམས་སྦྱར་བ་དང། རྩ་བ་དང་། འགྲེལ་པའོ། །
