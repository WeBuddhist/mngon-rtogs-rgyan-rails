Enumeration Block 1:
དྲུག་པ་ལ། ས་བཅུ་པས་བསྡུས་པའི་བཤེས་གཉེན་བསྟེན་པ་དང་། རྟོགས་པ་གོང་དུ་འཕེལ་བ་ལ་འགོད་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་བརྒྱད་ཀྱི་དང་པོ་བྱང་ཆུབ་ཀྱི་ཡན་ལག་ཐོབ་པ་ལ་འགོད་པ་ནི།
Enumeration Block 3:
གསུམ་པ་འགྲེལ་པ་ལ། སོ་སོར་བཤད་པ་དང་། དོན་བསྡུ་བའོ། །
དང་པོ་ལ། ལམ་ལ་འགོད་པ་དང་། ལམ་གྱི་འབྲས་བུ་ལ་འགོད་པའོ། །
དང་པོ་ལ། ཚོགས་ལམ་དང་། སྦྱོར་ལམ་དང་། མཐོང་ལམ་དང་། སྒོམ་ལམ་ལ་འགོད་པའོ། །
དང་པོ་ལ་དྲུག་གི་དང་པོ་སྐྱེས་བུ་འབྲིང་གི་བསམ་པ་ཐར་པ་དོན་གཉེར་ལ་འགོད་པ་ནི།
Enumeration Block 4:
བཞི་པ་སྒོམ་ལམ་ལ་འགོད་པ་ལ་དྲུག་གི་དང་པོ། ས་གཉིས་པ་ནས་ལྔ་པའི་བར་ལ་འགོད་པ་ནི།
Enumeration Block 5:
བཞི་པ་ས་བརྒྱད་པ་ལ་འགོད་པ་ལ། སྤྱོད་པ་ཁྱད་པར་ཅན་ལ་འགོད་པ་དང་། བདེན་འཛིན་མངོན་གྱུར་ཟད་པ་ལ་འགོད་པའོ། །
Enumeration Block 6:
དྲུག་པ་ལ། ས་བཅུ་པ་ཐོབ་མ་ཐག་པ་གང་ལ་འགོད་པ་དང། སྐྱེ་བ་གཅིག་གིས་ཐོགས་པ་དང། སྲིད་པ་ཐ་མ་པ་ལ་འགོད་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་སྐྱེ་བ་ཕྱི་མ་ལ་སངས་རྒྱ་བར་ངེས་པ་ལ་འགོད་པ་ནི།
Enumeration Block 8:
གསུམ་པ་ལ། ནུས་པའི་ཁྱད་པར་དང་། རྟོགས་པའི་ཁྱད་པར་དང་། སྤངས་པའི་ཁྱད་པར་དང་། དག་པའི་རྒྱུ་ཚོགས་ཀྱི་ཁྱད་པར་ལ་འགོད་པའོ། །
དང་པོ་ལ་བྱང་ཆུབ་འདྲེན་པར་བྱེད་པ་དང་། ལམ་ཆུད་མི་ཟ་བའི་ནུས་པའོ། །
Enumeration Block 9:
གཉིས་པ་ལ་ཇི་སྙེད་པ་རྟོགས་པ་དང་། ཇི་ལྟ་བ་རྟོགས་པ་ལ་འགོད་པའོ། །
Enumeration Block 10:
གསུམ་པ་ལ་ཕྱིན་ཅི་ལོག་ཟད་པ་དང་། དེའི་གཞི་ཟད་པ་ལ་འགོད་པའོ། །
Enumeration Block 11:
བཞི་པ་ལ་རང་བཞིན་རྣམ་དག་གི་ཆོས་སྐུའི་རྒྱུ་ཚོགས་ལ་འགོད་པ་དང་། གློ་བུར་དྲི་བྲལ་གྱི་རྒྱུ་ཚོགས་ལ་འགོད་པའོ། །
Enumeration Block 12:
གསུམ་པ་བསྡུས་དོན་གཞན་བསྟན་པ་ལ། དོན་དྲུག་ཏུ་བསྡུ་བ་དང་། དོན་གསུམ་དུ་བསྡུ་བའོ། །
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
