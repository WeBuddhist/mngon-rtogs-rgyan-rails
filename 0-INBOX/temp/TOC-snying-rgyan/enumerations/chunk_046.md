Enumeration Block 1:
གསུམ་པ་འགྲེལ་པ་ལ། སོ་སོར་བཤད་པ་དང་། དོན་བསྡུ་བའོ། །
Enumeration Block 2:
དང་པོ་ལ་བཞིའི་དང་པོ་དྲོ་བ་ནི།
Enumeration Block 3:
གཉིས་པ་ལ། མི་འཐད་པའི་ཕྱོགས་སུན་དབྱུང་བ་དང་། ལེགས་པར་གནས་པའི་ཕྱོགས་བཞག་པ་དང་། འགལ་བ་སྤང་བའོ། །
Enumeration Block 4:
གསུམ་པ་དེ་ལ་བརྟེན་ནས་མངོན་རྟོགས་ཁྱད་པར་ཅན་རྒྱུད་ལ་སྐྱེ་བའི་རིམ་པ་བཤད་པ་ལ། བླ་ན་མེད་པའི་བྱང་ཆུབ་ལས་ཕྱིར་མི་ལྡོག་པའི་རྟགས་བཤད་པ་དང་། སྐུ་གསུམ་སྒྲུབ་བྱེད་ཀྱི་ལམ་ཁྱད་པར་ཅན་བཤད་པའོ། །
Enumeration Block 5:
གཉིས་པ་ཡན་ལག་གི་དོན་ལ། མདོར་བསྟན། རྒྱས་བཤད། དོན་བསྡུ་བའོ། །
Enumeration Block 6:
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་སྤྱིའི་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 7:
གཉིས་པ་ལ། སྦྱོར་ལམ་དང་། མཐོང་ལམ་དང་། སྒོམ་ལམ་པ་ཕྱིར་མི་ལྡོག་པའི་རྟགས་སོ། །
Enumeration Block 8:
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 9:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
