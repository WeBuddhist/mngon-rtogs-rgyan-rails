Enumeration Block 1:
གསུམ་པ་འགྲེལ་པ་ལ། དངོས་གཞིའི་སྦྱོར་བ་ལྔ་ནི།
Enumeration Block 2:
སྔ་མ་ལྔ་དང་། ཕྱི་མ་རྣམ་པ་བཅོ་ལྔ་སྟེ་སྦྱོར་བ་ཉི་ཤུ་ཡིན་ནོ། །
Enumeration Block 3:
གཉིས་པ་སྦྱོར་བ་སྒོམ་པའི་སྐྱོན་ཡོན་ལ། སྦྱོར་བའི་ཡོན་ཏན་དང་། སྦྱོར་བ་སྒོམ་པའི་གེགས་སོ། །
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 4:
སྦྱོར་བ་སྒོམ་པའི་སྟོབས་ཀྱིས་བདུད་ཀྱི་མཐུ་བཅོམ་པ་དང་། ལ་སོགས་པ་ངེས་པར་འཐོབ་པའི་བར་གྱི་ཡོན་ཏན་རྣམ་པ་བཅུ་བཞི་འབྱུང་བའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 6:
སྦྱོར་བ་སྐྱེ་བའི་གེགས་དང་། རྒྱུན་གནས་པའི་གེགས་སྐྱོན་ནི་བཅུ་ཚན་བཞི་དང༌བཅས་པ་དྲུག་ཏུ་ངེས་པར་རྟོགས་པར་བྱའོ། །
Enumeration Block 7:
གསུམ་པ་འགྲེལ་པ་ལ། སོ་སོར་བཤད་པ་དང་། གྲངས་བསྡུ་བའོ། །
དང་པོ་ལ། སྦྱོར་བའི་འགལ་རྐྱེན་རང་ལ་བརྟེན་པ་ཉི་ཤུ། རང་གཞན་གང་རུང་ལ་བརྟེན་པ་མཐུན་རྐྱེན་མ་ཚང་བ་ཉེར་གསུམ། འགལ་རྐྱེན་གཞན་ལ་བརྟེན་པ་གསུམ་མོ། །
Enumeration Block 8:
གཉིས་པ་ལ། སློབ་དཔོན་ལ་བརྟེན་པ། རང་ཉིད་ལ་བརྟེན་པ། གཉིས་ཀ་ལ་བརྟེན་པའོ། །
Enumeration Block 9:
སྔ་མ་བཅུ་དང་། ཕྱི་མ་བཞི་དང་བཅུ་ཚན་བཅུ་བཞིའོ། །
Enumeration Block 10:
དེ་ལྟར་འགལ་རྐྱེན་ཉེ་བར་གནས་པ་ཉེར་གསུམ་དང་། མཐུན་རྐྱེན་མ་ཚང་བ་ཉེར་གསུམ་ཡོད་པ་དེ་ལྟར་ན་སྐྱོན་བཞི་བཅུ་རྩ་དྲུག་ཡིན་ནོ། །
Enumeration Block 11:
གསུམ་པ་སྦྱོར་བའི་མཚན་ཉིད་ལ། སྤྱིའི་དོན་དང་། ཡན་ལག་གི་དོན་ནོ། །
དང་པོ་ལ་སློབ་དཔོན་སྔ་མའི་ལུགས་དགོད་པ་དང་། རང་གི་ལུགས་གཞག་པའོ། །
Enumeration Block 12:
སྦྱོར་བའི་མཚན་ཉིད་ནི་མཚོན་པ་དང་། མཚན་གཞི་དང་། མཚོན་བྱ་དང་། མཚན་ཉིད་བཞིའོ། །
Enumeration Block 13:
དེ་ལ་དབྱེ་ན་ཁྱད་མཚན་བཅུ་དྲུག་དང་། བྱེད་མཚན་བཅུ་གཅིག་གོ །
Enumeration Block 14:
གཉིས་པ་རང་གི་ལུགས་ནི། མཚན་གཞི་དང་། མཚོན་བྱ་དང་། མཚན་ཉིད་དང་། ཇི་ལྟར་མཚོན་པའི་ཚུལ་དང་། ས་མཚམས་སོ། །
Enumeration Block 15:
གཉིས་པ་ནི། སྤྱི་དང་བྱེ་བྲག་གཉིས་ལས་དང་པོ་ནི།
Enumeration Block 16:
ལམ་དང་འབྲས་བུའི་ཤེར་ཕྱིན་ཉིད་ལ་མངོན་པར་རྟོགས་པ་བརྒྱད་དུ་ཕྱེ་བ་ཡིན་ནོ། །

Enumeration Block 1:
གཉིས་པ་རང་གི་ལུགས་ནི། མཚན་གཞི་དང་། མཚོན་བྱ་དང་། མཚན་ཉིད་དང་། ཇི་ལྟར་མཚོན་པའི་ཚུལ་དང་། ས་མཚམས་སོ། །
Enumeration Block 2:
སྤྱི་དང་བྱེ་བྲག་གཉིས་ལས
Enumeration Block 3:
བཞི་པ་ལ་སྤྱིའི་མཚོན་ཚུལ་དང་།བྱེ་བྲག་གི་མཚོན་ཚུལ་ལོ། །
Enumeration Block 4:
གཉིས་པ་ཡན་ལག་གི་དོན་ལ། སྤྱིའི་མཚམས་སྦྱར་བ། སོ་སོའི་དོན་བཤད་པ། སྤྱིའི་གྲངས་བསྡུ་བའོ། །
Enumeration Block 5:
གཉིས་པ་ལ། མདོར་བསྟན། རྒྱས་བཤད་དོ། །
Enumeration Block 6:
དང་པོ་ལ་གཉིས་ཀྱི་དང་པོ་རྩ་བ་ནི།
Enumeration Block 7:
འདིར་བསྟན་མཚན་ཉིད་དེ་ཡང་རྣམ་པ་གསུམ་དུ་དབྱེར་ཡོད་དེ། མཁྱེན་གསུམ་སྦྱོར་བ་མཚོན་བྱེད་ཤེས་པའི་མཚན་ཉིད་དང་། ཉན་རང་གི་སྦྱོར་བ་ལས་ཁྱད་པར་འཕགས་པའི་སྦྱོར་བར་མཚོན་བྱེད་ཁྱད་པར་གྱི་མཚན་ཉིད་དང་། གཞན་དོན་སྒྲུབ་པའི་བྱེད་ལས་ཁྱད་པར་ཅན་དང་ལྡན་པའི་སྦྱོར་བར་མཚོན་བྱེད་བྱེད་པའི་མཚན་ཉིད་དེ།
Enumeration Block 8:
གཉིས་པ་རྒྱས་བཤད་ལ། ཤེས་པ། ཁྱད་པར། བྱེད་པ། ངོ་བོ་ཉིད་ཀྱི་མཚན་ཉིད་དོ། །
Enumeration Block 9:
དང་པོ་ལ། གཞི་ཤེས། ལམ་ཤེས། རྣམ་མཁྱེན་སྦྱོར་བའི་མཚན་ཉིད་དོ། །
Enumeration Block 10:
དང་པོ་ལ་གསུམ་གྱི་དང་པོ། སྤྱི་དང་བྱེ་བྲག་གི་མཚམས་སྦྱར་ནི།
Enumeration Block 11:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།

Enumeration Block 2:
རྣམ་པ་ཐམས་ཅད་མཁྱེན་པ་ཉིད་ཀྱི་སྦྱོར་བ་ལ་ནི་འཇིག་རྟེན་གྱི་རྟེན་གྱི་མཛད་པ་གཅིག་སྟེ། བྱེད་པ་བཅུ་གཅིག་གོ །
Enumeration Block 3:
བཞི་པ་ངོ་བོ་ཉིད་ཀྱི་མཚན་ཉིད་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 4:
དང་པོ་ལ་གཞི་ཤེས་སྦྱོར་བའི་ངོ་བོ་ཉིད་ནི། ཐམས་ཅད་ཤེས་པ་ཉིད་ཀྱི་སྦྱོར་བ་ཉོན་མོངས་པའི་སྒྲིབ་པ་ཅི་རིགས་པས་དབེན་པའི་ངོ་བོ་ཉིད་བཞིའོ། །
Enumeration Block 5:
ལམ་ཤེས་སྦྱོར་བའི་ངོ་བོ་ནི་ལམ་ཤེས་པ་ཉིད་ཀྱི་སྦྱོར་བའི་ངོ་བོ་ཉིད་ལྔའོ། །
Enumeration Block 6:
