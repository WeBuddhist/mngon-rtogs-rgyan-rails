Enumeration Block 1:
གཉིས་པ་ལ། དོན་དམ་ལ་ལྟོས་པའི་རྩོད་སྤང་དང་། ཐ་སྙད་ལ་ལྟོས་པའི་རྩོད་སྤང་ངོ༌། །དང་པོ་ལ་གཉིས། རྩོད་པ་དང་། ལན་ནོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 2:
གཉིས་པ་ལན་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 3:
གསུམ་པ་འགྲེལ་པ་ལ། ཐ་སྙད་དུ་ཁྱབ་པ་མ་གྲུབ་པ་དང་། དོན་དམ་ལ་ལྟོས་ཏེ་འདོད་ལན་ནོ། །
Enumeration Block 4:
དང་པོ་ལ་གཉིས་ཀྱི་དང་པོ་དཔེ་སྒྲུབ་པ་ནི།
Enumeration Block 5:
གཉིས་པ་ལ། རྩོད་པ་དང་།ལན་ནོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 6:
གཉིས་པ་ལན་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 7:
གསུམ་པ་འགྲེལ་པ་ལ། རྩོད་པའི་ལན་དངོས་དང་། དེས་གཞན་ཡང་མཚོན་ཚུལ་ལོ། །
Enumeration Block 8:
དང་པོ་ལ་གཉིས། དཔེ་བསྒྲུབ་པ་དང་། དཔེ་དོན་སྦྱར་བའོ། །དང་པོ་ལ་ལྟོས་མེད་དུ་མི་སྲེག །ལྟོས་ནས་སྲེག་པའོ། །དང་པོ་ལ་གཉིས་ཀྱི་དང་པོ།
Enumeration Block 9:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 10:
གསུམ་པ་འགྲེལ་པ་ལ། ཟབ་མོའི་ངོ་བོ་དང་། དེ་རྟོགས་པ་རྟགས་སུ་འགྱུར་ཚུལ་ལོ། །
Enumeration Block 11:
གཉིས་པ་ལ། ཆོས་སྐུའི་རྒྱུ་སྲིད་ཞི་མཉམ་ཉིད་ཀྱི་སྦྱོར་བ། ལོངས་སྐུའི་རྒྱུ་ཞིང་དག་པའི་སྦྱོར་བ། སྤྲུལ་སྐུའི་རྒྱུ་ཐབས་ལ་མཁས་པའི་སྦྱོར་བའོ། །དང་པོ་ལ། མཚམས་སྦྱར་བ། རྩ་བ། འགྲེལ་པའོ། །
Enumeration Block 12:
གཉིས་པ་ལ། དངོས་ཀྱི་དོན་དང་། ཀླན་ཀ་སྤང་བའོ། །
Enumeration Block 13:
འདི་ལ། ཉིན་པར་ཡང་ལས་གསོག་པ་མི་འཐད་པར་ཐལ་བ་སྤང་བ། རྨི་ལམ་ན་ལས་ལམ་ཡོངས་སུ་རྫོགས་པར་ཐལ་བ་སྤང་བ། ལུང་དང་འགལ་བ་སྤང་བ། ཧ་ཅང་ཐལ་བ་སྤང་བའོ། །དང་པོ་ལ། ཀླན་ཀ་དང་། ལན་ནོ། །
Enumeration Block 14:
གཉིས་པ་ལ། རྩོད་པ་དང་། ལན་ནོ། །དང་པོ་ལ། རབ་འབྱོར་གྱིས་རྩོད་པའི་སྐབས་དབྱེ་བ་དང་། ཤཱ་རིའི་བུས་རྩོད་པ་དངོས་སོ། །
Enumeration Block 15:
གསུམ་པ་ལ། ཀླན་ཀ་དང་། ལན་ནོ། །
Enumeration Block 16:
བཞི་པ་ལ། ཀླན་ཀ་དང་། ལན་ནོ། །
Enumeration Block 17:
གཉིས་པ་རབ་འབྱོར་རང་ཉིད་ཀྱི་ལན་དོན་གྱིས་བཏབ་ཟིན་པ་དང་། བྱམས་པ་ལ་ཁ་འཕངས་པའོ། །
Enumeration Block 18:
གསུམ་པ་ལ། དངོས་ཀྱི་དོན། ཀླན་ཀ་སྤང་བ། དེས་གྲུབ་པའི་དོན་ནོ། །
Enumeration Block 19:
གཉིས་པ་ལ། ཀླན་ཀ་དང་། ལན་ནོ། །
Enumeration Block 20:
གཉིས་པ་ལན་ལ། ཁྱབ་པ་མ་ངེས་པའི་ལན་དང་། དཔེ་མ་གྲུབ་པའི་ལན་ནོ། །
Enumeration Block 21:
དང་པོ་ལ། ཉན་ཐོས་རང་ལ་གྲགས་པའི་ཁྱབ་པ་མ་ངེས་པ་དཔེར་བཀོད་པ་དང་། དེ་དབུ་མ་པ་ལ་ཡང་མཚུངས་པར་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། བློ་དོན་དམ་པའི་ངོར་གསད་བྱ་གསོད་བྱེད་མ་གྲུབ་པར་རང་ཉིད་ཀྱིས་ཁས་བླངས་པ་དང་། བློ་ཀུན་རྫོབ་པ་རྟོག་པའི་ཡུལ་དུ་གྲུབ་པར་ཡང་རང་ཉིད་ཀྱིས་ཁས་བླངས་པའོ། །
Enumeration Block 22:
གཉིས་པ་ལ། དབུ་མ་པ་ལ་དཔེ་མ་གྲུབ། དོན་སྨྲ་བ་ལ་དཔེ་མ་གྲུབ་པའོ། །
Enumeration Block 23:
གཉིས་པ་ལོངས་སྐུའི་རྒྱུ་ཞིང་དག་པའི་སྦྱོར་བ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 24:
གསུམ་པ་སྤྲུལ་སྐུའི་རྒྱུ་ཐབས་མཁས་སྦྱོར་བ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 25:
སྦྱོར་བའི་དབྱེ་བ་ནི་དགྲ་རྣམས་ལས་ནི་འདས་པ་དང་ཞེས་པ་ནས་ཐབས་ལ་མཁས་པའི་སྦྱོར་བའི་བར་རྣམ་པ་བཅུའོ། །
Enumeration Block 26:
གཉིས་པ་དབང་དུ་བྱ་བའི་འབྲས་བུ་རྩེ་མོའི་སྦྱོར་བ་ལ། འབྲེལ་བཀོད་པས་མཚམས་སྦྱར་བ་དང་། ལེའུའི་གཞུང་བཤད་པ་དང་། སྐབས་བསྡུ་བའོ། །
Enumeration Block 27:
གཉིས་པ་ལ།སྦྱོར་ལམ་རྩེ་མོ། མཐོང་ལམ། སྒོམ་ལམ། བར་ཆད་མེད་པའི་རྩེ་མོའོ། །དང་པོ་ལ་སོ་སོའི་ངོ་བོ་དང་། དོན་བསྡུ་བའོ། །དང་པོ་ལ། དྲོད་ཀྱི་རྩེ་སྦྱོར། རྩེ་མོ། བཟོད་པ། ཆོས་མཆོག་རྩེ་སྦྱོར་རོ། །དང་པོ་ལ་གཉིས་ཀྱི་དང་པོ་རྩ་བ་ནི།
Enumeration Block 28:
གཉིས་པ་རྩེ་མོའི་རྩེ་སྦྱོར་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱོར་བ་ནི།
Enumeration Block 29:
གསུམ་པ་བཟོད་པའི་རྩེ་སྦྱོར་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 30:
བཞི་པ་ཆོས་མཆོག་རྩེ་སྦྱོར་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 31:
གཉིས་པ་མཐོང་ལམ་རྩེ་སྦྱོར་ལ། མཚམས་སྦྱར་བ་དང་། སྤང་གཉེན་སོ་སོའི་དོན་བཤད་པའོ། །
Enumeration Block 32:
