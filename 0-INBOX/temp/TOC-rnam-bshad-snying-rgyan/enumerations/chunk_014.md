Enumeration Block 1:
སྦྱོར་བ་དེ་ལ་བཅུར་ཡོད་དེ། ཡུལ་གྱི་སྒོ་ནས་དབྱེ་བ་བཞི། ངོ་བོའི་སྒོ་ནས་གསུམ། བྱེད་པའི་སྒོ་ནས་གཉིས། ཤེས་བྱེད་ཀྱི་དཔེའི་སྒོ་ནས་བྱ་བ་རྣམས་སུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 2:
ངོ་བོའི་སྒོ་ནས་གསུམ་ཡོད་དེ། ལས་སུ་བྱ་བ་དང་། བྱེད་པ་པོ་དང་། བྱ་བ་འབྲས་བུ་ལ་བདེན་ཞེན་བཀག་པ་མི་འགྱུར་བ་དང་། བྱེད་པོ་མིན་པ་དང་། བྱ་དཀའ་རྣམ་གསུམ་སྦྱོར་བ་དང་གསུམ་ཡོད་པའི་ཕྱིར། བྱ་དཀའ་བ་གསུམ་ནི། ཆེད་དུ་བྱ་བ་བྱ་དཀའ་བ་དང་། སྦྱོར་བ་བྱ་དཀའ་བ་དང་། ལས་བྱ་དཀའ་བའོ། །
Enumeration Block 3:
བྱེད་པའི་སྒོ་ནས་གཉིས་ཡོད་དེ། འབྲས་བུ་བསྐྱེད་པའི་བྱ་བ་བྱེད་པའི་སྒོ་ནས། སྐལ་བ་ཇི་བཞིན་འབྲས་ཐོབ་པས། འབྲས་ཡོད་འདོད་པ་དེ་དང་ཕན་ཡོན་དང་ལྡན་པའི་སྒོ་ནས་གཞན་ལ་རག་ལས་མིན་གང་དང་གཉིས་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
བྱང་ཆུབ་སེམས་དཔའ་རྣམས་ཀྱི་སྦྱོར་བའི་ཡུལ་དེ་དང་དེ་ལ་བདེན་པར་ཞེན་པ་འགོག་པའི་སྦྱོར་བ་ཆོས་ཅན། རྣམ་པ་བཅུ་ཡོད་དེ། གཞིའི་ངོ་བོ་དང་ཁྱད་པར་ནས་སྣང་བ་རྣམ་པ་བདུན་ལ་སྒྲུབ་པའི་ཡོངས་སུ་ཤེས་པ་བདེན་འཛིན་བསལ་བའི་སྒོ་ནས་ཕྱེ་བ་རྣམས་ཡོད་པའི་ཕྱིར།
ཡུལ་གྱི་སྒོ་ནས་དབྱེ་བ་བཞི་ཡོད་དེ། ཁྱད་གཞི་གཟུགས་ལ་སོགས་པའི་ཆོས་ཐམས་ཅད་དང་དེ་དག་ཉིད་ཀྱི་ཁྱད་ཆོས་མི་རྟག་པ་དང་སྟོང་པ་ཉིད་ལ་སོགས་པ་དང་། རྟེན་གྱི་ཁྱད་པར་ཡོན་ཏན་གྱི་རྟེན་དུ་སོ་སོར་མ་རྫོགས་པ་དང་རྫོགས་པ་ཉིད་དང་། ཇི་སྙེད་པ་ལ་བདེན་ཞེན་བཀག་པ་གསུམ་དང་། ཇི་ལྟ་བ་ལ་དམིགས་པ་དོན་དམ་པར་ཆགས་པ་དང་ཆགས་པ་མེད་པ་ལ་བདེན་ཞེན་བཀག་པ་རྣམས་ཡོད་པའི་ཕྱིར།
Enumeration Block 5:
ངོ་བོའི་སྒོ་ནས་དབྱེ་བ་གསུམ་ཡོད་དེ། ལས་སུ་བྱ་བ་ཤེར་ཕྱིན་དོན་དམ་པར་འཕེལ་འགྲིབ་ཀྱིས་གཞན་དུ་མི་འགྱུར་བར་རྟོགས་པ་དང་། བྱེད་པའི་སྒོ་ནས་དོན་དམ་པར་བྱེད་པ་པོ་མེད་པ་ཉིད་དང་། འབྲས་བུའི་སྒོ་ནས་གོ་རིམས་བཞིན་དུ་ཐམས་ཅད་མཁྱེན་པ་ཉིད་གསུམ་གྱི་བདག་ཉིད་ཀྱི་རྣམ་མཁྱེན་དོན་དམ་པར་ཆེད་དུ་བྱ་བར་མ་དམིགས་ཀྱང་ཐ་སྙད་དུ་ཆེད་དུ་བྱ་བར་རྟོགས་པ་དང་། རྒྱུ་དུས་ཀྱི་ལམ་ཤེས་དོན་དམ་པར་མ་དམིགས་ཀྱང་ཐ་སྙད་དུ་རྣམ་མཁྱེན་གྱི་རྒྱུའི་སྦྱོར་བར་རྟོགས་པ་དང་། གཞི་ཤེས་དོན་དམ་པར་མ་དམིགས་ཀྱང་ཐ་སྙད་དུ་གདུལ་བྱ་གཞན་རྗེས་སུ་འཛིན་པའི་ཐབས་ཀྱི་བྱེད་པ་དང་ལྡན་པར་རྟོགས་པ་རྣམས་ཀྱི་བྱ་དཀའ་བ་གསུམ་གྱི་སྦྱོར་བ་ཉིད་དུ་ཡོད་པའི་ཕྱིར།
Enumeration Block 6:
གཞི་ཤེས་ཀྱི་སྦྱོར་བ་དེ་ཉིད་གང་གིས་ཟིན་པར་སྒོམ་པའི་སྦྱོར་བ་དེའི་མཉམ་པ་ཉིད་བཞི་ཡོད་དེ། གཟུགས་ལ་སོགས་པའི་ངོ་བོ་དང་། མཚན་མ་དང་། དབྱེ་བ་དང་། ཡུལ་ཅན་ལ་བདེན་པར་རློམ་པ་མེད་པའི་སྦྱོར་བ་རྣམ་པ་བཞི་ཡོད་པའི་ཕྱིར།
Enumeration Block 7:
འདིར་དངོས་སུ་བསྟན་པའི་འདའ་བར་བྱེད་པའི་མཐོང་ལམ་ཆོས་ཅན། བཅུ་དྲུག་ཡོད་དེ། བདེན་པ་བཞིའི་རྣམ་པ་ལ་དམིགས་ནས་བདེན་སྟོང་སྤྲོས་བྲལ་དུ་མངོན་སུམ་དུ་གསར་དུ་རྟོགས་པའི་བར་ཆད་མེད་ལམ་གྱིས་བསྡུས་པ་ལྡོག་པས་དབྱེ་བ་བརྒྱད་དང་། རྣམ་གྲོལ་ལམ་གྱིས་བསྡུས་པ་ལྡོག་པས་དབྱེ་བ་བརྒྱད་ཡོད་པའི་ཕྱིར།
Enumeration Block 8:
གཞི་ཤེས་ཀྱི་རྣམ་པ་ཉེར་བདུན་བསྟན་ཏེ། བདེན་པ་དང་པོ་གསུམ་སོ་སོ་ལ་བཞི་བཞི་དང་། ལམ་བདེན་ལ་གཞི་ཤེས་ཀྱི་རྣམ་པ་དེ་ནི་བཅོ་ལྔར་བཤད་པའི་ཕྱིར།
Enumeration Block 9:
