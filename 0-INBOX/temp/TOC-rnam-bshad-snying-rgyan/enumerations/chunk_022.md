Enumeration Block 1:
བཞི་པ་བར་ཆད་མེད་པའི་རྩེ་སྦྱོར་ལ་གཉིས། དངོས་དང་། ལོག་རྟོག་བསལ་བའོ། །
Enumeration Block 2:
དང་པོ་ལ་གཉིས། བསོད་ནམས་མང་པོས་མཚོན་ཏེ་བསྟན་པ་དང་། དམིགས་རྣམ་བཤད་པའོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 3:
གཉིས་པ་ལ། དྲི་བ་དང་། ལན་གཉིས་ཀྱི་དང་པོ་ནི།
Enumeration Block 4:
ལན་ལ་གཉིས་ཀྱི་དང་པོ་རྩ་བ་ནི།
Enumeration Block 5:
གསུམ་པ་འགྲེལ་པ་ལ། དངོས་དང་། གནས་འདི་ཟབ་པར་བསྟན་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 7:
ལོག་པར་རྟོག་པ་རྣམ་པ་བཅུ་དྲུག་དག་ཏུ་བཞེད་དེ།
Enumeration Block 8:
བཅུ་དྲུག་པོ་གང་ཞེ་ན། ལམ་སྒོམ་པའི་དམིགས་རྣམ་ལ་ལོག་པར་རྟོག་པ་གཉིས་དང་། སྒོམ་པའི་འབྲས་བུ་ལ་ལོག་པར་རྟོག་པ་གཅིག་དང་། གཞིའི་གནས་ལུགས་ཀུན་རྫོབ་དང་། དོན་དམ་བདེན་པ་མི་འཐད་པར་རྩོད་པ་གཉིས་དང་། སྤྱོད་པ་མི་འཐད་པར་ཐལ་བ་གཅིག་དང་། སྤྱོད་པའི་རྟེན་སྐྱབས་འགྲོ་ཡུལ་དང་བཅས་པ་མི་འཐད་པར་ཐལ་བ་གསུམ་དང། སྤྱོད་པའི་ཁྱད་པར་མི་འཐད་པར་ཐལ་བ་གཅིག་དང་། མངོན་རྟོགས་དང་། དེའི་སྤང་བྱ་མི་འཐད་པར་ཐལ་བ་གཉིས་དང་། ལམ་གྱི་ངོ་བོ་མི་འཐད་པར་ཐལ་བ་གཅིག་དང་། སྤང་གཉེན་གྱི་དབྱེ་བ་མི་འཐད་པར་ཐལ་བ་གཅིག་དང་། བསྒོམ་བྱ་རང་སྤྱིའི་མཚན་ཉིད་མི་འཐད་པར་ཐལ་བ་གཅིག་དང་། དེ་བསྒོམ་པ་མི་འཐད་པར་ཐལ་བ་གཅིག་གོ །
Enumeration Block 9:
གསུམ་པ་འགྲེལ་པ་ལ། བསལ་བྱ་ལོག་རྟོག་ངོས་བཟུང་བ་དང་། དེ་བསལ་ནས་བར་ཆད་མེད་པའི་རྩེ་སྦྱོར་བསྐྱེད་པར་གདམས་པའོ། །
Enumeration Block 10:
གཉིས་པ་བརྟན་པ་རྒྱུ་འབྲས་ལ་གཉིས།བརྟན་པ་ཐོབ་དོན་དུ་བསྒོམ་པ་མཐར་གྱིས་སྦྱོར་དང་། བརྟན་པ་ཐོབ་པ་སྐད་ཅིག་མའི་སྦྱོར་བའོ། །དང་པོ་ལ། འབྲེལ་བཀོད་པས་མཚམས་སྦྱར་བ་དང་། ལེའུའི་གཞུང་བཤད་པ་དང་། སྐབས་བསྡུ་བའོ། །
Enumeration Block 11:
གཉིས་པ་ལ་གཉིས་ཀྱི་དང་པོ་རྩ་བ་ནི།
Enumeration Block 12:
བཅུ་གསུམ་པོ་གང་ན། སྦྱིན་པ་ནས་ཤེས་རབ་ཀྱི་བར་ཕར་ཕྱིན་དྲུག་དག་དང་། སངས་རྒྱས་ལ་སོགས་དྲན་པའི་རྗེས་དྲན་དྲུག་དང་། ཆོས་ཐམས་ཅད་དོན་དམ་པར་དངོས་མེད་ངོ་བོ་ཉིད་དུ་རྟོགས་པའི་ཤེས་རབ་ཀྱིས་ཟིན་པའོ། །
Enumeration Block 13:
གཉིས་པ་བརྟན་པ་ཐོབ་པ་སྐད་ཅིག་མའི་སྦྱོར་བ་ལ། འབྲེལ་བཀོད་པས་མཚམས་སྦྱར་བ་དང་། ལེའུའི་གཞུང་བཤད་པ་དང་། སྐབས་བསྡུ་བའོ། །
Enumeration Block 14:
སྐད་ཅིག་སྦྱོར་དེ་ཡང་ཆོས་ཅན། བཞི་ཡོད་དེ།
Enumeration Block 15:
གཉིས་པ་ལ་བཞིའི་དང་པོ། རྣམ་སྨིན་མ་ཡིན་པའི་སྐད་ཅིག་སྦྱོར་ལ་གཉིས། དངོས་དང་དེ་མཚོན་བྱེད་ཀྱི་དཔེའོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 16:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 17:
གཉིས་པ་རྣམ་པར་སྨིན་པའི་སྐད་ཅིག་སྦྱོར་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 18:
གསུམ་པ་མཚན་ཉིད་མེད་པའི་སྐད་ཅིག་སྦྱོར་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 19:
བཞི་པ་གཉིས་སུ་མེད་པའི་སྐད་ཅིག་སྦྱོར་ལ། གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 20:
གསུམ་པ་ཆོས་སྐུ་རྒྱས་པར་བཤད་པ་ལ་གསུམ། འབྲེལ་བཀོད་པས་མཚམས་སྦྱར་བ་དང་། ལེའུའི་གཞུང་བཤད་པ་དང་། སྐབས་བསྡུ་བའོ། །
Enumeration Block 21:
ཆོས་ཀྱི་སྐུ་དེ་ཡང་ཆོས་ཅན། རྣམ་པ་བཞི་ཡིན་ཏེ།
Enumeration Block 22:
གཉིས་པ་ལ། སྐུའི་རྣམ་གཞག་དང་། མཛད་པ་འཕྲིན་ལས་སོ། །དང་པོ་ལ་གཉིས། སྤྱིའི་དོན་དང་། ཡན་ལག་གི་དོན་ནོ། །
Enumeration Block 23:
དང་པོ་ལ་གསུམ། འབྲས་བུ་འགྲུབ་པའི་དུས་མཚམས་དང་། སྐུ་གསུམ་གྱི་ངོ་བོ་ངོས་བཟུང་བ་དང་། དེ་ལ་ལོག་པར་རྟོགས་པ་བསལ་བའོ། །
Enumeration Block 24:
གཉིས་པ་ཡན་ལག་གི་དོན་ལ། ངོ་བོ་ཉིད་ཀྱི་སྐུ། ཡེ་ཤེས་ཆོས་ཀྱི་སྐུ། ལོངས་སྤྱོད་རྫོགས་པའི་སྐུ། མཆོག་གི་སྤྲུལ་པའི་སྐུའོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 25:
གསུམ་པ་འགྲེལ་པ་ལ་གཉིས། དངོས་དང་། ཆོས་ཅན་གྱི་སྐུ་གསུམ་ཆོས་ཉིད་ཀྱི་སྐུ་ལས་ཐ་དད་དུ་བཞག་པའི་དགོས་པའོ། །
Enumeration Block 26:
གཉིས་པ་ཡེ་ཤེས་ཆོས་ཀྱི་སྐུ་ལ། དངོས་ཀྱི་དོན་དང་། དེའི་ཁྱད་པར་བཤད་པ་དང་། དེ་ལ་རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ། ཡེ་ཤེས་ཆོས་ཀྱི་སྐུ་སྐུ་གསུམ་ལས་ཐ་དད་དུ་བསྟན་པ་དང་། ཐ་དད་དུ་མི་འདོད་པ་དགག་པ་དང་། ཐ་དད་དུ་འདོད་པ་ལ་རྩོད་པ་སྤང་བའོ། །
Enumeration Block 27:
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 28:
ཡེ་ཤེས་ཆོས་ཀྱི་སྐུ་ལ་སྡེ་ཚན་ཉི་ཤུ་རྩ་གཅིག་ཏུ་དབྱེར་ཡོད་དེ།
Enumeration Block 29:
གསུམ་པ་འགྲེལ་པ་ལ། དབྱེ་བ་དང་། དེ་དག་ཡེ་ཤེས་ཆོས་སྐུར་བཞག་པའོ། །
Enumeration Block 30:
སྡེ་ཚན་ལྔ་པ་ཟད་པར་ལ། དངོས་ཀྱི་དོན་དང་། རྣམ་ཐར། ཟིལ་གནོན། ཟད་པར་གསུམ་གྱི་ཁྱད་པར་རོ། །
