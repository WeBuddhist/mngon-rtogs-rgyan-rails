Enumeration Block 1:
གཉིས་པ་ཡན་ལག་གི་དོན་ལ། སྤྱིའི་མཚམས་སྦྱར་བ་དང་། སོ་སོའི་དོན་བཤད་པ་དང་། དོན་བསྡུ་བའོ། །
Enumeration Block 2:
གཉིས་པ་ལ། བསྟན་པ་དང་། བཤད་པའོ། །དང་པོ་ལ། གཟུང་རྟོག་བཤད་པ་དང་། འཛིན་རྟོག་བཤད་པ་གཉིས་ཀྱི་དང་པོ་ལ། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ། མཚམས་སྦྱར་བ་དང་། སོ་སོའི་དོན་ནོ། །
Enumeration Block 4:
གཉིས་པ་ལ། གཟུང་རྟོག་དང་། འཛིན་རྟོག་གོ །
Enumeration Block 5:
གཉིས་པ་ལ། རྫས་འཛིན་རྟོག་པ་དང་། བཏགས་འཛིན་རྟོག་པའོ། །
Enumeration Block 6:
གསུམ་པ་ཡོངས་འཛིན་བཤད་པ་ལ་གསུམ། གོ་རིམས་གཞན་གྱི་དགོས་པ་བསྟན་པས་མཚམས་སྦྱར་བ་དང་། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 7:
གསུམ་པ་གདམས་དོན་ཇི་ལྟར་སྒྲུབ་པའི་སྒྲུབ་པ་བཤད་པ་ལ་བཞི། སྒྲུབ་པའི་རྟེན་དང་། དམིགས་པ་དང་། ཆེད་དུ་བྱ་བ་དང་། སྒྲུབ་པའི་ངོ་བོའོ། །དང་པོ་ལ། སྤྱིའི་དོན་དང་། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ། ངོ་བོ་དང་། དབྱེ་བ་དང་། རྩོད་པ་སྤང་བ་དང་། རིགས་ནས་ཇི་ལྟར་འཁྲིད་པའི་ཚུལ་ལོ། །དང་པོ་ལ། སེམས་ཙམ་པའི་ལུགས་བཀོད་ནས་འཐད་མི་འཐད་དཔྱད་པ་དང་། རང་གི་ལུགས་སོ། །
Enumeration Block 8:
གཉིས་པ་ནི། དབུ་མ་པ་རང་གི་ལུགས་ལ་རང་བཞིན་དུ་གནས་པའི་རིགས་དང་། རྐྱེན་གྱིས་ཡང་དག་པར་བླངས་པ་ལས་བྱུང་བའི་རིགས་སོ། །
Enumeration Block 9:
རིགས་ཆད་བཤད་པའི་དགོངས་གཞི་དང་། དགོས་པ་དང་། སྒྲ་ཇི་བཞིན་པ་ལ་གནོད་བྱེད་དོ། །
Enumeration Block 10:
གཉིས་པ་ཡན་ལག་གི་དོན་ལ། རིགས་ཀྱི་དབྱེ་བ་དང་། རྩོད་སྤང་ངོ༌། །དང་པོ་ལ། མཚམས་སྦྱར་བ་དང་། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 11:
གསུམ་པ་ལ། བཤད་པ་དང་། བསྡུ་བའོ། །དང་པོ་ལ། སོ་སོའི་ངོ་བོ་དང་། གོ་རིམས་དང་། གྲངས་ངེས་སོ། །
Enumeration Block 12:
དེ་ལ་གྲངས་ངེས་ཀྱི་ཁྱད་པར་དང་། དགོངས་པ་ཅན་དང་། ལྡེམ་དགོངས་ཀྱི་ཁྱད་པར་རོ། །
Enumeration Block 13:
གཉིས་པ་རྩོད་པ་སྤང་བ་ནི། རྩོད་པ་དང་། ལན་ནོ། །དང་པོ་ལ་སྔ་འགྲེལ་དང་། རྩ་བའོ། །དང་པོ་ལ་འདོད་པ་བརྗོད་པ་དང་། ཐལ་བ་དགོད་པའོ། །
Enumeration Block 14:
གཉིས་པ་ལན་ལ། དོན་གྱིས་ཐོབ་པའི་ལན་དང་། དངོས་སུ་བསྟན་པའི་ལན་ནོ། །དང་པོ་ལ་མཐའ་དཔྱད་པ་དང་། ཚིག་དོན་ནོ། །
