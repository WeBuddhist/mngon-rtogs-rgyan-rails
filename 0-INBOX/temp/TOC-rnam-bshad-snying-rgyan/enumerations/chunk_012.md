Enumeration Block 1:
གསུམ་པ་བྱང་ཆུབ་སེམས་དཔའི་ལམ་ཤེས་པའི་རང་བཞིན་བཤད་པ་ལ་གཉིས། སྤྱིའི་མཚམས་སྦྱར་བ་དང་། སོ་སོའི་ངོ་བོའོ། །
Enumeration Block 2:
གཉིས་པ་ཡན་ལག་གི་དོན་ལ། སྐད་ཅིག་མ་མདོར་བསྟན། རྣམ་པ་སྒོམ་ཚུལ་རྒྱས་པར་བཤད། རྣམ་པ་མ་བསྟན་པར་འདོད་པ་དགག་པའོ། །དང་པོ་ལ་གཉིས་ཀྱི་དང་པོ་རྩ་བ་ནི།
Enumeration Block 3:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 4:
གསུམ་པ་འགྲེལ་པ་ལ། རྒྱས་པར་བཤད་པ་དང་། དོན་བསྡུ་བའོ། །དང་པོ་ལ་བཞིའི་དང་པོ་སྡུག་བསྔལ་གྱི་རྣམ་པ་ནི།
Enumeration Block 5:
གཉིས་པ་ལ། སྒོམ་ལམ་གྱི་བྱེད་པ་དང་། བྱེད་པ་ཅན་གྱི་སྒོམ་ལམ་མོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 6:
སྒོམ་པའི་ལམ་སྟེ་དེ་ཡང་རྣམ་པ་གཉིས་སོ། །རྟོག་པའི་ཟག་པ་དང་བཅས་པ་དང་ཟག་པ་མེད་པའི་བྱེ་བྲག་གིས་སོ། །གཉིས་པ་ལ། ཟག་བཅས་སྒོམ་ལམ་དང་། ཟག་མེད་སྒོམ་ལམ་མོ། །དང་པོ་ལ་གསུམ། དབྱེ་བས་མཚམས་སྦྱར་བ་དང་། སོ་སོའི་དོན་བཤད་པ་དང་། དོན་བསྡུ་བའོ། །
Enumeration Block 7:
གཉིས་པ་ལ། མོས་པ། བསྔོ་བ། རྗེས་སུ་ཡི་རང་བའོ། །དང་པོ་ལ་དངོས་དང་ཕན་ཡོན་གཉིས་ཀྱི་དང་པོ་ལ། གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 8:
གཉིས་པ་བསྔོ་བ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 9:
གསུམ་པ་རྗེས་སུ་ཡི་རང་བ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
