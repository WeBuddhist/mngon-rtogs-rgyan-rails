Enumeration Block 1:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ། སངས་རྒྱས་དཀོན་མཆོག་ལ་འདོམས་པ་ནི།
Enumeration Block 2:
གསུམ་པ་སྒྲུབ་པའི་ཁྱད་པར་གྱི་ཆོས་ལ་གདམས་པ་ལ་གསུམ། མི་མཐུན་ཕྱོགས་མངོན་གྱུར་སེལ་བ་ལ་གདམས་པ་དང་། ལམ་ཁྱད་པར་ཅན་བསྒྲུབ་པར་གདམས་པ་དང་། སྤང་བྱའི་ས་བོན་སེལ་བར་གདམས་པའོ། །
Enumeration Block 3:
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་སྒྲུབ་པ་མི་ཉམས་པའི་རྒྱུ་ལ་གདམས་པ་ནི།
Enumeration Block 4:
དེ་ལྟར་ན་ཐེག་ཆེན་གྱི་གདམས་ངག་ནི་འདིར་བསྟན་པ་རྣམ་པ་བཅུར་ངེས་པའོ། །
Enumeration Block 5:
ཉན་ཐོས་དང་ཐུན་མོང་མ་ཡིན་པ་དང་། བདེན་གཉིས་ལས་མི་འདའ་བ་མི་དམིགས་པ་དང་སྒྲུབ་པ་དེའི་དམིགས་པ་ཞེས་དང་། སྒྲུབ་པའི་རྟེན་ཞེས་དང་། སྒྲུབ་པ་གོང་ནས་གོང་དུ་ཁྱད་པར་དུ་ཞེས་དང་། སྒྲུབ་པ་ཉམས་སུ་ལེན་པ་ལས་མི་ལྡོག་པར་ཞེས་དང་། ཐེག་ཆེན་ལས་ཉམས་ནས་ཉན་རང་གི་ཐེག་པ་གཞན་གྱིས་ཞེས་དང་། སྒྲུབ་པ་ལ་རང་དབང་དུ་འཇུག་པས་གཞན་གྱི་ཞེས་དང་། ཚོགས་མྱུར་དུ་རྫོགས་པར་བྱེད་པས་རྣམ་པ་ཐམས་ཅད་ཅེས་དང་། སྒྲིབ་གཉིས་མཐའ་དག་ཟད་པའི་སྒོ་ནས་སྒྲུབ་པ་མཐར་ཐུག་པའི་རྒྱུ་གང་ཡིན་པ་མཐོང་བ་དང་སྒོམ་པའི་ལམ་ལ་འདོམས་པའི་གདམས་ངག་དག་སྟེ་བཅུའོ། །
Enumeration Block 6:
གཉིས་པ་དགེ་འདུན་དཀོན་མཆོག་བྱེ་བྲག་ཏུ་བཤད་པ་ལ་གཉིས། སྤྱིའི་དོན་དང་། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ། མཚོན་བྱེད་ཀྱི་དཔེ་དང་། མཚོན་བྱའི་དོན་ནོ། །དང་པོ་ལ། འབྲས་བུ་རྣམ་པར་བཞག་པ་དང་། གང་ཟག་རྣམ་པར་བཞག་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་བཞིའི་དང་པོ་རྒྱུན་ཏུ་ཞུགས་པའི་གང་ཟག་ལ་ཞུགས་གནས་གཉིས་ཀྱི་དང་པོའི་མཚན་ཉིད།
Enumeration Block 8:
དབྱེ་བ་ལ་ལྔའི་དང་པོ། བར་དོར་འདའ་བ་ནི།
Enumeration Block 9:
གཉིས་པ་ཡན་ལག་གི་དོན་ལ་གསུམ། མཚམས་སྦྱར་བ་དང། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 10:
གསུམ་པ་ལ་གཉིས། དམན་པའི་སྦྱོར་ལམ་ལས་ཁྱད་ཞུགས་པར་བསྒྲུབ་པ་དང་། དམིགས་ཚུལ་བཅུ་གཉིས་བཞིར་བསྡུ་བའོ། །དང་པོ་ལ་གཉིས། ཁྱད་པར་འཕགས་ཚུལ་དང་། དེའི་རྒྱུ་མཚན་ནོ། །
