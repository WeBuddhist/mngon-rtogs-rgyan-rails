Enumeration Block 1:
དོན་གསུམ་སྟེ། མཚན་གྱི་དོན་དང་། གཞུང་གི་དོན་དང་། མཇུག་གི་དོན་ནོ། །དང་པོ་ལ། དངོས་དང་། ཞར་བྱུང་ངོ༌། །དང་པོ་ལ། མཚན་བསྒྱུར་བ་དང་། མཚན་བཤད་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ། བམ་པོའི་གྲངས་དང་། འགྱུར་གྱི་ཕྱག་གོ །
Enumeration Block 3:
གཉིས་པ་ལ་གསུམ། བཤད་པ་ལ་འཇུག་པ་དང་། བཤད་པ་ཉིད་དགོད་པ་དང་། བཤད་པ་མཐར་ཕྱིན་པའི་ཚུལ་ལོ། །དང་པོ་ལ་གསུམ། མཆོད་པར་བརྗོད་ཅིང་བཤད་པར་དམ་བཅའ་བ་དང་། འགྲེལ་པ་རྩོམ་རིགས་པར་སྒྲུབ་པ་དང་། ཁེངས་སྐྱུང་ཞིང་སྤྲོ་བ་སྐྱེ་བའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ། ཕྱིའི་རྐྱེན་དགེ་བའི་བཤེས་གཉེན་གྱི་མན་ངག་དང་ལྡན་པར་སྒྲུབ་པ་དང་། ནང་གི་རྐྱེན་བསྟན་བཅོས་ཀྱི་དོན་མཐའ་དག་རྟོགས་པའི་ཤེས་རབ་དང་ལྡན་པར་སྒྲུབ་པ་དང་། དེས་ན་འགྲེལ་པ་རྩོམ་པ་རིགས་པའོ། །
Enumeration Block 5:
དང་པོ་ལ་བཞི་ལས།
Enumeration Block 6:
གཉིས་པ་བཤད་པ་ཉིད་དགོད་པ་ལ་གསུམ། མཆོད་བརྗོད་དང་། རྒྱས་པ་ལ་དད་པའི་གང་ཟག་ལ་ཕྱེ་སྟེ་བཤད་པ་དང་། བསྡུས་དོན་གཞན་བཤད་པའོ། །དང་པོ་ལ་གསུམ། མཚམས་སྦྱར་བ་དང་། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ། ཚིག་དོན་དང་། བརྒལ་ལན་གྱིས་གཏན་ལ་དབབ་པའོ། །དང་པོ་ལ། བསྟོད་པ་དང་། ཕྱག་འཚལ་བའོ། །དང་པོ་ལ། མཁྱེན་གསུམ་གྱི་ཡོན་ཏན་གྱི་སྒོ་ནས་བསྟོད་པ་དང་། འཕགས་བཞིའི་ཡུམ་བྱེད་པས་བསྟོད་པའོ། །
Enumeration Block 8:
གཉིས་པ་ལ། གོ་རིམས་ངེས་པ་དང་། གྲངས་ངེས་པ་དང་། ཡུམ་སྲས་ཀྱི་དོན་དང་། བསྟོད་ཡུལ་གྱི་མཁྱེན་གསུམ་ངོས་བཟུང་བའོ། །
Enumeration Block 9:
གསུམ་པ་ལ། བསྡུས་པའི་དོན་དང་། དགོས་པའི་དོན་དང་། རྩོད་པ་སྤོང་བ་དང་། ཚིག་གི་དོན་ནོ། །
Enumeration Block 10:
གཉིས་པ་ལ། རྒྱས་པར་བཤད་པ་དང་། དོན་བསྡུ་བའོ། །དང་པོ་ལ། དད་པ་སྐྱེ་ཚུལ་དང་། དེ་ལས་དོན་གཉེར་གྱི་འདུན་པ་སྐྱེ་བ་དང་། དེ་ལས་ཞུགས་ནས་འབྲས་བུ་ཐོབ་པའི་ཚུལ་ལོ། །དང་པོ་ལ། དབང་རྟུལ་དད་པ་སྐྱེ་ཚུལ་དང་། དབང་རྣོན་དད་པ་སྐྱེ་ཚུལ་ལོ། །
Enumeration Block 11:
དེ་ལ་སློབ་དཔོན་ཉིད་བཞེད་པའི་དགག་བྱའི་ཆོས་ངོས་བཟུང་བ་དང་། དེ་གཞི་གཞན་གྱི་སྟེང་དུ་འགོག་པའི་གཏན་ཚིགས་སོ། །
Enumeration Block 12:
གཉིས་པ་ལ། རྟགས་དགོད་པ་དང་། ཚུལ་བསྒྲུབ་པའོ། །
Enumeration Block 13:
གཉིས་པ་ལ། ཕྱོགས་ཆོས་བསྒྲུབ་པ་དང་། ཁྱབ་པ་བསྒྲུབ་པའོ། །དང་པོ་ལ། བདེན་པའི་གཅིག་བྲལ་དུ་བསྒྲུབ་པ་དང་། དུ་བྲལ་དུ་བསྒྲུབ་པའོ། །
