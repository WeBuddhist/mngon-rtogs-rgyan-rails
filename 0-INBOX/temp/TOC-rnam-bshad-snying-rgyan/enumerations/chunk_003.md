Enumeration Block 3:

Enumeration Block 4:

Enumeration Block 5:
གཉིས་པ་ལ་གཉིས་ཀྱི་དང་པོ།
Enumeration Block 6:
གསུམ་པ་ལ། གཞི་ཤེས་མཚོན་བྱེད་ཀྱི་ཆོས་དང་། བསྟན་བཤད་སྦྱར་བའོ། །དང་པོ་ལ། འབྲས་ཡུམ་ལ་ཉེ་རིང་གི་རྒྱུ་མཚན་དང་། རྒྱུ་མཚན་དེ་ཉིད་སྒྲུབ་པ་དང་། མི་མཐུན་པ་དང་གཉེན་པོའི་ཕྱོགས་ཀྱི་དབྱེ་བ་དང་། གཞི་ཤེས་ཀྱི་སྦྱོར་བའོ། །
Enumeration Block 7:
གཉིས་པ་ལ། དབང་དུ་བྱ་བ་རྒྱུ་འབྲས་དང་། བརྟན་པ་རྒྱུ་འབྲས་སོ། །དང་པོ་ལ་གཉིས་ཀྱི་དང་པོ། རྣམ་རྫོགས་སྦྱོར་བ་ལ་གཉིས། མཚོན་བྱེད་ཀྱི་ཆོས་དང་། བསྟན་བཤད་སྦྱར་བའོ། །དང་པོ་ལ། དགེ་རྩ་གསོག་པའི་རྟེན་གྱི་དབང་དུ་བྱས་ནས་སྤྱིའི་རྣམ་གཞག་དང་། དགེ་རྩ་སྨིན་པའི་རྟེན་གྱི་དབང་དུ་བྱས་ནས་རྒྱུད་ལ་སྐྱེ་བའི་རིམ་པ་དངོས་སུ་བསྟན་པའོ། །དང་པོ་ལ། ལམ་ཤེར་ཕྱིན་གྱི་རྣལ་འབྱོར་སྒོམ་པའི་འཛིན་སྟངས་ཀྱི་དབྱེ་བ་དང་། མཉམ་གཞག་གི་སྦྱོར་བ་དང་། སྦྱོར་བ་སྒོམ་པའི་སྐྱོན་ཡོན་དང་། ལམ་ཤེར་ཕྱིན་གྱི་རྣལ་འབྱོར་དུ་མཚོན་པའི་མཚན་ཉིད་དོ། །
Enumeration Block 8:

Enumeration Block 9:

Enumeration Block 10:
གསུམ་པ་ཚིག་དོན་ལ། མཁྱེན་པ་གསུམ་རྒྱས་པར་བཤད་པ་དང་། སྦྱོར་བ་བཞི་རྒྱས་པར་བཤད་པ་དང་། ཆོས་སྐུ་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ། དོན་དུ་གཉེར་བྱ་རྣམ་མཁྱེན་བཤད་པ་དང་། དེར་བགྲོད་པའི་ལམ་ཤེས་བཤད་པ་དང་། ལམ་ཤེས་རྣམ་པར་དག་བྱེད་ཀྱི་ཡན་ལག་གཞི་ཤེས་བཤད་པའོ། །དང་པོ་ལ། མཚམས་སྦྱར་བ་དང་། ཆོས་བཅུ་རྒྱས་པར་བཤད་པ་དང་། སྐབས་བསྡུ་བའོ། །
Enumeration Block 11:
གཉིས་པ་ལ་རྣམ་མཁྱེན་ཐོབ་པའི་ཆེད་དུ་དམ་བཅས་པའི་བསམ་པ་དམ་བཅའ་བཤད་པ་དང་། དམ་བཅའི་དོན་སྒྲུབ་པའི་ཐབས་སྟོན་པའི་གདམས་ངག་བཤད་པ་དང་། གདམས་དོན་ཇི་ལྟར་སྒྲུབ་པའི་སྒྲུབ་པ་བཤད་པའོ། །དང་པོ་ལ། སྤྱིའི་དོན་དང་། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ་ཐེག་ཆེན་སེམས་བསྐྱེད་སྐྱེ་བའི་རྟེན་དང་། རྒྱུ་དང་། ངོ་བོ་དང་། ཕན་ཡོན་ནོ། །
Enumeration Block 12:
གཉིས་པ་ལ་དཀྱུས་མ་མཚན་ཉིད་དམིགས་པ་དང་བཅས་པ་བཤད་པ་དང་། འཕྲོས་དོན་དབྱེ་བ་བཤད་པའོ། །དང་པོ་ལ། མཚན་ཉིད་དང་། དེ་ངེས་པའི་ཡན་ལག་དམིགས་པའོ། །དང་པོ་ལ། སྤྱིའི་མཚམས་སྦྱར་བ་དང་། རྩ་བ་དང་། འགྲེལ་པའོ། །
