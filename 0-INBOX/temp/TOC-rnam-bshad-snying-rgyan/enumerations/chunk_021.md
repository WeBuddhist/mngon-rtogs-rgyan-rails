Enumeration Block 5:
གཉིས་པ་རྩ་བ་ལ། མདོ་ལས་བསྟན་ཚུལ། བསྟན་བཅོས་ཀྱིས་བསྡུས་ཚུལ། ཐོད་བརྒལ་གྱི་རང་བཞིན་བཤད་པ་གསུམ་གྱིས་སྤྱིའི་རྣམ་གཞག་དང་། ཚིག་དོན་ནོ། །
Enumeration Block 6:
གཉིས་པ་ལ། གཟུང་རྟོག་དང་། འཛིན་རྟོག་གོ །དང་པོ་ལ། འཇུག་པ་གཟུང་རྟོག་དང་། ལྡོག་པ་གཟུང་རྟོག་གོ །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 7:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 8:
གཉིས་པ་འཛིན་རྟོག་བཤད་པ་ལ། རྫས་འཛིན་རྟོག་པ་དང་། བཏགས་འཛིན་རྟོག་པའོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 9:
གཉིས་པ་བཏགས་འཛིན་རྟོག་པ་བཤད་པ་ལ་གཉིས། མདོར་བསྟན་པ། རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 10:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 11:
གསུམ་པ། སྤང་བྱ་སྤངས་པས་ཐོབ་པའི་ཡོན་ཏན་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 12:
བཞི་པ་བར་ཆད་མེད་པའི་རྩེ་སྦྱོར་ལ་གཉིས། དངོས་དང་། ལོག་རྟོག་བསལ་བའོ། །དང་པོ་ལ་གཉིས། བསོད་ནམས་མང་པོས་མཚོན་ཏེ་བསྟན་པ་དང་། དམིགས་རྣམ་བཤད་པའོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 13:

Enumeration Block 14:
ལན་ལ་གཉིས་ཀྱི་དང་པོ་རྩ་བ་ནི།
Enumeration Block 15:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
