Enumeration Block 1:
གཉིས་པ་ལ། མཚམས་སྦྱར་བ་དང་། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 2:
གསུམ་པ་ལ། དཔེ་ཉེར་གཉིས་ཀྱིས་དོན་ཉེར་གཉིས་མཚོན་པའི་ཚུལ་དང་། ས་མཚམས་སོ། །དང་པོ་ལ། རྒྱས་པར་བཤད་པ་དང་། དོན་བསྡུ་བའོ། །
Enumeration Block 3:
གཉིས་པ་ལ། ས་མཚམས་སོ་སོར་བཤད་པ་དང་། ལམ་ཀུན་བསྡུས་པར་བསྟན་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ། དངོས་དང་། གདམས་ངག་གི་དོན་བསྒོམས་པས་སྟོང་ཉིད་ལ་དམིགས་པའི་སྒོམ་བྱུང་སྐྱེས་པའི་ཐོག་མ་བཤད་པའོ། །དང་པོ་ལ། མཚམས་སྦྱར་བ་དང་། དོན་བཤད་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ། སྤྱིའི་དབྱེ་བ་དང་། དགེ་འདུན་དཀོན་མཆོག་བྱེ་བྲག་ཏུ་བཤད་པའོ། །དང་པོ་ལ། རྩ་བ་དང་། འགྲེལ་པ་དང་། དོན་བསྡུ་བའོ། །
Enumeration Block 6:
སྒྲུབ་པའི་རྟེན་དང་བརྟེན་པ་གཉིས་ལས་སྔ་མ་སངས་རྒྱས་ལ་སོགས་དཀོན་མཆོག་གསུམ་ལ་གདམས་པ་དང་། ཕྱི་མ་ལ། ཁྱད་གཞི་དང། ཁྱད་ཆོས་སོ། །
Enumeration Block 7:
གཉིས་པ་ལ། བརྟེན་པ་སྒྲུབ་པ་ལ་གདམས་པ་དང་། སྒྲུབ་པའི་རྟེན་ལ་གདམས་པ་དང་། སྒྲུབ་པའི་ཁྱད་པར་གྱི་ཆོས་ལ་གདམས་པའོ། །དང་པོ་ལ། སྒྲུབ་པ་རང་གི་ངོ་བོ་ལ་གདམས་པ་དང་། དེའི་དམིགས་པ་ལ་གདམས་པའོ། །
Enumeration Block 8:
འདིར་བདེན་པ་གཉིས་ལ། མཚན་ཉིད་དང་། མིང་དོན་དང་། མཚན་གཞིའི་དབྱེ་བ་དང་། གཅིག་དང་ཐ་དད་བརྟག་པའོ། །
Enumeration Block 9:
དོན་དམ་ལ་ནི་རྣམ་གྲངས་པའི་དོན་དམ་རིགས་ཤེས་རྗེས་དཔག་དང་། རྣམ་གྲངས་མ་ཡིན་པའི་དོན་དམ་དོན་དམ་གཟིགས་པའི་འཕགས་པའི་མཉམ་གཞག་གོ །ཀུན་རྫོབ་བདེན་པ་ལ་དབྱེ་ན། ཡང་ལོག་གཉིས་སུ་ཤེས་པར་བྱའོ། །
Enumeration Block 10:
གཉིས་པ་ལ། སྤྱིའི་དོན་དང་། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ། བདེན་པ་བཞིའི་གྲངས་ངེས་པ་དང་། གོ་རིམས་ངེས་པ་དང་། མཚན་གཞི་དང་། དེ་ཉིད་ངེས་བྱེད་ཀྱི་ཚད་མའོ། །
Enumeration Block 11:
བཞི་པ་ལ། ལོག་རྟོག་བཅུ་དྲུག་ངོས་བཟུང་བ་དང་། དེ་དང་འགལ་བ་བདེན་པའི་རྣམ་པ་བཅུ་དྲུག་ངོས་བཟུང་བའོ། །
Enumeration Block 12:
གཉིས་པ་ལ། སྤྱིའི་དོན་དང་། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ། ཐུན་མོང་མ་ཡིན་པའི་དཀོན་མཆོག་གསུམ་ངོས་བཟུང་བ་དང་། སྐྱབས་སྤྱིའི་རྣམ་གཞག་དང་། ཀུན་རྫོབ་པ་དང་དོན་དམ་པའི་སྐྱབས་ཀྱི་ཁྱད་པར་དང་། ཇི་ལྟར་སྐྱབས་སུ་འགྲོ་བའི་ཚུལ་ལོ། །
Enumeration Block 13:
གསུམ་པ་སྒྲུབ་པའི་ཁྱད་པར་གྱི་ཆོས་ལ་གདམས་པ་ལ་གསུམ། མི་མཐུན་ཕྱོགས་མངོན་གྱུར་སེལ་བ་ལ་གདམས་པ་དང་། ལམ་ཁྱད་པར་ཅན་བསྒྲུབ་པར་གདམས་པ་དང་། སྤང་བྱའི་ས་བོན་སེལ་བར་གདམས་པའོ། །
Enumeration Block 14:
གཉིས་པ་ལ། སྒྲུབ་པ་ལ་རང་དབང་དུ་འཇུག་པའི་རྒྱུ་སྤྱན་ལྔ་ལ་གདམས་པ་དང་། སྒྲུབ་པ་མྱུར་དུ་རྫོགས་པའི་རྒྱུ་མངོན་ཤེས་དྲུག་ལ་གདམས་པའོ། །
