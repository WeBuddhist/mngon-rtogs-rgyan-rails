Enumeration Block 1:
གཉིས་པ་ཡེ་ཤེས་ཆོས་ཀྱི་སྐུ་ལ། དངོས་ཀྱི་དོན་དང་། དེའི་ཁྱད་པར་བཤད་པ་དང་། དེ་ལ་རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ། ཡེ་ཤེས་ཆོས་ཀྱི་སྐུ་སྐུ་གསུམ་ལས་ཐ་དད་དུ་བསྟན་པ་དང་། ཐ་དད་དུ་མི་འདོད་པ་དགག་པ་དང་། ཐ་དད་དུ་འདོད་པ་ལ་རྩོད་པ་སྤང་བའོ། །
Enumeration Block 2:
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 3:
ཡེ་ཤེས་ཆོས་ཀྱི་སྐུ་ལ་སྡེ་ཚན་ཉི་ཤུ་རྩ་གཅིག་ཏུ་དབྱེར་ཡོད་དེ།
Enumeration Block 4:
གསུམ་པ་འགྲེལ་པ་ལ། དབྱེ་བ་དང་། དེ་དག་ཡེ་ཤེས་ཆོས་སྐུར་བཞག་པའོ། །
Enumeration Block 5:
སྡེ་ཚན་ལྔ་པ་ཟད་པར་ལ། དངོས་ཀྱི་དོན་དང་། རྣམ་ཐར། ཟིལ་གནོན། ཟད་པར་གསུམ་གྱི་ཁྱད་པར་རོ། །
Enumeration Block 6:
གཉིས་པ་ལ། སྔར་གྱི་ཚིགས་བཅད་སྔ་ཕྱི་གཉིས་ཀ་ངོ་བོ་ཉིད་ཀྱི་སྐུ་སྟོན་པའི་བསྟན་བཤད་དུ་འདོད་པའི་ལུགས་བརྗོད་པ་དང་། སྐུ་མི་འདྲ་བ་གཉིས་སོ་སོར་བསྟན་ཡང་ཚིག་དོན་ལ་མ་ཞུགས་པའི་ཉེས་པ་མེད་པའི་བཞེད་པའོ། །
Enumeration Block 7:
གསུམ་པ་ལ། རྩོད་པ་དང་། ལན་ནོ། །
Enumeration Block 8:
གཉིས་པ་དེའི་ཁྱད་པར་བཤད་པ་ལ། ཉོན་མོངས་མེད་པའི་ཏིང་ངེ་འཛིན་དང་། སྨོན་གནས་མཁྱེན་པའི་ཏིང་ངེ་འཛིན་ཏོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 9:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 10:
གསུམ་པ་དེ་ལ་རྩོད་པ་སྤང་བ་ལ། ཆོས་སྐུ་རྟག་པ་ལ་རྩོད་པ་སྤང་བ་དང་། ཁྱབ་རྟག་གཉིས་ཀ་ལ་རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ་གཉིས་ཀྱི་དང་པོ་རྩོད་པས་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 11:
གཉིས་པ་ལན་ལ། སེམས་ཅན་རང་རྒྱུད་ཀྱི་ཚོགས་ཀྱི་ཁྱད་པར་ལ་ལྟོས་པ་དང་། སེམས་ཅན་རང་རྒྱུད་ཀྱི་རྐྱེན་མ་ཚང་ན་སྐུ་དངོས་སུ་མི་སྣང་བ་དཔེས་བཤད་པའོ། །
Enumeration Block 12:
དང་པོ་ལ་གཉིས་ཀྱི་དང་པོ་རྩ་བ་ནི།
Enumeration Block 13:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 14:

Enumeration Block 15:
ལན་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 16:
གསུམ་པ་ལོངས་སྤྱོད་རྫོགས་པའི་སྐུ་ལ། མཚན་ཉིད་ཀྱི་སྒོ་ནས་མདོར་བསྟན་པ་དང་། ཡོན་ཏན་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 17:
གཉིས་པ་ལ། མཚན་དང་། དཔེ་བྱད་དོ། །དང་པོ་ལ། འབྲས་བུ་མཚན་དང་། རྒྱུ་འབྲས་ཀྱི་འབྲེལ་བ་དང་། རྒྱུ་མདོ་ལས་འབྱུང་བ་བཤད་པའོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 18:

Enumeration Block 20:

Enumeration Block 21:

Enumeration Block 22:

Enumeration Block 23:
