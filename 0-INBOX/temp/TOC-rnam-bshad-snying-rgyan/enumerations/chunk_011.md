Enumeration Block 1:
འདི་ལ་གཉིས། གཞན་གྱི་ལུགས་དགག་པ་དང་། རང་གི་ལུགས་རྣམ་པར་བཞག་པའོ། །
Enumeration Block 2:
འདི་ལ་གཞན་གྱི་འདོད་པ་སུན་དབྱུང་བ་དང་། རང་གི་ལུགས་རྣམ་པར་བཞག་པའོ། །
Enumeration Block 3:
བཞི་པ་ལམ་ཤེས་ཀྱི་རང་བཞིན་ལ། ཚིག་དོན་དང་། མཐའ་དཔྱད་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལམ་ཤེས་ཀྱི་རང་བཞིན་ལ། ཉན་ཐོས་དང་། རང་རྒྱལ་དང་། བྱང་སེམས་ཀྱི་ལམ་གྱི་རང་བཞིན་ཤེས་པའོ། །དང་པོ་ལ། ལམ་ཤེས་ཀྱི་ངོ་བོ་དང་། རྒྱུ་ངེས་འབྱེད་ཆ་མཐུན་ནོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 5:
གསུམ་པ་འགྲེལ་པ་ལ། ཤེས་བྱའི་ལམ་དང་། དེ་ཇི་ལྟར་ཤེས་པའི་ཚུལ་ལོ། །
Enumeration Block 6:
འདིར་འགྲེལ་པས་འཆད་པ་ལ་གསུམ། སྡུག་ཀུན་གྱི་རྣམ་པ་དང་། འགོག་བདེན་གྱི་རྣམ་པ་དང་། ལམ་བདེན་གྱི་རྣམ་པའོ། །
Enumeration Block 7:
དང་པོ་ལ་སྡུག་ཀུན་སོ་སོའི་རྣམ་པ་དང་། ཐུན་མོང་གི་རྣམ་པའོ། །དང་པོ་ལ་གཉིས་ཀྱི་དང་པོ།
Enumeration Block 8:
གཉིས་པ་ལ། མཚམས་སྦྱར་བ་དང་། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 9:
གཉིས་པ་རང་རྒྱལ་གྱི་ལམ་ཤེས་པའི་རང་བཞིན་ལ། སྤྱི་དང་། ཡན་ལག་གི་དོན་ནོ། །
Enumeration Block 10:
གཉིས་པ་ལ་རྟེན་གྱི་ཁྱད་པར། དེའི་ལམ་ཇི་ལྟར་ཤེས་པའི་ཚུལ། དེའི་རྒྱུ་ངེས་འབྱེད་ཆ་མཐུན་བཤད་པའོ། །དང་པོ་ལ། ཁྱད་ཆོས་དངོས་དང་། རྩོད་སྤང་ངོ༌། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 11:
གསུམ་པ་འགྲེལ་པ་ལ། ལམ་བགྲོད་པའི་ཁྱད་པར་དང་། ཆོས་སྟོན་པའི་ཁྱད་པར་རོ། །
Enumeration Block 12:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 13:
གཉིས་པ་ལ། མཚམས་སྦྱར་བ་དང་། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 14:
གཉིས་པ་ལ། ཚིག་དོན་དང་། མཐའ་དཔྱད་པའོ། །
