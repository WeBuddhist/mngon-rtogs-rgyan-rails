Enumeration Block 1:
གཉིས་པ་ལ། དངོས་ཀྱི་དོན་དང་། མངོན་པར་རྟོགས་པ་དྲུག་གི་གོ་རིམས་ལ་ལོག་པར་རྟོག་པ་དགག་པའོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 2:
གསུམ་པ་འགྲེལ་པ་ལ། སོ་སོར་བཤད་པ་དང་། དོན་བསྡུ་བའོ། །
Enumeration Block 3:
དང་པོ་ལ་བཞིའི་དང་པོ་དྲོ་བ་ནི།
Enumeration Block 4:
གཉིས་པ་ལ། མི་འཐད་པའི་ཕྱོགས་སུན་དབྱུང་བ་དང་། ལེགས་པར་གནས་པའི་ཕྱོགས་བཞག་པ་དང་། འགལ་བ་སྤང་བའོ། །
Enumeration Block 5:
གསུམ་པ་དེ་ལ་བརྟེན་ནས་མངོན་རྟོགས་ཁྱད་པར་ཅན་རྒྱུད་ལ་སྐྱེ་བའི་རིམ་པ་བཤད་པ་ལ། བླ་ན་མེད་པའི་བྱང་ཆུབ་ལས་ཕྱིར་མི་ལྡོག་པའི་རྟགས་བཤད་པ་དང་། སྐུ་གསུམ་སྒྲུབ་བྱེད་ཀྱི་ལམ་ཁྱད་པར་ཅན་བཤད་པའོ། །
Enumeration Block 6:
དང་པོ་ལ། སྤྱིའི་དོན་དང་། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ་ཕྱིར་མི་ལྡོག་པའི་གང་ཟག་གི་དབྱེ་བ་དང་། ཕྱིར་མི་ལྡོག་པའི་དོན་དང་། རྟགས་ཀྱིས་དཔོག་པའི་ཚུལ་ལོ། །
Enumeration Block 7:
གཉིས་པ་ཡན་ལག་གི་དོན་ལ། མདོར་བསྟན། རྒྱས་བཤད། དོན་བསྡུ་བའོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་སྤྱིའི་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 8:
གཉིས་པ་ལ། སྦྱོར་ལམ་དང་། མཐོང་ལམ་དང་། སྒོམ་ལམ་པ་ཕྱིར་མི་ལྡོག་པའི་རྟགས་སོ། །དང་པོ་ལ། མདོར་བསྟན། རྒྱས་བཤད་དོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 9:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 10:
དྲོད་ལ་གནས་པའི་རྟགས་རྣམ་པ་བཅུ་གཅིག་དང་། རྩེ་མོ་ལ་གནས་པའི་རྣམ་པ་དྲུག་དང་། བཟོད་པ་ལ་གནས་པའི་རྣམ་པ་གཉིས་དང་། ཆོས་མཆོག་ལ་གནས་པའི་རྣམ་པ་གཅིག་གིས་
Enumeration Block 11:
དྲོད་ལ་གནས་པའི་རྟགས་བཅུ་གཅིག་ནི།
Enumeration Block 12:
རྩེ་མོའི་རྟགས་དྲུག་ནི།
Enumeration Block 13:
བཟོད་པ་ལ་གནས་པའི་རྟགས་གཉིས་ནི།
Enumeration Block 14:
ཆོས་མཆོག་ལ་གནས་པའི་རྟགས་གཅིག་ནི།
Enumeration Block 15:
གཉིས་པ་མཐོང་ལམ་པ་ཕྱིར་མི་ལྡོག་གི་རྟགས་ལ། མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 16:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 17:
གསུམ་པ་འགྲེལ་པ་ལ། རྒྱས་པར་བཤད་པ་དང་། དོགས་པ་བཅད་པའོ། །དང་པོ་ལ་བཞིའི་དང་པོ་སྡུག་བདེན་གྱི་སྐད་ཅིག་མའི་རྣམ་པ་ནི།
Enumeration Block 18:
གཉིས་པ་ཀུན་འབྱུང་ལ་བརྟེན་པའི་རྣམ་པ་བཞི་ནི།
Enumeration Block 19:
གསུམ་པ་འགོག་པའི་སྐད་ཅིག་མ་བཞི་ནི།
Enumeration Block 20:
བཞི་པ་ལམ་གྱི་སྐད་ཅིག་མ་བཞི་ནི།
Enumeration Block 21:
གསུམ་པ་སྒོམ་ལམ་པ་ཕྱིར་མི་ལྡོག་གི་རྟགས་ལ། ཐེག་ཆེན་གྱི་སྒོམ་ལམ་རྒྱས་པར་བཤད་པ་དང་། ཕྱིར་མི་ལྡོག་པའི་རྟགས་ཀྱི་ཁྱད་པར་བཤད་པའོ། །དང་པོ་ལ་གསུམ། སྒོམ་ལམ་གྱི་ཁྱད་ཆོས། ཁྱད་གཞི་སྒོམ་ལམ། སྒོམ་ལམ་གྱི་དབྱེ་བའོ། །
Enumeration Block 22:
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 23:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 24:
གསུམ་པ་ལ། དབྱེ་བ་དངོས་དང་། རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ་གཉིས་ཀྱི་དྲི་བ་ནི།
Enumeration Block 25:
ལན་ལ་གཉིས་ཀྱི་དང་པོ་རྩ་བ་ནི། ཐེག་ཆེན་འཕགས་པའི་སྒོམ་ལམ་དེ་ནི་རྣམ་པ་དགུར་བཞེད་དོ། །
Enumeration Block 26:
གཉིས་པ་ལ། གྲངས་ངེས་ལ་རྩོད་སྤང་དང་། བྱེད་པ་ལ་རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ་གཉིས་ཀྱི་དང་པོ་རྩོད་པ་ནི།
Enumeration Block 27:

Enumeration Block 28:
གཉིས་པ་འགྲེལ་པ་ལ། དོན་དམ་ལ་ལྟོས་ཏེ་རྟགས་མ་གྲུབ་པ་དང་། ཀུན་རྫོབ་ལ་ཁྱབ་པ་མ་གྲུབ་པའི་ལན་ནོ། །
Enumeration Block 29:
གཉིས་པ་ལ། དོན་དམ་ལ་ལྟོས་པའི་རྩོད་སྤང་དང་། ཐ་སྙད་ལ་ལྟོས་པའི་རྩོད་སྤང་ངོ༌། །དང་པོ་ལ་གཉིས། རྩོད་པ་དང་། ལན་ནོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 30:

Enumeration Block 31:
གསུམ་པ་འགྲེལ་པ་ལ། ཐ་སྙད་དུ་ཁྱབ་པ་མ་གྲུབ་པ་དང་། དོན་དམ་ལ་ལྟོས་ཏེ་འདོད་ལན་ནོ། །
Enumeration Block 32:

Enumeration Block 33:

Enumeration Block 34:
གཉིས་པ་ལན་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
