Enumeration Block 1:
གཉིས་པ་ཡན་ལག་གི་དོན་ལ། སྤྱིའི་མཚམས་སྦྱར་བ། སོ་སོའི་དོན་བཤད་པ། སྤྱིའི་གྲངས་བསྡུ་བའོ། །
Enumeration Block 2:
གཉིས་པ་ལ། མདོར་བསྟན། རྒྱས་བཤད་དོ། །
Enumeration Block 3:
དང་པོ་ལ་གཉིས་ཀྱི་དང་པོ་རྩ་བ་ནི།
Enumeration Block 4:
འདིར་བསྟན་མཚན་ཉིད་དེ་ཡང་རྣམ་པ་གསུམ་དུ་དབྱེར་ཡོད་དེ། མཁྱེན་གསུམ་སྦྱོར་བ་མཚོན་བྱེད་ཤེས་པའི་མཚན་ཉིད་དང་། ཉན་རང་གི་སྦྱོར་བ་ལས་ཁྱད་པར་འཕགས་པའི་སྦྱོར་བར་མཚོན་བྱེད་ཁྱད་པར་གྱི་མཚན་ཉིད་དང་། གཞན་དོན་སྒྲུབ་པའི་བྱེད་ལས་ཁྱད་པར་ཅན་དང་ལྡན་པའི་སྦྱོར་བར་མཚོན་བྱེད་བྱེད་པའི་མཚན་ཉིད་དེ།
Enumeration Block 5:
མཚན་ཉིད་ཀྱི་སྒྲ་སྦྱོར་བའི་གཞི་མཚན་ཉིད་ནི་རྣམ་པ་བཞིར་ཤེས་པར་བྱའོ། །
Enumeration Block 6:
གཉིས་པ་རྒྱས་བཤད་ལ། ཤེས་པ། ཁྱད་པར། བྱེད་པ། ངོ་བོ་ཉིད་ཀྱི་མཚན་ཉིད་དོ། །དང་པོ་ལ། གཞི་ཤེས། ལམ་ཤེས། རྣམ་མཁྱེན་སྦྱོར་བའི་མཚན་ཉིད་དོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ།
Enumeration Block 7:
དེ་ཡང་སྔོན་གྱི་མཐའ་ལ་བརྟེན་པ་དང་། ཕྱི་མའི་མཐའ་ལ་བརྟེན་པ་དང་། མྱ་ངན་ལས་འདས་པ་ལ་བརྟེན་པའི་ལྟ་བ་བཞི་བཞི་དང་། ལུས་སྲོག་ལ་བརྟེན་པའི་ལྟ་བ་གཉིས་སོ། །
Enumeration Block 8:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 9:
གསུམ་པ་ལ། གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 10:
གཉིས་པ་ཁྱད་པར་གྱི་མཚན་ཉིད་ལ། མཚམས་སྦྱར་བ། མདོར་བསྟན། རྒྱས་བཤད་དོ། །
Enumeration Block 11:
གཉིས་པ་ལ་གཉིས་ཀྱི་དང་པོ་རྩ་བ་ནི།
Enumeration Block 12:
གསུམ་པ་རྒྱས་བཤད་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 13:
གསུམ་པ་འགྲེལ་པ་ལ། རྒྱས་པར་བཤད་པ་དང་། གང་ལས་ཁྱད་ཞུགས་པའི་ཡུལ་དངོས་སུ་མ་བསྟན་པའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 14:
གསུམ་པ་བྱེད་པའི་མཚན་ཉིད་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 15:
ཕན་པ་ལ་སོགས་པའི་བྱེད་པ་གསུམ་མོ། །
Enumeration Block 16:
ལམ་ཤེས་པ་ཉིད་ཀྱི་སྦྱོར་བའི་བྱེད་པ་སྐྱབས་ལ་སོགས་པ་བྱེད་པ་བདུན་ནོ། །
Enumeration Block 17:
རྣམ་པ་ཐམས་ཅད་མཁྱེན་པ་ཉིད་ཀྱི་སྦྱོར་བ་ལ་ནི་འཇིག་རྟེན་གྱི་རྟེན་གྱི་མཛད་པ་གཅིག་སྟེ། བྱེད་པ་བཅུ་གཅིག་གོ །
Enumeration Block 18:
བཞི་པ་ངོ་བོ་ཉིད་ཀྱི་མཚན་ཉིད་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 19:
གསུམ་པ་འགྲེལ་པ་ལ། སོ་སོར་བཤད་པ་དང་། དོན་བསྡུ་བའོ། །
Enumeration Block 20:
ཐམས་ཅད་ཤེས་པ་ཉིད་ཀྱི་སྦྱོར་བ་ཉོན་མོངས་པའི་སྒྲིབ་པ་ཅི་རིགས་པས་དབེན་པའི་ངོ་བོ་ཉིད་བཞིའོ། །
Enumeration Block 21:
ལམ་ཤེས་སྦྱོར་བའི་ངོ་བོ་ནི་ལམ་ཤེས་པ་ཉིད་ཀྱི་སྦྱོར་བའི་ངོ་བོ་ཉིད་ལྔའོ། །
Enumeration Block 22:
རྣམ་པ་ཐམས་ཅད་མཁྱེན་པ་ཉིད་ཀྱི་སྦྱོར་བའི་ངོ་བོ་ཉིད་བདུན་ནོ། །བདུན་ཡོད་དེ།
Enumeration Block 23:
གཉིས་པ་ཐར་པ་ཆ་མཐུན་ནས་བཟུང་སྟེ་རྒྱུད་ལ་སྐྱེ་བའི་རིམ་པ་བཤད་པ་ལ་གསུམ། བསྐལ་པ་གྲངས་མེད་གསུམ་ནས་འཚང་རྒྱ་བའི་ལམ་གྱི་ཐོག་མ་བཤད་པའི་སྒོ་ནས་རྒྱན་གྱི་ཆེད་དུ་བྱ་བའི་གདུལ་བྱ་ངོས་བཟུང་བ་དང་། རྒྱུད་སྨིན་བྱེད་ཀྱི་ལམ་སྐྱེ་བའི་རིམ་པ་དང་། དེ་ལ་བརྟེན་ནས་མངོན་རྟོགས་ཁྱད་པར་ཅན་རྒྱུད་ལ་སྐྱེ་བའི་རིམ་པ་བཤད་པའོ། །དང་པོ་ལ། ལམ་སྤྱིའི་མཚན་ཉིད་དང་། ལམ་གྱི་ཆིངས་ལྔར་བསྡུས་ནས་དེ་ལ་མཁས་པའི་གདུལ་བྱ་ངོས་བཟུང་བའོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 24:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 25:
གཉིས་པ་རྩ་བ་ལ། ལམ་སྤྱིའི་ཆིངས་ལ་མཁས་པའི་ཚད་དང་། དེ་ལ་མཁས་པའི་རྒྱན་གྱི་གདུལ་བྱ་ངོས་བཟུང་བའོ། །དང་པོ་ལ། ཐེག་ཆེན་གྱི་འཇུག་སྒོ་སེམས་བསྐྱེད་དུ་བསྟན་པ་དང་། སྤྱོད་པ་ལ་སློབ་པའི་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས་ཀྱི་དང་པོ།
Enumeration Block 26:
གཉིས་པ་ལ། སྤྱོད་པ་སྤྱི་ལ་བསླབ་པ་དང་། ཕར་ཕྱིན་ཐ་མ་གཉིས་ལ་བསླབ་པའོ། །
Enumeration Block 27:
གཉིས་པ་ལ་གཉིས་ཀྱི་དང་པོ་བསམ་གཏན་གྱི་ཕར་ཕྱིན་ལ་བསླབ་པ་ནི།
Enumeration Block 28:
རྒྱན་གྱི་ཆེད་དུ་བྱ་བའི་གདུལ་བྱ་དེ་ལ་དབང་པོའི་རིམ་པས་གཉིས་སུ་ཡོད་དེ། བྱང་ཆུབ་སེམས་དཔའ་དབང་པོ་རྣོན་པོ་ཡིས་རྫོགས་པའི་བྱང་ཆུབ་རྟོགས་ཤིང་ཐོབ་པར་སླ་བ་དང་སེམས་དཔའ་དབང་པོ་རྟུལ་པོས་རྟོགས་དཀར་བཞེད་པའི་ཕྱིར་རོ། །
Enumeration Block 29:
རྒྱན་གྱི་ཆེད་དུ་བྱ་བའི་གདུལ་བྱ་དེ་ལ། དད་པའི་རྗེས་འབྲང་དང་། ཆོས་ཀྱི་རྗེས་འབྲང་གཉིས་སུ་ངེས་པར་སྟོན་པ་ཡིན་གྱི།
Enumeration Block 30:
གསུམ་པ་འགྲེལ་པ་ལ། ཡུལ་ལྔ་ལ་མཁས་པའི་ཁྱད་པར་དང་། དབང་པོ་རྣོ་རྟུལ་གྱིས་ལམ་བགྲོད་པའི་ཁྱད་པར་དང་། ཤུགས་ལ་འཕངས་པའི་དོན་ནོ། །
Enumeration Block 31:
གཉིས་པ་ལ། དངོས་ཀྱི་དོན་དང་། མངོན་པར་རྟོགས་པ་དྲུག་གི་གོ་རིམས་ལ་ལོག་པར་རྟོག་པ་དགག་པའོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 32:
གསུམ་པ་འགྲེལ་པ་ལ། སོ་སོར་བཤད་པ་དང་། དོན་བསྡུ་བའོ། །དང་པོ་ལ་བཞིའི་དང་པོ་དྲོ་བ་ནི།
Enumeration Block 33:
གཉིས་པ་ལ། མི་འཐད་པའི་ཕྱོགས་སུན་དབྱུང་བ་དང་། ལེགས་པར་གནས་པའི་ཕྱོགས་བཞག་པ་དང་། འགལ་བ་སྤང་བའོ། །
