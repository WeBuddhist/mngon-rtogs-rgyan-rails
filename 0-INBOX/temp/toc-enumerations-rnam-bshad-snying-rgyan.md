ཉན་ཐོས་དང་ཐུན་མོང་མ་ཡིན་པ་དང་། བདེན་གཉིས་ལས་མི་འདའ་བ་མི་དམིགས་པ་དང་སྒྲུབ་པ་དེའི་དམིགས་པ་ཞེས་དང་། སྒྲུབ་པའི་རྟེན་ཞེས་དང་། སྒྲུབ་པ་གོང་ནས་གོང་དུ་ཁྱད་པར་དུ་ཞེས་དང་། སྒྲུབ་པ་ཉམས་སུ་ལེན་པ་ལས་མི་ལྡོག་པར་ཞེས་དང་། ཐེག་ཆེན་ལས་ཉམས་ནས་ཉན་རང་གི་ཐེག་པ་གཞན་གྱིས་ཞེས་དང་། སྒྲུབ་པ་ལ་རང་དབང་དུ་འཇུག་པས་གཞན་གྱི་ཞེས་དང་། ཚོགས་མྱུར་དུ་རྫོགས་པར་བྱེད་པས་རྣམ་པ་ཐམས་ཅད་ཅེས་དང་། སྒྲིབ་གཉིས་མཐའ་དག་ཟད་པའི་སྒོ་ནས་སྒྲུབ་པ་མཐར་ཐུག་པའི་རྒྱུ་གང་ཡིན་པ་མཐོང་བ་དང་སྒོམ་པའི་ལམ་ལ་འདོམས་པའི་གདམས་ངག་དག་སྟེ་བཅུའོ། །
Enumeration Block 6:
གཉིས་པ་དགེ་འདུན་དཀོན་མཆོག་བྱེ་བྲག་ཏུ་བཤད་པ་ལ་གཉིས། སྤྱིའི་དོན་དང་། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ། མཚོན་བྱེད་ཀྱི་དཔེ་དང་། མཚོན་བྱའི་དོན་ནོ། །དང་པོ་ལ། འབྲས་བུ་རྣམ་པར་བཞག་པ་དང་། གང་ཟག་རྣམ་པར་བཞག་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་བཞིའི་དང་པོ་རྒྱུན་ཏུ་ཞུགས་པའི་གང་ཟག་ལ་ཞུགས་གནས་གཉིས་ཀྱི་དང་པོའི་མཚན་ཉིད།
Enumeration Block 8:
དབྱེ་བ་ལ་ལྔའི་དང་པོ། བར་དོར་འདའ་བ་ནི།
Enumeration Block 9:
གཉིས་པ་ཡན་ལག་གི་དོན་ལ་གསུམ། མཚམས་སྦྱར་བ་དང། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 10:
གསུམ་པ་ལ་གཉིས། དམན་པའི་སྦྱོར་ལམ་ལས་ཁྱད་ཞུགས་པར་བསྒྲུབ་པ་དང་། དམིགས་ཚུལ་བཅུ་གཉིས་བཞིར་བསྡུ་བའོ། །དང་པོ་ལ་གཉིས། ཁྱད་པར་འཕགས་ཚུལ་དང་། དེའི་རྒྱུ་མཚན་ནོ། །

Enumeration Block 1:
གཉིས་པ་ལ། མདོར་བསྟན་པ་དང་། རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ། མཚམས་སྦྱར་བ་དང་། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 2:
གསུམ་པ་ལ་གཉིས། དམན་པའི་སྦྱོར་ལམ་ལས་ཁྱད་ཞུགས་པར་བསྒྲུབ་པ་དང་། དམིགས་ཚུལ་བཅུ་གཉིས་བཞིར་བསྡུ་བའོ། །དང་པོ་ལ་གཉིས། ཁྱད་པར་འཕགས་ཚུལ་དང་། དེའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 3:
གཉིས་པ་ལ་བཞི། དངོས་དང་། རྣམ་པ་གཞན་གྱི་སྒོ་ནས་དམིགས་པ་དང་། དེ་འདིར་དངོས་སུ་མི་སྟོན་པའི་རྒྱུ་མཚན་དང་། རྩོད་པ་སྤང་བའོ། །
Enumeration Block 4:
གཉིས་པ་རྒྱས་བཤད་ལ། ཁྱད་ཆོས་སྔ་མ་གསུམ་བཤད་པ་དང་། རྟོག་པའི་ཁྱད་ཆོས་དང་ཡོངས་འཛིན་བཤད་པའོ། །དང་པོ་ལ་གསུམ། སྤྱིའི་མཚམས་སྦྱར། སོ་སོའི་དོན་བཤད། བརྗོད་ཚུལ་ལ་རྩོད་པ་སྤང་བའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་བཞིའི་དང་པོ་དྲོད་ཀྱི་དམིགས་རྣམ་རྒྱུའི་ཁྱད་པར་དང་བཅས་པ་ལ་གཉིས། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ། བཤད་པ་དང་། བསྡུ་བའོ། །
Enumeration Block 7:
གཉིས་པ་རྩེ་མོ་ལ། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 8:
རྩེ་མོ་ཆུང་ངུའི་དམིགས་རྣམ་ལ་བདེན་པ་རྣམ་པར་མ་བཞག་པ་དང་བཞག་པ་གཉིས་ལས།
Enumeration Block 9:
གཉིས་པ་ལ། བཤད་པ་དང་། བསྡུ་བའོ། །
Enumeration Block 10:
གསུམ་པ་བཟོད་པ་ལ་རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 11:
གཉིས་པ་ལ། བཤད་པ་དང་། བསྡུ་བའོ། །
Enumeration Block 12:
བཞི་པ་ཆོས་མཆོག་ལ། རྩ་བ་དང་། འགྲེལ་པའོ། །དང་པོ་ལ། ཆོས་མཆོག་གི་དམིགས་རྣམ་བྱེ་བྲག་ཏུ་བཤད་པ་དང་། སྤྱིའི་དོན་བསྡུ་བའོ། །
Enumeration Block 13:
གཉིས་པ་ལ། བཤད་པ་དང་། བསྡུ་བའོ། །
Enumeration Block 14:
གསུམ་པ་བརྗོད་ཚུལ་ལ་རྩོད་པ་སྤང་བ་ལ། རྩོད་པ་དང་། ལན་ནོ། །
Enumeration Block 15:
ལན་ལ། ཆོས་ཅན་བདེན་བཞི་ལ་བརྟེན་པར་དངོས་སུ་མ་བརྗོད་པས་དེར་མི་རྟོགས་པའི་སྐྱོན་མེད་པ་དང་། དེ་ལྟར་དངོས་སུ་མ་བརྗོད་ཀྱང་དོན་གྱིས་གོ་བར་བྱ་བའོ། །
Enumeration Block 16:
གཉིས་པ་རྟོག་པའི་ཁྱད་ཆོས་ལ། སྤྱི་དང་། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ་སྤྱིའི་ངོས་འཛིན་དང་། དགག་སྒྲུབ་གང་གི་རྣམ་པ་ཅན་ཡིན་དཔྱད་པ་དང་། ཁྱད་ཆོས་སུ་འགྱུར་ཚུལ་ལོ། །
Enumeration Block 17:
སྤྱིར་རྟོག་པ་གསུམ་སྟེ། ཡང་དག་པ་མ་ཡིན་པའི་ཀུན་རྟོག་དང་། སེམས་རྩིང་བའི་རྣམ་པ་ཅན་དང་། འདྲེར་རུང་འཛིན་པའི་རྟོག་པ་ལས་འདིར་ནི་ཕྱི་མའོ། །
Enumeration Block 18:
ད་ནི་འདི་ལྟར་བཤད་དེ། གཟུང་འཛིན་གྱི་རྟོག་པ་སྤྱིའི་ངོས་འཛིན་དང་། འཛིན་རྟོག་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 19:
ལོངས་སྤྱད་བྱ་གཟུང་བ་དང་། ལོངས་སྤྱོད་བྱེད་ལ་འཛིན་པར་བྱས་པ་སྟེ། སྔ་མ་ལ་ཀུན་ནས་ཉོན་མོངས་ཀྱི་ཕྱོགས་ཀྱིས་བསྡུས་པ་དང་། རྣམ་བྱང་གི་ཕྱོགས་ཀྱིས་བསྡུས་པ་དང་། ཕྱི་མ་ལ་ཡང་། གང་ཟག་གིས་བསྡུས་པ་དང་། ཤེས་རིག་གིས་བསྡུས་པ་གཉིས་ཡིན་ལ། དེ་རེ་རེ་ལ་ཡང་དམིགས་པའི་སྒོ་ནས་དགུ་དགུར་དབྱེའོ། །
Enumeration Block 20:
རྫས་འཛིན་ལ་གཉིས་ཏེ། གང་ཟག་དོན་བྱེད་ནུས་པར་འཛིན་པ་དང་། རང་སྐྱ་ཐུབ་པའི་རྫས་ཡོད་དུ་འཛིན་པའོ། །
Enumeration Block 21:
གཉིས་པ་ཡན་ལག་གི་དོན་ལ། སྤྱིའི་མཚམས་སྦྱར་བ་དང་། སོ་སོའི་དོན་བཤད་པ་དང་། དོན་བསྡུ་བའོ། །
Enumeration Block 22:
གཉིས་པ་ལ། བསྟན་པ་དང་། བཤད་པའོ། །དང་པོ་ལ། གཟུང་རྟོག་བཤད་པ་དང་། འཛིན་རྟོག་བཤད་པ་གཉིས་ཀྱི་དང་པོ་ལ། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 23:

འཇུག་པའི་སྒྲུབ་པ་རྣམ་པ་དགུ་པོ་དེ་ཡང་གཉིས་སུ་འདུས་ཏེ། རྒྱུ་ཐེག་པ་ཆེན་པོའི་ལམ་ལ་འཇུག་པ་དང་། དེའི་འབྲས་བུ་ལ་འཇུག་པ་གཉིས་སུ་ངེས་པའི་ཕྱིར། དང་པོ་ལ་གསུམ་ཡོད་དེ། རྟེན་ཐེག་ཆེན་གྱིས་བསྡུས་པའི་འཇིག་རྟེན་པའི་ལམ་བསམ་གཏན་ནས་གཟུགས་མེད་པའི་སྙོམས་པར་འཇུག་པ་ཉམས་སུ་ལེན་པའི་བྱ་བ་གཅིག་དང་། འཇིག་རྟེན་ལས་འདས་པའི་ལམ་ལ་འཇུག་པ་དང་། དེ་གཉིས་ཀ་ཐེག་དམན་ལས་འབྱེད་པའི་ཆོས་རྣམས་ཡོད་པའི་ཕྱིར།
བར་པ་ལ་བཞི་ཡོད་དེ། རང་དོན་རྟོགས་པ་ཕུན་ཚོགས་ཐོབ་བྱེད་སྦྱིན་པ་ལ་སོགས་པའི་ཕ་རོལ་ཏུ་ཕྱིན་པ་དྲུག་དང་། སྤངས་པ་ཕུན་ཚོགས་ཐོབ་བྱེད་མཐོང་བ་ལ་སོགས་པའི་ལམ་དང་གཞན་དོན་འགྲུབ་པའི་ཐབས་བྱམས་སོགས་ཚད་མེད་པ་བཞི་དང་། གཞན་དོན་རྣམ་པར་དག་བྱེད་སྟོང་ཉིད་རྟོགས་པའི་མི་དམིགས་པ་དང་ལྡན་པ་རྣམས་ཡོད་པའི་ཕྱིར། ཐེག་དམན་ལས་འབྱེད་པའི་ཆོས་གསུམ་ཡོད་དེ། ཕར་ཕྱིན་དྲུག་གི་དངོས་པོ་ཐམས་ཅད་ལ་ལས་བྱ་བྱེད་བདེན་པས་སྟོང་པར་རྟོགས་པའི་འཁོར་གསུམ་ཡོངས་སུ་དག་པ་དང་། དགེ་རྩ་བླ་མེད་བྱང་ཆུབ་ཏུ་བསྔོ་བའི་ཆེད་དུ་བྱ་བ་གསུམ་གྱི་དོན་དུ་བསྒྱུར་བ་དང་། ཚོགས་མྱུར་དུ་རྫོགས་པའི་ཐབས་མངོན་པར་ཤེས་པ་དྲུག་ལ་འཇུག་པ་དང་། འབྲས་བུ་ལ་འཇུག་པ་རྣམ་པ་ཐམས་ཅད་མཁྱེན་པ་ཉིད་དག་ལ་དམིགས་ནས་ཡང་དག་པར་གནས་པའི་མཚན་ཉིད་ཀྱི་ཉམས་ལེན་གྱི་བྱ་བ་རྣམས་ཡོད་པའི་ཕྱིར་རོ། །

Enumeration Block 1:
གསུམ་པ་ལ། སོ་སོའི་དོན་དང་། རྟོགས་དཀའ་བ་བྱེ་བྲག་ཏུ་བཤད་པའོ། །
Enumeration Block 2:
འཇུག་པའི་སྒྲུབ་པ་རྣམ་པ་དགུ་པོ་དེ་ཡང་གཉིས་སུ་འདུས་ཏེ། རྒྱུ་ཐེག་པ་ཆེན་པོའི་ལམ་ལ་འཇུག་པ་དང་། དེའི་འབྲས་བུ་ལ་འཇུག་པ་གཉིས་སུ་ངེས་པའི་ཕྱིར། དང་པོ་ལ་གསུམ་ཡོད་དེ། རྟེན་ཐེག་ཆེན་གྱིས་བསྡུས་པའི་འཇིག་རྟེན་པའི་ལམ་བསམ་གཏན་ནས་གཟུགས་མེད་པའི་སྙོམས་པར་འཇུག་པ་ཉམས་སུ་ལེན་པའི་བྱ་བ་གཅིག་དང་། འཇིག་རྟེན་ལས་འདས་པའི་ལམ་ལ་འཇུག་པ་དང་། དེ་གཉིས་ཀ་ཐེག་དམན་ལས་འབྱེད་པའི་ཆོས་རྣམས་ཡོད་པའི་ཕྱིར།
Enumeration Block 3:
བར་པ་ལ་བཞི་ཡོད་དེ། རང་དོན་རྟོགས་པ་ཕུན་ཚོགས་ཐོབ་བྱེད་སྦྱིན་པ་ལ་སོགས་པའི་ཕ་རོལ་ཏུ་ཕྱིན་པ་དྲུག་དང་། སྤངས་པ་ཕུན་ཚོགས་ཐོབ་བྱེད་མཐོང་བ་ལ་སོགས་པའི་ལམ་དང་གཞན་དོན་འགྲུབ་པའི་ཐབས་བྱམས་སོགས་ཚད་མེད་པ་བཞི་དང་། གཞན་དོན་རྣམ་པར་དག་བྱེད་སྟོང་ཉིད་རྟོགས་པའི་མི་དམིགས་པ་དང་ལྡན་པ་རྣམས་ཡོད་པའི་ཕྱིར། ཐེག་དམན་ལས་འབྱེད་པའི་ཆོས་གསུམ་ཡོད་དེ། ཕར་ཕྱིན་དྲུག་གི་དངོས་པོ་ཐམས་ཅད་ལ་ལས་བྱ་བྱེད་བདེན་པས་སྟོང་པར་རྟོགས་པའི་འཁོར་གསུམ་ཡོངས་སུ་དག་པ་དང་། དགེ་རྩ་བླ་མེད་བྱང་ཆུབ་ཏུ་བསྔོ་བའི་ཆེད་དུ་བྱ་བ་གསུམ་གྱི་དོན་དུ་བསྒྱུར་བ་དང་། ཚོགས་མྱུར་དུ་རྫོགས་པའི་ཐབས་མངོན་པར་ཤེས་པ་དྲུག་ལ་འཇུག་པ་དང་། འབྲས་བུ་ལ་འཇུག་པ་རྣམ་པ་ཐམས་ཅད་མཁྱེན་པ་ཉིད་དག་ལ་དམིགས་ནས་ཡང་དག་པར་གནས་པའི་མཚན་ཉིད་ཀྱི་ཉམས་ལེན་གྱི་བྱ་བ་རྣམས་ཡོད་པའི་ཕྱིར་རོ། །
Enumeration Block 4:
གཉིས་པ་ནི། བསམ་གཏན་དང་གཟུགས་མེད་བཤད་པ་ལ། རྒྱུ་ངོ་བོ་འབྲས་བུའོ། །
Enumeration Block 5:
གཉིས་པ་ལ། དངོས་ཀྱི་དོན་དང་། དབྱེ་བ་དང་། ཕྱེ་བ་སོ་སོའི་དོན་ནོ། །དང་པོ་ལ། བསམ་གཏན་དང་གཟུགས་མེད་གཉིས་ཀྱི་དང་པོ་བསམ་གཏན་ལ་རྒྱུ་སྙོམས་འཇུག་དང་འབྲས་བུ་སྐྱེ་བའི་བྱེ་བྲག་གིས་གཉིས་ཡིན་ལ།
Enumeration Block 6:
གཉིས་པ་ནི། བསམ་གཏན་ལ་དང་པོ་ནས་བཞི་པའི་བར་དང་། གཟུགས་མེད་ལ་ནམ་མཁའ་མཐའ་ཡས་སྐྱེ་མཆེད་སོགས་བཞིའོ། །
Enumeration Block 7:
བསམ་གཏན་བཞི་དང་གཟུགས་མེད་དང་པོ་གསུམ་ལ་ཉོན་མོངས་ཅན་དང་། དག་པ་བ་དང་། ཟག་མེད་གསུམ་གསུམ་ཡོད་ལ།
Enumeration Block 8:
གསུམ་པ་ནི། བསམ་གཏན་དང་པོ་ལ་དངོས་གཞི་ཙམ་དང་། ཁྱད་པར་ཅན་གཉིས་ཀྱི་དང་པོ་ནི།
Enumeration Block 9:
དེ་ཡང་ཉམས་པ་ཆ་མཐུན་དང་། གནས་པ་ཆ་མཐུན་དང་། ཁྱད་པར་ཆ་མཐུན་དང་། ངེས་འབྱེད་ཆ་མཐུན་བཞིའོ། །
Enumeration Block 10:
བསམ་གཏན་དང་པོ་ལ་ཡན་ལག་ལྔ་སྟེ་རྟོག་དཔྱོད་དང་། དབེན་པ་ལས་སྐྱེས་པའི་དགའ་བདེ་དང་། སེམས་རྩེ་གཅིག་པའོ། །གཉིས་པ་ལ་བཞི་སྟེ། ནང་རབ་ཏུ་དང་བ་དང་། ཏིང་ངེ་འཛིན་ལས་སྐྱེས་པའི་དགའ་བདེ་དང་། སེམས་རྩེ་གཅིག་པའོ། །གསུམ་པ་ལ་ལྔ་སྟེ། དྲན་ཤེས་བཞིན་བཏང་སྙོམས་དང་། བདེ་བ་དང་། སེམས་རྩེ་གཅིག་པའོ། །བཞི་པ་ལ་ཡན་ལག་བཞི་སྟེ། དྲན་པ་དང་བཏང་སྙོམས་ཡོངས་སུ་དག་པ་དང་། ཚོར་བ་བཏང་སྙོམས་དང་། སེམས་རྩེ་གཅིག་པའོ། །
Enumeration Block 11:
གསུམ་པ་ལ།སྤྱིར་བསྟན་པ་དང་། ཚོགས་གསུམ་བྱེ་བྲག་ཏུ་བཤད་པའོ། །དང་པོ་ལ། མཚམས་སྦྱར་བ་དང་། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 12:
གསུམ་པ་ལ། སོ་སོའི་ངོ་བོ་དང་། ཚོགས་སུ་འཇོག་པའི་རྒྱུ་མཚན་དང་། གྲངས་ངེས་སོ། །
Enumeration Block 13:

Enumeration Block 10:
ཟག་པ་མེད་པའི་སྒོམ་པའི་ལམ་དེ་ཡང་ཆོས་ཅན། རྣམ་པ་གཉིས་ཏེ། སྒྲུབ་པ་སྒོམ་ལམ་དང་། རྣམ་དག་སྒོམ་ལམ་གཉིས་ཡོད་པའི་ཕྱིར། གཉིས་པ་ལ། སྒྲུབ་པ་སྒོམ་ལམ་དང་། རྣམ་དག་སྒོམ་ལམ་མོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།

སྒྲུབ་པ་སྒོམ་ལམ་སོགས་ཆོས་ཀྱིས་ཕོངས་པའི་རྒྱུ་དག་ནི་བཞི་ཡོད་དེ།

གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།

གསུམ་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།

བཞི་པ་ལ། རྣམ་དག་ཤིན་ཏུ་བ་ཡིན་མིན་གྱི་ཁྱད་པར་དང་། སངས་རྒྱས་ཀྱི་རྣམ་དག་ཤིན་ཏུ་བར་བསྒྲུབ་པའོ། །དང་པོ་ལ་གཉིས་ཀྱི་དྲི་བ་ནི།

ལན་ལ་གཉིས་ཀྱི་དང་པོ་རྩ་བ་ནི།

གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 19:
གསུམ་པ་ལམ་ཤེས་རྣམ་པར་དག་བྱེད་ཀྱི་ཡན་ལག་གཞི་ཤེས་བཤད་པ་ལ། འབྲེལ་དགོད་པས་མཚམས་སྦྱར། ལེའུའི་གཞུང་བཤད་པ་དང་། སྐབས་བསྡུ་བའོ། །

གཉིས་པ་ལ། གཞི་ཤེས་ཀྱི་རང་བཞིན་དང་། མཁྱེན་པ་གསུམ་གྱི་མཇུག་བསྡུ་བའོ། །དང་པོ་ལ། ཉེ་རིང་གི་ལམ་བཤད་པ་དང་། གཞི་ཤེས་ཀྱི་སྦྱོར་བ་དང་། སྦྱོར་བ་སྒོམ་པའི་འབྲས་བུའོ། །དང་པོ་ལ། ལམ་ཉེ་རིང་གི་རྒྱུ་མཚན་དང་། རྒྱུ་མཚན་དེ་ཉིད་བསྒྲུབ་པ་དང་། མི་མཐུན་ཕྱོགས་དང་གཉེན་པོའི་དབྱེ་བའོ། །དང་པོ་ལ། རྩ་བ་དང་། འགྲེལ་པའོ། །
Enumeration Block 21:
གཉིས་པ་འགྲེལ་པ་ལ་གཉིས།དངོས་བསྟན་སྲིད་ཞིའི་མཐའ་འགོག་བྱེད་ཀྱི་ལམ་དང་། ཤུགས་བསྟན་ཉན་རང་ལམ་དེ་དག་དང་བྲལ་བར་བསྟན་པའོ། །

Enumeration Block 24:
གསུམ་པ་ལ། གཞི་ལམ་ལ་མཚན་འཛིན་གྱི་སྤང་གཉེན་དང་། འབྲས་བུ་ལ་མཚན་འཛིན་གྱི་སྤང་གཉེན་དང་། མཇུག་བསྡུ་བའོ། །དང་པོ་ལ། སྤང་བྱ་དང་། གཉེན་པོའོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 25:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 26:
གཉིས་པ་ལ། འབྲས་བུ་ལ་མཚན་འཛིན་གྱི་ངོ་བོ་དང་། སྤོང་བྱེད་ཀྱི་གཉེན་པོ་དང་། འཕྲོས་དོན་ནོ། །དང་པོ་ལ་གཉིས་ཀྱི་དང་པོ་རྩ་བ་ནི།
Enumeration Block 27:
གཉིས་པ་ལ། མི་མཐུན་ཕྱོགས་ཡིན་པའི་རྒྱུ་མཚན་དང་། སྤོང་བྱེད་གཉེན་པོའོ། །དང་པོ་ལ་གཉིས་ཀྱི་དང་པོ་དྲི་བ་ནི། ཡང་ཇི་ལྟར། ཞེས་སོ། །ལན་ལ་གཉིས་ཀྱི་དང་པོ་རྩ་བ་ནི།
Enumeration Block 28:
གཉིས་པ་ལ་གཉིས་ཀྱི་དྲི་བ་ནི། འོ་ན། ཞེས་སོ། །ལན་ལ་གཉིས་ཀྱི་དང་པོ་རྩ་བ་ནི།
Enumeration Block 29:

Enumeration Block 6:
གཉིས་པ་རྒྱས་བཤད་ལ་གསུམ་གྱི་དང་པོ། ཉོན་སྒྲིབ་ཀྱི་གཉེན་པོ་ལ་བཞིར་དབྱེ་བ་ནི།
Enumeration Block 7:
གཉིས་པ་ལམ་ཤེས་ཀྱི་རྣམ་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 8:
གསུམ་པ་འགྲེལ་པ་ལ། སྤྱིར་བསྟན། སོ་སོར་བཤད། སྤྱིའི་དོན་བསྡུ་བའོ། །
Enumeration Block 9:
གཉིས་པ་ལ་བཞིའི་དང་པོ། ཀུན་འབྱུང་སྤང་གཉེན་གྱི་སྒོ་ནས་བསྟན་པ་ནི།
Enumeration Block 10:
གསུམ་པ་རྣམ་མཁྱེན་གྱི་རྣམ་པ་ལ། མདོར་བསྟན་པ། རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 11:
གཉིས་པ་ལ། ཉན་ཐོས་དང་རྗེས་སུ་མཐུན་པའི་གཞི་ཤེས་ཀྱི་རྣམ་པ་དང་། བྱང་ཆུབ་སེམས་དཔའ་ལ་ཡོད་པ་དང་རྗེས་སུ་མཐུན་པའི་ལམ་ཤེས་ཀྱི་རྣམ་པ་དང་། ཐུན་མོང་མ་ཡིན་པའི་རྣམ་མཁྱེན་གྱི་རྣམ་པའོ། །དང་པོ་ལ། སོ་སོར་བཤད་པ་དང་། དོན་བསྡུ་བའོ། །དང་པོ་ལ་བདུན་གྱི་དང་པོ་དྲན་པ་ཉེར་གཞག་ནི།
Enumeration Block 12:
གཉིས་པ་བྱང་ཆུབ་སེམས་དཔའི་ལམ་ཤེས་དང་རྗེས་སུ་མཐུན་པའི་རྣམ་པ་ལ། སོ་སོར་བཤད་པ་དང་། དོན་བསྡུ་བའོ། །དང་པོ་ལ་དྲུག་གི་དང་པོ།
Enumeration Block 13:
གཉིས་པ་སྤྲུལ་པའི་ལམ་ནི། སྤྲུལ་པའི་ལམ་ལ་རྣམ་པར་ཐར་པའི་སྒོ་རྣམ་པ་གསུམ་མོ། །
Enumeration Block 14:
གསུམ་པ་མཐོང་ཆོས་བདེ་གནས་ཀྱི་ལམ་ནི། མཐོང་བའི་ཆོས་ཚེ་འདི་ལ་ལུས་སེམས་བདེ་བར་གནས་པའི་ལམ་ལ་རྣམ་པ་ལྔའོ། །
Enumeration Block 15:
བཞི་པ་འཇིག་རྟེན་ལས་འདས་པའི་ལམ་ནི།འཇིག་རྟེན་ལས་འདས་པའི་ལམ་ལ་མཐར་གྱིས་གནས་པའི་སྙོམས་པར་འཇུག་པ་དགུའོ། །
Enumeration Block 16:
ལྔ་པ་སྤོང་བའི་ལམ་ནི། སྤོང་བའི་ལམ་ལ་རྣམ་པ་བཞིའོ། །
Enumeration Block 17:
དྲུག་པ་སངས་རྒྱས་ཀྱི་ལམ་ནི་སངས་རྒྱས་ཉིད་ཀྱི་ལམ་ལ་བཅུ་སྟེ།
Enumeration Block 18:
གསུམ་པ་རྣམ་མཁྱེན་གྱི་རྣམ་པ་ལ། མདོར་བསྟན་པ། རྒྱས་པར་བཤད་པ། དོན་བསྡུ་བའོ། །དང་པོ་ནི།
Enumeration Block 19:
གཉིས་པ་ལ། ཡོན་ཏན་གྱི་དབྱེ་བ་དང་། ངོ་བོ་དང་། རྟེན་དང་། ཆེད་དུ་བྱ་བའོ། །དང་པོ་ལ་བཞིའི་དང་པོ། སྟོབས་བཅུ་ནི།
Enumeration Block 20:
བཞི་པ་སངས་རྒྱས་ཀྱི་ཆོས་མ་འདྲེས་པ་བཅོ་བརྒྱད་ནི། དེ་ལྟར་སངས་རྒྱས་ཀྱི་ཆོས་རྟེན་འོག་མ་རྣམས་དང་མ་འདྲེས་པ་བཅོ་བརྒྱད་ཀྱི་རྣམ་པ་དག་ནི་སྤྱོད་པས་བསྡུས་པ་དྲུག་དང་རྟོགས་པས་བསྡུས་པ་དྲུག་དང་། འཕྲིན་ལས་ཀྱིས་བསྡུས་པ་གསུམ་དང་། ཡེ་ཤེས་ཀྱིས་བསྡུས་པ་གསུམ་སྟེ་བཅོ་བརྒྱད་དོ། །
Enumeration Block 21:
གསུམ་པ་དོན་བསྡུ་བ་ལ་གཉིས་ཀྱི་དང་པོ་ངོ་བོའི་དོན་བསྡུ་བ་ནི།

Enumeration Block 1:
གཉིས་པ་ལ། ཡོན་ཏན་གྱི་དབྱེ་བ་དང་། ངོ་བོ་དང་། རྟེན་དང་། ཆེད་དུ་བྱ་བའོ། །དང་པོ་ལ་བཞིའི་དང་པོ།
Enumeration Block 2:
མི་འཇིགས་པའི་རྣམ་པ་བཞི་ཡོད་དེ།
Enumeration Block 3:
སོ་སོ་ཡང་དག་པར་རིག་པའི་རྣམ་པ་བཞི་ཡོད་དེ། བཤད་བྱ་ལ་ཐོགས་པ་མེད་པ་དང་པོ་གཉིས་དང་། འཆད་བྱེད་ལ་ཐོགས་པ་མེད་པ་ཕྱི་མ་གཉིས་ཡོད་པའི་ཕྱིར།
Enumeration Block 4:
སངས་རྒྱས་ཀྱི་ཆོས་རྟེན་འོག་མ་རྣམས་དང་མ་འདྲེས་པ་བཅོ་བརྒྱད་ཀྱི་རྣམ་པ་དག་ནི་སྤྱོད་པས་བསྡུས་པ་དྲུག་དང་རྟོགས་པས་བསྡུས་པ་དྲུག་དང་། འཕྲིན་ལས་ཀྱིས་བསྡུས་པ་གསུམ་དང་། ཡེ་ཤེས་ཀྱིས་བསྡུས་པ་གསུམ་སྟེ་བཅོ་བརྒྱད་དོ། །
Enumeration Block 5:
གསུམ་པ་དོན་བསྡུ་བ་ལ་གཉིས་ཀྱི་དང་པོ་ངོ་བོའི་དོན་བསྡུ་བ་ནི།
Enumeration Block 6:
གཉིས་པ་བདེན་འཛིན་དངོས་སུ་འཇོམས་བྱེད་ཀྱི་སྦྱོར་བ་ཁྱད་པར་ཅན་ངོས་བཟུང་བ་ལ། དགེ་བའི་རྩ་བ་གསོག་པའི་རྟེན་དང་། སྦྱོར་བ་དངོས་སོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 7:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 8:
གཉིས་པ་རྩ་བ་ནི། སྦྱོར་བ་རང་གི་ངོ་བོ་དང་། རྟེན་གྱི་གང་ཟག་གི་སྒོ་ནས་དབྱེ་བ་དང་། སྦྱོར་བ་རྫོགས་པའི་ཐབས་ཀྱི་སྒོ་ནས་དབྱེ་བ་དང་། འབྲས་བུ་དང་དུས་ཀྱི་སྒོ་ནས་བཞག་པའོ། །
Enumeration Block 9:
སྦྱོར་བ་པོའི་སྒོ་ནས་དབྱེ་བ་ནི་བརྒྱད་དེ།
Enumeration Block 10:
གཉིས་པ་སྦྱོར་བ་སྒོམ་པའི་སྐྱོན་ཡོན་ལ། སྦྱོར་བའི་ཡོན་ཏན་དང་། སྦྱོར་བ་སྒོམ་པའི་གེགས་སོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 11:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 12:
སྦྱོར་བ་སྐྱེ་བའི་གེགས་དང་། རྒྱུན་གནས་པའི་གེགས་སྐྱོན་ནི་བཅུ་ཚན་བཞི་དང༌བཅས་པ་དྲུག་ཏུ་ངེས་པར་རྟོགས་པར་བྱའོ། །གསུམ་པ་འགྲེལ་པ་ལ། སོ་སོར་བཤད་པ་དང་། གྲངས་བསྡུ་བའོ། །དང་པོ་ལ། སྦྱོར་བའི་འགལ་རྐྱེན་རང་ལ་བརྟེན་པ་ཉི་ཤུ། རང་གཞན་གང་རུང་ལ་བརྟེན་པ་མཐུན་རྐྱེན་མ་ཚང་བ་ཉེར་གསུམ། འགལ་རྐྱེན་གཞན་ལ་བརྟེན་པ་གསུམ་མོ། །དང་པོ་ལ་སྤོབས་པའི་དབང་དུ་བྱས་པ་གཉིས་ནི།
Enumeration Block 13:
གཉིས་པ་ལ། སློབ་དཔོན་ལ་བརྟེན་པ། རང་ཉིད་ལ་བརྟེན་པ། གཉིས་ཀ་ལ་བརྟེན་པའོ། །
Enumeration Block 14:

Enumeration Block 5:
གསུམ་པ་དེ་ལ་བརྟེན་ནས་མངོན་རྟོགས་ཁྱད་པར་ཅན་རྒྱུད་ལ་སྐྱེ་བའི་རིམ་པ་བཤད་པ་ལ། བླ་ན་མེད་པའི་བྱང་ཆུབ་ལས་ཕྱིར་མི་ལྡོག་པའི་རྟགས་བཤད་པ་དང་། སྐུ་གསུམ་སྒྲུབ་བྱེད་ཀྱི་ལམ་ཁྱད་པར་ཅན་བཤད་པའོ། །

གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།

Enumeration Block 24:

Enumeration Block 25:

Enumeration Block 28:

གཉིས་པ་མཛད་པ་འཕྲིན་ལས་ལ། དངོས་ཀྱི་དོན་དང་། ཚིག་དོན་གཞན་གྱི་གོ་རིམས་ཀྱང་དོན་བདུན་ཅུའི་དང་པོ་དང་ཐ་མ་ལ་བརྟེན་ནས་རིག་པར་བྱ་བའོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ལ། སྐུ་གསུམ་བཤད་ཟིན་པར་བསྟན་པ་དང་། འཕྲིན་ལས་འཆད་པར་བསྟན་པའོ། །

Enumeration Block 1:
དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ལ། སྐུ་གསུམ་བཤད་ཟིན་པར་བསྟན་པ་དང་། འཕྲིན་ལས་འཆད་པར་བསྟན་པའོ། །
Enumeration Block 2:
གཉིས་པ་རྩ་བ་ལ་གསུམ་གྱི་དང་པོ་དུས་ཀྱི་སྒོ་ནས་མདོར་བསྟན་པ་ནི།
Enumeration Block 3:
གཉིས་པ་དབྱེ་བའི་སྒོ་ནས་རྒྱས་པར་བཤད་པ་ལ། ལམ་ལ་འགོད་པ་དང་། ལམ་གྱི་འབྲས་བུ་ལ་འགོད་པའོ། །དང་པོ་ལ། ཚོགས་ལམ་དང་། སྦྱོར་ལམ་དང་། མཐོང་ལམ་དང་། སྒོམ་ལམ་ལ་འགོད་པའོ། །
Enumeration Block 4:
དང་པོ་ལ། བསམ་པ་ཕུན་ཚོགས་ལ་འགོད་པ་དང་། གཞན་རྒྱུད་སྨིན་བྱེད་ཀྱི་སྦྱོར་བ་དང་། བདེན་བཞི་རྟོགས་པའི་ལྟ་བ་ལ་འགོད་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ། བསམ་པ་ཕུན་ཚོགས་དང་། རང་རྒྱུད་སྨིན་བྱེད་ཀྱི་སྦྱོར་བ་དང་། ལྟ་བ་རྣམ་དག་ལ་འགོད་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ། དངོས་དང་། གཉིས་དོན་གྱི་སྤྱོད་པ་ལ་འགོད་པའོ། །
Enumeration Block 7:
བཞི་པ་ལ་དྲུག །ས་དྲི་མ་མེད་པ་སོགས་གཉིས་ལ་འགོད་པ་དང་། ས་བཞི་པ་སོགས་གསུམ་ལ་འགོད་པ་དང་། བདུན་པ་ལ་འགོད་པ་དང་། བརྒྱད་པ་ལ་འགོད་པ་དང་། དགུ་པ་ལ་འགོད་པ་དང་། བཅུ་པ་ལ་འགོད་པའོ། །
Enumeration Block 8:
བཞི་པ་ལ་ལམ་གསུམ་ཤེས་པའི་ལམ་ཤེས་ལ་འགོད་པ་དང་། བདེན་འཛིན་ཞི་བ་དང་། སངས་རྒྱས་དཀོན་མཆོག་བཏགས་པ་བ་ཐོབ་པ་དང་། ཞིང་དག་པའི་སྦྱོར་བ་ལ་འགོད་པའོ། །
Enumeration Block 9:
ལྔ་པ་ལ། རང་སངས་རྒྱ་བར་ངེས་པ་དང་། གཞན་སྨིན་པར་བྱེད་པ་ལ་འགོད་པའོ། །
Enumeration Block 10:
དྲུག་པ་ལ། ས་བཅུ་པས་བསྡུས་པའི་བཤེས་གཉེན་བསྟེན་པ་དང་། རྟོགས་པ་གོང་དུ་འཕེལ་བ་ལ་འགོད་པའོ། །
Enumeration Block 11:
གཉིས་པ་ལ་བརྒྱད་ཀྱི་དང་པོ་བྱང་ཆུབ་ཀྱི་ཡན་ལག་ཐོབ་པ་ལ་འགོད་པ་ནི།
Enumeration Block 12:
གསུམ་པ་འགྲེལ་པ་ལ། སོ་སོར་བཤད་པ་དང་། དོན་བསྡུ་བའོ། །དང་པོ་ལ། ལམ་ལ་འགོད་པ་དང་། ལམ་གྱི་འབྲས་བུ་ལ་འགོད་པའོ། །དང་པོ་ལ། ཚོགས་ལམ་དང་། སྦྱོར་ལམ་དང་། མཐོང་ལམ་དང་། སྒོམ་ལམ་ལ་འགོད་པའོ། །
Enumeration Block 13:
དང་པོ་ལ་དྲུག་གི་དང་པོ་སྐྱེས་བུ་འབྲིང་གི་བསམ་པ་ཐར་པ་དོན་གཉེར་ལ་འགོད་པ་ནི།
Enumeration Block 14:
བཞི་པ་སྒོམ་ལམ་ལ་འགོད་པ་ལ་དྲུག་གི་དང་པོ། ས་གཉིས་པ་ནས་ལྔ་པའི་བར་ལ་འགོད་པ་ནི།
Enumeration Block 15:
བཞི་པ་ས་བརྒྱད་པ་ལ་འགོད་པ་ལ། སྤྱོད་པ་ཁྱད་པར་ཅན་ལ་འགོད་པ་དང་། བདེན་འཛིན་མངོན་གྱུར་ཟད་པ་ལ་འགོད་པའོ། །
Enumeration Block 16:
དྲུག་པ་ལ། ས་བཅུ་པ་ཐོབ་མ་ཐག་པ་གང་ལ་འགོད་པ་དང། སྐྱེ་བ་གཅིག་གིས་ཐོགས་པ་དང། སྲིད་པ་ཐ་མ་པ་ལ་འགོད་པའོ། །
Enumeration Block 17:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་སྐྱེ་བ་ཕྱི་མ་ལ་སངས་རྒྱ་བར་ངེས་པ་ལ་འགོད་པ་ནི།
Enumeration Block 18:
གསུམ་པ་ལ། ནུས་པའི་ཁྱད་པར་དང་། རྟོགས་པའི་ཁྱད་པར་དང་། སྤངས་པའི་ཁྱད་པར་དང་། དག་པའི་རྒྱུ་ཚོགས་ཀྱི་ཁྱད་པར་ལ་འགོད་པའོ། །དང་པོ་ལ་བྱང་ཆུབ་འདྲེན་པར་བྱེད་པ་དང་། ལམ་ཆུད་མི་ཟ་བའི་ནུས་པའོ། །
Enumeration Block 19:
གཉིས་པ་ལ་ཇི་སྙེད་པ་རྟོགས་པ་དང་། ཇི་ལྟ་བ་རྟོགས་པ་ལ་འགོད་པའོ། །
Enumeration Block 20:
གསུམ་པ་ལ་ཕྱིན་ཅི་ལོག་ཟད་པ་དང་། དེའི་གཞི་ཟད་པ་ལ་འགོད་པའོ། །
Enumeration Block 21:
བཞི་པ་ལ་རང་བཞིན་རྣམ་དག་གི་ཆོས་སྐུའི་རྒྱུ་ཚོགས་ལ་འགོད་པ་དང་། གློ་བུར་དྲི་བྲལ་གྱི་རྒྱུ་ཚོགས་ལ་འགོད་པའོ། །
Enumeration Block 22:
གསུམ་པ་བསྡུས་དོན་གཞན་བསྟན་པ་ལ། དོན་དྲུག་ཏུ་བསྡུ་བ་དང་། དོན་གསུམ་དུ་བསྡུ་བའོ། །དང་པོ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 23:
རྒྱན་གྱི་དོན་བསྡུས་བརྒྱད་ལས་གཞན་ཏེ་རྣམ་པ་དྲུག་ཏུ་ཤེས་པར་བྱ་སྟེ། མཁྱེན་པ་གསུམ་གྱི་ངོ་བོར་གྱུར་པའི་མཚན་ཉིད་དང་། མཁྱེན་གསུམ་དེའི་ཉམས་སུ་ལེན་པའི་རྣམ་རྫོགས་སྦྱོར་བ་དང་། སྦྱོར་བ་དེ་རབ་ཏུ་གྱུར་པའི་རྩེ་མོ་དང་། མཁྱེན་གསུམ་དེའི་ཉམས་ལེན་གྱི་གོ་རིམས་མཐར་གྱིས་པ་དང་། མཁྱེན་གསུམ་དེའི་སྦྱོར་བ་མཐར་ཐུག་པ་སྐད་ཅིག་མ་དང་། མཁྱེན་གསུམ་དེའི་རྣམ་སྨིན་ཆོས་སྐུ་དང་དྲུག་ནི།
Enumeration Block 24:
གསུམ་པ་འགྲེལ་པ་ལ། སོ་སོར་བཤད་པ་དང་། དོན་བསྡུས་ནས་ཚིག་དོན་རྒྱས་པ་སྔ་མ་ལ་ཁ་འཕང་བའོ། །
Enumeration Block 25:
གཉིས་པ་ལ་གསུམ་གྱི་དང་པོ་མཚམས་སྦྱར་བ་ནི།
Enumeration Block 26:
ཡུམ་གསུམ་གྱི་དོན་བསྡུས་པ་སྔ་མ་གཉིས་ལས་གཞན་ཏེ། ཡུལ་དང་རྒྱུ་དང་འབྲས་བུ་རྣམ་པ་གསུམ་མོ། །
Enumeration Block 27:
གསུམ་པ་བཤད་པ་མཐར་ཕྱིན་པའི་བྱ་བ་ལ་གསུམ། བཤད་བྱ་འཆད་བྱེད་ཀྱི་ཁྱད་པར་དང་། བརྩམས་པའི་དགེ་བ་བསྔོ་བ་དང་། ཁེངས་སྐྱུང་ཞིང་འགྲེལ་པ་རྩོམ་པ་སྤྲོ་བའི་རྒྱུ་མཚན་ནོ། །དང་པོ་ལ། བཤད་བྱའི་ཁྱད་པར་དང་། གང་ལ་བརྟེན་ནས་ཚུལ་ཇི་ལྟར་བཤད་པའོ། །
Enumeration Block 28:
