གཉིས་པ་ལ་གསུམ། རྩོད་པ། ལན། ལན་ལ་རྩོད་སྤང་ངོ༌། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 2:
གསུམ་པ་ལ་བཞི། རྟོག་པའི་ངོ་བོ། སྤང་བྱར་བསྟན་པ། དབྱེ་བ། འཁྲུལ་པར་སྒྲུབ་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། གཟུང་རྟོག་འཛིན་རྟོག་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། འཇུག་པ་དང་། ལྡོག་པ་གཟུང་རྟོག་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 4:
གསུམ་པ་ལ་གཉིས། རྟོག་པའི་ངོ་བོ་དང་། གཉེན་པོའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 6:
གསུམ་པ་ལ་གཉིས། སྤང་བྱ་རྟོག་པ། སྤོང་བྱེད་གཉེན་པོའོ། །
Enumeration Block 7:
འདི་ལ་བཞི། གང་གི་དང་། གང་མཇུག་ཏུ་འགྲོ་བ་དང་། གང་དུ་འགྲོ་བ་དང་། དེའི་རྒྱུ་མཚན་ནོ། །

Enumeration Block 1:
འདི་ལ་བཞི། གང་གི་དང་། གང་མཇུག་ཏུ་འགྲོ་བ་དང་། གང་དུ་འགྲོ་བ་དང་། དེའི་རྒྱུ་མཚན་ནོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། རྫས་འཛིན་དང་། བཏགས་འཛིན་རྟོག་པ་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 3:
དེ་ཡང་གཉིས་ཏེ། རྒྱུ་ཞེན་མེད་ཀྱི་ལམ་ལས་ཉམས་པ་དང་། འབྲས་བུ་རྣམ་མཁྱེན་མི་འཐོབ་པའོ། །
དང་པོ་ལ་གསུམ་སྟེ། སྤྱོད་པ་དང་། ཤེས་བྱ་དང་། སྤང་གཉེན་པའོ། །
དང་པོ་ལ་གསུམ་སྟེ། ཀུན་སློང་དང་། ངོ་བོ་དང་། ཉེས་དམིགས་སོ། །
གཉིས་པ་ལ་གསུམ་སྟེ། དང་པོར་དང་། རྒྱུན་དུ་དང་། ཐ་སྙད་དུ་ཞེན་པའོ། །
གསུམ་པ་ལ་གཉིས་ཏེ། སྤང་བྱ་དང་། གཉེན་པོ་ལ་ཞེན་པ་སྟེ་འཛིན་འདོར་སོགས་དང་རིམ་བཞིན་ནོ། །
Enumeration Block 4:
གསུམ་པ་ལ་གཉིས། སྤང་བྱ་རྟོག་པ། སྤོང་བྱེད་གཉེན་པོའོ། །
Enumeration Block 5:
ཡུལ་དེ་དག་སྤྱོད་པ་ལ་ལྟོས་པ་དང་། རྟོགས་པའི་དབང་དུ་བྱས་པའི་སྤང་གཉེན་གཉིས་སུ་འདུ་ལ།
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། གཉེན་པོ་དང་། སྤང་བྱའོ། །
གཉེན་པོ་ལ་བཞི། རྟོག་པའི་ངོ་བོ། ཡུལ་རྟོགས་ཚུལ། ལམ་ལ་སློབ་ཚུལ། དེ་དག་གི་ནུས་པ་སྟེ་དགུའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 8:
དེ་ཡང་གསུམ་དུ་འདུས་ཏེ། དོན་དུ་གཉེར་བྱ་མི་འཐོབ་པ་དང་། ཕྱིན་ཅི་ལོག་ཏུ་རྟོག་པས་ཟིན་པ་དང་། ཡང་དག་པའི་ལམ་དང་འགལ་བའོ། །
གཉིས་པ་ལ་གཉིས། ལམ་དང་ཤེས་བྱ་ལ་ཕྱིན་ཅི་ལོག་པའོ། །
དེ་ལ་གསུམ། དགག་སྒྲུབ་དང་ལྡན། མི་ལྡན་དང་། ངོ་བོ་ལ་དོན་དམ་དུ་ཞེན་པའོ། །
ལམ་དང་འགལ་བ་ལ་བཞི། ཐེག་ཆེན་གྱི་རིགས་དང་། རྫོགས་བྱང་དོན་གཉེར་དང་། རྣམ་མཁྱེན་གྱི་རྒྱུ་ཡུམ་དོར་བ་དང་། དོར་བ་དེ་དག་གི་ཉེས་དམིགས་ཏེ། ཆེད་བཞིན་སོགས་དང་གྲངས་བཞིན་ནོ། །
སློབ་དཔོན་ལྟར་ན་ཉན་རང་གི་ལམ་དང་བྱང་སེམས་ཀྱི་ལམ་དང་དེ་གཉིས་ཀའི་མི་མཐུན་ཕྱོགས་ཀྱི་དབང་དུ་བྱས་པ་སྟེ་གཉིས་དང་དྲུག་དང་གཅིག་རྣམས་རིམ་བཞིན་ནོ། །
Enumeration Block 9:
གསུམ་པ་ལ་གཉིས། སྤང་བྱ་རྣམ་རྟོག །སྤོང་བྱེད་གཉེན་པོའོ། །
Enumeration Block 10:
གཉིས་པ་ལ་གཉིས། ཞར་བྱུང་དང་། དཀྱུས་མའོ། །དང་པོ་ལ་གཉིས། མཐོང་རྩེའི་གྲོགས། དེའི་འབྲས་བུའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 11:
གཉིས་པ་ལ་གཉིས། གཞན་དང་། རང་གི་རྒྱུད་སྦྱོང་བའོ། །དང་པོ་ལ་གཉིས། རྟོགས་པའི་ཆོས་དང་། རྒྱུ་ལུང་གི་ཆོས་ལ་འགོད་པའོ། །
Enumeration Block 12:
གསུམ་པ་ལ་གསུམ་ལས།
