Enumeration Block 1:
འདི་ལ་གཉིས། སྐུ་དང་། མཛད་པའོ། །དང་པོ་ལ་བཞི། ངོ་བོ་ཉིད་དང་། ཡེ་ཤེས་དང་། ལོངས་སྤྱོད་རྫོགས་པ་དང་། སྤྲུལ་པའི་སྐུའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 2:
གསུམ་པ་ལ་བཞི། དོན་དངོས་དང་། ངེས་པའི་ཚིག །འཐོབ་པའི་ཚུལ།ཆོས་ཅན་གསུམ་དང་ཐ་དད་ཡིན་མིན་ནོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གསུམ། དངོས་ཀྱི་དོན། དེའི་ཁྱད་པར་བཤད། དེ་ལ་རྩོད་སྤང་ངོ༌། །དང་པོ་ལ་གསུམ། ཡེ་ཤེས་ཐ་དད་པའི་སྐུར་བསྟན།
ཐ་མི་དད་པར་འདོད་པ་དགག །ཐ་དད་པ་ལ་རྩོད་པ་སྤང་བའོ། །
དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 4:
གསུམ་པ་ལ་གཉིས། ཡོན་ཏན་སོ་སོར་བཤད་པ་དང་། བསྡོམས་ཏེ་སྐུར་བཞག་པའོ། །
Enumeration Block 5:
སྡེ་ཚན་ལྔ་པ་ཟད་པར་ལ་དགུ། ངོ་བོ། དབྱེ་བ། རྟེན། སྦྱོང་ཚུལ། མཚན་མ།
དེ་ཡིད་ལ་བྱེད་ཚུལ།བྱེད་ལས།
སྐྱེ་མཆེད་གཞན་ལ་ཟད་པར་མི་འཇོག་པའི་རྒྱུ་མཚན། ངེས་ཚིག་གོ །
Enumeration Block 6:
བཞི་པ་ལ་གཉིས། སྔར་སྦྱང་བ་བྱས་པས་འགྲུབ་ཚུལ་དང་། མ་བྱས་པས་སྦྱོང་ཚུལ་ལོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གཉིས། དམིགས་པ་རྟེན་དུ་བྱེད་པ་དང་། དེ་ལ་ཡིད་གཏོད་པའི་ཚུལ་ལོ། །
Enumeration Block 8:
ལྔ་པ་ལ་གཉིས། མ་གྲུབ་པའི་རྟགས་འཛིན་པའི་མཚན་མ། གྲུབ་པའི་རྟགས་སྣང་བའི་མཚན་མ་འཆར་ཚུལ་ལོ། །
