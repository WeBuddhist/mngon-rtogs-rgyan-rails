Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང་། དོན་བཤད་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། སྤང་བྱ་དང་། གཉེན་པོའོ། །དང་པོ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང་། དོན་བཤད་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ། མདོར་བསྟན། རྒྱས་པར་བཤད། གཉེན་པོ་མཚོན་ཚུལ་ལོ། །དང་པོ་ལ་གཉིས། གཟུང་རྟོག་དང་། འཛིན་རྟོག་མདོར་བསྟན་པའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 6:
གསུམ་པ་ལ་བཞི། རྟོག་པའི་ངོ་བོ། མི་མཐུན་ཕྱོགས་སུ་བསྟན་པ། དབྱེ་བ། འཁྲུལ་པར་སྒྲུབ་པའོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 7:

Enumeration Block 8:
གཉིས་པ་ལ་གཉིས། དངོས་ཀྱི་དོན་དང་། རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 9:
