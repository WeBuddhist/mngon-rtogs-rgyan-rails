Enumeration Block 1:
བཅུ་དྲུག་ཡོད་ཀྱང་གསུམ་དུ་འདུ་སྟེ་ཡུམ་ལ་བརྟེན་ནས་བདེ་བར་གནས་ཚུལ་དང་། དེ་དེའི་དྲིན་དུ་དང་། དེས་འཇིག་རྟེན་བསྟེན་ཚུལ་ཤེས་པ་སྟེ་དང་པོ་དང་དེ་ནས་ལྔ་དང་ལྷག་མ་རྣམས་རིམ་པ་ལྟར་རོ། །
གཉིས་པ་ལ་ཀུན་རྫོབ་དང་དོན་དམ་དུ་ཤེས་ཚུལ་གཉིས་ཏེ་བཞི་དང་གཅིག་རིམ་པ་ལྟར་རོ། །
གསུམ་པ་ལ་བདེན་གཉིས་དང་དུས་དང་ཡུལ་ཡུལ་ཅན་དང་དགག་བྱ་འགོག་ཚུལ་གྱི་དབང་དུ་བྱས་པའི་མཁྱེན་པ་བཞི་སྟེ། གཉིས་དང་བཞི་དང་གཉིས་དང་གཉིས་རྣམས་གྲངས་བཞིན་ནོ། །
Enumeration Block 2:
གསུམ་པ་ལ་གསུམ་ལས།
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། མཚམས་སྦྱར། དོན་བཤད་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ། ཁྱད་ཆོས་གྲངས་ཀྱི་སྒོ་ནས་མདོར་བསྟན། དེ་ཉིད་ངོ་བོའི་སྒོ་ནས་རྒྱས་པར་བཤད། དམན་ལམ་དངོས་སུ་མི་སྟོན་པའི་འཐད་པའོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 6:
འདི་ལ་བཞི། སྡུག་བསྔལ་དང་། ཀུན་འབྱུང་དང་། འགོག་པ་དང་། ལམ་གྱི་བདེན་པའི་སྐད་ཅིག་མའི་ཁྱད་པར་རོ། །
