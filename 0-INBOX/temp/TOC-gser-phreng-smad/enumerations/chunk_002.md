Enumeration Block 1:
བཤད་པ་ལ་གཉིས། གོ་རིམ་ལ་རྩོད་སྤངས། གོ་རིམ་ཅན་གྱི་རྣམ་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། གྲངས་ཀྱི་སྒོ་ནས་ཡོང་ས་མདོར་བསྟན། ངོ་བོའི་སྒོ་ནས་ཡོང་ཆོས་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་བཞི། ཀུན་བདེན་སྤང་གཉེན་དང་། ལམ་བདེན་དམ་བཅའ་དང་འཐད་པ་དང་། སྡུག་བདེན་རང་སྤྱིའི་མཚན་ཉིད་དང་། འགོག་བདེན་སྟོང་ཉིད་ཀྱི་སྒོ་ནས་བསྟན་པའོ། །
Enumeration Block 4:
འདི་ལ་ལྔ། དངོས། བཏགས་པ། བྱེད་པ་པོ། ཡུལ་དུ་འཁྲུལ་བ། ངོ་བོ་ཉིད་འགོག་པའོ། །
Enumeration Block 5:
གསུམ་པ་ལ་གསུམ་ལས།
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། དངོས་དང་། རྩོད་པ་སྤང་བའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གཉིས་ལས།
