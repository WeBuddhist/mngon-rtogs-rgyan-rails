Enumeration Block 1:
གཉིས་པ་ལ་གཉིས། གཉེན་པོའི་གྲངས་ངེས་དང་། བྱེད་པ་ལ་རྩོད་སྤང་ངོ༌། །དང་པོ་ལ་གཉིས། རྩོད་པ་དང་། ལན་ནོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས་ལས།
Enumeration Block 3:
འདི་ལ་གསུམ། གྲངས་མེད་སོགས་རྫས་ཐ་དད་དུ་མི་འགྲུབ། ལྡོག་པ་ཐ་དད་པར་བསྟན་པའི་དགོས་པ། དེས་ན་གྲངས་ངེས་མི་འཇིག་པར་བསྟན་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། རྩོད་པ་དང་། ལན་ནོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། ལན་དངོས་དང་། དེ་ལ་རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། སྣང་ཚོད་དུ་ཉམས་འཕེལ་བྱེད་པར་བསྟན། རང་བཞིན་ལ་ཉམས་འཕེལ་མེད་པར་བསྟན་པའོ། །
Enumeration Block 7:
འདི་ལ་གསུམ། ཀུན་རྫོབ་ཏུ་ཁྱབ་པ་མ་གྲུབ་པ། དོན་དམ་དུ་འདོད་པའི་ལན། དེ་གཉིས་ཀྱི་དོན་བསྡུ་བའོ། །དང་པོ་ལ་གཉིས། དཔེ་དགོད་པ་དང་། དོན་ལ་སྦྱར་བའོ། །
Enumeration Block 8:
གཉིས་པ་ལ་གཉིས། རྩོད་པ་དང་ལན་ནོ། །དང་པོ་ལ་གསུམ་ལས།
