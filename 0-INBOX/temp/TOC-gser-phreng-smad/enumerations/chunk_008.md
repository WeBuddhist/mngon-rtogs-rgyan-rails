Enumeration Block 1:
གསུམ་པ་གང་ལ་སྙོམས་པར་ཞུགས་ན། མཐོང་བའི་ཆོས་ཚེ་འདི་ལ་བདེ་བར་གནས་པ་སྟེ་ལུས་སེམས་ལ་ཕན་འདོགས་པའི་ལམ་ལ་རྣམ་པ་ལྔའོ། །
Enumeration Block 2:
འདི་ལ་གཉིས་ལས།
Enumeration Block 3:
བཞི་པ་འཇིག་རྟེན་ལས་འདས་པའི་ལམ་ལ་དགུའོ། །
གང་ན་བསམ་གཏན་བཞི་ནས་འགོག་པའི་སྙོམས་པར་འཇུག་པ་དག་སྟེ་དེ་དགུའོ། །
Enumeration Block 4:
འདིར་འགོག་སྙོམས་ཀྱི་མཐའ་བཅད་པ་ལ་བདུན། གང་ཟག་གང་གིས་དང་། སེམས་གང་ལ་བརྟེན་ནས་དང་། ཡིད་ལ་བྱེད་པ་གང་གིས་དང་། དགག་བྱ་གང་འགོག་པ་དང་། ངོ་བོ་དང་། དུས་དང་། ཁམས་གང་དུ་སྙོམས་པར་འཇུག་པའོ། །
Enumeration Block 5:
ལྔ་པ་ལ་གཉིས། འདོད་པ་དགོད། རྩོད་པ་སྤང་བའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། ཁས་བླངས་བརྗོད། དེ་དགག་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གཉིས། སྐུ་མཆེད་ཀྱི་དགོངས་པ་མིན་པར་བསྟན། དེ་ལས་ལོགས་སུ་འདོད་པ་མི་འཐད་པའོ། །
