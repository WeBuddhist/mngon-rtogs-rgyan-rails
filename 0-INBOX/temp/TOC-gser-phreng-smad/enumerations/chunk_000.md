Enumeration Block 1:
གཉིས་པ་འཇུག་པ་སྦྱོར་བཞིའི་ཡན་ལག་རྒྱས་པར་བཤད་པ་ལ་གཉིས། དབང་དུ་བྱ་བ་དང་། བརྟན་པ་རྒྱུ་འབྲས་ཀྱི་ཡན་ལག་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། དབང་དུ་བྱེད་པའི་རྒྱུ་རྣམ་ཀུན་དང་། དབང་དུ་བྱ་བའི་འབྲས་བུ་རྩེ་མོའི་ཡན་ལག་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གསུམ། འབྲེལ་བརྗོད་པས་མཚམས་སྦྱར། རྣམ་ཀུན་གྱི་ཆོས་རྒྱས་པར་བཤད། སྐབས་བསྡུ་བའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། སྦྱོར་བ་ཁྱད་པར་ཅན་རྒྱུད་ལ་བསྐྱེད་པ་དང་། སྦྱོར་བ་ཁྱད་པར་ཅན་རྒྱུད་ལ་སྐྱེས་པའི་སྒོམ་རིམ་མོ། །དང་པོ་ལ་བཞི། སྦྱར་ས་རྣམ་པ། སྦྱོར་བ་པོ་གང་ཟག །སྦྱོར་བ་རང་གི་ངོ་བོ། སྦྱོར་བའི་སྔོན་འགྲོའི་ཆོས་སོ། །དང་པོ་ལ་གསུམ། མདོར་བསྟན། རྒྱས་པར་བཤད། དོན་བསྡུ་བའོ། །དང་པོ་ལ་གཉིས། རྩ་བས་བསྟན། འགྲེལ་པས་བཤད་པའོ། །དང་པོ་ལ་གཉིས། ངོ་བོ་དང་། དབྱེ་བ་མདོར་བསྟན་པའོ། །
Enumeration Block 3:

Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། སྤྱི་དང་། ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ་བཞི། རྣམ་པའི་ངོས་འཛིན། མདོ་ནས་གསུངས་ཚུལ། བསྟན་བཅོས་སུ་བསྡུས་ཚུལ། ཇི་ལྟར་སྒོམ་ཚུལ་ལོ། །
Enumeration Block 5:
རྟོགས་བྱ་བདེན་བཞི་དང་རྟོགས་པ་པོ་མཁྱེན་གསུམ་ལ་ཡོད་པའི་ཆོས་ཀྱི་ཁྱད་པར་གཉིས་ཏེ། ལས་དང་བྱེད་པའི་རྣམ་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང་། དོན་བཤད་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གསུམ། གཞི་ཤེས་དང་། ལམ་ཤེས་དང་། རྣམ་མཁྱེན་གྱི་རྣམ་པ་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་བཞི། སྦྱར་བསྟན་བཤད་དོན་བསྡུ་བའོ། །
