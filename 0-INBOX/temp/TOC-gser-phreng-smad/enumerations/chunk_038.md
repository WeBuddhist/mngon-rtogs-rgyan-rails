Enumeration Block 1:
གཉིས་པ་ལ་གཉིས། དངོས་པོར་སྨྲ་བའི་ལུགས་དགག །སྟོང་པར་སྨྲ་བའི་ལུགས་བཞག་པའོ། །དང་པོ་ལ་གཉིས། ཁྱབ་བྱེད་མ་དམིགས་པ་དང་། ཁས་བླངས་ནང་འགལ་གྱིས་དགག་པའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 2:
གཉིས་པ་ལ་གསུམ། རྩ་བའི་དོན་བླངས་ཏེ་བཤད་བྱ་དགོད། རྩ་བའི་དོན་མདོ་ཙམ་དུ་བསྟན། དེ་ཉིད་ཕྱི་འགྲེལ་གྱིས་རྒྱས་པར་བཤད་པའོ། །
Enumeration Block 3:
གསུམ་པ་ལ་གཉིས། ཁས་བླངས་འགལ་བའི་རྒྱུ་མཚན། ཁས་བླངས་འགལ་བ་དངོས་སོ། །དང་པོ་ལ་གཉིས། གཞུང་གི་འབྲེལ་བསམ། ཚིག་གི་དོན་བཤད་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། དབུ་མའི་ལྟ་བས་སྒྲིབ་པ་རྫོགས་པར་སྤང་ནུས་པ་དང་། དངོས་སྨྲའི་ལྟ་བས་སྒྲིབ་པ་རྫོགས་པར་སྤང་མི་ནུས་པར་བསྟན་པའོ། །
Enumeration Block 5:
རང་ལུགས་ཀྱིས་སྒྲིབ་པ་སྤོང་ཚུལ་ལ་གཉིས། ཉོན་སྒྲིབ་དང་། ཤེས་སྒྲིབ་སྤོང་ཚུལ་ལོ། །དང་པོ་ལ་གསུམ། ཆོས་རྣམས་བདག་མེད་དུ་གཏན་ལ་དབབ། དེ་སྒོམ་པའི་ཚུལ། བསྒོམས་པས་བདག་ལྟ་སྤོང་ཚུལ་ལོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གསུམ། གཟུང་བ་དང་། འཛིན་པ་དང་། གཉིས་མེད་ལ་ཞེན་པའི་ཤེས་སྒྲིབ་སྤོང་ཚུལ་ལོ། །དང་པོ་ལ་གསུམ། གཟུང་བ་བདེན་མེད་དུ་གཏན་ལ་དབབ། དེ་ཇི་ལྟར་ཉམས་སུ་ལེན་ཚུལ། ཉམས་སུ་བླངས་པས་གཟུང་རྟོག་སྤོང་ཚུལ་ལོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གསུམ། འཛིན་པ་བདེན་མེད་དུ་གཏན་ལ་དབབ། དེ་རྟོགས་ཏེ་སྒོམ་ཚུལ། བསྒོམས་པས་འཛིན་རྟོག་སྤོང་ཚུལ་ལོ། །
Enumeration Block 8:
གསུམ་པ་ལ་གསུམ། རང་རིག་བདེན་མེད་དུ་གཏན་ལ་དབབ། དེ་རྟོགས་པས་སྒོམ་ཚུལ། བསྒོམས་པས་དེ་ལ་ཞེན་པ་ལྡོག་ཚུལ་ལོ། །
