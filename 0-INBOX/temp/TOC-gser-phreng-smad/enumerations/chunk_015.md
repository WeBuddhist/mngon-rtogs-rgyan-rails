Enumeration Block 1:
ཤེས་པ་དང་ཁྱད་པར་དང་བྱེད་པའི་མཚན་ཉིད་དེ་གསུམ་དང་། ལས་སུ་སྒྲུབ་པ་བཟུང་ཞིང་དེའི་དབང་དུ་བྱས་ནས་ངོ་བོ་ཉིད་དང་མཚན་ཉིད་གཞི་མཐུན་པས་ངོ་བོ་ཉིད་ཀྱི་མཚན་ཉིད་གཅིག་སྟེ་རྣམ་པ་བཞིར་རོ། །
Enumeration Block 2:
གཉིས་པ་ལ་བཞི། ཤེས་པ། ཁྱད་པར། བྱེད་པ། ངོ་བོ་ཉིད་ཀྱི་མཚན་ཉིད་དོ། །དང་པོ་ལ་གསུམ། གཞི་ཤེས། ལམ་ཤེས། རྣམ་མཁྱེན་གྱི་མཚན་ཉིད་དོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 3:
དེ་དག་ཀྱང་གཉིས་སུ་འདུ་སྟེ། རྟོགས་པ་པོ་དེ་བཞིན་གཤེགས་པ་སྐྱེད་པའི་ཚུལ་དང་དེས་ཇི་ལྟར་རྟོགས་ཚུལ་ཤེས་པ་སྟེ་དང་པོ་དང་ལྷག་མ་རིམ་བཞིན་ནོ། །
གཉིས་པ་ཡང་གསུམ་སྟེ། འཇིག་རྟེན་དང་སེམས་ཀྱི་སྤྱོད་པ་དང་དེ་བཞིན་ཉིད་མཁྱེན་པ་སྟེ་གཉིས་པ་དང་། དེ་ནས་བཅུ་པའི་བར་དང་ཐ་མ་གཉིས་དང་རིམ་པ་ལྟར་རོ། །
Enumeration Block 4:
འདིའི་མཐའ་དཔྱད་པ་ལ་བཞི། ལྟ་བའི་ངོ་བོ། སེམས་བཞི་དགག་སྒྲུབ་གཉིས་དང་སྦྱོར་ཚུལ། གང་ཟག་གང་གི་ཡིན་པ། སྒྲ་བཤད་པའོ། །
Enumeration Block 5:
སྔོན་གྱི་མཐའ་ལ་བརྟེན་པ་བཞི། ཕྱི་མའི་མཐའ་ལ་བརྟེན་པ་བཞི། མྱ་ངན་ལས་འདས་པ་ལ་བརྟེན་པ་བཞི་སྟེ་བཅུ་གཉིས་དང་། ལུས་སྲོག་གཅིག་ཏུ་ལྟ་བ་དང་དེ་གཉིས་ཐ་དད་དུ་ལྟ་བ་སྟེ་བཅུ་བཞིའོ། །
