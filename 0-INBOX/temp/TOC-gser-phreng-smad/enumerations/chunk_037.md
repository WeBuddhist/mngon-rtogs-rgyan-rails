Enumeration Block 1:
གཉིས་པ་ལ་གཉིས། གཞན་དང་། རང་གི་རྒྱུད་སྦྱོང་བའོ། །དང་པོ་ལ་གཉིས། རྟོགས་པའི་ཆོས་དང་། རྒྱུ་ལུང་གི་ཆོས་ལ་འགོད་པའོ། །
Enumeration Block 2:
གསུམ་པ་ལ་གསུམ་ལས།
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། དོན་ལ་གནས་པའི་བྱང་ཆེན་བསྟན། རྟོག་པས་བཏགས་པའི་བྱང་ཆེན་དགག་པའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 4:
གསུམ་པ་ལ་གཉིས། རྟགས་དགོད་པ་དང་། ཕྱོགས་ཆོས་སྒྲུབ་པའོ། །
Enumeration Block 5:
འདི་ལ་གཉིས། ལུང་དང་། རིགས་པས་སྒྲུབ་པའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས།
དངོས་པོར་སྨྲ་བའི་ལུགས་དགག །སྟོང་པར་སྨྲ་བའི་ལུགས་བཞག་པའོ། །
དང་པོ་ལ་གཉིས། ཁྱབ་བྱེད་མ་དམིགས་པ་དང་། ཁས་བླངས་ནང་འགལ་གྱིས་དགག་པའོ། །དང་པོ་ལ་གསུམ་ལས།
