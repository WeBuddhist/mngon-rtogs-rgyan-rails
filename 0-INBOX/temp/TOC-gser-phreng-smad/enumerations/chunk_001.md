Enumeration Block 1:
གཉིས་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང་། དོན་བཤད་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གསུམ། གཞི་ཤེས་དང་། ལམ་ཤེས་དང་། རྣམ་མཁྱེན་གྱི་རྣམ་པ་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་བཞི། སྦྱར་བསྟན་བཤད་དོན་བསྡུ་བའོ། །
Enumeration Block 3:
གསུམ་པ་ལ་གཉིས། བདེན་པ་དང་པོ་གསུམ་དང་། ལམ་གྱི་བདེན་པའི་རྣམ་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ། རྟེན་ལམ་དང་། བརྟེན་པ་རྣམ་པའི་རབ་དབྱེ། གྲངས་ཀྱིས་དོན་བསྡུ་བའོ། །དང་པོ་ལ་གཉིས། དབྱེ་བ་དངོས་དང་། མཐའ་དཔྱད་པའོ། །
Enumeration Block 5:
དབྱེ་ངོ་ནི་རྣམ་པ་གསུམ་མོ། །
Enumeration Block 6:
དང་པོ་བཞི་ཉོན་སྒྲིབ་དང་ལྷག་མ་བཅུ་གཅིག་ཤེས་སྒྲིབ་ཀྱི་གཉེན་པོར་འཇོག་པ་དང་། ཤེས་སྒྲིབ་ཀྱི་གཉེན་པོ་ལ་དང་པོ་ལྔ་ཟག་བཅས་དང་ཐ་མ་དྲུག་ཟག་མེད་དུ་འཇོག་པ་དང་། དེ་ཡང་རིམ་པ་ལྟར་སྒོམ་ལམ་དང་མཐོང་ལམ་ལ་འཇོག་པ་དང་། ཉོན་སྒྲིབ་ཀྱི་གཉེན་པོ་ལ་མ་ཕྱེ་བར་ཤེས་སྒྲིབ་ཀྱི་གཉེན་པོ་ལ་གཉིས་སུ་ཕྱེ་བའི་རྒྱུ་མཚན་དང་། ལམ་གསུམ་པོ་དེའི་རྟེན་དང་རང་གི་ངོ་བོ་དཔྱད་པ་སྟེ་ལྔས་རིག་པར་བྱའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གསུམ། བཞི་དང་། ལྔ་དང་། དྲུག་ཏུ་དབྱེ་བའོ། །
Enumeration Block 8:
གཉིས་པ་ལ་བཞི་ལས།
Enumeration Block 9:
བཤད་པ་ལ་གཉིས། གོ་རིམ་ལ་རྩོད་སྤངས། གོ་རིམ་ཅན་གྱི་རྣམ་པའོ། །
