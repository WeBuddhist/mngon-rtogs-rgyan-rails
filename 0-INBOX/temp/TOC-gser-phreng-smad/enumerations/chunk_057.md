Enumeration Block 1:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 2:
གསུམ་པ་ལ་གཉིས། ཆོས་སྐུ་ཁྱབ་པ་དང་། རྟག་པ་གཉིས་ཀ་ལ་རྩོད་སྤང་ངོ༌། །དང་པོ་ལ་གཉིས། རྩོད་པས་མཚམས་སྦྱར། ལན་གྱིས་དོན་བཤད་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། དོན་དངོས་དང་། དེ་དཔེས་སྒྲུབ་པའོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། རྩ་བའི་དོན་དཀྲོལ། དེས་གྲུབ་པའི་ལན་ནོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། རྩོད་པས་མཚམས་སྦྱར།ལན་གྱིས་དོན་བཤད་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གཉིས་ལས།
Enumeration Block 8:
གསུམ་པ་ལ་གཉིས། རང་བཞིན་མདོར་བསྟན། ཡོན་ཏན་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གསུམ་ལས།
