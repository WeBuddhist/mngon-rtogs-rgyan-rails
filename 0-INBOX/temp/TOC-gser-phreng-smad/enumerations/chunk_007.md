Enumeration Block 1:
གཉིས་པ་ལམ་ཤེས་པ་ཉིད་ཀྱི་རྣམ་པ་སྟོན་པ་ལ་གཉིས། སོ་སོར་བཤད་པ་དང་། དོན་བསྡུ་བའོ། །དང་པོ་ལ་དྲུག །གཉེན་པོ་དང་། སྤྲུལ་པ་དང་། མཐོང་ཆོས་ལ་བདེར་གནས་དང་། འཇིག་རྟེན་ལས་འདས་པ་དང་། སྤོང་བ་དང་། སངས་རྒྱས་ཀྱི་ལམ་མོ། །དང་པོ་ནི། གཉེན་པོའི་ལམ་ལ་རྣམ་པར་ཐར་པའི་སྒོ་གསུམ་གྱི་རྣམ་པ་གསུམ་མོ། །
Enumeration Block 2:
གཉིས་པ་ནི། སྤྲུལ་པ་སྒྲུབ་པའི་ལམ་ལ་རྣམ་པར་ཐར་པ་རྣམ་པ་གསུམ་མོ། །
Enumeration Block 3:
འདི་ལ་གསུམ་ལས།
Enumeration Block 4:
འདི་ལ་དྲུག །རྟེན་གང་གིས། ས་གང་ལ་བརྟེན་ནས། ཡུལ་གང་ལ། ཚུལ་ཇི་ལྟར། ངེས་ཚིག །དགོས་པ་གང་གི་ཕྱིར་ལྟ་བའོ། །
Enumeration Block 5:
འདི་ལ་བཞི་ལས།
Enumeration Block 6:
གསུམ་པ་གང་ལ་སྙོམས་པར་ཞུགས་ན། མཐོང་བའི་ཆོས་ཚེ་འདི་ལ་བདེ་བར་གནས་པ་སྟེ་ལུས་སེམས་ལ་ཕན་འདོགས་པའི་ལམ་ལ་རྣམ་པ་ལྔའོ། །
Enumeration Block 7:
འདི་ལ་གཉིས་ལས།
