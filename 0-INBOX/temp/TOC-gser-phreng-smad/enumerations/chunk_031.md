Enumeration Block 1:
གཉིས་པ་ལ་གཉིས། དཔེ་དགོད་པ་དང་། དོན་ལ་སྦྱར་བའོ། །
Enumeration Block 2:
གཞན་དཔེ་མ་གྲུབ་པ་ལ་ཡང་གཉིས། ལུང་གཞན་དང་མདོ་འདི་ཉིད་ཀྱི་དོན་བཤད་པས་དཔེ་མ་གྲུབ་པར་བསྟན་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 4:
སེམས་ཅན་དང་སྣོད་ཀྱི་འཇིག་རྟེན་གཉིས་ཡོད་པའི་བྱེ་བྲག་གིས་སངས་རྒྱས་ཀྱི་ཞིང་དག་པར་བྱེད་པ་རྣམ་པ་གཉིས་ཡོད་པ་ལས།
Enumeration Block 5:
གསུམ་པ་ལ་གསུམ་ལས།
Enumeration Block 6:
གཉིས་པ་ལ་གསུམ། སྦྱོར་བའི་ཡུལ། ཡུལ་ཅན་སྦྱོར་བའི་ངོ་བོ། སོ་སོའི་དབྱེ་བའོ། །
Enumeration Block 7:
ཐབས་ལ་མཁས་པའི་སྦྱོར་བ་འདི་ལ་ནི་རྣམ་པ་བཅུ་ཡོད་དོ། །
Enumeration Block 8:
གསུམ་པ་ལ་གཉིས། སོ་སོའི་སྒོ་ནས་རྒྱས་པར་བཤད། ཡུལ་དང་ངོ་བོའི་སྒོ་ནས་དོན་བསྡུ་བའོ། །
Enumeration Block 9:
བདུད་བཞིའི་མཐའ་ཅུང་ཟད་དཔྱད་ན། ངོ་བོ་ངོས་གཟུང་བ། བཞིར་འཇོག་པའི་རྒྱུ་མཚན། གང་ནས་འཇོག་པའི་ཚུལ་གསུམ་གྱིས་རིག་པར་བྱའོ། །
