Enumeration Block 1:
གསུམ་པ་ལ་གསུམ། རྟེན་སྒོམ་ལམ། སྤང་བྱ་རྣམ་རྟོག །བརྟེན་པ་ཡོན་ཏན་ནོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། ཐོད་རྒལ་དངོས་དང་། དེ་ལ་རྩོད་པ་སྤང་བའོ། །དང་པོ་ལ་གསུམ། མདོ་ལས་ཇི་ལྟར་གསུངས་པ་དང་། བསྟན་བཅོས་ཀྱིས་བསྡུས་པའི་ཚུལ། མཐའ་བཅད་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། སྦྱོར་བ་དང་། དངོས་གཞིའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། སོང་བ་དང་། འོངས་པའོ། །དང་པོ་ལ་གཉིས། འགོག་པ་དང་མ་སྤེལ་བ་དང་། སྤེལ་བའི་སོང་བའོ། །
Enumeration Block 5:
གསུམ་པ་ལ་གསུམ། གང་ལ་སྤེལ་བར་བྱ་བའི་གཞི། གང་ཞིག་སྤེལ་བར་བྱ་བའི་ཆོས། ཇི་ལྟར་སྤེལ་བའི་ཚུལ་ལོ། །
Enumeration Block 6:
གསུམ་པ་ལ་གསུམ། སྦྱོར་བ། དངོས་གཞི། དོན་བསྡུ་བའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གཉིས། སོང་བ་དང་འོངས་པའོ། །དང་པོ་ལ་གཉིས། འགོག་པ་མ་སྤེལ་བ་དང་། སྤེལ་བའི་སོང་བའོ། །
