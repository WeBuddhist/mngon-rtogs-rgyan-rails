Enumeration Block 1:
འདི་ལ་གསུམ་ལས་དང་པོ་ཐམས་ཅད་ཤེས་པ་ཉིད་ཀྱི་སྦྱོར་བའི་ངོ་བོ་ཉིད་ལ་ནི་དབེན་པ་བཞི་ཡོད་དོ། །
Enumeration Block 2:
གཉིས་པ་ལམ་ཤེས་ཀྱི་སྦྱོར་བའི་ངོ་བོ་ཉིད་ལ་ནི་ལྔའོ། །
Enumeration Block 3:
གསུམ་པ་རྣམ་མཁྱེན་གྱི་སྦྱོར་བའི་ངོ་བོ་ཉིད་ལ་ནི་བདུན་ཡོད་དོ། །
Enumeration Block 4:
བཞི་པ་ལ་གཉིས། མཚམས་སྦྱར། དོན་བཤད་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གཉིས། སྤྱི་དང་ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ་གསུམ། གང་ལ་སྐྱེ་བའི་རྟེན། བརྟེན་པ་ལམ་གྱི་ངོ་བོ། རྟགས་དང་སྒྲ་དོན་ནོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། ངོ་བོ་དང་། དབྱེ་བའོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 7:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 8:
གཉིས་པ་ལ་གཉིས། ངོ་བོ་དང་རྒྱུད་ཀྱི་སྒོ་ནས་དབྱེ་བའོ། །
