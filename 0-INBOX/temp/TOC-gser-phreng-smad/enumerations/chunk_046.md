Enumeration Block 1:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 2:
གསུམ་པ་ལ་གཉིས། མདོར་བསྟན། རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། དངོས་ཀྱི་དོན། དེས་ཟབ་པར་འཕངས་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 5:
གསུམ་པ་ལ་གསུམ། བསལ་བྱ་རྣམ་རྟོག །སེལ་བྱེད་ཀྱི་ལན། བསལ་ནས་ཏིང་ངེ་འཛིན་སྐྱེད་ཚུལ་ལོ། །
Enumeration Block 6:
དང་པོ་ལ་བཞི། ཡུལ་གང་ལ་རྟོག་པ། ཚུལ་ཇི་ལྟར་རྟོག་པ། དེ་ལྟར་རྟོག་པའི་རྒྱུ་མཚན། ལོག་པར་རྟོག་མཁན་གྱི་གང་ཟག་གོ །
Enumeration Block 7:
བདེན་གཉིས་ཀྱི་མཐའ་ཅུང་ཟད་དཔྱད་པ་ལ་གཉིས། བདེན་གཉིས་གཏན་ལ་དབབ་དགོས་པ་དང་། གཏན་ལ་དབབ་བྱ་བདེན་གཉིས་ཀྱི་རང་བཞིན་ནོ། །
