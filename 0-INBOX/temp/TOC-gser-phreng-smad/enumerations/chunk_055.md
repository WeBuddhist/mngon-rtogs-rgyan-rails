Enumeration Block 1:
བཞི་པ་ལ་གཉིས། སྔར་སྦྱང་བ་བྱས་པས་འགྲུབ་ཚུལ་དང་། མ་བྱས་པས་སྦྱོང་ཚུལ་ལོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། དམིགས་པ་རྟེན་དུ་བྱེད་པ་དང་། དེ་ལ་ཡིད་གཏོད་པའི་ཚུལ་ལོ། །
Enumeration Block 3:
ལྔ་པ་ལ་གཉིས། མ་གྲུབ་པའི་རྟགས་འཛིན་པའི་མཚན་མ། གྲུབ་པའི་རྟགས་སྣང་བའི་མཚན་མ་འཆར་ཚུལ་ལོ། །
Enumeration Block 4:
དབྱེ་གྲངས་ནི་རྣམ་པ་བརྒྱད་དེ་དེ་ཡང་དབྱིབས་དང་ཁ་དོག་ཟིལ་གྱིས་གནོན་པ་རྣམ་པ་བཞི་བཞི་སྟེ་དེ་ལྟར་ནའོ། །
Enumeration Block 5:
བཅུ་གཅིག་པ་ཡོངས་སུ་དག་པ་ལ་ནི་བཞི་སྟེ།
Enumeration Block 6:
བཅུ་གཉིས་པ་དབང་ལ་ནི་རྣམ་པ་བཅུ་སྟེ།
Enumeration Block 7:
གཉིས་པ་ལ་གཉིས། འདོད་པ་བརྗོད་པ་དང་། དེ་དགག་པའོ། །
