Enumeration Block 1:
གསུམ་པ་ལ་གཉིས། སྤྱི་དང་ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ་གསུམ། མཚན་མཚོན་གྱི་རྣམ་གཞག །མཚན་ཉིད་ཤེས་པ་སྔོན་དུ་འགྲོ་ཚུལ། དེའི་ས་མཚམས་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། གཞན་ལུགས་བསྟན། འཐད་ཕྱོགས་ངོས་གཟུང་བའོ། །དང་པོ་ལ་གཉིས། ལུགས་དགོད་པ་དང་། དེ་དགག་པའོ། །དང་པོ་ལ་གཉིས། བསྡུས་དོན་མཁན་དང་། སྔ་རབས་པའི་ལུགས་སོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། སྤྱིའི་རྣམ་གཞག་དང་། ཁྱད་པར་གྱི་མཚོན་ཚུལ་ལོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། བྱེད་སྒྲུབ་དང་ལས་སྒྲུབ་ཀྱི་དོན། ཐུན་མོང་མ་ཡིན་པའི་མཚོན་ཚུལ་ལོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང་། དོན་བཤད་པའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ། ངོ་བོའི་སྒོ་ནས་མདོར་བསྟན། དབྱེ་བའི་སྒོ་ནས་རྒྱས་པར་བཤད། གྲངས་ཀྱི་སྒོ་ནས་དོན་བསྡུ་བའོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 6:
གཉིས་པ་ལ་བཞི། ཤེས་པ། ཁྱད་པར། བྱེད་པ། ངོ་བོ་ཉིད་ཀྱི་མཚན་ཉིད་དོ། །དང་པོ་ལ་གསུམ། གཞི་ཤེས། ལམ་ཤེས། རྣམ་མཁྱེན་གྱི་མཚན་ཉིད་དོ། །དང་པོ་ལ་གསུམ་ལས།
