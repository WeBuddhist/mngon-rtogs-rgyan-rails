Enumeration Block 1:
གཉིས་པ་ལ་གསུམ། དུས་ཀྱི་སྒོ་ནས་མདོར་བསྟན། དབྱེ་བའི་སྒོ་ནས་རྒྱས་པར་བཤད། གྲངས་ཀྱི་སྒོ་ནས་མཇུག་བསྡུ་བའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གསུམ། ལམ་གྱི་རྟེན་དང། ལམ་དང་། ལམ་གྱི་འབྲས་བུ་ལ་འགོད་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་བཞི། ཚོགས་སྦྱོར་མཐོང་སྒོམ་ལ་འགོད་པའོ། །དང་པོ་ལ་ལྔ་ལས།
Enumeration Block 4:
བཞི་པ་ལ་དྲུག །ས་ལྔ་པའི་བར། དྲུག་པ། བདུན་པ། བརྒྱད་པ། དགུ་པ།
བཅུ་པ་ལ་འགོད་པའོ། །
Enumeration Block 5:
བཞི་པ་ལ་གཉིས། རྟོགས་པ་དང་། སྤངས་པའོ། །
Enumeration Block 6:
དྲུག་པ་ལ་གསུམ།
བཅུ་པ་ཐོབ་མ་ཐག་པ་དང་། སྐྱེ་བ་གཅིག་གིས་ཐོགས་པ་དང་། སྲིད་པ་ཐ་མ་ལ་འགོད་པའོ། །
Enumeration Block 7:
ས་བཅུ་པ་ཐོབ་མ་ཐག་ཏུ་དབང་བསྐུར་བས་ཞིང་དག་པར་འགྱུར་བ་ལ་གཉིས། སྣང་བས་ཕྲིན་ལས་སྒྲུབ་པ་དང་། མཆོད་པས་དབང་བསྐུར་ཐོབ་པའོ། །དང་པོ་ལ་སྣོད་དང་། བཅུད་དག་པའི་སྣང་བ།
ཕྲིན་ལས་སྒྲུབ་པ་གསུམ་ལས།
Enumeration Block 8:
གཉིས་པ་ལ་གཉིས། མཆོད་པ་དང་། དབང་བསྐུར་བའོ། །
Enumeration Block 9:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 10:
གསུམ་པ་ལ་བཞི། ནུས་པ། རྟོགས་པ། སྤངས་པ། དག་པའི་རྒྱུ་ཚོགས་སོ། །
