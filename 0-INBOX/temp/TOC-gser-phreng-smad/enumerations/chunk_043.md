Enumeration Block 1:
གསུམ་པ་ལ་གསུམ། སྦྱོར་བ། དངོས་གཞི། དོན་བསྡུ་བའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། སོང་བ་དང་འོངས་པའོ། །དང་པོ་ལ་གཉིས། འགོག་པ་མ་སྤེལ་བ་དང་། སྤེལ་བའི་སོང་བའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གསུམ། མཚམས་སྦྱར། དོན་བཤད། གཉེན་པོ་མཚོན་ཚུལ་ལོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས། གཟུང་རྟོག་དང་། འཛིན་རྟོག་གོ །དང་པོ་ལ་གཉིས། འཇུག་པ་དང་། ལྡོག་པ་གཟུང་རྟོག་གོ །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ། ཡུལ། ངོ་བོ། གཉེན་པོའོ། །
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། རྟོག་པའི་ངོ་བོ་དང་། གཉེན་པོའོ། །
Enumeration Block 7:
གཟུང་རྟོག་དང་པོ་དབྱེ་གཞི། དབྱེ་ངོ་ནི་རྣམ་པ་དགུའོ། །
Enumeration Block 8:
ལེགས་ལམ་སྟེ་འདི་ལ་གསུམ་ལས།
Enumeration Block 9:

Enumeration Block 12:
