Enumeration Block 1:
གཉིས་པ་ལ་གཉིས། སློབ་དཔོན་གྱི་བཞེད་པ་ཡིན་མིན་དང་། བསྟན་བཅོས་ཀྱི་དགོངས་པར་གནས་མི་གནས་དཔྱད་པའོ། །
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། བསྟན་བཅོས་ཀྱི་དགོངས་པར་མི་འདོད་པའི་སུན་འབྱིན་དགོད། དེ་གནོད་བྱེད་དུ་སོང་མ་སོང་བརྟག་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། མཚམས་སྦྱར་བ་དང་། དོན་བཤད་པའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གཉིས་ལས།
སྤྱི་དང་ཡན་ལག་གི་དོན་ནོ། །
དང་པོ་ལ་བཞི། ཕྱིར་མི་ལྡོག་པའི་གང་ཟག་དང་། ཕྱིར་མི་ལྡོག་པའི་དོན། ཕྱིར་མི་ལྡོག་པའི་རྟགས། རྟགས་ལས་ཕྱིར་མི་ལྡོག་ཏུ་མཚོན་ཚུལ་ལོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ། རྟགས་ཀྱི་ཡོད་སའི་སྒོ་ནས་མདོར་བསྟན། ཡོད་ཆོས་ཀྱི་རྟགས་ཀྱི་ངོ་བོ་རྒྱས་པར་བཤད། རྟགས་དང་རྟགས་ཅན་གཉིས་ཀྱི་དོན་བསྡུ་བའོ། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 6:
གཉིས་པ་ལ་གཉིས། མཚམས་སྦྱར། དོན་བཤད་པའོ། །
Enumeration Block 7:
གཉིས་པ་ལ་གསུམ། སྦྱོར་ལམ་པ། མཐོང་ལམ་པ། སྒོམ་ལམ་པ་ཕྱིར་མི་ལྡོག་པའི་རྟགས་སོ། །དང་པོ་ལ་གཉིས། མདོར་བསྟན། རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 8:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 9:
འདི་ལ་བཞི་ལས།
