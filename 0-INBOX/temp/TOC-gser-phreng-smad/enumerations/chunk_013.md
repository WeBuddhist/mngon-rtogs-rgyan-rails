Enumeration Block 1:
དེ་རེ་རེ་ལ་ལེའུ་རེ་རེར་བྱས་པས་བཅུ་སྟེ། ཁོང་དུ་ཆུད་པ་དང་། སྒྲུབ་པ་དང་། ལུང་གི་ལེའུ་གསུམ་པོ་རེ་རེ་ལ་གསུམ་གསུམ་སྟེ་དེ་ཡང་དགྲ་བཅོམ་ཕྱིར་མི་འོང་རྒྱུན་ཞུགས་ཀྱི་ལེའུ་གསུམ་དང། ལྷག་མཐོང་ཏིང་ངེ་འཛིན་ཚུལ་ཁྲིམས་ཀྱི་ལེའུ་གསུམ་དང་། མངོན་པ་མདོ་སྡེ་འདུལ་བའི་ལེའུ་གསུམ་སྟེ་དགུ་དང་། རྟགས་ཙམ་གྱི་ལེའུའོ། །

Enumeration Block 4:

Enumeration Block 5:
སྦྱོར་བའི་སྐྱོན་ཏེ། དེ་ལ་ནི་བཞི་བཅུ་རྩ་དྲུག་ཡོད་དོ། །ཇི་ལྟར་ཞེ་ན། སྦྱོར་བ་མ་སྐྱེས་པ་སྐྱེད་པ་ལ་འགལ་རྐྱེན་ཉེ་བར་གནས་པ་ཉེར་གསུམ་དང་མཐུན་རྐྱེན་མ་ཚང་བ་ཉེར་གསུམ་སྟེ་དེ་ལྟར་ནའོ། །
དང་པོ་ལ་གཉིས། རང་དང་གཞན་ལ་བརྟེན་པའོ། །དང་པོ་ལ་གསུམ། དོན་ཡོངས་སུ་ཤེས་པ་དང་། སྒོ་གསུམ་གྱི་བྱ་བ་དང་། ཐེག་ཆེན་ལ་འཇུག་པའི་བར་གཅོད་དོ། །

Enumeration Block 7:

Enumeration Block 8:
གསུམ་པ་ལ་གཉིས། སྤྱི་དང་ཡན་ལག་གི་དོན་ནོ། །དང་པོ་ལ་གསུམ། མཚན་མཚོན་གྱི་རྣམ་གཞག །མཚན་ཉིད་ཤེས་པ་སྔོན་དུ་འགྲོ་ཚུལ། དེའི་ས་མཚམས་བསྟན་པའོ། །དང་པོ་ལ་གཉིས། གཞན་ལུགས་བསྟན། འཐད་ཕྱོགས་ངོས་གཟུང་བའོ། །དང་པོ་ལ་གཉིས། ལུགས་དགོད་པ་དང་། དེ་དགག་པའོ། །དང་པོ་ལ་གཉིས། བསྡུས་དོན་མཁན་དང་། སྔ་རབས་པའི་ལུགས་སོ། །
