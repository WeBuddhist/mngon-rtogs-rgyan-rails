Enumeration Block 1:
བཞི་པ་ལ་གསུམ་ལས།
Enumeration Block 2:
གཉིས་པ་ལ་གསུམ་ལས། མཚམས་སྦྱར་བ་ལ་གཉིས། བཤད་ཟིན་དང་འཆད་འགྱུར་གྱིའོ། །
Enumeration Block 3:
དེར་ཇི་ལྟར་བསྟན་ན་འདི་ལ་གསུམ་ལས།
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ། དུས་ཀྱི་སྒོ་ནས་མདོར་བསྟན། དབྱེ་བའི་སྒོ་ནས་རྒྱས་པར་བཤད། གྲངས་ཀྱི་སྒོ་ནས་མཇུག་བསྡུ་བའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ། ལམ་གྱི་རྟེན་དང། ལམ་དང་། ལམ་གྱི་འབྲས་བུ་ལ་འགོད་པའོ། །
