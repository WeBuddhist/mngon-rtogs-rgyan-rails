Enumeration Block 1:
གཉིས་པ་ལ་གསུམ། རྩོད་པ། ལན། ལན་ལ་རྩོད་སྤང་ངོ༌། །དང་པོ་ལ་གཉིས་ལས།
Enumeration Block 2:
གསུམ་པ་ལ་བཞི། རྟོག་པའི་ངོ་བོ། སྤང་བྱར་བསྟན་པ། དབྱེ་བ། འཁྲུལ་པར་སྒྲུབ་པའོ། །
Enumeration Block 3:
གཉིས་པ་ལ་གཉིས། གཟུང་རྟོག་འཛིན་རྟོག་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གཉིས། འཇུག་པ་དང་། ལྡོག་པ་གཟུང་རྟོག་རྒྱས་པར་བཤད་པའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 4:
གསུམ་པ་ལ་གཉིས། རྟོག་པའི་ངོ་བོ་དང་། གཉེན་པོའོ། །
Enumeration Block 5:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 6:
གསུམ་པ་ལ་གཉིས། སྤང་བྱ་རྟོག་པ། སྤོང་བྱེད་གཉེན་པོའོ། །
Enumeration Block 7:
འདི་ལ་བཞི། གང་གི་དང་། གང་མཇུག་ཏུ་འགྲོ་བ་དང་། གང་དུ་འགྲོ་བ་དང་། དེའི་རྒྱུ་མཚན་ནོ། །
