Enumeration Block 1:
འདི་ལ་བཞི། སྡུག་བསྔལ་དང་། ཀུན་འབྱུང་དང་། འགོག་པ་དང་། ལམ་གྱི་བདེན་པའི་སྐད་ཅིག་མའི་ཁྱད་པར་རོ། །
Enumeration Block 2:
གསུམ་པ་ལ་གསུམ་ལས།
Enumeration Block 3:
བྱེད་པ་བཅུ་གཅིག་ནིའོ། །
Enumeration Block 4:
བཅུ་གཅིག་ཏུ་ཇི་ལྟར་འགྱུར་ན། གཞི་ཤེས་ལམ་ཤེས་རྣམ་མཁྱེན་གྱི་བྱེད་པ་གསུམ་དང། བདུན་དང་གཅིག་ཏུ་ཡོད་པ་དེ་ལྟར་ནའོ། །
Enumeration Block 5:
འདི་ལ་གསུམ་ལས། དང་པོ་ཐམས་ཅད་ཤེས་པ་ཉིད་ཀྱི་དབང་དུ་བྱས་པའི་ཕན་པ་དང་སོགས་པས་བདེ་བ་དང་སྐྱོབ་པའི་བྱེད་པ་གསུམ་ཡོད་དོ། །
Enumeration Block 6:
གཉིས་པ་ལམ་ཤེས་ཀྱི་དབང་དུ་བྱས་པའི་སྐྱབས་དང་སོགས་པས་གནས་དཔུང་གཉེན་གླིང་ཡོངས་འདྲེན་ལྷུན་གྱིས་གྲུབ་པ་ཐེག་གསུམ་གྱིས་ངེས་པར་འབྱུང་ཞིང་དེའི་འབྲས་བུ་མངོན་དུ་མི་བྱེད་པའི་བྱེད་པ་བདུན་ཡོད་དོ། །
Enumeration Block 7:
གསུམ་པ་རྣམ་མཁྱེན་གྱི་དབང་དུ་བྱས་པ་ལ་ནི་རྟེན་གྱི་མཛད་པ་གཅིག་གོ །
Enumeration Block 8:
བཞི་པ་ལ་གསུམ་ལས།
Enumeration Block 9:
གང་ན། ཉོན་མོངས་ཀྱིས་དབེན་པ་སོགས་བཅུ་དྲུག་གོ །
Enumeration Block 10:
བཅུ་དྲུག་ཇི་ལྟར་ན། ངོ་བོ་ཉིད་བཞི་ནས་བདུན་གྱི་བར་དུ་ཡོད་པ་དེ་ལྟར་ནའོ། །
Enumeration Block 11:
འདི་ལ་གསུམ་ལས་དང་པོ་ཐམས་ཅད་ཤེས་པ་ཉིད་ཀྱི་སྦྱོར་བའི་ངོ་བོ་ཉིད་ལ་ནི་དབེན་པ་བཞི་ཡོད་དོ། །
