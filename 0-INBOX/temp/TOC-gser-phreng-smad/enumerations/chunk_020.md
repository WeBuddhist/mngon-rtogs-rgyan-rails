Enumeration Block 1:
གཉིས་པ་ལ་གསུམ་ལས།
Enumeration Block 2:
གཉིས་པ་ལ་གཉིས། ངོ་བོ་དང་རྒྱུད་ཀྱི་སྒོ་ནས་དབྱེ་བའོ། །
Enumeration Block 3:
གསུམ་པ་ལ་གཉིས། ངོ་བོ་དང་། རྒྱུད་ཀྱི་སྒོ་ནས་དབྱེ་བའོ། །
Enumeration Block 4:
གཉིས་པ་ལ་གསུམ། སྦྱོར་བ་ཁྱད་པར་ཅན་སྐྱེས་པའི་དུས། སྐྱེས་པའི་རྟེན་གྱི་གང་ཟག །གང་ཟག་དེའི་སྒོམ་རིམ་མོ། །
Enumeration Block 5:
དང་པོ་ལ་གཉིས། དངོས་དང་། ཟློས་པ་སྤང་བའོ། །དང་པོ་ལ་གསུམ་ལས།
Enumeration Block 6:
གཉིས་པ་ལ་བཞི་ལས། དང་པོ་དྲོད་ཀྱི་དམིགས་རྣམ་གཉིས་ལས།
Enumeration Block 7:
གཉིས་པ་རྩེ་མོར་གྱུར་པ་ལ་གསུམ་ལས།
Enumeration Block 8:
གསུམ་པ་ལ་གཉིས། སོ་སོར་བཤད་པ་དང་། དོན་བསྡུ་བའོ། །དང་པོ་ལ་བཞི་ལས།
